# 资料索引外观主题切换需求规格

Feature Name: `ui-theme-switching`
Updated: 2026-07-26
Status: Confirmed for design

## Introduction

资料索引应用需要在现有“羊皮卷”视觉之外提供“极简黑白”视觉，并允许用户在设置页即时切换。主题同时控制界面颜色、标题字体、正文字体、等宽字体、边框、焦点状态和操作状态，用户选择在应用重启和索引配置备份恢复后保持一致。

## Glossary

- **应用**：Windows 本地资料索引桌面软件。
- **外观主题**：应用颜色与字体令牌的完整集合。
- **羊皮卷主题**：当前以暖白纸张、深绿色侧栏、金色强调和衬线标题为特征的视觉方案。
- **极简黑白主题**：以纯白和浅灰表面、黑灰文字、克制绿色状态色和现代无衬线字体为特征的视觉方案。
- **主题选择器**：设置页中展示主题名称、视觉预览和选中状态的控件。
- **界面偏好**：保存在本机并可随索引配置备份导出和恢复的非业务设置。

## Requirements

### Requirement 1：完整主题方案

**User Story:** 作为资料索引用户，我希望拥有两套完整的界面风格，以便根据阅读习惯选择合适外观。

#### Acceptance Criteria

1. WHILE 羊皮卷主题处于选中状态，应用应使用现有暖色纸张、深绿色侧栏、金色强调色、衬线标题和现有正文字体。
2. WHILE 极简黑白主题处于选中状态，应用应使用白色与浅灰表面、黑灰文字、克制绿色状态色和现代系统无衬线字体。
3. WHILE 任一主题处于选中状态，应用应将该主题应用到应用外壳、导航、搜索、资料列表、主题详情、预览、待整理、索引位置、设置、反馈消息和确认对话框。
4. WHILE 任一主题处于选中状态，应用应为正文、标题、元数据、边框、悬停、选中、焦点、成功、警告和危险状态提供对应视觉令牌。
5. WHILE 应用渲染任一主题，应用应使用 Windows 本机可用字体栈完成显示。

### Requirement 2：设置页即时切换

**User Story:** 作为资料索引用户，我希望在设置页查看并切换主题，以便立即比较两套视觉方案。

#### Acceptance Criteria

1. WHEN 用户进入设置页，应用应展示“羊皮卷”和“极简黑白”两个主题选项。
2. WHEN 用户选择主题选项，应用应在当前窗口立即应用对应颜色与字体。
3. WHEN 用户选择主题选项，应用应在主题选择器中标记当前主题。
4. WHEN 用户使用键盘操作主题选择器，应用应支持 Tab 导航和 Enter 或 Space 选择。
5. WHILE 主题选项获得键盘焦点，应用应展示满足可见性要求的焦点轮廓。

### Requirement 3：主题偏好持久化

**User Story:** 作为资料索引用户，我希望应用记住主题选择，以便每次启动保持相同外观。

#### Acceptance Criteria

1. WHEN 用户选择主题，应用应将主题标识保存为本机界面偏好。
2. WHEN 应用再次启动，应用应在首个界面帧渲染前恢复已保存主题。
3. IF 本机主题偏好缺失或包含未知值，应用应使用羊皮卷主题。
4. IF 浏览器存储暂时不可用，应用应在当前会话应用用户选择并继续提供完整功能。

### Requirement 4：备份与恢复

**User Story:** 作为使用索引配置备份的用户，我希望主题偏好随备份迁移，以便恢复后保持熟悉外观。

#### Acceptance Criteria

1. WHEN 用户导出索引配置备份，应用应在备份偏好中包含当前主题标识。
2. WHEN 用户恢复包含主题标识的索引配置备份，应用应立即应用恢复的主题。
3. WHEN 用户恢复早期版本的索引配置备份，应用应使用羊皮卷主题补全主题偏好。
4. IF 备份包含未知主题标识，应用应拒绝恢复并返回稳定的输入校验错误。

### Requirement 5：可读性与布局稳定性

**User Story:** 作为资料索引用户，我希望切换主题只改变视觉表达，以便现有操作位置和阅读层级保持稳定。

#### Acceptance Criteria

1. WHEN 用户切换主题，应用应保持当前工作区、搜索条件、展开主题、预览文档和扫描状态。
2. WHILE 任一主题处于选中状态，应用应保持桌面与窄屏布局断点一致。
3. WHILE 任一主题处于选中状态，应用应使常规文字与背景的对比度达到 WCAG 2.1 AA 的 4.5:1。
4. WHILE 任一主题处于选中状态，应用应使大号文字与背景的对比度达到 WCAG 2.1 AA 的 3:1。
5. WHEN Windows 缺少字体栈中的首选字体，应用应使用同类系统后备字体并保持界面可操作。
