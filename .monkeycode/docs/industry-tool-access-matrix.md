## 3. 行业映射原则

### 原则 1：先复用通用底层工具
- 同一个底层能力只保留一份，例如 `roi`、`payback`、`script`、`headline`。

### 原则 2：行业页展示的是行业封装结果
- 行业页不直接强调技术工具名，而是强调老板场景，例如“菜品定价”“续费催课”“耗卡预警”。

### 原则 3：高阶专项独立挂载
- `企业增长诊断`、`抖音经营`、`老板IP`、`小红书运营` 不混入普通行业入口层级。

## 10. 当前建议的开发优先级

1. 先做餐饮/教培/美业的高频经营计算器行业版。
2. 再做教培续费消课、美业耗卡复购、餐饮外卖利润这类强场景工具。
3. 抖音经营优先补 `投流保本ROI` 和 `GPM`。
4. 所有新工具都要补充会员等级、免费策略、行业归属和场景归属字段。
