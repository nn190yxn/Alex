# 我赢AI行业表格模板矩阵

本文件用于把 `需求文档_v4_表格模板详表` 中的行业表格模板，正式并入我赢AI的产品结构体系，便于后续前端入口规划、权限设计、知识库挂载和多 Agent 协作时统一参考。

最后更新：2026-05-01
状态：v1 首轮并入版

## 1. 结构定位

### 表格模板在产品中的角色
- 表格模板不是孤立附件，而是各行业工作台中的“数据输入层 / 经营记录层 / 输出报表层”。
- 未来应与计算器、诊断工具、方案工具形成联动，而不是单独堆文件下载按钮。

### 三种挂载方式

| 挂载方式 | 说明 | 示例 |
|------|------|------|
| 输入模板 | 用户先填表，再驱动计算器或诊断结果 | 食材成本核算表 -> 毛利率/菜品定价 |
| 经营记录表 | 用户持续记录经营数据，系统给趋势和预警 | 每日营收记录表、翻台率统计表 |
| 输出报表 | 工具计算完成后，自动生成可复用结果表 | 续费优先级名单、投流复盘表 |

## 2. 权限设计原则

| 模板类型 | 建议层级 | 说明 |
|------|------|------|
| 通用记录类 | `starter` | 如考勤、客户登记、供应商管理 |
| 行业核心经营表 | `starter` | 如营收、库存、会员管理、排期 |
| 强分析型行业专用表 | `pro` | 如翻台率统计、续费率追踪、拓客ROI追踪 |
| 高阶专项联动表 | `annual` | 如老板IP内容库、深度运营知识库联动表 |

### 免费层策略
- 免费层不建议开放完整表格体系。
- 可开放：少量示例预览、字段说明、演示版只读样例。
- 不建议开放：完整在线填写、多员工协作、完整导出。

## 6. 与现有工具矩阵的合并规则

### 餐饮
- `食材成本核算表` -> 挂到 `毛利率计算器（餐饮版）`、`菜品定价计算器`
- `翻台率统计表` -> 挂到 `翻台率计算器`
- `每日营收记录表` -> 挂到 `利润率计算器（餐饮版）`、`现金流预测计算器（餐饮版）`

### 教培
- `会员管理表`、`课时消耗统计表` -> 挂到 `课时消耗率计算器`、`消课率计算器`
- `续费率追踪表` -> 挂到 `续费率计算器`
- `体验课转化表` -> 挂到 `获客成本计算器（教培版）`、`回报率计算器（教培版）`

### 美业
- `会员管理表` -> 挂到 `耗卡率计算器`、`复购率计算器（美业版）`
- `项目消耗统计表` -> 挂到 `项目利润计算器（美业版）`
- `拓客转化追踪表` -> 挂到 `拓客转化率计算器`、`回报率计算器（美业版）`
- `品项组合定价表` -> 挂到 `项目利润计算器（美业版）`，后续可扩 `组合定价计算器`

## 7. 第一轮落地建议

1. 不急着把 33 张表都做成独立页面。
2. 第一轮先做“工具关联模板”的结构设计，不做完整交互系统。
3. 优先接入以下 6 张高价值表：
   - 餐饮：`食材成本核算表`、`翻台率统计表`
   - 教培：`课时消耗统计表`、`续费率追踪表`
   - 美业：`会员管理表`、`拓客转化追踪表`
4. 页面上先支持：
   - 模板说明
   - 关键字段列表
   - 能联动哪些工具
   - 后续再补在线填写和导出
