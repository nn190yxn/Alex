# 我赢AI会员权限结构总表

本文件用于沉淀我赢AI的正式会员权限结构，供后续前端展示、后端权限配置、知识库挂载、行业工作台扩展和多 Agent 协作时统一参考。

最后更新：2026-05-01
状态：当前为 v1 基线版，可继续微调价格、次数和个别能力归属，但建议先保持整体结构稳定。

## 1. 会员层级定义

| 层级 | 代号 | 核心定位 | 主要卖点 |
|------|------|----------|----------|
| 免费版 | `free` | 感知价值 | 先体验高频内容和基础计算 |
| 初阶版 | `starter` | 日常经营 | 把行业经营工具真正用进门店 |
| 进阶版 | `pro` | 诊断增长 | 看清问题、判断增长方向、使用平台经营能力 |
| 高阶版 | `annual` | 专项系统 | 老板IP、小红书、深度抖音和知识库驱动能力 |

## 2. 各层级权限原则

### 免费版 `free`
- 目标：让老板快速感受到产品价值。
- 原则：可体验、有限次、轻结果。
- 不开放：完整诊断、高阶专项、深度知识库输出。

### 初阶版 `starter`
- 目标：承接门店和机构的日常经营刚需。
- 原则：给行业版基础能力、表格模板、制度模板和执行工具。

### 进阶版 `pro`
- 目标：承接增长和诊断需求。
- 原则：不只给结果，还给判断、建议和下一步动作。

### 高阶版 `annual`
- 目标：承接高溢价专项和长期复利能力。
- 原则：围绕老板个人品牌、专项运营和知识库智能输出形成差异化。

## 3. 免费层限次策略

免费层必须限次，尤其是高频生成类能力，避免被长期白嫖。

| 能力类型 | 免费策略 | 说明 |
|------|------|------|
| 高频内容生成 | 严格限次 | 最容易被薅羊毛 |
| 基础计算器 | 中等限次 | 让用户体验价值，但不形成完整替代 |
| 基础诊断/简版判断 | 中等偏严 | 可感知价值，但不给完整决策 |
| 表格模板/报表 | 只给样例或部分下载 | 避免一次性拿走全部资产 |

推荐的首版免费额度：

| 功能类别 | 免费额度建议 |
|------|------|
| 爆款标题 / 朋友圈 / 卖点 / 钩子 | `3次/天` |
| 通用脚本生成 | `2次/天` |
| 通用选题生成 | `2次/天` |
| 基础 ROI / 回本 / 简单计算器 | `3次/天` |
| 行业基础计算器 | `1次/天` 或仅开放简版结果 |
| 企业增长诊断 | 不开放免费完整版 |
| 抖音经营专项 | 不开放免费完整版 |
| 老板IP / 小红书运营 | 不开放免费版 |

### 抖音经营的两层拆法

#### `pro` 开放
- 投流保本ROI
- GPM
- 团购组品建议
- 直播脚本基础版
- 数据复盘和经营判断

#### `annual` 开放
- 抖音经营与老板IP联动方案
- 长期内容定位
- 高阶直播表达脚本
- 深度知识库驱动输出

## 8. 行业与场景组织原则

### 原则 1：不要重复造工具
- 相同底层能力应采用“通用底层能力 + 行业/场景包装层”的方式组织。

### 原则 2：行业页按场景组织
- 行业页优先按老板工作场景组织，而不是按技术能力名称组织。

### 原则 3：场景版不是重复工具
- 例如“选题生成器”保留通用版。
- “抖音团购选题”“餐饮探店选题”“教培招生选题”应是带行业预设、输出结构和指标约束的场景版入口。

## 9. 表格、模板与知识库的融合方式

用户后续上传的表格、公式、知识库内容，不建议简单做成新的孤立工具按钮，优先按以下 3 种方式融合：

### 作为输入模板
- 餐饮毛利计算：上传菜品成本表
- 教培续费诊断：上传学员到期表
- 美业耗卡分析：上传会员余额表

### 作为输出报表
- 毛利分级表
- 排班优化表
- 续费预警表
- 投流复盘表

### 作为行业动作模板
- 菜品利润表
- 校区续费跟进表
- 美业耗卡跟踪表
- 抖音投流日报表

## 10. 前台展示规则

### 板块级提示
- 用简短提示说明本板块主要包含哪些层级，例如：
  - `本板块包含免费与初阶能力`
  - `本板块以进阶能力为主`
  - `本板块为高阶专项`

### 工具级提示
- 使用统一短徽章：`免费` / `初阶` / `进阶` / `高阶`

### 锁定提示
- 需要明确显示：
  - 当前等级
  - 该工具等级
  - 升级后可获得什么

## 11. 当前建议的产品基线

### 免费版
- 高频内容工具有限次
- 基础计算工具有限次
- 不覆盖完整经营体系

### 初阶版
- 行业基础经营能力
- 表格、模板、制度、行业版内容工具

### 进阶版
- 企业增长诊断
- 抖音经营核心能力
- 经营分析与增长判断

### 高阶版
- 老板IP
- 小红书运营
- 抖音深度联动
- 知识库驱动专项能力

## 12. 后续更新建议

后续每次新增能力时，建议至少补充以下字段：
- 能力ID
- 能力名称
- 底层能力类型
- 所属会员层级
- 适用行业
- 适用场景
- 是否高阶专项
- 是否通用底层能力
- 是否行业封装能力

这样无论前端展示、后端权限、知识库挂载还是多 Agent 协作，都会更稳定。
