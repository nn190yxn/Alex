# 小程序轻量营销版开发计划

## 目标

把当前小程序从“登录/会员/返利入口”升级为“轻输入、快输出、马上可发”的营销助手。

核心定位：

- 聚焦文案营销
- 聚焦 AI 对话
- 聚焦高频使用
- 聚焦快速转化

不做的方向：

- 不做表格中心
- 不做复杂经营录入
- 不做深度报告型页面
- 不做大量重计算器搬运
- 不做长链路、多步骤后台式流程

## 产品原则

1. 每次使用 10 秒到 1 分钟完成
2. 每个页面只做一件事
3. 输入少，输出快，结果可直接复制或转发
4. 优先做模板化场景，再叠加 AI 改写
5. 先做高频营销工具，再做行业专版

## V1 范围

V1 只保留 4 个主入口：

- 首页
- AI
- 工具
- 我的

支撑页面：

- 登录
- 注册
- 会员中心
- 邀请返利
- 历史记录
- 收藏

## V1 功能清单

### 1. 首页

功能：

- AI 快捷输入框
- 6 到 8 个高频营销工具按钮
- 最近使用
- 会员升级入口

首页信息结构：

- 输入框：用户直接问问题
- 快捷问题：如“写 3 条火锅店朋友圈文案”
- 热门工具：爆款标题、朋友圈、抖音脚本、小红书、卖点提炼、活动文案
- 最近生成：最近 5 条内容
- 会员卡片：升级入口

### 2. AI 对话页

功能：

- 单会话聊天
- 行业预设身份
- 快捷问题模板
- 最近 10 条历史
- 结果复制
- 一键追问

首批行业预设：

- 餐饮老板
- 教培校长
- 美容院老板
- 生活服务门店老板

首批快捷问题：

- 给我写 3 条朋友圈文案
- 给我出 5 个抖音选题
- 帮我写一个小红书笔记
- 帮我写一条促单话术
- 帮我提炼门店卖点
- 帮我做一个周末活动文案

### 3. 工具页

只放营销类工具，不放表格，不放复杂计算。

首批 8 个工具：

- 爆款标题生成器
- 朋友圈文案生成器
- 短视频脚本生成器
- 小红书笔记生成器
- 促单话术生成器
- 卖点提炼器
- 活动海报文案生成器
- 老板 IP 文案生成器

每个工具统一交互：

- 选择行业
- 输入产品/服务
- 输入场景
- 选择风格
- 点击生成
- 复制结果
- 再来一版

### 4. 我的

功能：

- 用户信息
- 会员中心入口
- 邀请返利入口
- 我的历史
- 我的收藏
- 退出登录

### 5. 会员中心

功能：

- 当前会员等级
- 套餐列表
- 创建订单
- 订单状态刷新
- 支付结果提示

### 6. 邀请返利

功能：

- 推荐码展示
- 推荐码复制
- 小程序分享
- 邀请人数统计
- 累计返利统计
- 返利明细列表

## 非目标

V1 不做：

- 表格中心
- 57 个表格模板接入
- 诊断问卷与深度报告
- 大批量经营计算器
- 多行业复杂筛选树
- 后台管理能力

## 技术方案

### 前端

- 保持 `uni-app + Vue3`
- 保持轻页面结构
- 工具执行页使用统一表单模板
- AI 对话与工具结果统一成卡片结果组件
- 收藏、历史、会员状态统一放入 store

### 后端

- 继续复用 Web 端登录、会员、返利、生成接口
- 对小程序新增聚合接口，减少前端拼装成本
- AI 对话与营销工具结果统一输出结构

统一结果结构建议：

```json
{
  "title": "结果标题",
  "content": "主结果内容",
  "items": ["分条结果1", "分条结果2"],
  "actions": ["复制", "再来一版", "继续追问"],
  "meta": {
    "industry": "restaurant",
    "toolCode": "headline"
  }
}
```

## 验收标准

### 功能验收

- 用户可以登录注册
- 用户可以进入首页、AI、工具、我的四个主入口
- 用户可以完成至少 8 个营销工具的生成
- 用户可以发起 AI 对话并复制结果
- 用户可以查看最近历史
- 用户可以查看会员权益并创建订单
- 用户可以查看返利和分享推荐码

### 体验验收

- 单次生成路径不超过 3 步
- 页面打开速度稳定
- 结果展示支持一键复制
- 样式统一，输入负担轻

## 里程碑

### M1：轻量可用版

- 首页 + AI + 工具 + 我的完成
- 8 个营销工具上线

### M2：转化版

- 会员、返利、历史、收藏完成

### M3：增长版

- 分享、活动位、常用模板、运营配置完成

## 结论

小程序方向明确为：

- 做轻
- 做快
- 做营销
- 做 AI

Web 继续承载深度经营工具；小程序聚焦“文案营销 + AI 随问随答 + 会员转化 + 邀请裂变”。
