# 我赢AI表格模板接入方案 v1

本文件用于把第一轮优先接入的 6 张高价值表，进一步落到前端共享数据和后续页面结构中，确保下一步做页面接入时不需要重新梳理字段。

最后更新：2026-05-01
状态：v1

## 1. 接入目标

第一轮不做完整在线表格系统，先完成以下 4 件事：

1. 在共享目录中定义模板元数据。
2. 明确每张表的关键字段和自动输出。
3. 明确每张表属于哪个行业子板块。
4. 明确它和哪些现有/规划工具联动。

## 4. 前端接入建议

### 方案 A：先做行业页模板卡片
- 在行业页每个场景分组下新增“推荐表格模板”区域。
- 优点：改动小，能快速把结构展示出来。

### 方案 B：工具详情页显示关联模板
- 在工具详情页增加“推荐输入模板/经营记录表”区域。
- 优点：用户更容易理解“先填什么，再算什么”。

### 当前建议
- 第一阶段先做方案 A。
- 第二阶段再给工具详情页补“关联模板”。
