## 一、提示词黄金公式（所有场景通用）

**RTFSC增强版：角色 + 任务 + 背景 + 约束 + 目标 + 示例**

```
你是【专业角色，如：10年经验市场总监/百万粉丝朋友圈文案主笔/资深社群运营】。
请【具体任务，如：撰写朋友圈营销文案/生成10条转化文案】。
背景：【受众/场景/上下文，如：面向年轻职场人/用于新品推广/面向宝妈群体】。
约束：【语言/格式/字数/风格限制，如：150字以内/口语化/带emoji/避免专业术语】。
目标：【希望达成的效果，如：引发好奇/激发购买欲/引导私聊咨询】。
示例（可选）：【提供1-2个参考样式】
```

## 二、通用万能朋友圈文案模板（全行业适用）

### 模板1：产品种草型

```
你是资深营销文案专家，为【目标受众】创作朋友圈营销文案，
围绕【产品名称】的核心卖点，要求：
- 风格：【活泼有趣/专业可信/温暖治愈】
- 结构：痛点引入 → 产品亮点 → 用户评价 → 行动引导
- 字数：100-150字，口语化，像跟朋友推荐
- 必须包含：1个真实使用场景 + 1个具体效果
- 结尾引导：提问式互动，如"你们用过类似的好物吗？"
```

### 模板2：干货知识型

```
你是【行业】领域的专业顾问，针对【目标人群】写一篇朋友圈干货文案，
主题是【具体知识点】，要求：
- 语气：接地气、不说教
- 分3个核心要点，每个要点配1个简单案例
- 别用专业术语，小白也能看懂
- 字数：150-200字
- 结尾加引导互动："你平时怎么解决【问题】？评论区聊聊"
```

### 模板3：客户见证型

```
你是社群运营专家，基于以下客户案例写一条朋友圈见证文案：
- 客户背景：【如：30岁宝妈/创业者/企业高管】
- 使用前痛点：【具体问题】
- 使用后效果：【具体数据/变化】
- 时间周期：【如：21天/1个月/3个月】
要求：
- 语气真诚，像朋友分享好消息
- 突出前后对比
- 字数：80-120字
- 加1-2个emoji增强感染力
```

### 模板4：促销活动型

```
你是营销活动策划专家，为【品牌/产品】写一条朋友圈促销文案：
- 活动类型：【如：限时秒杀/满减优惠/新品首发】
- 优惠力度：【具体数字】
- 活动时间：【如：仅限今天/倒计时3小时/本周周末】
- 目标受众：【人群画像】
要求：
- 开头制造紧迫感
- 中间突出核心价值
- 结尾明确行动指令（如"扫码抢购"/"私信预留"）
- 字数：80-150字
- 必须包含具体数字和截止时间
```

### 模板5：情感共鸣型

```
你是情感文案专家，围绕【情感主题：如治愈/新年祝福/成长感悟/职场共鸣】，
写3-5条适合朋友圈的短句文案：
- 贴近日常说话，别用华丽辞藻
- 别灌鸡汤，要有烟火气
- 每句不超过20个字
- 适合配图发布
- 能引发点赞和评论
```

### 模板6：日常互动型

```
你是社群运营专家，为【目标人群】写一条朋友圈互动文案：
- 主题：【如：周末话题/投票/有奖问答/求助建议】
- 目的：提升朋友圈互动率
- 要求：
  - 开头设置悬念或提问
  - 提供2-3个选项降低参与门槛
  - 字数：50-80字
  - 结尾用emoji引导参与
```

## 三、分行业朋友圈文案Prompt

### 教培行业

```
你是教育行业资深文案，为【教培机构类型：如英语培训/K12辅导/艺术培训】
写一条朋友圈文案：
- 目标受众：【如：3-6岁孩子家长/初高中生家长】
- 核心痛点：【如：孩子不主动学习/成绩提升慢/缺乏兴趣】
- 解决方案：【课程/方法/服务亮点】
- 社会证明：【如：学员进步数据/家长好评/教师资质】
要求：
- 语气专业可信但不说教
- 用家长能听懂的语言
- 突出"孩子改变"而非"我们多厉害"
- 字数：100-150字
- 结尾引导："你家孩子有类似问题吗？私信聊聊"
```

### 美业行业

```
你是美业营销文案专家，为【美容项目：如面部护理/皮肤管理/美甲美睫】
写一条朋友圈文案：
- 目标受众：【如：25-40岁女性/上班族/宝妈】
- 核心痛点：【如：换季皮肤干燥/暗沉/皱纹/敏感】
- 效果承诺：【具体改善效果，用数据说话】
- 价格锚点：【原价vs活动价】
要求：
- 开头制造焦虑或共鸣（痛点切入）
- 中间展示专业方案
- 结尾限时优惠+行动指令
- 字数：80-120字
- 配前后对比图描述
```

### 餐饮行业

```
你是餐饮营销文案专家，为【餐厅类型/菜品】写一条朋友圈文案：
- 目标场景：【如：工作日午餐/周末聚餐/闺蜜下午茶/夜宵】
- 核心卖点：【如：新鲜食材/特色口味/环境氛围/性价比】
- 促销信息：【如：满减优惠/套餐特价/新品尝鲜】
要求：
- 开头制造食欲或场景感
- 描述要具体（色泽、口感、氛围）
- 用"今天""今晚"等时间词增强即时性
- 字数：80-120字
- 结尾明确行动指令（如"约吗？""扫码订位"）
```

### 房产行业

```
你是房产营销文案专家，为【楼盘/房源】写一条朋友圈文案：
- 房源亮点：【如：学区/地铁/景观/户型/价格】
- 目标客群：【如：刚需首套/改善置换/投资客】
- 稀缺性：【如：仅剩X套/限时优惠/即将售罄】
要求：
- 开头突出核心卖点（学区/地段/价格）
- 中间用数据说话（面积/单价/周边配套）
- 结尾制造紧迫感+看房邀约
- 字数：100-150字
- 语气专业可信
```

### 汽车行业

```
你是汽车行业营销文案专家，为【车型/品牌】写一条朋友圈文案：
- 车型定位：【如：家用SUV/豪华轿车/新能源车】
- 核心卖点：【如：空间/油耗/智能配置/安全性能】
- 促销信息：【如：金融方案/置换补贴/限时优惠】
要求：
- 开头场景化描述（家庭出行/通勤/自驾游）
- 中间突出3个核心配置优势
- 结尾试驾邀约
- 字数：100-150字
```

### 零售行业

```
你是零售营销文案专家，为【产品类型】写一条朋友圈文案：
- 产品类型：【如：服饰/美妆/家居/数码】
- 核心卖点：【如：性价比/品质/颜值/实用性】
- 促销信息：【如：新品首发/限时折扣/满减包邮】
要求：
- 开头用"姐妹们""宝子们"等亲切称呼
- 突出使用场景和搭配建议
- 制造稀缺感（限量/限时/断码预警）
- 字数：80-120字
- 结尾引导下单
```

## 四、朋友圈文案生成高级Prompt技巧

### 技巧1：Few-shot示例法

```
你是资深朋友圈文案专家。请参考以下3个成功文案的风格，为【新产品】写3条朋友圈文案：

示例1："用了一周这个护眼仪，加班到凌晨眼睛也不酸了！之前买过好几个都不行，这个真的绝。"
示例2："闺蜜推荐的颈椎按摩器，每天下班按15分钟，脖子舒服多了！打工人必备神器。"
示例3："给爸妈买的足浴盆，他们说泡脚后睡眠质量好多了，昨晚睡得特别香。"

要求：
- 风格：像朋友分享好物，真实自然
- 包含具体使用场景和效果
- 字数100字左右
- 避免广告腔
```

### 技巧2：风格一致性控制

```
你是一位【具体身份，如：十年教培校长/美业创始人/餐饮老板】的朋友圈文案助手。
你的朋友圈人设：
- 专业但不高冷
- 会分享行业干货
- 偶尔展现个人生活
- 推荐产品时真诚不做作

请写一条关于【主题】的朋友圈文案，保持以上人设一致性。
```

### 技巧3：A/B测试文案生成

```
你是营销文案专家，为【产品/活动】生成3个不同风格的朋友圈文案版本：

版本A：痛点焦虑型 - 开头制造焦虑，中间给方案，结尾引导行动
版本B：数据说服型 - 用具体数据和案例证明价值
版本C：故事共鸣型 - 用一个真实故事引发共鸣

每个版本80-120字，方便我测试哪个效果更好。
```

### 技巧4：批量生成文案

```
你是内容运营专家，为【品牌/个人IP】生成一周（7天）的朋友圈文案：

周一：干货知识型 - 分享行业小知识
周二：客户见证型 - 分享客户好评/案例
周三：促销活动型 - 限时优惠推广
周四：日常互动型 - 提问/投票/话题讨论
周五：产品种草型 - 推荐好物/服务
周六：生活分享型 - 个人生活/团队日常
周日：复盘总结型 - 一周收获/下周预告

每条80-120字，标注配图建议。
```

## 五、朋友圈文案AI生成避坑指南

| 常见错误 | 正确做法 |
|---------|---------|
| 指令太空："写一条朋友圈文案" | 指令要具体：角色+场景+目标+约束 |
| 要求完美："写一篇10万+爆款文案" | 要求具体指标：字数/风格/结构/CTA |
| 一次性要太多："写50条不同行业的文案" | 分批生成，每批5-10条，保持质量 |
| 不参考历史："随便写" | 提供参考示例，让AI学习风格 |
| 接受所有输出 | 每次至少生成3个版本，选最优的 |
