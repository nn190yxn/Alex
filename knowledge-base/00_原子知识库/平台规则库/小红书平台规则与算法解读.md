## 一、小红书推荐算法核心机制

### 1.1 流量分发漏斗

```
发布笔记
  ↓
机器审核（敏感词/违规检测）—— 不通过 → 笔记被隐藏/删除
  ↓ 通过
初始曝光池（200-500 曝光）
  ↓
评估数据（CTR、互动率、完读率）
  ↓ 达标
进入推荐池（5000-50000 曝光）
  ↓ 继续达标
进入更大推荐池（10 万+曝光）
  ↓ 持续爆款
进入热门流量池（百万+曝光）
```

### 1.2 算法评估的关键指标（按权重排序）

| 指标 | 权重 | 说明 |
|------|------|------|
| 收藏率 | 最高 | 代表内容 "有用"，是小红书最看重的指标 |
| 评论率 | 高 | 代表内容有讨论价值 |
| 点赞率 | 中 | 代表内容被认可 |
| 转发率 | 中 | 代表内容可传播 |
| 完读率 | 隐形 | 用户是否看完/读完 |
| 主页访问率 | 辅助 | 用户是否进一步了解账号 |
| 关注转化率 | 辅助 | 用户是否关注 |

| 更新时间 | 更新内容 | 影响 |
|---------|---------|------|
| 2024 Q2 | 强化 "真实体验" 权重 | 摆拍/虚假种草内容被降权 |

## 二、社区规范红线

### 2.1 内容违规类别

#### 一级违规（直接删帖/封号）

| 违规类型 | 示例 | 处罚 |
|---------|------|------|
| 政治敏感 | 涉及政治话题/领导人 | 删帖 + 封号 |
| 色情低俗 | 暴露/暗示性内容 | 删帖 + 封号 |
| 暴力血腥 | 暴力画面/描述 | 删帖 + 封号 |
| 违法信息 | 赌博/毒品/诈骗 | 删帖 + 封号 + 可能报警 |

#### 二级违规（限流/删帖）

| 违规类型 | 示例 | 处罚 |
|---------|------|------|
| 虚假宣传 | "最""第一"等绝对化用语 | 限流 + 删帖 |
| 医疗违规 | 未经认证的医疗建议/药品推荐 | 限流 + 删帖 |
| 金融违规 | 投资推荐/理财建议（无资质） | 限流 + 删帖 |
| 侵权 | 盗图/抄袭/搬运 | 删帖 + 账号降权 |

#### 三级违规（轻微限流/警告）

| 违规类型 | 示例 | 处罚 |
|---------|------|------|
| 营销过度 | 频繁发布硬广内容 | 限流 |
| 引流违规 | 放微信号/外链 | 删帖 + 限流 |
| 刷量行为 | 买赞/买粉/互刷 | 限流 + 降权 |
| 内容质量低 | 图片模糊/字数过少 | 限流 |

### 2.2 违禁词速查

#### 绝对化用语（广告法禁用）

```
最、第一、唯一、绝对、极致、完美、顶级、首选
国家级、世界级、全网第一、史上最好
```

#### 营销敏感词

```
加微信、加 V、私信我发链接、淘宝搜索、下单
免费领取（频繁使用）、秒杀、清仓（频繁使用）
```

#### 医疗相关（非认证账号禁用）

```
治疗、治愈、药效、处方、医生推荐、临床验证
```

### 2.3 规避违禁词的技巧

| 技巧 | 示例 | 说明 |
|------|------|------|
| 用数据代替绝对词 | "月销 10000+" 代替 "销量第一" | 数据可验证 |
| 用感受代替疗效 | "感觉皮肤变好了" 代替 "治愈痘痘" | 主观感受合规 |
| 用推荐代替购买 | "可以试试" 代替 "赶紧下单" | 降低营销感 |
| 用平台内功能代替外链 | "主页查看" 代替 "淘宝搜索" | 遵守平台规则 |

## 三、账号权重机制

### 3.1 账号权重等级

| 等级 | 特征 | 初始曝光 |
|------|------|---------|
| 新号（0-30 天） | 平台给予扶持流量 | 500-1000 |
| 成长号（1-3 个月） | 权重逐步建立 | 300-800 |
| 成熟号（3+ 个月） | 权重稳定 | 200-500 |
| 高权重号（万粉+） | 额外加权 | 1000-3000 |
| 低权重号（有违规） | 降权处理 | 50-200 |

### 3.2 提升账号权方法

| 方法 | 效果 | 周期 |
|------|------|------|
| 持续发布优质内容 | 权重稳步提升 | 1-3 个月 |
| 内容垂直度高 | 算法精准匹配 | 持续 |
| 互动率高 | 每篇笔记加权 | 持续 |
| 粉丝活跃度高 | 推荐加权 | 持续 |
| 企业号认证 | 基础权重提升 | 即时 |
| 原创声明 | 原创保护加权 | 持续 |

### 3.3 账号权重下降的信号

- 新笔记初始曝光持续低于 200
- 搜索自己的笔记，排名持续下降
- 粉丝增长放缓甚至减少
- 笔记互动率持续低于行业基准

## 四、2026 年重要新规解读

### 4.1 本地生活新规

**核心变化**：
- 真实到店权重提升：只有真实到店用户的评价才具有高权重
- 评价闭环：笔记标注 POI + 用户真实到店 = 双重加权
- 虚假评价严打：非到店评价被识别后降权处理

**应对策略**：
- 引导真实顾客发布带 POI 的笔记
- 建立到店打卡激励机制
- 杜绝刷评价行为

### 4.2 内容原创保护新规

**核心变化**：
- AI 生成内容需标注：使用 AI 生成的内容需添加 "AI 生成" 标签
- 原创保护加强：抄袭/洗稿内容更容易被识别和处罚
- 二次创作规范：引用他人内容需标注来源

**应对策略**：
- 坚持原创，避免抄袭
- 使用 AI 辅助但不完全依赖
- 引用内容明确标注来源

### 4.3 商业内容规范新规

**核心变化**：
- 商业合作需报备：品牌合作笔记需通过蒲公英平台报备
- 带货内容标注：推荐产品需标注 "广告" 或 "合作"
- 佣金透明：带货佣金比例需公开

**应对策略**：
- 通过蒲公英平台进行品牌合作
- 商业内容明确标注
- 遵守佣金披露要求

## 五、专业深化

### 行业数据基准

- **算法更新频率**：小红书每年进行 4-6 次重大算法更新
- **违规处罚响应时间**：系统自动处罚通常在 1 分钟内完成
- **人工审核响应时间**：申诉处理通常 3-5 个工作日
- **新号扶持期**：前 30 天给予 2-3 倍初始曝光
- **高权重号优势**：万粉账号的初始曝光是新号的 3-5 倍

### 常见坑

1. **不知道规则更新**：平台规则更新后仍按旧规则操作。**正确做法**：定期关注小红书官方公告和运营社区。

2. **忽视违规通知**：收到违规通知不重视，继续违规。**正确做法**：收到通知后立即排查并整改。

3. **AI 内容不标注**：使用 AI 生成内容但不标注，被处罚。**正确做法**：按新规要求添加 "AI 生成" 标签。

4. **商业内容不报备**：品牌合作不走蒲公英平台，被处罚。**正确做法**：所有商业合作通过蒲公英平台报备。
