## 模板1：9.9元体验课引流方案

**适用场景**：新开业校区或淡季招生，目标快速获取新线索

### 一、活动设计

**活动名称**：9.9元抢价值299元体验课（限量100份）

**课程包内容**：
- 3节正式课程（每次45-60分钟）
- 1份学习能力测评报告
- 1份课程学习规划方案
- 精美教具礼盒（价值49元）

**原价对比**：原价299元，限时9.9元（制造稀缺感）

### 二、目标人群

- 3-12岁儿童家长
- 周边3公里社区居民
- 有意向培养孩子某项技能的家长

### 三、引流渠道

| 渠道 | 具体方式 | 预期线索量 |
|-----|---------|-----------|
| 线下地推 | 学校门口、社区摆摊 | 30-50条 |
| 朋友圈广告 | 本地定向投放 | 50-80条 |
| 异业合作 | 书店、游乐场放置传单 | 20-30条 |
| 老带新 | 老学员分享海报 | 10-20条 |

### 四、转化流程

**Day 1-3：预热造势**
- 朋友圈发布倒计时海报
- 建立意向家长群
- 发布往期学员成果视频

**Day 4-7：集中成交**
- 限量100份，抢完即止
- 群内定时发布抢购战报
- 班主任1v1私聊催单

**Day 8-14：体验课进行**
- 第一节课：展示教学特色
- 第二节课：关注孩子表现
- 第三节课前：学管师与家长深度沟通

**Day 15-21：续费转化**
- 展示孩子3节课的进步对比
- 推出限时续费优惠（立减500元）
- 限量优惠名额刺激决策

### 五、话术模板

**地推话术**：
"家长您好，我们机构在做新学员体验活动，9.9元可以上3节正式课，还送学习能力测评和教具礼盒。咱们孩子多大了？我帮您看看适不适合参加。"

**转化电话话术**：
"您好，是XX妈妈吗？我是XX机构的班主任老师。孩子3节课体验完了，整体表现特别好，特别是[具体亮点]。我们最近有一个续费优惠，原价XX元的课程，现在报名可以立减500元，您这边考虑得怎么样了？"

### 六、关键数据指标

| 指标 | 目标值 | 预警值 |
|-----|-------|-------|
| 线索转化率 | ≥30% | <20% |
| 到店率 | ≥50% | <40% |
| 体验课转正价率 | ≥25% | <15% |
| 单个获客成本 | ≤80元 | >120元 |

### 关键要点
- 体验课内容必须精心设计，展现教学实力
- 第三次课前是最佳转化时机
- 设置阶梯优惠，制造紧迫感

## 模板2：免费测评引流方案

**适用场景**：学科类培训机构，目标精准获取有提分需求的家长

**活动名称**："0元学情诊断"——30分钟找到孩子学习问题

**诊断内容**：
- 学科知识漏洞检测（30分钟）
- 个性化学习报告（当场出具）
- 1对1学习规划咨询（30分钟）

### 二、目标人群

- 小学生/初中生家长
- 孩子成绩中等或偏下
- 对提分有强烈需求

### 三、邀约话术

**电话邀约**：
"您好，是XX妈妈吗？我们机构最近在做一个免费的学情诊断活动，专门帮孩子找出学习中的薄弱环节。30分钟就能测出孩子哪类题型最容易丢分，还能拿到一份专属的学习报告。您这周末有时间带孩子过来吗？"

**微信邀约**：
"【免费学情诊断】孩子的同桌都在用的学习方法，快来测一测！30分钟诊断+当场出报告+1对1规划，回复【1】预约。"

### 四、测评流程

| 环节 | 时长 | 负责人 |
|-----|------|-------|
| 接待签到 | 5分钟 | 前台 |
| 测评进行 | 30分钟 | 测评教师 |
| 报告解读 | 20分钟 | 咨询师 |
| 课程推荐 | 10分钟 | 咨询师 |

### 五、报告设计

**学情报告内容**：
1. 知识点掌握雷达图
2. 典型错题分析
3. 与同龄人对比
4. 提分建议
5. 推荐课程方案

**价值塑造**：报告价值199元，今天免费送

### 六、转化策略

- 报告解读时强调问题严重性
- 与竞品对比展示教学优势
- 限时优惠：今天报名立减1000元
- 名额限制：本期仅收20人

### 关键要点
- 测评题目要有区分度，能测出真实水平
- 报告要专业、具体，有数据支撑
- 咨询师要经过专业培训

## 模板4：地推体验课方案

**适用场景**：线下地推转化，需要快速提升到店率

### 一、地推执行流程

**时间选择**：放学后16:00-18:00（学校门口）
**地点选择**：重点小学、幼儿园周边
**人员配置**：2-3人/组

### 二、地推话术

**开场白**：
"家长您好，打扰一下，我们在做儿童[XX]体验课，可以让孩子免费试试~"

**价值塑造**：
"这个课原价299元，现在可以9.9元体验3节课，还送一份学习能力测评和教具礼盒，非常划算。"

**加微信话术**：
"我加您微信发您详细信息，您可以先了解下，不报名也没关系~"

### 三、物料准备

| 物料 | 数量 | 备注 |
|-----|------|------|
| 体验课海报 | 50张 | A3尺寸，突出价格和价值 |
| 体验券 | 100张 | 可撕式副券设计 |
| 小礼品 | 50份 | 气球、风车等孩子喜欢 |
| 二维码贴纸 | 100张 | 微信/公众号 |
| 登记表 | 2本 | 记录家长信息 |

### 四、海报设计要点

- 标题：醒目、数字化（如"9.9元体验3节课"）
- 副标题：价值对比（原价299元）
- 信任背书：机构名称、教学成果
- 紧迫感：限时限量
- 行动号召：扫码领取

### 五、到店率提升技巧

1. **当天回访**：地推结束后2小时内微信跟进
2. **预约确认**：电话确认到店时间
3. **到店提醒**：上课前1天再次确认
4. **到店礼**：到店即送小礼品

### 关键要点
- 地推话术要简短有力，30秒内说完
- 体验券必须当天激活，不能拖延
- 最好选在放学时间，家长接孩子心情好

### 专业方法论

#### 一、体验课转化漏斗模型
```
曝光量 → 点击/领取 → 到店核销 → 完整体验 → 正价转化

转化公式：
最终转化率 = 曝光量 × 领取率 × 到店率 × 完课率 × 转化率

各环节行业基准：
- 领取率：3-8%（受渠道和海报质量影响）
- 到店率：40-60%（受跟进质量影响）
- 完课率：70-85%（受课程质量和家长满意度影响）
- 转化率：15-25%（受咨询师能力和优惠设计影响）
```

#### 二、体验课转化率公式
```
体验课转化率 = 到店率 × 体验满意度 × 报价合理性 × 紧迫感

各因子行业基准：
- 到店率：35-50%（地推获取的线索到店率较低，约35-40%）
- 体验满意度：70-85%（课程质量和服务体验决定）
- 报价合理性：0.6-0.9（价格匹配家长预期程度）
- 紧迫感：0.5-0.8（优惠力度和稀缺性设计）

示例计算：
转化率 = 42% × 78% × 0.75 × 0.65 ≈ 16%
```

#### 三、获客成本精准核算公式
```
单客获客成本 = 总营销成本 ÷ 实际付费新学员数

总营销成本包含：
- 广告投放费用
- 地推人员成本
- 物料制作费用
- 体验课补贴（教具、场地、师资）
- 提成和激励

优秀标准：
- 素质类：≤200元/人
- K12类：≤300元/人
- 职业教育：≤500元/人
```

#### 四、体验课产品设计法则
```
引流产品 = 低价格 + 高感知价值 + 明确正价转化钩子

要素拆解：
1. 价格锚点：原价299元 → 体验价9.9元（制造30倍价值感）
2. 体验课时：3节（1节太短，5节太长）
3. 附赠品：教具礼盒（提升到店率和分享欲）
4. 转化钩子：测评报告、学习规划（为续费铺垫）

最佳体验课结构：
- 第1节：展示专业，建立信任
- 第2节：关注孩子，建立情感
- 第3节前：学管师与家长深度沟通，催单
```

### 真实案例数据

#### 案例一：某儿童体适能馆暑期引流（2024年）

**活动配置**：
- 产品：9.9元体验课（3节）+ 59元教具礼盒
- 目标：引流200组家庭
- 预算：1.5万元

**执行数据**：
| 环节 | 数据 | 转化率 |
|-----|------|-------|
| 地推曝光 | 3000人次 | - |
| 领取体验课 | 187组 | 6.2% |
| 到店核销 | 156组 | 83.4% |
| 完整体验（3节） | 142组 | 91% |
| 正价转化 | 44组 | 31% |
| 实际营收 | 25.5万元 | - |

**关键数据**：
- 实际获客成本：1.5万 ÷ 44 = 341元/人
- 投入产出比：25.5万 ÷ 1.5万 = 17倍
- 转化率 = 6.2% × 83.4% × 91% × 31% = 1.46%

**成功要素**：
1. 地推时间选在放学后，家长接孩子心情好
2. 教具礼盒现场领取，提升到店率
3. 第3节课前学管师一对一催单
4. 限时优惠：当天报名减500元

### 常见坑

#### 1. 坑：体验课设计太敷衍
【为什么是坑】家长感受不到专业度，认为"低价课就这样"，不会转化为正价
【正确做法】体验课质量=正价课质量，甚至更好，才能建立信任

#### 2. 坑：只做引流不做转化
【为什么是坑】引流只是开始，转化才是目的，没有催单动作等于白干
【正确做法】第3节课前学管师必须介入，设计限时优惠，24小时内催单

#### 3. 坑：到店率低（<40%）
【为什么是坑】线索浪费，转化无从谈起
【正确做法】当天回访+到店提醒+到店礼，3重保障提升到店率

#### 4. 坑：获客成本过高（>500元）
【为什么是坑】获客成本超过客单价40%，盈利困难
【正确做法】优化渠道组合，提升转介绍占比，降低单一渠道依赖

#### 5. 坑：体验课产品不聚焦
【为什么是坑】什么都想展示，反而什么都没讲清楚
【正确做法】聚焦1个核心卖点，让家长记住你最强的一点

#### 6. 坑：忽视线上线下联动
【为什么是坑】线上留资后没有私域运营，家长凉了就忘了
【正确做法】留资后24小时内加微信，朋友圈持续种草，7天内安排体验
