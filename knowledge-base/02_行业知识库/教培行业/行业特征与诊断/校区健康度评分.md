# 校区健康度评分

> 适用工具：校区健康度诊断
> 适用行业：教培

---

## 评分维度总览

| 维度 | 权重 | 评分范围 | 行业基准线 |
|-----|------|---------|----------|
| 财务健康度 | 25% | 0-100分 | ≥60分 |
| 教学质量 | 25% | 0-100分 | ≥65分 |
| 运营效率 | 20% | 0-100分 | ≥55分 |
| 客户满意度 | 15% | 0-100分 | ≥70分 |
| 团队稳定性 | 15% | 0-100分 | ≥50分 |

**综合评分** = Σ（各维度得分 × 权重）

## 一、财务健康度（权重25%）

### 评分维度

| 指标 | 计算方式 | 评分标准 |
|-----|---------|---------|
| 现金流健康度 | 现金储备/月支出 | 充足≥6月：80-100分<br>3-6月：60-79分<br>1-3月：40-59分<br><1月：0-39分 |
| 招生完成率 | 实际招生/目标招生 | ≥100%：90-100分<br>80-99%：70-89分<br>60-79%：50-69分<br><60%：0-49分 |
| 续费率 | 续费人数/应续人数 | ≥85%：90-100分<br>70-84%：70-89分<br>55-69%：50-69分<br><55%：0-49分 |
| 生均成本 | 月支出/在读学员数 | <500元：90-100分<br>500-800元：70-89分<br>800-1200元：50-69分<br>>1200元：0-49分 |
| 坪效比 | 月收入/校区面积 | >150元/㎡：90-100分<br>100-150元/㎡：70-89分<br>60-100元/㎡：50-69分<br><60元/㎡：0-49分 |

### 评分示例

**某校区财务数据**：
- 现金储备：60万
- 月支出：10万
- 现金流月数：6个月 → 85分
- 招生完成率：75% → 65分
- 续费率：68% → 55分
- 生均成本：600元 → 75分
- 坪效比：120元/㎡ → 80分

**财务健康度得分** = (85×20%+65×20%+55×25%+75×20%+80×15%) = 72分

### 行业基准线

| 机构规模 | 续费率基准 | 续费率预警 | 生均成本基准 |
|---------|----------|----------|------------|
| 小型（<50人） | ≥70% | <55% | 600-900元/月 |
| 中型（50-150人） | ≥75% | <60% | 400-700元/月 |
| 大型（>150人） | ≥80% | <65% | 300-500元/月 |

### 诊断结论

| 评分区间 | 结论 | 建议 |
|---------|------|------|
| 80-100分 | 财务状况优秀 | 保持现状，适度扩张 |
| 60-79分 | 财务状况良好 | 关注成本，优化结构 |
| 40-59分 | 财务状况一般 | 需要开源节流 |
| <40分 | 财务状况堪忧 | 急需改善 |

### 专业方法论

#### 一、校区健康度雷达图模型
```
         财务健康度
            ▲
           / \
          /   \
         /     \
        /   75  \
       /    ★    \
      ────────────────
     /      │      \
    /       │       \
   /  70   │   65  \
  /    ★    │    ★   \
 ▼        ▼        ▼
教学质量 客户满意度 团队稳定性
```

**诊断方法**：
- 绘制五维雷达图
- 识别"凹陷"维度（得分低于60分）
- 分析凹陷原因，制定针对性改进计划

#### 二、校区盈利公式
```
校区利润 = 课消收入 - 固定成本 - 变动成本

课消收入 = 在读学员数 × 月均课消 × 月数
固定成本 = 房租 + 工资（基本）+ 社保 + 折旧
变动成本 = 课时费提成 + 绩效奖金 + 营销费用

利润率 = 利润 ÷ 课消收入 × 100%
```

#### 三、校区运营效率公式
```
教师人效 = 在读学员数 ÷ 教师数
行业标准：1:8-12为最佳

场地坪效 = 月课消收入 ÷ 场地面积
行业标准：≥150元/㎡

教练产能利用率 = 实际上课时长 ÷ 最大可排课时长
行业标准：≥80%
```

#### 四、客户生命周期价值模型
```
LTV（生命周期价值）= 月均消费 × 平均续费周期 × 毛利率

计算示例：
LTV = 500元/月 × 18个月 × 30% = 2700元

各类型机构LTV参考：
- 素质类（体育/艺术）：2000-4000元
- K12学科类：3000-6000元
- 早教类：5000-10000元
```

### 常见坑

#### 1. 坑：只看营收不看利润
【为什么是坑】流水高≠盈利，预收款是负债，课消才是收入
【正确做法】用"课消收入-成本=利润"核算，关注结转和利润率

#### 2. 坑：忽视现金流管理
【为什么是坑】账上有钱≠有钱花，预收款被挪作他用，退费时无钱可退
【正确做法】保持6个月以上的现金流储备，专款专用

#### 3. 坑：人效过高或过低
【为什么是坑】人效<1:6说明人太多，成本高；人效>1:15说明服务缩水
【正确做法】人效保持在1:8-12范围，根据业务调整

#### 4. 坑：客户满意度虚高
【为什么是坑】满意度4.5分≠实际体验好，可能存在"给面子"成分
【正确做法】结合NPS、投诉率、退费率、转介绍率综合评估

#### 5. 坑：团队问题被掩盖
【为什么是坑】员工不满会传染给家长，导致客户流失
【正确做法】定期做员工满意度调查，关注团队稳定性指标
