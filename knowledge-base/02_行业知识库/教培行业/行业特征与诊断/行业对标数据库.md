## 对标诊断规则

### 财务健康度判定

- **优秀**：净利率 >= 行业优秀值，所有成本占比低于基准值上限
- **良好**：净利率 >= 行业基准值，至少2项成本占比在基准范围内
- **一般**：净利率低于行业基准值，但高于10%
- **较差**：净利率 < 10%，或至少2项成本占比超标
- **危险**：净利率为负，或任意成本占比超过上限10个百分点

### 教学健康度判定

- **优秀**：师生比达标，满班率 >= 80%，续费率 >= 75%
- **良好**：满班率 >= 70%，续费率 >= 60%
- **一般**：满班率 >= 60%，续费率 >= 50%
- **较差**：满班率 < 60%，或续费率 < 50%
- **危险**：退费率 > 15%，或师生比严重超标

### 招生健康度判定

- **优秀**：体验课转化率 >= 40%，获客成本低于基准值下限
- **良好**：体验课转化率 >= 30%，获客成本在基准范围内
- **一般**：体验课转化率 >= 20%
- **较差**：体验课转化率 < 20%，获客成本超标
- **危险**：招生数量连续3个月下滑

### 综合健康评分公式

```
健康分 = 财务健康分 × 0.30 + 教学健康分 × 0.30 + 招生健康分 × 0.20 + 团队健康分 × 0.20

各项满分100分，总分100分：
- 90-100分：健康状态优秀
- 75-89分： 健康状态良好
- 60-74分： 健康状态一般，需要改进
- 40-59分： 健康状态较差，需要重点改善
- 0-39分：  健康状态危险，需要紧急干预
```
