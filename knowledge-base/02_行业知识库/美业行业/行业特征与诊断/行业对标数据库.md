## 对标诊断规则

### 财务健康度判定

- **优秀**：净利率 >= 行业优秀值，所有成本占比低于基准值上限
- **良好**：净利率 >= 行业基准值，至少2项成本占比在基准范围内
- **一般**：净利率低于行业基准值，但高于10%
- **较差**：净利率 < 10%，或至少2项成本占比超标
- **危险**：净利率为负，或任意成本占比超过上限10个百分点

### 运营效率判定

- **优秀**：床位利用率 >= 65%，人效达到优秀值
- **良好**：床位利用率 >= 50%，人效达到基准值
- **一般**：床位利用率 >= 40%，人效略低于基准值
- **较差**：床位利用率 < 40%，人效明显低于基准值
- **危险**：床位利用率 < 30%，耗卡率 < 40%

### 客户健康度判定

- **优秀**：复购率 >= 45%，转介绍率 >= 25%
- **良好**：复购率 >= 35%，转介绍率 >= 15%
- **一般**：复购率 >= 25%，转介绍率 >= 10%
- **较差**：复购率 < 25%，或转介绍率 < 10%
- **危险**：客户流失率连续3个月上升

### 综合健康评分公式

```
健康分 = 财务健康分 × 0.30 + 运营健康分 × 0.25 + 客户健康分 × 0.25 + 团队健康分 × 0.20

各项满分100分，总分100分：
- 90-100分：健康状态优秀
- 75-89分： 健康状态良好
- 60-74分： 健康状态一般，需要改进
- 40-59分： 健康状态较差，需要重点改善
- 0-39分：  健康状态危险，需要紧急干预
```
