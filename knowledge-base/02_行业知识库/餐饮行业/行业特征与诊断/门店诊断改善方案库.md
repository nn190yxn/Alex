# 餐饮门店诊断改善方案库

本库根据餐饮门店诊断结果，输出针对性的改善动作。按改善维度分类，每个维度包含具体措施、执行步骤、预期效果和时间周期。

## 盈利能力改善

### 方案1：提升客单价

**适用场景**：客单价低于行业同地段平均水平

**具体措施**：
1. 套餐组合设计
   - 将单品组合成套餐，套餐价比单点低10-15%，但整体客单价提升20-30%
   - 设置主食+饮品+小吃的经典组合
   - 推出"招牌必点"推荐组合

2. 加料/升级选项
   - 提供加料选项（加肉、加菜、加蛋）
   - 设置大小份选择，引导选择大份
   - 推出"升级套餐"选项（+3元升级大杯、+5元升级套餐）

3. 推荐话术培训
   - "要不要加一份我们家的招牌小吃？很多客人都喜欢"
   - "今天有套餐活动，比单点划算15元"
   - "再加5元可以升级大份，更划算"

**执行步骤**：
1. 第1周：分析现有菜单，设计3-5个套餐组合
2. 第2周：制作套餐海报和菜单更新
3. 第3周：员工话术培训
4. 第4周：上线执行，每日跟踪数据

**预期效果**：客单价提升15-25%，毛利率提升3-5个百分点

**时间周期**：4周见效

### 方案2：优化产品毛利结构

**适用场景**：整体毛利率低于行业基准

**具体措施**：
1. 菜品ABC分类
   - A类（高毛利高销量）：重点推广，保持品质
   - B类（高毛利低销量）：加大推荐力度
   - C类（低毛利高销量）：控制成本或适当提价
   - D类（低毛利低销量）：考虑下架

2. 成本控制
   - 与供应商重新议价，争取5-10%的进货价优惠
   - 优化食材用量，减少浪费
   - 标准化配方，控制每份用量

3. 定价策略
   - 低毛利菜品小幅提价（5-8%）
   - 高毛利菜品保持价格，增加推广
   - 推出高毛利新品替代低毛利产品

**执行步骤**：
1. 第1周：统计近30天每道菜的销量和毛利
2. 第2周：完成ABC分类，制定调整方案
3. 第3周：菜单更新和员工培训
4. 第4-6周：跟踪毛利变化，微调方案

**预期效果**：整体毛利率提升5-8个百分点

**时间周期**：6周见效

## 运营效率改善

### 方案3：翻台率提升

**适用场景**：翻台率低于2次/天（正餐）或低于4次/天（快餐）

**具体措施**：
1. 缩短等位时间
   - 提供线上取号，减少现场排队
   - 等位区提供小食和水，提升体验
   - 提前点餐，入座即上菜

2. 优化出餐速度
   - 高峰前提前备菜备料
   - 优化后厨动线，减少无效走动
   - 设置出餐时间标准（快餐15分钟内，正餐25分钟内）

3. 加快结账流程
   - 支持扫码点餐和结账
   - 提供桌边结账服务
   - 减少客人等账单时间

**执行步骤**：
1. 第1周：统计当前各环节时间（等位、点餐、出餐、结账）
2. 第2周：找出瓶颈环节，制定优化方案
3. 第3-4周：实施方案
4. 第5-6周：跟踪翻台率变化

**预期效果**：翻台率提升0.5-1次/天，营收提升15-25%

**时间周期**：6周见效

### 方案4：人力效率优化

**适用场景**：人力成本占比超过20%

**具体措施**：
1. 排班优化
   - 按客流峰谷排班，高峰多排人，低谷少排人
   - 推行"一专多能"，员工能胜任多个岗位
   - 设置兼职/小时工，应对高峰时段

2. 流程标准化
   - 制定SOP，减少无效操作
   - 简化服务流程，减少不必要的环节
   - 引入自助服务（扫码点餐、自助调料等）

3. 人效考核
   - 设定人均服务桌数/人均营收目标
   - 将人效纳入店长考核指标
   - 每月复盘人效数据，持续优化

**执行步骤**：
1. 第1周：统计当前各时段客流和人力配置
2. 第2周：重新设计排班表
3. 第3-4周：培训一专多能
4. 第5-6周：跟踪人力成本占比

**预期效果**：人力成本占比降低2-5个百分点

**时间周期**：6周见效

## 顾客满意改善

### 方案5：差评率降低

**适用场景**：差评率超过5%或平台评分低于4.2

**具体措施**：
1. 差评预警
   - 用餐中主动询问客人满意度
   - 发现问题当场解决，避免事后差评
   - 设置"不满意免单"机制，拦截差评

2. 差评处理
   - 收到差评2小时内回复
   - 24小时内联系客人，了解具体情况
   - 给出补偿方案，争取修改评价

3. 好评引导
   - 用餐结束时邀请好评
   - 设置"好评送小菜"活动
   - 员工主动引导，提高好评率

**执行步骤**：
1. 第1周：分析近30天差评原因，分类统计
2. 第2周：针对主要原因制定改进措施
3. 第3-4周：执行改进方案
4. 第5-6周：跟踪差评率变化

**预期效果**：差评率降低50%以上，评分提升0.3-0.5分

**时间周期**：6周见效

### 方案6：复购率提升

**适用场景**：复购率低于20%

**具体措施**：
1. 会员体系
   - 消费即会员，扫码自动注册
   - 积分兑换菜品或折扣
   - 会员专享价，增强归属感

2. 回访机制
   - 消费后3天发送回访短信
   - 7天未复购发送优惠提醒
   - 30天未复购启动唤醒活动

3. 活动留存
   - 每月推出会员日活动
   - 生日当月赠送专属礼品
   - 储值赠送，锁定长期消费

**执行步骤**：
1. 第1周：搭建会员体系（可使用小程序或收银系统自带功能）
2. 第2周：制定回访话术和流程
3. 第3-4周：执行回访和活动
4. 第5-8周：跟踪复购率变化

**预期效果**：复购率提升10-20个百分点

**时间周期**：8周见效

## 成本控制改善

### 方案7：食材成本管控

**适用场景**：食材成本占比超过40%

**具体措施**：
1. 采购优化
   - 建立供应商比价机制，定期询价
   - 集中采购，争取批发价
   - 淡季提前囤货，锁定低价

2. 库存管理
   - 先进先出原则，减少过期损耗
   - 每日盘点，控制库存天数（不超过3天）
   - 设置安全库存线，避免紧急采购

3. 出品管控
   - 标准化用量，每份定量
   - 边角料再利用（如骨头熬汤、蔬菜做配菜）
   - 控制试菜和员工餐成本

**执行步骤**：
1. 第1周：统计当前食材成本占比和损耗率
2. 第2周：优化采购渠道和库存管理
3. 第3-4周：执行标准化出品
4. 第5-6周：跟踪食材成本变化

**预期效果**：食材成本占比降低3-8个百分点

**时间周期**：6周见效

### 方案8：能耗成本管控

**适用场景**：能耗成本占比超过5%

**具体措施**：
1. 用电管理
   - 高峰时段关闭不必要的设备
   - 使用节能灯具和设备
   - 制定开/关空调时间标准

2. 用水管理
   - 检查水管漏水，及时维修
   - 洗碗水循环利用
   - 安装节水设备

3. 燃气管理
   - 定期维护灶具，提高燃烧效率
   - 合理安排出餐顺序，减少空烧
   - 定期检查燃气泄漏

**执行步骤**：
1. 第1周：统计当前能耗费用
2. 第2周：制定节能措施
3. 第3-4周：执行节能方案
4. 第5-6周：跟踪能耗变化

**预期效果**：能耗成本降低10-20%

**时间周期**：6周见效
