## 对标诊断规则

### 财务健康度判定

- **优秀**：净利率 >= 行业优秀值，所有成本占比低于基准值上限
- **良好**：净利率 >= 行业基准值，至少2项成本占比在基准范围内
- **一般**：净利率低于行业基准值，但高于5%
- **较差**：净利率 < 5%，或至少2项成本占比超标
- **危险**：净利率为负，或任意成本占比超过上限10个百分点

### 运营效率判定

- **优秀**：翻台率/坪效/人效均达到优秀值
- **良好**：至少2项指标达到基准值
- **一般**：仅1项指标达到基准值
- **较差**：所有指标均低于基准值

### 顾客满意度判定

- **优秀**：好评率 >= 92%，复购率 >= 30%
- **良好**：好评率 >= 85%，复购率 >= 20%
- **一般**：好评率 >= 80%，复购率 >= 15%
- **较差**：好评率 < 80%，或复购率 < 15%

### 综合健康评分公式

```
健康分 = 财务健康分 × 0.35 + 运营效率分 × 0.25 + 顾客满意度分 × 0.25 + 营销指标分 × 0.15

各项满分100分，总分100分：
- 90-100分：健康状态优秀
- 75-89分： 健康状态良好
- 60-74分： 健康状态一般，需要改进
- 40-59分： 健康状态较差，需要重点改善
- 0-39分：  健康状态危险，需要紧急干预
```
