## 词汇使用指南

### 如何运用常用词汇

1. **情感共鸣**：用情感类词汇（如"意难平"、"破防"、"慰藉"）建立与消费者的情感连接
2. **场景营造**：用场景类词汇（如"烟火气"、"江湖"、"远方"）构建品牌故事背景
3. **态度表达**：用态度类词汇（如"无畏"、"滚烫的人生"、"肆意而为"）传递品牌精神
4. **句式模板**：用句式类词汇（如"以前…如今…"、"拒绝…渴望…"）快速构建文案框架

### 如何运用主题词汇

1. **活动命名**：直接套用主题模板，替换XX部分即可生成活动名称
2. **广告语创作**：选择合适的主题模板，微调后作为广告语使用
3. **内容策划**：以主题词汇为灵感，延展为完整的营销活动方案
4. **社交媒体话题**：将主题词汇转化为社交媒体话题标签

### 词汇组合技巧

- **常用词汇 + 主题词汇**：如"破防" + "XX不散场" = "青春不散场，感动不破防"
- **情感词汇 + 行动词汇**：如"慰藉" + "去创造" = "用创造慰藉每一颗孤独的心"
- **句式模板 + 品牌关键词**：如"以前…如今…" + 品牌名 = "以前你不懂我，如今[品牌名]懂你"
