# 内容营销MSG HOUSE模板：信息屋架构完整指南

## 概述

MSG HOUSE（Message House）信息屋是一种全球通用的战略沟通框架，由国际公关协会推广，被苹果、雀巢、澳大利亚政府等知名组织广泛采用。它能将复杂的品牌信息简化为一个可视化的层级结构，确保团队在所有传播场景中保持信息一致性。

## 一、什么是MSG HOUSE

### 核心定义

MSG HOUSE将品牌核心信息组织为一个类似房屋的层级结构：

- **屋顶（Roof）**：一个核心定位信息，概括品牌最核心的价值
- **支柱（Pillars）**：3-4个支撑核心信息的子主题
- **地基（Foundation）**：支撑每个支柱的具体证据和数据

### 为什么需要MSG HOUSE

团队在传播中常面临的问题：

- 不同渠道、不同人传递的信息不一致
- 缺乏证据支撑，传播内容显得空洞
- 每次都要从头思考“该说什么”

MSG HOUSE解决这些问题，让团队能够：

- **统一认知**：所有人都说同一件事
- **快速响应**：面对媒体提问可直接调用框架
- **保持一致**：无论渠道和场景，信息始终如一

## 二、MSG HOUSE标准结构

### 屋顶：核心定位信息

#### 定义

屋顶是一个简洁有力的核心陈述，通常1-2句话，表达品牌最核心的价值。它回答的问题是：“我们希望用户记住我们什么？”

#### 撰写原则

1. **清晰**：普通人能立即理解
2. **差异化**：竞争对手无法轻易复制
3. **可信**：有证据支撑，不是空洞口号
4. **灵活**：适用于多种场景和人群

#### 屋顶示例

```
原屋顶：某科技公司——“我们是一家创新科技公司”
优化屋顶：某科技公司——“我们用AI技术让中小企业也能享受智能客服，7×24小时响应，零漏客”
```

### 支柱：核心支撑主题

#### 定义

每个支柱解释屋顶信息的一个关键维度，3-4个支柱共同支撑屋顶的成立。

#### 支柱命名原则

- 每个支柱应有独特主题，避免重叠
- 支柱应是受众关心的利益点，而非功能特征
- 每个支柱能用一句话概括

#### 支柱结构示例

```
屋顶：用AI技术让中小企业也能享受智能客服

支柱1：省钱——节省80%客服人力成本
支柱2：高效——7×24小时秒级响应
支柱3：智能——深度学习越用越懂客户
```

### 地基：证据支撑

#### 定义

每个支柱需要具体、可验证的证据支撑，将主张转化为可信事实。

#### 证据类型

| 类型 | 示例 |
|------|------|
| 数据指标 | “服务超过10000家企业” |
| 客户案例 | “某电商客户使用后，响应速度提升300%” |
| 第三方认证 | “通过ISO27001安全认证” |
| 专家背书 | “被 Gartner 评为Cool Vendor” |
| 用户评价 | “用户NPS评分达65分” |

## 四、制作步骤详解

### 步骤一：明确目标与受众

在开始制作MSG HOUSE前，需要明确：

- **传播目标**：品牌认知、产品推广、危机公关？
- **核心受众**：谁应该记住这些信息？
- **使用场景**：官网、媒体采访、销售话术？

### 步骤二：收集输入信息

整理现有的品牌定位、产品卖点、客户反馈、竞品差异点等信息，作为MSG HOUSE的素材。

### 步骤三：撰写屋顶

从以下角度提炼屋顶信息：

1. 我们为用户解决什么问题？
2. 我们与其他品牌有何不同？
3. 用户选择我们的核心理由是什么？

### 步骤四：定义支柱

围绕屋顶，从3-4个维度展开：

1. 每个支柱应独立且互不重叠
2. 每个支柱应对应用户的一个核心利益
3. 用简洁的语言概括每个支柱

### 步骤五：构建证据体系

为每个支柱准备证据支撑：

1. 列举所有可能的证据
2. 筛选最具说服力的3-4个
3. 确保证据具体、可验证

### 步骤六：压力测试

用以下问题检验MSG HOUSE：

- [ ] 不同团队成员能否快速理解？
- [ ] 能否在15秒内向用户解释清楚？
- [ ] 每个支柱是否有足够的证据支撑？
- [ ] 是否与竞品形成有效差异？

## 五、应用场景

### 场景一：官网内容规划

```
首页标题：[屋顶信息]
子页面1：[支柱1标题] + [支柱1证据]
子页面2：[支柱2标题] + [支柱2证据]
子页面3：[支柱3标题] + [支柱3证据]
```

### 场景二：销售话术

```
开场：[屋顶信息]
展开：[支柱1简述] → [证据]
      [支柱2简述] → [证据]
      [支柱3简述] → [证据]
收尾：[地基整体信任状]
```

### 场景三：媒体采访

| 问题类型 | 参考支柱 | 引用证据 |
|----------|----------|----------|
| 关于产品 | 支柱2（核心功能） | 具体数据 |
| 关于团队 | 支柱1（专业背景） | 团队资质 |
| 关于用户 | 支柱3（用户价值） | 用户证言 |

### 场景四：社交媒体内容规划

```
屋顶 = 品牌核心价值 = 每条内容应回归的核心

支柱1主题 = 内容主题方向1（占40%内容）
支柱2主题 = 内容主题方向2（占30%内容）
支柱3主题 = 内容主题方向3（占30%内容）
```

## 六、小微企业应用建议

### 聚焦核心

小微企业资源有限，建议：

1. **聚焦1个屋顶信息**：不要试图说太多，一个核心足够
2. **3个支柱足够**：太少则信息单薄，太多则记忆负担
3. **证据宁精勿多**：每个支柱选2-3个最强证据

### 本地化调整

不同渠道可调整表达方式，但核心结构不变：

- **正式场合**：完整引用支柱和证据
- **社交媒体**：突出屋顶+1个亮点证据
- **销售话术**：屋顶+最相关的1个支柱

### 持续迭代

MSG HOUSE不是一成不变的文档，需要定期更新：

- 产品升级时更新证据
- 用户反馈变化时调整支柱
- 竞品变化时强化差异化

## 结语

MSG HOUSE是品牌信息管理的基础设施。它不追求覆盖所有信息，而是帮助团队在复杂环境中保持清晰和一致。对于小微企业而言，一个简洁有力的MSG HOUSE，能让团队在所有传播场景中“说同样的话”，从而在用户心智中建立清晰、统一的品牌形象。
