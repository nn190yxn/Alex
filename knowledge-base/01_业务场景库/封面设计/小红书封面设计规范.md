# 小红书封面设计规范

> 适用工具：封面文案生成器、笔记生成器、封面设计助手
> 平台特性：封面是用户在信息流中看到的第一视觉，决定 80% 的点击率
> 核心逻辑：封面=注意力捕获器+信息预告器+品牌识别载体

---

## 一、封面设计的核心原则

小红书用户滑动信息流时，**0.5 秒内**决定是否点击。封面承担三重任务：
1. **视觉吸引**：颜色、构图、文字排版抓住眼球
2. **信息预告**：让用户一眼知道这篇笔记讲什么
3. **品牌识别**：统一的视觉风格建立账号辨识度

---

## 二、封面尺寸与格式

### 2.1 推荐尺寸

| 尺寸比例 | 像素 | 适用场景 | 推荐度 |
|---------|------|---------|-------|
| 3:4（竖版） | 1080×1440 | 教程、干货、种草 | ⭐⭐⭐⭐⭐ |
| 1:1（方版） | 1080×1080 | 产品展示、对比图 | ⭐⭐⭐⭐ |
| 4:3（横版） | 1440×1080 | 场景图、环境图 | ⭐⭐⭐ |

**推荐首选 3:4 竖版**，因为：
- 在手机信息流中占据最大面积
- 视觉冲击力最强
- 适合放标题文字和要点列表

### 2.2 图片格式

| 格式 | 适用场景 |
|------|---------|
| JPG | 照片类、实拍类 |
| PNG | 设计类、文字类（保持清晰度） |
| 动图（封面视频） | 教程类、过程展示类 |

## 三、封面文字规范

### 3.1 文字字数

| 位置 | 字数限制 | 说明 |
|------|---------|------|
| 主标题（封面图文字） | 5-10 字 | 最大最醒目，一眼看懂 |
| 副标题 | 不超过 15 字 | 补充信息 |
| 标签/角标 | 2-4 字 | 如 "干货""必看""实测" |

### 3.2 字体选择

| 用途 | 推荐字体 | 避免 |
|------|---------|------|
| 主标题 | 思源黑体、站酷酷黑、庞门正道标题体 | 过于花哨的艺术字 |
| 正文说明 | 思源黑体、微软雅黑 | 手写体、行书 |
| 数字/英文 | DIN、Montserrat | 装饰性过强的字体 |

### 3.3 文字排版原则

1. **居中对齐**最安全，**左对齐**次之
2. **字号层次**：主标题 > 副标题 > 说明文字
3. **文字与背景对比度**要足够（深色背景用浅色字，反之亦然）
4. **不超过 3 种字号**，保持简洁
5. **文字区域不超过封面的 1/3**，留白是美感的关键

## 四、6 大封面模板类型

### 模板 1：大字报型

**适用**：教程、干货、清单类

**特征**：
- 纯色/渐变背景
- 超大字号标题居中
- 副标题在下方

**示例**：
```
┌──────────────┐
│              │
│   开餐厅      │
│  千万别做     │
│  这 5 件事    │
│              │
│  ⭐ 干货必看   │
└──────────────┘
```

**设计要点**：
- 背景色用品牌色或高饱和度色
- 标题字号占封面高度的 30-40%
- 适合知识密度高的内容

### 模板 2：实拍+文字叠加型

**适用**：探店、美食、产品种草类

**特征**：
- 实拍照片作为背景
- 半透明蒙层覆盖部分区域
- 文字叠加在蒙层上

**示例**：
```
┌──────────────┐
│  [菜品实拍图]  │
│              │
│ ┌─────────┐  │
│ │ 人均 50  │  │
│ │ 吃到撑   │  │
│ └─────────┘  │
└──────────────┘
```

**设计要点**：
- 照片质量是核心，模糊/暗的照片不要用
- 蒙层透明度 40-60%，文字清晰可读
- 文字区域不超过画面 1/3

### 模板 3：对比图型

**适用**：测评、前后对比、方案对比类

**特征**：
- 左右或上下分栏
- 对比双方各自展示
- 中间加分隔线或 "VS"

**示例**：
```
┌─────┬─────┐
│ 修改前│ 修改后│
│      │      │
│ 图A  │ 图B  │
│      │      │
│ 差评 │ 好评 │
└─────┴─────┘
```

**设计要点**：
- 对比要明显，一眼看出差异
- 两侧色调可以不同（如左边偏暗右边明亮）
- 加 "VS" 或 "Before/After" 标注

### 模板 4：列表/要点型

**适用**：清单、步骤、要点总结类

**特征**：
- 列表式排版
- 每行一个要点
- Emoji 或数字标记

**示例**：
```
┌──────────────┐
│  小红书起号    │
│  5 步搞定     │
│              │
│  ① 确定定位   │
│  ② 准备内容   │
│  ③ 优化主页   │
│  ④ 持续发布   │
│  ⑤ 数据分析   │
└──────────────┘
```

**设计要点**：
- 要点不超过 7 个
- 每行文字不超过 12 字
- 编号/Emoji 统一风格

### 模板 5：人物出镜型

**适用**：个人 IP、创业故事、经验分享类

**特征**：
- 人物照片为主体
- 表情自然有感染力
- 文字作为补充

**示例**：
```
┌──────────────┐
│              │
│   [人物照]    │
│              │
│  开店 3 年    │
│  亏了 40 万   │
│  然后呢？     │
└──────────────┘
```

**设计要点**：
- 人物表情要真实自然，不要太摆拍
- 眼神看向镜头更有亲和力
- 文字放在人物旁边或上方空白处

### 模板 6：数据/成果展示型

**适用**：数据报告、成果分享、案例拆解类

**特征**：
- 数据图表或截图
- 关键数据高亮
- 结论性文字

**示例**：
```
┌──────────────┐
│  [数据截图]   │
│              │
│  3 天涨粉     │
│  5000+       │
│              │
│  附完整攻略   │
└──────────────┘
```

**设计要点**：
- 数据要真实可验证
- 关键数字放大加粗
- 图表清晰易懂

## 五、配色方案

### 5.1 高点击率配色

| 配色方案 | 主色 | 辅色 | 文字色 | 适用场景 |
|---------|------|------|-------|---------|
| 红白配 | #FF4444 | #FFFFFF | #FFFFFF | 促销、活动、紧急通知 |
| 黄黑配 | #FFD700 | #000000 | #000000 | 干货、教程、重点提示 |
| 蓝白配 | #4A90D9 | #FFFFFF | #FFFFFF | 专业、可信、科技感 |
| 粉白配 | #FF6B9D | #FFFFFF | #FFFFFF | 女性、美食、生活 |
| 绿白配 | #2ECC71 | #FFFFFF | #FFFFFF | 健康、自然、环保 |

### 5.2 配色禁忌

- 不要用超过 3 种主色
- 避免荧光色/过于刺眼的颜色
- 文字和背景对比度要足够（可用 WCAG 对比度工具检测）

## 六、封面文案的 5 种写法

| 类型 | 写法 | 示例 |
|------|------|------|
| 数字型 | 具体数字 + 结果 | "3 天涨粉 5000" |
| 疑问型 | 问题 + 暗示答案 | "为什么这家店排队 3 小时？" |
| 命令型 | 动作指令 | "别再犯这 5 个错" |
| 利益型 | 好处/价值 | "月省 3000 的省钱攻略" |
| 悬念型 | 留白/不完整信息 | "开店第一年，我差点..." |

**封面文案与标题的配合**：
- 封面文字是标题的 "预告片"，不是重复
- 封面：抓眼球，5-10 字
- 标题：给信息，12-20 字
- 两者互补，不说同一件事

## 七、专业深化

### 行业数据基准

- **封面点击率**：优秀 >15%，良好 8-15%，需优化 <8%
- **封面图清晰度**：模糊/压缩严重的封面点击率降低 60%
- **文字占比**：封面文字区域占 20-30% 点击率最高
- **色彩饱和度**：高饱和度封面比低饱和度点击率高 25%
- **统一风格收益**：连续 30 天使用统一封面风格的账号，粉丝增长率高 40%

### 检查清单

- [ ] 封面尺寸 3:4（1080×1440）
- [ ] 封面文字 5-10 字
- [ ] 文字与背景对比度足够
- [ ] 不超过 3 种颜色
- [ ] 与账号以往封面风格统一
- [ ] 封面文案与标题互补不重复
- [ ] 图片清晰不模糊
- [ ] 无明显水印或边框

### 常见坑

1. **封面文字太多**：用户看不清重点。**正确做法**：封面只留最核心的 5-10 字，详情放标题和正文。

2. **风格不统一**：每篇封面颜色/排版都不一样，账号没有辨识度。**正确做法**：制定封面模板，固定配色和字体。

3. **使用低清图片**：拉伸/压缩导致模糊。**正确做法**：使用原始尺寸图片，导出时保持高分辨率。

4. **封面与标题重复**：信息浪费。**正确做法**：封面抓眼球（情绪/数字），标题给信息（具体内容）。

5. **忽视首图以外的图片**：用户会滑动查看多图。**正确做法**：第二张图放要点/步骤，第三张放成果/效果。
