# 小红书行业笔记风格模板

> 适用工具：笔记生成器、内容创作助手
> 平台特性：不同行业的笔记在内容风格、视觉呈现、互动方式上差异显著
> 核心逻辑：行业模板=行业特点+用户习惯+平台调性的结合

---

## 一、餐饮行业笔记模板

### 1.1 探店种草类

**标题公式**：
- `城市 + 品类 + 数字 + 评价词` → "成都必吃的 5 家老火锅"
- `价格 + 体验感` → "人均 50 吃到撑！这家火锅店值哭了"
- `位置 + 特色` → "藏在菜市场的 20 年老店"

**封面风格**：
- 主图：菜品特写（暖色调，突出食欲感）
- 辅图：店内环境、排队场景、老板出镜

**正文结构**：
```
【引入】一句话勾起食欲/好奇心

📍 店名 | 地址
💰 人均：XX 元
⭐ 推荐：⭐⭐⭐⭐

🥢 必点：
· 菜品 1 - 推荐理由（口感/味道）
· 菜品 2 - 推荐理由
· 菜品 3 - 推荐理由

📸 拍照建议：
· 哪个角度好看
· 什么时间去光线最好

⏰ 营业时间 | 🅿️ 停车

💬 你去过这家吗？评论区聊聊~
```

**标签组合**：
`#城市美食` `#品类推荐` `#探店` `#性价比餐厅` `#[具体位置]美食`

### 1.2 菜品制作/配方类

**标题公式**：
- `时间/成本 + 成果` → "5 分钟搞定餐厅同款糖醋排骨"
- `身份 + 秘方` → "30 年老厨师的独门配方"

**封面风格**：
- 主图：成品菜品特写（高清晰度）
- 辅图：制作步骤图（3-5 张）

**正文结构**：
```
【引入】这道菜的魅力/背景

📌 准备材料：
· 材料 1 + 用量
· 材料 2 + 用量

👨‍🍳 步骤：
Step 1 | ...
Step 2 | ...
Step 3 | ...

💡 关键技巧：
· 技巧 1（决定成败的点）
· 技巧 2

⚠️ 注意：常见错误/避坑

👇 收藏起来周末试试！
```

## 二、教培行业笔记模板

### 2.1 学习方法/干货类

**标题公式**：
- `人群 + 问题 + 解决方案` → "小学生注意力不集中？3 个方法解决"
- `时间 + 成果` → "30 天让孩子爱上阅读"
- `身份 + 经验` → "10 年教培老师的真心建议"

**封面风格**：
- 主图：大字报风格（标题 + 关键词）
- 辅图：学习方法示意图/表格

**正文结构**：
```
【痛点引入】家长的烦恼/孩子的困难

✅ 方法 1：名称
具体操作 + 适用场景

✅ 方法 2：名称
具体操作 + 适用场景

✅ 方法 3：名称
具体操作 + 适用场景

📊 效果对比：
使用前 vs 使用后

💡 核心原则：一句话总结

💬 你家孩子有这个问题吗？
```

### 2.2 课程/活动推广类

**标题公式**：
- `限时 + 福利` → "暑期体验课限时免费！"
- `成果承诺` → "3 个月让孩子英语开口说"

**正文结构**：
```
【场景引入】孩子的学习困境

🎯 课程适合谁：
· 年龄段
· 学习目标
· 当前水平

📚 课程内容包括：
· 模块 1
· 模块 2
· 模块 3

⭐ 课程优势：
· 优势 1
· 优势 2
· 优势 3

📍 上课地点 | ⏰ 上课时间
🎁 限时福利：XXX

💬 想了解详情的家长可以私信~
```

## 三、美业行业笔记模板

### 3.1 护肤教程类

**标题公式**：
- `肤质 + 问题 + 解决方案` → "油皮夏季护肤步骤，清爽不闷痘"
- `成分 + 功效` → "早 C 晚 A 正确打开方式"

**封面风格**：
- 主图：产品集合/护肤步骤图（干净清爽风格）
- 辅图：使用前/后对比

**正文结构**：
```
【肤质说明】适合什么肤质/解决什么问题

🧴 护肤步骤：
Step 1 | 清洁 - 产品名称 + 使用方法
Step 2 | 爽肤水 - 产品名称 + 使用方法
Step 3 | 精华 - 产品名称 + 使用方法
Step 4 | 面霜 - 产品名称 + 使用方法

💡 关键提示：
· 早晚区别
· 使用顺序
· 注意事项

⚠️ 避坑：
· 错误做法 1
· 错误做法 2

💬 你是哪种肤质？评论区帮你搭配~
```

### 3.2 项目/服务介绍类

**标题公式**：
- `项目 + 效果` → "光子嫩肤做完是什么样的？"
- `体验 + 评价` → "第一次做热玛吉，真实感受分享"

**正文结构**：
```
【体验背景】为什么做这个项目

📋 项目信息：
· 项目名称
· 价格范围
· 时长
· 恢复期

📝 体验过程：
Step 1 | 面诊
Step 2 | 操作
Step 3 | 术后护理

📊 效果记录：
· 第 1 天
· 第 7 天
· 第 30 天

⚠️ 注意事项：
· 适合人群
· 不适合人群
· 术后护理要点

💬 有问题的姐妹评论区问我~
```

## 四、通用行业适配要点

### 4.1 不同行业的语气风格

| 行业 | 推荐语气 | 避免 |
|------|---------|------|
| 餐饮 | 亲切、接地气、有食欲感 | 过于正式/学术 |

| 知识付费 | 干货密集、专业可信 | 空洞说教 |

## 五、专业深化

### 检查清单

- [ ] 标题符合行业特点和用户搜索习惯
- [ ] 封面风格与行业调性一致
- [ ] 正文结构匹配用户阅读预期
- [ ] 标签使用行业精准关键词
- [ ] 互动引导方式符合行业习惯
- [ ] Emoji 使用符合行业偏好
- [ ] 语气风格与目标人群匹配

### 常见坑

1. **行业语气错位**：餐饮笔记用学术腔调，美业笔记用销售腔调。**正确做法**：语气要匹配行业特点和目标人群。

2. **照搬其他行业模板**：直接把教培的模板套到餐饮上。**正确做法**：每个行业有其独特的内容结构和用户预期。

3. **忽视行业视觉偏好**：餐饮用冷淡风封面，美业用粗糙图片。**正确做法**：封面视觉要符合行业审美标准。
