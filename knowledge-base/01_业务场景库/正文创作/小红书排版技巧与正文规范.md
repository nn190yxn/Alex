# 小红书排版技巧与正文规范

> 适用工具：笔记生成器、文案优化器、排版检查工具
> 平台特性：小红书正文不支持富文本格式，只能通过文字、Emoji、空行来排版
> 核心逻辑：排版=可读性=完读率=推荐量

---

## 一、小红书排版的核心挑战

小红书正文编辑器功能有限，**不支持**：
- 粗体/斜体/下划线
- 标题层级（H1/H2/H3）
- 文字颜色/背景色
- 表格/代码块

**只能用**：
- 文字本身
- Emoji 符号
- 空行/换行
- 特殊符号（| - # * 等）

因此，**好的排版全靠文字组织和符号巧用**。

---

## 二、正文排版基础规则

### 2.1 段落规则

| 规则 | 说明 |
|------|------|
| 每段 1-3 行 | 手机屏幕宽度约 15-18 个汉字/行 |
| 段间空一行 | 增加视觉呼吸感 |
| 关键结论独立成段 | 重要信息单独一行，不被淹没 |
| 长列表每项空一行 | 方便快速扫描 |

**对比示例**：

不好（一大段）：
```
开店 3 年总结的经验：第一要选好位置，位置选对了就成功了一半，第二菜单要精简，菜品太多备货麻烦出餐也慢，第三一定要做线上推广，现在不做小红书和抖音就等于放弃了 50% 的客流。
```

好（分段排版）：
```
开店 3 年总结的 3 条血泪经验：

1️⃣ 选好位置
位置选对了，就成功了一半

2️⃣ 菜单精简
菜品太多 = 备货麻烦 + 出餐慢

3️⃣ 做线上推广
不做小红书和抖音 = 放弃 50% 客流
```

### 2.2 Emoji 排版规则

| 用途 | 推荐 Emoji | 用法 |
|------|-----------|------|
| 编号/序号 | 1️⃣ 2️⃣ 3️⃣ / ① ② ③ | 步骤、要点编号 |
| 标记分类 | 📍 📌 💡 ⚠️ ✅ ❌ | 不同类型信息的视觉标签 |
| 分隔段落 | —— | 长文中间的分隔线 |
| 情绪点缀 | 😭 ❤️ 😂 🔥 | 关键信息的情绪加强 |

**Emoji 密度控制**：
- 正文 300-600 字：5-15 个 Emoji
- 正文 600-1000 字：10-20 个 Emoji
- 超过上限会显得 "微商感" 过重

### 2.3 分隔线用法

用以下符号创建视觉分隔：

```
——
———
···
━━━━━
```

**适用场景**：
- 长文中不同章节之间
- 正文和互动引导之间
- 不同话题切换时

## 三、不同类型笔记的排版模板

### 3.1 教程类排版

```
【标题式开头】一句话说明能解决什么

📌 准备：
· 材料/工具 1
· 材料/工具 2
· 材料/工具 3

——

Step 1 | 步骤名称
具体操作描述...
⚠️ 注意：常见错误/避坑

Step 2 | 步骤名称
具体操作描述...

Step 3 | 步骤名称
具体操作描述...

——

✨ 最终效果：描述成果

💡 小贴士：补充建议

👇 收藏起来随时看！
```

### 3.2 种草/推荐类排版

```
【场景引入】让用户代入

📍 店铺名称 | 地址

💰 人均：XX 元
⭐ 推荐指数：⭐⭐⭐⭐⭐

🥢 必点：
· 菜品 1 - 推荐理由
· 菜品 2 - 推荐理由
· 菜品 3 - 推荐理由

——

📸 拍照建议：
· 哪个角度好看
· 什么时间光线好

⏰ 营业时间：XX:XX-XX:XX
🅿️ 停车：是否有停车位

——

💬 你吃过这家吗？评论区聊聊 👇
```

### 3.3 干货/经验类排版

```
【痛点引入】为什么需要看这篇

❌ 常见错误：
· 错误 1
· 错误 2
· 错误 3

——

✅ 正确做法：

1. 第一步
   详细说明...

2. 第二步
   详细说明...

3. 第三步
   详细说明...

——

💡 核心原则：一句话总结

📌 适用人群：谁最需要看

👇 觉得有用就收藏吧！
```

### 3.4 对比/测评类排版

```
【测评背景】为什么做这个测评

📊 测评标准：
标准 1 | 标准 2 | 标准 3

——

🥇 第一名：产品名称
优点：✅ xxx
缺点：❌ xxx
价格：¥XX
推荐指数：⭐⭐⭐⭐⭐

🥈 第二名：产品名称
优点：✅ xxx
缺点：❌ xxx
价格：¥XX
推荐指数：⭐⭐⭐⭐

...

——

📝 总结：
· 预算有限选 X
· 追求品质选 Y
· 性价比选 Z

💬 你用过哪个？感受如何？
```

### 3.5 故事/经历类排版

```
【悬念开头】一句话抓住注意力

故事开始...
时间、地点、人物

——

转折点：
"关键的那句话/那个瞬间"

——

结果：
现在怎么样了...

——

💭 感悟：
1-2 句话的核心感悟

💬 你有类似的经历吗？
```

## 四、特殊场景排版技巧

### 4.1 表格替代方案

小红书不支持表格，用以下方式替代：

**方式一：列表式**
```
📊 对比：

A 产品
· 价格：¥100
· 优点：xxx
· 缺点：xxx

B 产品
· 价格：¥150
· 优点：xxx
· 缺点：xxx
```

**方式二：符号对齐**
```
产品    | 价格  | 评分
A      | ¥100 | ⭐⭐⭐⭐
B      | ¥150 | ⭐⭐⭐⭐⭐
```

### 4.2 代码/公式替代方案

用代码块标记风格：
```
公式：
营业额 = 客流量 × 转化率 × 客单价

例：
100 人 × 30% × 50 元 = 1500 元/天
```

### 4.3 长文结构标记

超过 500 字的笔记，用小标题分段：

```
【一】第一部分标题
内容...

【二】第二部分标题
内容...

【三】第三部分标题
内容...
```

## 五、手机端预览检查清单

发布前，用手机预览检查：

- [ ] 每段不超过 3 行（手机屏幕）
- [ ] Emoji 不过多也不过少
- [ ] 关键信息在第一屏可见
- [ ] 列表项对齐清晰
- [ ] 分隔线使用一致
- [ ] 没有错别字
- [ ] 整体视觉 "呼吸感" 充足

## 六、专业深化

### 行业数据基准

- **排版对完读率的影响**：良好排名的笔记完读率比无排版的高 60%
- **Emoji 密度最佳值**：每 100 字 2-3 个 Emoji
- **段落长度最佳值**：每段 10-30 字
- **空行使用频率**：每 2-3 段空一行效果最佳
- **首屏信息密度**：前 3 屏（约 150 字）必须包含核心价值

### 检查清单

- [ ] 段落长度适中（1-3 行）
- [ ] 段间有空行分隔
- [ ] Emoji 数量 5-15 个
- [ ] 使用了视觉标记（编号/分类符号）
- [ ] 长文有小标题分段
- [ ] 列表项格式统一
- [ ] 关键信息在前 150 字
- [ ] 无连续空行超过 2 行

### 常见坑

1. **段落太长**：手机上看像文字墙。**正确做法**：每 1-3 句分段，空一行。

2. **Emoji 太少或太多**：太少显得干巴巴，太多显得不专业。**正确做法**：5-15 个，用于标记和情绪点缀。

3. **没有视觉层次**：全文一个字号一个颜色（小红书限制下）。**正确做法**：用 Emoji、分隔线、空行创建视觉层次。

4. **关键信息藏太深**：用户没耐心看完就走了。**正确做法**：核心价值在前 150 字内给出。
