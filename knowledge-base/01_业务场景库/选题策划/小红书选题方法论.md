# 小红书选题策划方法论

> 适用工具：选题生成器、热点追踪、竞品分析助手
> 平台特性：小红书选题决定笔记的流量上限，好选题 = 40% 的爆款因素
> 核心逻辑：选题=用户搜索需求+平台热点趋势+账号定位匹配

---

## 一、选题为什么是小红书运营的核心

在小红书的流量体系中：
- **选题决定流量上限** — 没人搜索/关注的主题，内容再好也没流量
- **内容决定流量下限** — 选题对了，内容差也能有一些流量
- **封面决定点击率** — 选题和封面配合才能获得高点击

**爆款公式**：
```
爆款 = 好选题（40%）+ 好内容（30%）+ 好封面（20%）+ 运气（10%）
```

## 二、5 大万能选题公式

### 公式 1：痛点解决型

**逻辑**：用户有明确痛点 → 你提供解决方案

**选题方法**：
1. 列出目标人群的 10 个常见痛点
2. 每个痛点写 3-5 个解决方案
3. 每个解决方案 = 1 篇笔记

**示例（餐饮老板人群）**：
- 痛点：菜品没人点
  → 选题："菜单上这 3 类菜赶紧砍掉"
- 痛点：员工流失率高
  → 选题："餐饮老板如何留住优秀员工？"
- 痛点：新客不回头
  → 选题："新客变老客的 5 个关键动作"

### 公式 2：热点借势型

**逻辑**：平台/社会热点 → 结合账号定位输出观点

**选题方法**：
1. 关注小红书站内热搜
2. 关注微博/抖音社会热点
3. 关注行业节日/季节性节点
4. 热点 + 你的专业角度 = 选题

**示例**：
- 热点：春节 → 餐饮选题："年夜饭菜单怎么安排？"
- 热点：开学季 → 教培选题："新学期孩子学习习惯怎么养？"
- 热点：换季 → 美业选题："春夏交替敏感肌怎么护理？"

### 公式 3：数据报告型

**逻辑**：数据/调查 → 提炼有价值的结论

**选题方法**：
1. 收集行业数据/报告
2. 找出反常识/有冲击力的数据
3. 用通俗语言解读数据

**示例**：
- "2024 餐饮行业数据：80% 的新店活不过 1 年"
- "测评了 50 家网红店，这 5 家真的值得去"
- "调查了 1000 个小红书用户，她们最喜欢这类内容"

### 公式 4：经验教训型

**逻辑**：你的真实经历 → 踩过的坑帮别人避开

**选题方法**：
1. 列出你在这个领域的 10 个失败/成功经历
2. 每个经历提炼 1-3 个教训
3. 教训 + 解决方案 = 选题

**示例**：
- "开店第一年亏了 40 万，我总结了 5 个教训"
- "做了 3 年小红书，这些坑希望你别踩"
- "从 0 到 1 万粉，我踩过的 8 个坑"

### 公式 5：对比选择型

**逻辑**：用户面临选择困难 → 你帮他们做决定

**选题方法**：
1. 列出目标人群常见的选择难题
2. 对比不同方案的优缺点
3. 给出明确的推荐

**示例**：
- "加盟 vs 自营，餐饮新手到底该选哪个？"
- "小红书 vs 抖音，餐饮推广哪个更划算？"
- "3 家连锁品牌对比，加盟哪家最靠谱？"

## 三、九宫格选题法

### 3.1 方法原理

用 3×3 矩阵组合不同维度，生成 9 个选题方向：

```
              内容形式
          教程     测评     清单
        ┌───────┬───────┬───────┐
  痛点  │ 教程  │ 测评  │ 清单  │
  解决  │ +痛点 │ +痛点 │ +痛点 │
        ├───────┼───────┼───────┤
  热点  │ 教程  │ 测评  │ 清单  │
  借势  │ +热点 │ +热点 │ +热点 │
        ├───────┼───────┼───────┤
  经验  │ 教程  │ 测评  │ 清单  │
  分享  │ +经验 │ +经验 │ +经验 │
        └───────┴───────┴───────┘
```

### 3.2 实操示例（餐饮行业）

| | 教程 | 测评 | 清单 |
|--|------|------|------|
| 痛点解决 | 菜单精简教程 | 外卖平台测评 | 避坑指南清单 |
| 热点借势 | 春节备菜教程 | 年货礼盒测评 | 年夜饭餐厅清单 |
| 经验分享 | 后厨管理教程 | 供应商测评 | 开店必备清单 |

## 四、竞品选题分析法

### 4.1 分析步骤

1. **找对标账号**：同领域 5-10 个优质账号
2. **筛选热门笔记**：点赞>500 的笔记
3. **提取选题模式**：
   - 标题结构是什么？
   - 内容角度是什么？
   - 解决什么需求？
4. **找选题空白**：竞品没覆盖但用户有需求的领域
5. **差异化输出**：用不同角度写同类选题

### 4.2 选题差异化策略

| 竞品做了 | 你的差异化角度 |
|---------|---------------|
| 正面推荐 | 反面避坑 |
| 专业教程 | 小白友好版 |
| 单一角度 | 多方案对比 |
| 理论讲解 | 实操案例 |
| 个人经验 | 行业数据支撑 |

## 五、选题日历管理

### 5.1 月度选题规划

| 周次 | 主题方向 | 选题数量 | 内容类型 |
|------|---------|---------|---------|
| 第 1 周 | 痛点解决 | 3-4 篇 | 教程/经验 |
| 第 2 周 | 热点借势 | 2-3 篇 | 观点/解读 |
| 第 3 周 | 干货输出 | 3-4 篇 | 教程/清单 |
| 第 4 周 | 互动话题 | 2-3 篇 | 讨论/投票 |

### 5.2 选题库维护

| 操作 | 频率 | 说明 |
|------|------|------|
| 新增选题 | 每天 | 随时记录灵感 |
| 选题筛选 | 每周 | 从选题库选出下周发布的内容 |
| 选题复盘 | 每月 | 分析哪些选题效果好，哪些差 |
| 选题更新 | 每季度 | 删除过时选题，补充新方向 |

## 六、专业深化

### 行业数据基准

- **爆款选题命中率**：优秀创作者选题命中率约 20-30%（每 3-5 篇出 1 篇爆款）
- **热点选题时效**：热点发布后 24 小时内发布内容效果最佳
- **痛点选题长尾值**：痛点类选题的搜索流量可持续 3-6 个月
- **选题库规模**：成熟创作者选题库应常备 50-100 个待用选题
- **选题 A/B 测试**：同选题不同角度发布，数据差异可达 3-10 倍

### 检查清单

- [ ] 本月选题已提前规划完成
- [ ] 每个选题都有明确的目标人群
- [ ] 选题覆盖了痛点/热点/干货多个维度
- [ ] 竞品选题已分析，找到差异化角度
- [ ] 选题库常备 50+ 个待用选题
- [ ] 每周复盘选题数据，优化选题方向

### 常见坑

1. **自嗨选题**：自己想写什么写什么，不管用户需不需要。**正确做法**：选题基于用户搜索数据和痛点分析。

2. **追热点偏离定位**：为了追热点发与账号定位无关的内容。**正确做法**：热点必须与账号领域结合，不追无关热点。

3. **选题同质化**：跟竞品写完全一样的选题，角度也没差异。**正确做法**：找到竞品没覆盖的空白，或用不同角度切入。

4. **没有选题储备**：到发布日才想写什么。**正确做法**：提前 1-2 周规划选题，建立选题库。
