### 二、专业方法论

#### 2.1 AIDA文案公式（美业适配版）
```
A - Attention（注意力）：前3秒抓住眼球
├── 痛点共鸣："你是不是也有这些皮肤问题？"
├── 数字钩子："90%的女生都不知道的护肤秘密"
└── 视觉冲击：高清对比图/精美海报

I - Interest（兴趣）：建立专业信任
├── 权威背书："国家认证美容师/10年经验"
├── 真实案例："上周服务的张女士..."
└── 数据支撑："1000+成功案例"

D - Desire（欲望）：激发购买动机
├── 限时限量："仅剩5个名额"
├── 价格锚点："原价XX，现价XX"
└── 情感共鸣："给自己投资，永远值得"

A - Action（行动）：明确行动指引
├── 私信引导："私信'变美'，优先预约"
├── 评论区互动："评论区扣1，获取报价"
└── 立即行动："扫码预约，享受首单5折"
```

### 四、检查清单

#### 4.1 内容合规自查（发圈前必查）
- [ ] 无绝对化用语："最佳"、"第一"、"唯一"等
- [ ] 无医疗效果承诺："治疗"、"祛除"、"根治"等
- [ ] 价格标示完整：原价、现价、有效期
- [ ] 无虚假对比：效果对比图真实、未PS
- [ ] 无个人信息泄露：客户头像/姓名打码
- [ ] 专利/认证信息真实可查

#### 4.2 发布效率检查
- [ ] 发布时间符合最佳时段
- [ ] 文案长度适中（50-150字）
- [ ] 图片清晰、水印统一
- [ ] 文案有行动号召（CTA）
- [ ] 话题标签使用正确（1-3个）
- [ ] @好友数量≤3人

#### 4.3 互动管理检查
- [ ] 发布后1小时内回复所有评论
- [ ] 私信24小时内回复
- [ ] 每周至少2次朋友圈互动
- [ ] 朋友圈置顶最新活动

### 五、常见坑与避坑指南

#### 5.1 文案致命错误
| 错误类型 | 后果 | 正确做法 |
|----------|------|----------|
| 夸大效果 | 投诉+违规+封号 | 用"改善"、"淡化"，不用"祛除" |
| 虚假价格 | 虚假宣传罚款 | 明确标注有效期和条件 |
| 盗用图片 | 侵权赔偿 | 用自己拍的或购买正版图 |
| 频繁刷屏 | 被屏蔽/拉黑 | 每天≤5条，内容多样化 |
| 硬广堆砌 | 掉粉+转化低 | 软硬结合，3:7比例 |

#### 5.2 图片使用雷区
| 雷区行为 | 风险 | 合规做法 |
|----------|------|----------|
| 使用网红/明星图 | 肖像侵权 | 用真实顾客（有授权）或自己拍 |
| 使用网络下载图 | 版权风险 | 购买正版图库或AI生成 |
| 过度PS对比图 | 虚假宣传 | 同一光线、角度拍摄 |
| 展示效果数据 | 违规风险 | 用"顾客反馈"、"个人体验" |

#### 5.3 朋友圈封号/限流原因
| 原因 | 占比 | 预防措施 |
|------|------|----------|
| 频繁添加好友 | 30% | 每天≤20人，自然增长 |
| 营销内容过多 | 25% | 内容多样化，非广告占比≥50% |
| 敏感词触发 | 20% | 使用谐音或表情代替 |
| 举报过多 | 15% | 避免硬广，尊重用户体验 |
| 外部链接 | 10% | 少用直接跳转，用私信替代 |
