## 案例1：新客咨询促单话术

**适用场景**：顾客首次咨询

### 具体话术

**场景1：顾客问价格**
"您好，感谢咨询～我们项目价格是根据您的皮肤状况来定的。先帮您做个皮肤检测，了解您的皮肤问题后，再给您推荐合适的项目，这样更有针对性。您方便来店里吗？可以免费做一次皮肤检测。"

**场景2：顾客问效果**
"效果是因人而异的，主要看皮肤状态和护理方案。不过我们有很多顾客做完效果都很好，这边可以发一些真实反馈给您看看。做一次护理肯定比不做要好很多，您先来体验一下，感受一下效果再做决定。"

**场景3：顾客说要比较**
"好的，比较是应该的。建议您可以从三个方面来比较：1. 资质和口碑 2. 产品品质 3. 服务专业度。我们店开了X年，积累了很多老顾客，靠的就是口碑。您可以先来店体验，不满意不收费。"

### 关键要点
- 先了解需求
- 不强推
- 邀请体验

### 二、专业方法论

#### 2.1 SPIN顾问式销售模型（美业适配版）
```
S - Situation（现状问题）
├── "您平时是怎么护肤的？"
├── "多久做一次专业护理？"
└── "皮肤最困扰您的问题是什么？"

P - Problem（困难痛点）
├── "这些问题对您日常生活有影响吗？"
├── "您有尝试过什么解决方法？"
└── "效果怎么样？"

I - Implication（影响放大）
├── "长期这样下去，皮肤问题会越来越严重"
├── "护肤品只能作用于表皮层，深层问题无法解决"
└── "现在不处理，以后修复成本会更高"

N - Need-payoff（需求满足）
├── "我们专门针对您这类问题设计了一套方案"
├── "坚持护理3个月，皮肤会有明显改善"
└── "现在办卡还能享受XX优惠，很划算"
```

#### 2.2 升单策略（ABC法则）
| 客户类型 | 推荐策略 | 话术要点 |
|----------|----------|----------|
| A类（高消费） | 直接推荐高套餐 | "您适合我们的VIP定制套餐..." |
| B类（中等消费） | 阶梯式引导 | "基础套餐+加项，灵活选择" |
| C类（低消费） | 体验式转化 | "先体验，感受好再升级" |

#### 2.3 促单时机判断（客户释放的成交信号）
| 信号类型 | 具体表现 | 应对策略 |
|----------|----------|----------|
| 语言信号 | "这个怎么做的？"、"多少钱？"、"能优惠吗？" | 准备促单 |
| 行为信号 | 反复看价目表、点头、靠近 | 直接提出成交 |
| 表情信号 | 眼神放光、微笑、满意点头 | 强化价值、促成 |
| 肢体信号 | 身体前倾、触摸产品 | 立即促单 |

### 四、检查清单

#### 4.1 促单前准备检查
- [ ] 了解客户来源和基本信息
- [ ] 准备好案例对比图/视频
- [ ] 确认当日优惠活动
- [ ] 准备好成交工具（合同/收据/POS机）
- [ ] 预约好下次服务时间
- [ ] 备好客户可能需要的产品小样

#### 4.2 促单过程合规检查
- [ ] 无强制消费/捆绑销售
- [ ] 价格明示、无隐形消费
- [ ] 效果描述真实、无夸大
- [ ] 客户有权拒绝、不施压
- [ ] 退款政策清晰告知
- [ ] 合同条款无霸王条款

#### 4.3 促单后跟进检查
- [ ] 当场发送护理注意事项
- [ ] 预约下次服务时间
- [ ] 24小时内发送满意度回访
- [ ] 7天内发送护理效果跟进
- [ ] 30天内发送会员活动信息

### 五、常见坑与避坑指南

#### 5.1 促单致命错误
| 错误类型 | 后果 | 正确做法 |
|----------|------|----------|
| 过度承诺效果 | 客诉+退款+口碑受损 | 用"一般"、"通常"等留有余地 |
| 强行推销逼单 | 客户流失+差评 | 尊重客户节奏、提供价值 |
| 贬低竞争对手 | 法律风险+格局低 | 客观对比、突出自身优势 |
| 价格不透明 | 信任崩塌 | 明码标价、主动告知 |
| 无视客户需求 | 反感+拒绝 | 先听再做、按需推荐 |

#### 5.2 价格异议应对话术
| 客户说 | 错误应对 | 正确话术 |
|--------|----------|----------|
| 太贵了 | "不贵呀，这已经很便宜了" | "理解您，这确实是笔投资。但您算一下，每周XX元，每天不到XX元，就能解决皮肤问题..." |
| 我考虑一下 | "好的，那您考虑好了联系我" | "理解您需要考虑。请问您主要考虑哪方面？是效果还是价格？我帮您分析一下..." |
| 比别家贵 | "别家产品质量不行" | "感谢您比价。建议您关注三点：1.产品资质 2.技师经验 3.售后保障。我们在这三方面都有优势..." |
| 超出预算 | "可以分期付款" | "理解您有预算考虑。我们有不同价位的方案，先体验基础项目，感受好了再升级也可以..." |

#### 5.3 客户流失预警信号
| 信号 | 风险等级 | 应对措施 |
|------|----------|----------|
| 多次预约取消 | 高 | 主动关心、调整方案 |
| 不回复消息 | 中 | 换时间段再联系 |
| 只问价不下单 | 中 | 提供对比优势 |
| 负面评价 | 高 | 24小时内处理 |
| 推荐竞争门店 | 极高 | 深度访谈、针对性解决 |
