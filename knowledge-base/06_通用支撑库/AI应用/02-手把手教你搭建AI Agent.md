## 一、ChatGPT 创建 GPTs

### 1.1 第一步：打开官网，探索GPT

- 访问 [ChatGPT 官网](https://chat.openai.com)
- 登录你的 OpenAI 账号（需为 Plus 或 Team 等付费用户）
- 在左侧导航栏点击 **"Explore GPTs"**（探索 GPT），浏览已有的 GPTs 获取灵感
- 了解不同 GPTs 的功能定位和提示词写法，为自己的创作积累思路

### 1.2 第二步：创建

- 在 "Explore GPTs" 页面右上角，点击 **"Create"**（创建）按钮
- 进入 GPT Builder（GPT 构建器）界面
- 你可以通过对话的方式告诉 GPT Builder 你想要创建什么样的助手，也可以手动进行配置

### 1.3 第三步：进行配置

GPTs 的配置是整个创建过程中最核心的部分，包含以下多个配置项：

#### 1.3.1 名称（GPT命名）

- **头像**：上传一张图片或让 DALL-E 自动生成一个符合主题的头像
- **名字**：简洁明了，便于识别，建议格式为"功能+助手"，例如：
  - "文案写作助手"
  - "数据分析专家"
  - "英语口语教练"

#### 1.3.2 描述（功能简介）

- 用一两句话明确介绍助手的作用、能力和应用场景
- 示例：
  - "专注于小红书风格的种草文案创作，擅长吸引眼球的标题和emoji搭配"
  - "帮你快速分析Excel数据，生成可视化图表和分析报告"

#### 1.3.3 指令（功能与限制）

这是**最关键的配置部分**，决定了 GPT 的核心能力。提示词需要做到**系统化、结构化、步骤化**。

编写建议：

```
## 角色设定
你是一个 [角色名称]，拥有 [专业背景/技能] ...

## 核心能力
1. [能力1]
2. [能力2]
3. [能力3]

## 工作流程
- 第一步：[具体操作]
- 第二步：[具体操作]
- 第三步：[具体操作]

## 输出格式
- 使用 [格式要求] 输出
- 包含 [必要元素]

## 限制与规则
- 不要 [禁止事项]
- 始终 [必须事项]
- 如果遇到 [特殊情况]，则 [处理方式]
```

#### 1.3.4 对话开场白（初始提示）

- 提供给用户第一次交互时的引导语
- 建议包含：
  - 简短自我介绍
  - 能做什么的说明
  - 引导用户提问的示例
- 示例：
  - "你好！我是你的文案写作助手。我可以帮你创作小红书、公众号、朋友圈等多种平台的文案。请告诉我你想写什么内容？"

#### 1.3.5 知识（知识库文件上传）

- 允许上传以下格式的文件作为 GPT 的专属知识库：
  - **PDF** 文件
  - **文本** 文件（.txt, .md 等）
  - **Excel** 文件（.xlsx, .csv）
- 上传后，GPT 在回答时会优先参考这些文件中的内容
- 适用场景：
  - 公司产品手册
  - 个人知识笔记
  - 行业报告数据
  - SOP操作文档

#### 1.3.6 功能区

GPTs 提供了以下可选功能模块：

| 功能 | 说明 |
|------|------|
| **网页搜索**（Web Browsing） | 开启后，GPT 可以实时检索互联网上的最新信息，适合需要最新数据的场景 |
| **画布**（Canvas） | 提供一个预览窗口，适合代码编辑、文档写作等需要实时预览的任务 |
| **DALL-E 图片生成** | 开启后，GPT 可以根据描述生成图片，适合设计、创意类助手 |
| **代码解译器和数据分析** | 开启后，GPT 可以运行 Python 代码，进行数学计算、数据分析和文件处理 |

#### 1.3.7 预览

- 配置完成后，可以在右侧**预览区域**实时直观地看到最终对话界面
- 建议进行多轮测试对话，验证：
  - 是否能正确理解用户意图
  - 输出格式是否符合预期
  - 知识库是否被正确调用
  - 功能模块是否正常工作

#### 1.3.8 创建选项（发布设置）

完成配置和测试后，选择发布范围：

| 选项 | 说明 | 适用场景 |
|------|------|----------|
| **只有我** | 仅自己可见可用 | 个人工具、测试阶段 |
| **知道链接的任何人** | 通过分享链接可访问 | 团队内部使用、小范围分享 |
| **GPT商店** | 发布到 GPT Store，所有用户可搜索 | 希望公开分享给更多人使用 |

### 1.4 第四步：保存

- 确认所有配置无误后，点击 **"Save"**（保存）按钮
- 选择发布范围后确认
- 保存成功后，你的 GPT 将出现在左侧导航栏的 GPT 列表中
- 后续可以随时返回编辑和优化

## 二、Gemini 创建 Gem

### 2.1 第一步：打开官网，探索Gem

- 访问 [Gemini 官网](https://gemini.google.com)
- 登录你的 Google 账号
- 在左侧导航栏找到 **"Gem"** 或 **"Gems"** 入口
- 浏览已有的 Gems 获取灵感，了解不同 Gem 的功能定位

### 2.2 第二步：新建Gem

- 点击 **"New Gem"**（新建 Gem）按钮
- 进入 Gem 编辑界面

### 2.3 第三步：配置及保存

Gem 的配置相比 GPTs 更加简洁，主要包含以下部分：

| 配置项 | 说明 |
|--------|------|
| **名称** | 为你的 Gem 起一个简洁明了的名字 |
| **指令** | 编写系统提示词，定义 Gem 的角色、能力和行为规则（参考 GPTs 的指令编写方法） |
| **知识来源** | 可关联 Google Drive 中的文件作为知识库 |

- 配置完成后点击 **"Save"** 保存
- 保存后即可在对话列表中使用你创建的 Gem

## 三、工作流应用创建智能体

除了 ChatGPT 和 Gemini 等原生平台，还可以通过**工作流应用平台**来创建功能更强大的智能体。这类平台的优势在于支持多模型切换、工作流编排、插件扩展等高级功能。

### 3.1 主流工作流应用平台

#### 扣子（Coze）

- **官网**：[coze.com](https://www.coze.com)（国际版）/ [coze.cn](https://www.coze.cn)（国内版）
- **支持的大模型**：

| 模型 | 说明 |
|------|------|
| 豆包 | 字节跳动自研大模型 |
| DeepSeek-R1 / V3 | DeepSeek 系列推理与通用模型 |
| 通义千问-Max | 阿里云通义千问旗舰模型 |
| 智谱-4 | 智谱AI大模型 |
| Kimi | 月之暗面大模型 |

#### Dify

- **官网**：[dify.ai](https://dify.ai)
- **支持的大模型**：

| 模型 | 说明 |
|------|------|
| GPT-4o | OpenAI 旗舰模型 |
| Claude-3.5 Sonnet | Anthropic 高性能模型 |
| DeepSeek 系列 | DeepSeek 全系列模型 |
| Gemini 系列 | Google Gemini 全系列模型 |
| 通义千问 QWQ | 阿里云推理模型 |

### 3.2 工作流应用 vs 原生平台对比

| 对比维度 | ChatGPT GPTs / Gemini Gems | 工作流应用（Coze/Dify） |
|----------|---------------------------|------------------------|
| 模型选择 | 仅限平台自有模型 | 支持多种第三方模型切换 |
| 工作流编排 | 不支持 | 支持复杂多节点工作流 |
| 插件扩展 | 有限 | 丰富的插件生态 |
| 知识库 | 基础文件上传 | 支持多种格式和数据库 |
| 发布方式 | 平台内分享 | 支持多渠道部署（API、微信、飞书等） |
| 定制灵活性 | 中等 | 高 |
| 上手难度 | 低 | 中等 |

## 四、扣子（Coze）做智能体详解

扣子（Coze）是目前国内最流行的智能体搭建平台之一，功能丰富且对新手友好。以下为详细的操作指南。

### 4.1 创建智能体

**操作步骤：**

1. **登录官网**：访问 [coze.cn](https://www.coze.cn)，使用手机号或抖音账号登录
2. **点击"+"**：在左侧导航栏或首页点击 **"+"** 按钮
3. **输入基本信息**：
   - 输入智能体的**名称**
   - 填写智能体的**功能介绍**（简短描述它能做什么）
4. **确认创建**：点击确认，进入智能体编辑页面

### 4.2 功能配置详解

#### 4.2.1 模型选择

扣子支持多种大模型，可根据任务需求灵活切换：

| 模型 | 特点 | 推荐场景 |
|------|------|----------|
| 豆包 | 字节自研，中文能力强 | 日常对话、中文创作 |
| DeepSeek-R1 | 强推理能力 | 数学推理、逻辑分析 |
| DeepSeek-V3 | 通用能力强 | 综合任务、代码生成 |
| 通义千问-Max | 阿里旗舰，知识面广 | 知识问答、专业咨询 |
| 智谱-4 | 中文理解优秀 | 中文写作、翻译 |
| Kimi | 长文本处理出色 | 长文档分析、论文阅读 |

#### 4.2.2 提示词（人设与回复逻辑）

提示词是智能体的"灵魂"，定义了它的性格、能力和行为方式。

**编写要点：**

- **人设定义**：明确智能体是谁、有什么专业背景
- **回复逻辑**：规定智能体应该如何思考和回答
- **格式要求**：指定输出的结构和风格

**示例模板：**

```
# 角色
你是一位资深的 [领域] 专家，拥有 [X] 年的从业经验。

# 专业领域
- [领域1]：[具体能力]
- [领域2]：[具体能力]
- [领域3]：[具体能力]

# 回复规则
1. 回答要专业、准确、有条理
2. 使用通俗易懂的语言解释专业概念
3. 给出具体可操作的建议
4. 如果不确定，诚实说明

# 输出格式
- 使用分点列举
- 重点内容加粗标注
- 必要时提供示例
```

#### 4.2.3 技能

技能是智能体的"手脚"，让它能执行具体的操作。扣子提供三种技能类型：

**（1）插件（Plugins）**

- **官方插件**：平台预置的插件，涵盖：
  - 新闻资讯
  - 天气查询
  - 股票行情
  - 图片搜索
  - 地图导航
  - 邮件发送
  - 日程管理
  - 等等...
- **自建插件**：通过 API 接入外部服务，实现自定义功能

**（2）工作流（Workflows）**

- 将复杂任务拆解为多个节点的自动化处理流程
- 支持的节点类型包括：
  - 大模型节点（LLM）：调用AI模型处理文本
  - 条件判断节点：根据条件分支执行
  - 代码节点：运行自定义代码
  - 知识库节点：检索外部知识
  - 变量节点：存储和传递数据
  - HTTP请求节点：调用外部API
- 适用场景：
  - 多步骤的数据处理
  - 需要条件判断的复杂任务
  - 多个系统的联动操作

**（3）触发器（Triggers）**

- 让智能体在特定条件下自动执行任务
- 支持的触发方式：
  - **定时触发**：每天/每周固定时间自动运行
  - **事件触发**：当特定事件发生时自动响应
- 适用场景：
  - 定时新闻摘要推送
  - 数据监控与报警
  - 定期报告生成

#### 4.2.4 知识

为智能体提供专属的外部知识库，支持以下格式：

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| **文本** | TXT、Markdown 等纯文本文件 | 产品文档、操作手册、FAQ |
| **表格** | Excel、CSV 等结构化数据 | 产品价格表、规格参数、客户数据 |
| **照片** | JPG、PNG 等图片文件 | 产品图片、流程图、截图 |

上传知识后，智能体在回答时会自动检索和引用相关知识内容，大幅提升回答的准确性和专业性。

#### 4.2.5 记忆

扣子提供三种记忆机制，让智能体具备"记忆"能力：

| 记忆类型 | 说明 | 适用场景 |
|----------|------|----------|
| **变量** | 保存用户的个人偏好和设置 | 用户名、语言偏好、风格喜好 |
| **数据库** | 以表格形式结构化存储数据 | 客户管理、任务记录、 inventory |
| **长期记忆** | 模仿人脑的自动记忆机制 | 记住用户的聊天历史和偏好，跨对话保持记忆 |

#### 4.2.6 文件盒子

- 为智能体配置文件存储空间
- 用户可以上传文件，智能体可以读取和处理这些文件
- 适用场景：
  - 文档分析助手
  - 简历优化工具
  - 合同审核助手

### 4.3 对话体验优化

为了让用户获得更好的交互体验，扣子提供了以下对话配置选项：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| **开场白** | 用户首次进入对话时看到的欢迎语 | "你好！我是你的数据分析助手，请上传你的数据文件开始分析。" |
| **用户问题建议** | 预设一些常见问题，方便用户快速提问 | "帮我分析这份销售数据"、"生成月度报表"、"找出异常数据" |
| **快捷指令** | 一键触发的预设指令，简化操作流程 | "一键总结"、"快速翻译"、"生成周报" |
| **背景指令** | 在每次对话中自动注入的隐藏指令 | "始终使用中文回答"、"回答控制在200字以内" |
| **语音** | 支持语音输入和语音输出 | 适合移动端使用、语音交互场景 |
| **用户输入方式** | 支持打字输入和语音输入两种方式 | 用户可根据场景自由选择 |

## 附录：快速选择指南

| 需求场景 | 推荐平台 | 理由 |
|----------|----------|------|

| 国内用户首选 | 扣子（Coze） | 国内访问稳定，中文支持好 |
