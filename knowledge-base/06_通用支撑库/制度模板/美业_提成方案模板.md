### 二、专业方法论

#### 2.1 "固定给+步合制"薪酬体系设计
```
┌─────────────────────────────────────────────────────────┐
│                    月薪结构                              │
├─────────────────────────────────────────────────────────┤
│ 固定部分（60%）          │  绩效部分（40%）            │
│ ├── 底薪（保底）         │  ├── 手工费（多劳多得）     │
│ ├── 全勤奖（行为引导）   │  ├── 业绩提成（结果导向）   │
│ └── 餐补/交通补          │  └── 耗卡奖励（粘性激励）  │
└─────────────────────────────────────────────────────────┘
```

#### 2.2 手工费两种计算模式对比
| 模式 | 计算方式 | 优点 | 缺点 | 适用场景 |
|------|----------|------|------|----------|
| 按次计费 | 固定金额×服务次数 | 简单直观、多劳多得 | 忽视项目难度差异 | 小型门店 |
| 按额计费 | 项目实收×百分比 | 体现项目价值差异 | 计算复杂、需培训 | 中大型门店 |
| 混合模式 | 基础+浮动组合 | 平衡效率与公平 | 方案设计复杂 | 综合门店 |

#### 2.3 耗卡激励设计（防流失关键）
| 指标 | 计算公式 | 激励标准 | 行业参考 |
|------|----------|----------|----------|
| 耗卡率 | 实际耗卡额÷期末卡金余额 | ≥40%优秀，≥30%合格 | 行业均值25% |
| 奖励方式 | 耗卡额×2%-5% | 1000元耗卡=20-50元奖励 | 视客单价定 |
| 惩罚机制 | 连续3月<20%耗卡 | 扣减底薪10% | 仅警告无罚款 |

|----------|--------------|----------|

#### 3.3 拓客奖励效果数据

- **转介绍奖励**：老客带新客，消费后给老客10%返利，ROI 1:5
- **首单分成**：新客首单给拓客员工3%-5%分成，激励明显

### 四、检查清单

#### 4.1 提成方案合规自查
- [ ] 提成比例不低于当地最低工资保障
- [ ] 加班费另算，不纳入提成基数
- [ ] 离职当月业绩提成已结算
- [ ] 请假/旷工期间不计发提成
- [ ] 方案调整提前30天公示
- [ ] 书面签字确认，员工知晓规则

#### 4.2 月度薪酬发放核查
- [ ] 考勤数据与工资系统一致
- [ ] 手工统计次数与系统记录一致
- [ ] 业绩数据与收银系统一致
- [ ] 耗卡数据与会员系统一致
- [ ] 奖励/扣款有原始凭证
- [ ] 工资条发放，员工签字确认

#### 4.3 薪酬公平性检查
- [ ] 同岗位、同级别、同城市薪资一致
- [ ] 新老员工提成标准统一
- [ ] 门店间差异有合理依据
- [ ] 特殊奖励名单公示透明

### 五、常见坑与避坑指南

#### 5.1 提成方案设计错误
| 错误类型 | 实际损失 | 正确做法 |
|----------|----------|----------|
| 手工费固定太低 | 员工消极怠工 | 每半年市场调研调整 |
| 业绩目标过高 | 员工放弃努力 | 70%员工可达成为宜 |
| 阶梯太密集 | 计算争议多 | 不超过5个阶梯 |
| 奖励只给冠军 | 打击多数人 | 设TOP10%-20%奖励 |

#### 5.2 薪酬争议高频场景
| 争议场景 | 裁判规则 | 预防措施 |
|----------|----------|----------|
| 离职后提成发放 | 约定优先，无约定按比例 | 合同明确"离职结算条款" |
| 请假扣全勤还是扣工资 | 两者性质不同，分别规定 | 明确"全勤奖定义" |
| 试用期提成比例 | 不得低于转正后80% | 合同注明试用期标准 |
| 项目取消/退款扣提成 | 比例返还或全扣有争议 | 明确退款扣款规则 |

#### 5.3 避税风险提示
| 风险行为 | 后果 | 合规做法 |
|----------|------|----------|
| 现金发放提成 | 偷税漏税风险 | 统一银行转账 |
| 微信/支付宝发放 | 无凭证、无法举证 | 走公司账户 |
| 拆分工资（底薪低+提成高） | 社保基数低、员工维权 | 合理结构、如实申报 |
