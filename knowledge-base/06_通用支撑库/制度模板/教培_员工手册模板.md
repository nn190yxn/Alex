## 模板1：小型教培机构员工手册

**适用场景**：10-20人教育培训机构

### 具体内容

**第一章 总则**

欢迎加入XX教育！本手册旨在帮助您快速了解机构文化、规章制度及工作要求，请仔细阅读并遵守。

**第二章 入职与试用期**

1. 新员工试用期1-3个月
2. 入职需提供身份证、学历证明、健康证
3. 试用期满前一周提交转正申请
4. 转正后签订正式劳动合同

**第三章 工作时间**

1. 周二至周五：9:00-18:00（午休12:00-13:30）
2. 周六周日：8:00-18:00（轮班制）
3. 法定节假日正常排课，按规定调休

**第四章 薪酬福利**

1. 月薪=基础工资+课时费+绩效奖金
2. 每月15日发薪
3. 试用期工资为正式工资的80%
4. 购买五险

**第五章 教师行为规范**

1. 准时上课，不迟到、不早退、不拖堂
2. 着装得体，态度亲切
3. 严禁体罚、辱骂学生
4. 不得私下收受家长财物
5. 不得泄露学员个人信息

**第六章 课程顾问行为规范**

1. 诚实守信，不夸大课程效果
2. 不得诋毁其他机构
3. 保护家长隐私
4. 积极响应家长需求

**第七章 奖惩规定**

奖励：月度优秀员工、年终奖金、晋升机会
惩罚：迟到早退扣款、家长投诉处理、重大失误追责

### 关键要点
- 手册要简洁，10-20人小机构不用太复杂
- 教师行为规范是重点
- 课时费和绩效要明确

## 模板2：艺术培训员工手册

**适用场景**：美术、舞蹈、音乐等艺术培训机构

### 具体内容

**第一章 机构理念**

我们相信每个孩子都有艺术天赋，我们要做的是激发这份天赋。

**第二章 岗位职责**

**主教老师**
- 负责课程研发和教学
- 维护课堂秩序
- 定期与家长沟通
- 参与招生宣传

**助教老师**
- 协助主教上课
- 课前准备、课后整理
- 维护教室卫生
- 关注学生状态

**课程顾问**
- 接待家长咨询
- 跟进报名缴费
- 维护学员档案
- 处理家长投诉

**第三章 教学规范**

1. 提前5分钟到教室
2. 课前检查教具、材料
3. 关注每位学员状态
4. 课后填写教学记录
5. 定期拍照记录学员作品

**第四章 安全规范**

1. 教室门窗课前课后检查
2. 利器、颜料等妥善保管
3. 紧急情况按应急预案处理
4. 学员接送做好交接记录

**第五章 薪资待遇**

| 岗位 | 基础工资 | 课时费 | 其他 |
|------|----------|--------|------|
| 主教 | 3500元 | 80-150元/节 | 续费提成 |
| 助教 | 2800元 | 30-50元/节 | - |
| 顾问 | 3000元 | 招生提成 | 续费提成 |

### 关键要点
- 艺术培训重在激发兴趣
- 安全是重中之重
- 作品展示很重要

"让每个孩子找到适合自己的学习方法"是我们的使命。

1. 师范类毕业生优先
2. 有教师资格证优先

5. 续费：跟进学员续费

**第四章 服务规范**

1. 接待家长要热情专业

3. 处理投诉要积极主动
4. 保护学员隐私信息

**第五章 绩效考核**

| 项目 | 占比 | 考核内容 |
|------|------|----------|
| 教学效果 | 40% | 学生进步率、满意度 |
| 课时量 | 30% | 完成课时数 |
| 服务态度 | 20% | 家长反馈 |
| 团队协作 | 10% | 配合度 |

**第六章 违规处理**

- 迟到早退：扣款+绩效扣分

### 关键要点
- k12培训重在提分效果
- 教师资格证是加分项
- 家校沟通很重要

## 专业深化板块

### 一、行业数据基准

**法规政策层面**
- 教育部2021年9号令《校外培训机构从业人员管理办法》明确规定：从事学科类培训的教师须具教师资格证，机构需与全职人员签订劳动合同并缴纳社保
- 《民办教育促进法》要求培训费须存入指定账户，按周期退还，收费周期不超过3个月
- 2024年教培行业劳动合规案件增长37%，主要集中在社保缴纳、加班费计算、试用期解除三个领域

**人员配置标准**
- 义务教育阶段学科类机构：生师比不高于15:1
- 体育类机构：技能课1:20，实践课1:15
- 艺术类机构：实操课1:15，理论课1:25
- 早教机构：保育人员与婴儿比不低于1:3

**离职率数据**
- 2024年教培行业离职率20.8%，连续六年位居各行业之首
- 新人3个月留存率仅38%，6个月留存率降至52%
- 教师岗位主动离职率高于课程顾问岗位12个百分点

### 二、专业方法论

**员工手册合规审查七步法**
1. 查资质：核对机构办学许可证与营业执照一致性
2. 验合同：确保劳动合同与岗位性质匹配（专职/兼职）
3. 核社保：确认试用期满即缴纳，而非转正后
4. 审薪酬：检查加班费计算基数是否符合当地最低工资标准
5. 明职责：岗位职责说明书与实际工作内容一致
6. 定考核：绩效指标需量化可测量，避免主观评价
7. 建档案：员工档案包含入职登记表、资质证书、体检证明

**艺术培训机构人员配置公式**
- 主教老师数量 = 在读学员数 ÷ (平均班额 × 周均课时 × 满班率)
- 满班率参考值：寒暑假85%，春秋季70%
- 助教配置比例：实操类课程1:2，理论类课程1:3

### 三、真实案例数据

**案例1：某连锁体育培训机构合规整改**
- 问题：32名员工中有18人未缴社保，均以"灵活就业"方式自行缴纳
- 处理结果：补缴社保总额127万元，罚款34万元
- 教训：兼职教师可签服务协议，但专职教师必须缴纳社保

**案例2：儿童体适能机构课时费纠纷**
- 纠纷：教师主张排课等待时间应计入工时
- 法院判决：排课间隔不足2小时的部分应支付待岗工资
- 规范做法：在手册中明确"有效工时"计算方式

**案例3：舞蹈培训机构学员受伤事故**
- 事件：学员在做跳跃动作时扭伤
- 责任认定：机构因未配备防滑垫承担70%责任
- 合规启示：手册中必须包含详细的安全操作规程

### 四、检查清单

**员工手册发布前合规核查表**
- [ ] 劳动合同版本经法务审核
- [ ] 薪酬结构符合当地最低工资标准
- [ ] 加班费计算方式明确标注
- [ ] 请假审批流程与考勤制度一致
- [ ] 师德师风规范包含体罚、收礼等禁止项
- [ ] 竞业限制条款仅限高管岗位
- [ ] 离职交接流程包含资产归还、客户移交
- [ ] 异议处理途径明确（申诉渠道+时效）

**教师资质核查表**
- [ ] 教师资格证原件核对
- [ ] 学历证书与教学岗位匹配
- [ ] 心理健康证明（幼教岗位必需）
- [ ] 急救证书（体育、游泳类必需）
- [ ] 前任职教机构离职证明

### 五、常见坑

**坑1：试用期滥用**
- 表现：连续使用试用期、不签试用期合同、试用期不缴社保
- 风险：员工可主张双倍工资差额赔偿
- 规避：试用期包含在劳动合同内，入职当月签合同缴社保

**坑2：薪资结构模糊**
- 表现：将"课时费""绩效"拆分规避加班费
- 风险：离职时引发工资差额争议
- 规避：明确"正常工作日工资"与"加班费"计算基数

**坑3：竞业限制扩大化**
- 表现：对普通教师、课程顾问也约定竞业限制
- 风险：员工离职后若违反，机构需支付经济补偿
- 规避：仅对高管和核心技术人员约定竞业限制

**坑4：规章制度未经民主程序**
- 表现：老板直接制定规则，员工签字即生效
- 风险：制度可能被认定无效
- 规避：经职工代表大会或全体职工讨论，与工会协商确定

**坑5：离职证明内容不当**
- 表现：写明"违纪开除"等负面评价
- 风险：员工以"名誉侵权"起诉
- 规避：仅写明合同期限、岗位名称，不做主观评价
