## 模板1：校长/机构负责人岗位职责

**适用场景**：培训机构校长

### 具体内容

**一、运营管理**
- 制定机构发展规划和年度目标
- 统筹日常运营管理
- 监督各部门工作执行

**二、教学管理**
- 把控教学质量
- 监督教师培训考核
- 制定教学标准

**三、招生管理**
- 制定招生策略
- 监督招生团队
- 控制招生成本

**四、人员管理**
- 负责员工招聘培训
- 制定考核激励方案
- 维护团队稳定

**五、财务管理**
- 审核财务报表
- 控制成本支出
- 监督资金安全

**六、安全管理**
- 确保场地安全合规
- 建立应急预案
- 处理突发事件

### 关键要点
- 校长是机构的核心
- 要平衡教学和运营
- 团队建设很重要

## 专业深化板块

### 一、行业数据基准

**岗位配置标准数据**
- 小型机构（5-20人）：校长1人+教务1人+顾问2-3人+教师3-5人
- 中型机构（20-50人）：校长1人+教学主管1人+教务2-3人+顾问3-5人+教师8-15人
- 师生比：学科类≤15:1，体育实操类≤10:1，艺术实操类≤15:1
- 课程顾问与教师比例：约1:3（小型）至1:5（大型）

**SOP标准操作流程覆盖率**
- 头部机构SOP覆盖率：92%
- 中型机构SOP覆盖率：67%
- 小型机构SOP覆盖率：31%
- SOP执行到位率：头部89%、中型72%、小型58%

### 二、专业方法论

**岗位职责描述撰写五要素**
1. 核心目标：该岗位存在的意义
2. 主要职责：日常工作的3-5项核心任务
3. 关键指标：可量化的考核指标（KPI）
4. 协作关系：与哪些岗位配合
5. 权限边界：该岗位能做什么、不能做什么

**教务主管工作SOP框架**
- 每日：课表确认→教师到岗检查→课堂巡检→家长问题处理→数据记录
- 每周：排课调整→教师会议→问题汇总→数据报表
- 每月：续费跟进→排课优化→绩效核算→家校活动

**课程顾问销售漏斗管理**
- 线索录入→首次跟进→需求确认→邀约到店→体验转化→报名缴费→续费维护

### 三、真实案例数据

**案例1：某体育培训机构职责梳理**
- 问题：教师和顾问互相推诿，家长服务断档
- 原因：职责边界不清晰，协作流程缺失
- 解决方案：绘制"家长服务全流程图"，明确每个触点的责任人和标准话术
- 效果：家长投诉率下降67%，续费率提升18%

**案例2：早教机构教务主管工作量化**
- 原状态：教务主管每天忙于琐事，核心工作（排课、数据分析）无暇顾及
- 优化方案：将工作分层：自己做（排课、分析）、分配做（日常沟通）、外包做（数据录入）
- 效果：工作效率提升40%，数据准确率从82%提升至98%

**案例3：艺术培训机构教师职责扩展**
- 原职责：只负责教学
- 新增职责：课前朋友圈预热+课后作品展示+家长反馈+续费跟进
- 配套措施：提供朋友圈文案模板+拍照技巧培训+续费话术培训
- 效果：教师主动获客带来的新学员占比35%

### 四、检查清单

**岗位职责说明书核查表**
- [ ] 核心目标是否一句话说明？（该岗位为什么存在）
- [ ] 职责是否3-7条？（太少不全面，太多难执行）
- [ ] 是否有可量化的KPI？（不能量化的职责难以考核）
- [ ] 是否明确汇报对象和协作对象？
- [ ] 是否标注岗位权限边界？
- [ ] 是否与相邻岗位的职责有交叉但边界清晰？

**职责分工合理性自查**
- [ ] 是否有职责真空？（没人负责的工作）
- [ ] 是否有职责重叠？（多人负责同一工作）
- [ ] 关键职责是否有人承担？
- [ ] 协作流程是否顺畅？

### 五、常见坑

**坑1：职责描述过于笼统**
- 表现："负责日常工作""配合其他部门"
- 风险：执行无标准，考核无依据
- 纠偏：用"动词+内容+标准"格式描述，如"每天放学前完成次日课表确认，冲突率≤1%"

**坑2：职责与权限不匹配**
- 表现：教务主管负责排课但没有教室调配权
- 风险：工作无法执行到位
- 纠偏：职责描述必须包含对应的权限

**坑3：一人多岗职责混乱**
- 表现：小机构一人多岗，但职责描述仍是单岗模板
- 风险：绩效考核无法执行
- 纠偏：针对实际情况重新梳理多岗职责，明确时间分配

**坑4：职责与薪酬脱节**
- 表现：职责写了10条，但绩效考核只考2条
- 风险：员工只做考核项，其他职责被忽视
- 纠偏：职责与绩效必须一致

**坑5：职责描述长期不更新**
- 表现：岗位职责还是3年前的，业务早已变化
- 风险：职责描述与实际工作脱节
- 纠偏：每年至少审视一次岗位职责是否需要更新
