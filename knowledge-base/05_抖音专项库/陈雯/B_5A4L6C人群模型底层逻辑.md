## 一、抖音推流底层逻辑

### 1.1 核心机制："一加四"框架

抖音本地生活的流量体系核心是**"召回（Recall）"与"排序（Ranking）"**，构成"一加四"框架中的"人与马"。

```
召回（人） → 决定"有没有机会"出现在用户面前
排序（马） → 决定"能跑多远"
```

### 1.2 召回（Recall）：推流的门槛

**召回本质是"概率预估"过程**

| 概念 | 说明 |
|------|------|
| **海选机制** | 系统每秒从千万级视频/直播间库中筛选用户可能感兴趣的内容，缩小到"千"或"万"级 |
| **5A标签决定机会** | 用户与品牌"交情"越深（A等级越高），被召回概率呈指数级提升 |
| **触达过才更易触达** | 用户成为A3后，系统会在千万级内容库中优先"抓"出该商家内容推送 |
| **召回优先级** | A5 > A4 > A3 > A2 > A1；A4/A5是触发推荐频率的**天花板** |

**召回的核心逻辑**：
- 用户通过**停留60秒**成为品牌A3
- 商家开播/发视频时，系统优先从内容库中召回该用户
- A等级越高，召回确定性越强

### 1.3 排序（Ranking）：赛马机制

**排序 = 赛马，决定"推多少"**

| 维度 | 说明 |
|------|------|
| **小批量测试原则** | 系统先将内容推送给100-300人小波用户，根据反馈决定是否进入下一层 |
| **分层赛马** | 先召回铁粉（高A人群）进行第一轮赛马，观察反馈 |
| **行为决定分值** | 2026年更看重长期价值行为（收藏、分享、主页回访、搜推互动） |
| **M1池考核** | 收藏、分享、平均播放时长等内容力指标 |
| **M2/M3池考核** | **GPM（千次曝光成交金额）**、点击率、转化率、成交密度 |
| **赢者通吃** | 第一轮胜出 → 扩大召回范围 → 进入下一层级更大规模排序 |
| **赛马失败后果** | 初始测试数据垫底 → 赛马得分为0 → 系统停止推流 → 流量枯竭 |

**赛马破圈路径**：
```
初始测试（100-300人）
  ↓ 数据达标
铁粉层（最高优先级）
  ↓ 胜出
活粉层
  ↓ 胜出
自有5A资产层
  ↓ 胜出
同行5A资产层
  ↓ 胜出
同城泛人群层
  ↓ 胜出
全国泛人群层（最外层）
```

### 1.3.1 赛马失败的根本原因

**核心结论："决定5A和赛马成绩的始终是行为，而不是内容。"**

| 失败场景 | 原因 | 后果 |
|----------|------|------|
| 人群与内容不匹配 | 200万泛流量直接推补漆广告 | 两秒跳出率极高，五秒完播率极低 |
| 初始测试垫底 | 系统判定内容与人群不匹配 | 赛马得分为0，停止推流 |
| 推错人 | 未经过滤的泛流量直接转化 | 数据崩盘，3000播放都拿不到 |

**"你的短视频跑得快不快，80%出在短视频选题（定向）的问题上。"**

### 1.3.2 短视频前3秒定向（人群筛选底层原理）

**核心原理**：在视频开头通过特定元素直接筛选目标人群，非目标人群2秒内划走，系统后续推荐的全都是类似高精准人群。

| 定向元素 | 示例 | 筛选目标 |
|----------|------|----------|
| 方言 | "老丝儿们"、"甭啰" | 地域人群 |
| 特定身份称呼 | "郑州的宝马车主" | 精准车主 |
| 画面 | 孩子入水瞬间 | 宝妈群体 |
| 画面 | 美甲特写 | 女性用户 |

**底层逻辑**：前3秒定向本质是**零成本的人群预筛选**，确保跑出来的5A模型极其精准。

### 1.3.3 直播开场定江山（人为投喂成交模型底层原理）

**核心原理**：利用私域/鱼塘/老客在开场15-30分钟内密集成交，人为冲高GPM。系统捕捉到成交画像后，以此为模型在公域中通过"排序（赛马）"机制召回更多相似精准流量。

**数据流向**：
```
私域/鱼塘密集成交 → 系统捕捉成交画像 → 学习精准人群特征 → 公域排序赛马 → 召回更多相似高质量流量
```

**关键阈值**：开场15-30分钟数据决定全场上限。成交密度 + GPM vs 同层级竞品。

### 1.3.4 赛马机制的应用场景

| 场景 | 赛马机制 | 关键指标 |
|------|----------|----------|
| **短视频推流** | 先推铁粉，看点赞/收藏/完播 | 数据达标则破圈推同城 |
| **直播间实时推流** | 开场15-30分钟数据决定全场上限 | 成交密度 + GPM vs 同层级竞品 |
| **货架/商城排序** | 人群资产标签 + 交易力指标 | 高A人群或本地推可跨越距离排首屏 |

### 1.4 召回与排序的协同作用

| 策略 | 机制 | 效果 |
|------|------|------|
| **洗流量（增量逻辑）** | 蓝V/老板号在M1池发布泛内容，蓝V"播放即A3"特权 | 低成本积累大量A3资产 |
| **付费流强制召回（M3）** | 本地推全域投放强行插队，优先消耗自有5A | 确保"蜜月期"A3被精准召回 |
| **确定性转化** | 私域/鱼塘导流（人为投喂成交模型） | 系统学习成交画像，后续排序获更高权重 |
| **货架流量特殊性** | 商城/搜索场景叠加人群资产标签 | 有新鲜A3标签即便销量不如大品牌，也可虎口夺食 |

**核心结论**：
- **召回**决定你有没有机会出现在用户面前
- **排序（赛马）**决定你能跑多远
- 5A打法的本质：**不断打磨内容赢得赛马得分 + 不断积累人群资产确保被高频召回**

### 1.5 量化规则

| 规则 | 说明 |
|------|------|
| 用户行为决定标签 | 行为可被量化，标签决定召回机会 |
| 过去的偏好不代表现在 | 抖音追求推送当下喜欢的内容 |
| 多行为取高 | 同一用户多个行为，按最高等级计算 |

### 1.6 赛马机制（简化版）

```
第一轮：召回铁粉A3/A4/A5 → 赛马
第二轮：赢了 → 扩大召回活粉A1/A2 → 赛马
第三轮：继续扩大 → 同城泛人群 → ...
层层递进，赢者获得更多流量
```

## 二、5A人群模型

### 2.1 模型定义

| 等级 | 名称 | 定义 | 核心动作 |
|------|------|------|----------|
| **O** | 机会人群 | 同行人群，未被触达 | - |
| **A1** | 被动触达 | 首次曝光，无互动 | 被看到（曝光/播放） |
| **A2** | 浅层交互 | 点赞、收藏、页面停留 | 点赞、收藏、点击锚点 |
| **A3** | 主动交互 | 深度交互意向 | 搜索品牌、点击商品2次+、停留60秒+ |
| **A4** | 购买 | 完成支付 | 下单支付 |
| **A5** | 复购/拥护 | 多次购买或推荐 | 复购、推荐、好评 |

### 2.2 A3的黄金权重（2026年）

**A3是种草人群的黄金水库**

| 行为 | A3判定 |
|------|--------|
| 搜索品牌关键词 | **直接A3** |
| 点击商品详情≥2次 | **直接A3** |
| 直播间停留>60秒 | **直接A3** |
| 收藏/分享 | **直接A3**（2026年高权重） |
| 评论互动 | A3 |
| 白色锚点点击 | A2 |

### 2.3 2026年A3有效期变化（重要！）

| 年份 | A3有效期 | 变化 |
|------|----------|------|
| 2024年 | 15天内保持层级 | 去年：只要成为A3，15天内都保持 |
| **2026年** | **动态衰减** | 今年：多次不互动，曝光概率**直线下降**，撑不到15天 |

**核心结论**：A3不是保命符，是转瞬即逝的窗口

### 2.4 十大触点（2026年新增）

> 引用来源：十大触点（2026-03-28补充资料）
> 触点是系统判定用户进入5A哪个等级的唯一依据，遵循"论迹不论心"原则——通过量化用户具体行为来衡量对品牌的喜欢程度

| 序号 | 触点 | 行为描述 | 判定价值 |
|------|------|---------|---------|
| 1 | **搜索（Search）** | 用户主动搜索品牌词/门店名，或点击"看后搜"词条 | 极高权重，搜索品牌名通常直接判定为**A3** |
| 2 | **巨量本地推（OceanEngine）** | 用户刷到本地推投放广告并停留/点击/转化 | 强行召回和打标，新鲜A3几乎100%再次触达，可强化A3或促成向A4流转 |
| 3 | **自然内容（UGC/打卡）** | 普通用户发布带白色锚点（门店定位）的内容 | 低成本获取**A1**；酒旅等行业UGC视频有额外流量加持 |
| 4 | **常规广告（DOU+/挑战赛）** | 通过抖加或挑战赛等非本地推渠道分发曝光 | 扩大漏斗最前端，配合蓝V/老板号可将泛流量低成本洗成初始5A资产 |
| 5 | **达人端（KOL/KOC）** | 用户观看达人团购短视频或进入达人直播间 | 2026年权重下调，一次通常仅算A1，多次深度互动（如点击货架）才能升A3 |
| 6 | **官方账号（蓝V/老板号/职人号）** | 用户刷到商家发布的非挂车短视频 | 拥有"判定特权"，有效播放（2-3秒）即可判定为**A3** |
| 7 | **官方主页** | 用户点击头像进入商家主页查看置顶视频或商家信息 | 对客资行业（留资类）权重极高，卡在**A2与A3之间** |
| 8 | **官方直播** | 用户进入自播间，产生停留>60秒/评论/点击小黄车 | 直播间打标A3最高效的路径；福袋和引流款点击是往A4进阶的关键 |
| 9 | **POI详情页/商品详情页** | 用户点击锚点进入门店详情页或查看团购商品介绍 | **2026年重大变化**：POI页目前通常判定为**A2**（而非过去的A3）；商品详情页权重下调但仍是转化关键 |
| 10 | **购买与核销** | 用户完成下单支付（A4）以及到店核销 | **最高权重触点**：核销后用户永久留在品牌资产中，获得**90天（餐饮）/365天（酒旅）**高频优先推荐 |

**核心结论**：运营的本质就是通过设计这些"触点"动作，让用户从低等级向高等级流转。"触达过才更易触达"，高A等级意味着更高的系统推荐频率和下单概率。

## 三、4L人群分层模型

### 3.1 模型定义

| 层级 | 定义 | 包含人群 | 运营策略 |
|------|------|----------|----------|
| **L1** | 潜在机会人群 | 全部A1-A3人群 | 拉新、扩圈、种草 |
| **L2** | 新客户 | 首次下单客户 | 首单转化、引导核销 |
| **L3** | 复购客户 | 2次及以上购买客户 | 促活、复购激励 |
| **L4** | 沉默客户 | 超过30天未核销/未复购 | 唤醒、流失挽回 |

### 3.2 L3/L4的核心价值

**L3和L4是触发推荐频率最高的人群**

- 能**跨越A3的15天有效期**
- 有效期可达**半年到一年**
- 一旦完成核销，用户**永远留在品牌资产中**

### 3.3 沉默用户的致命性

```
用户脱离L2/L3进入L4
  ↓
挽回成本 = 拉新成本的3-5倍
```

### 3.4 4L与5A6C版本差异（适用对象）

| 版本 | 适用商家 | 人群细分方式 |
|------|----------|--------------|
| **4L版本** | 单店及中小商家 | L1（潜在机会）/L2（新客）/L3（复购）/L4（沉默） |
| **5A6C版本** | 全国连锁大品牌 | 5A人群资产 + C1-C6内容类型分层 |

**5A6C版本专属 - C6（支付唤醒人群）**：
- **定义**：专门用于量化通过营销手段救活的流失用户
- **作用**：追踪"已流失但被营销手段重新激活"的用户群体
- **价值**：帮助大品牌精确衡量老客唤醒活动的效果

**版本选择原则**：
- 单店/中小商家 → 使用4L版本即可
- 全国连锁大品牌 → 使用5A6C版本实现精细化运营

## 四、6C内容类型模型

### 4.1 模型定义

| 内容类型 | 对应人群 | 转化目标 | 使用场景 |
|----------|----------|----------|----------|
| **C1 泛内容** | A1-A2 | 扩圈、拉新 | 日常短视频 |
| **C2 品牌内容** | A2-A3 | 种草、认知 | 品牌理念、产品介绍 |
| **C3 促销内容** | A3-A4 | 转化、成交 | 优惠活动 |
| **C4 用户证言** | A3-A4 | 信任、决策 | 用户评价 |
| **C5 会员权益** | A4-A5 | 复购、留存 | 会员福利 |
| **C6 服务内容** | A4-A5 | 体验、口碑 | 服务展示 |

### 4.2 内容力与算法关系

- **人设型视频**：一般只引发点赞，流量趋势走弱
- **强品卖货视频**：容易引发收藏/分享，有流量红利
- **揭秘行业黑幕**：提升信任，引发主页访问，流量表现更好

## 五、行业周期底层规则

### 5.1 周期规则（必须死记硬背）

| 行业 | A1-A3有效期 | L2新客支付周期 | L4沉默核销周期 |
|------|-------------|----------------|----------------|
| **餐饮/综合** | 15天 | 30天 | 90天 |
| **酒旅** | 60天 | 90天 | 365天 |

### 5.2 周期死线逻辑

| 周期 | 含义 | 后果 |
|------|------|------|
| 30天未核销 | 从L2新客 → 流失 | 流失召回成本3-5倍 |
| 90天未核销 | 从L3复购 → L4沉默 | 需要超大场激活 |

### 5.3 酒旅行业特殊规则

- 所有渠道人群等级**比餐饮降一级**
- 但A1/A2/A3有效期**长达60天**（比餐饮的15天更长）

## 六、三池融合逻辑

### 6.1 M1/M2/M3定义

| 池子 | 名称 | 特点 |
|------|------|------|
| **M1** | 非交易泛流 | 曝光大，但不直接产生交易 |
| **M3** | 付费流 | 精准投放，消耗自有5A资产 |
| **M2** | 自然交易流 | 高GPM触发，免费流量奖励 |

### 6.2 三池融合公式

```
ECPM（广告竞价）→ 决定能否抢占M3精准流量位
GPM（成交密度） → 决定能否获得M2自然流奖励
```

### 6.3 流转逻辑

```
M1泛内容获取A1/A2
  ↓ 开启M3付费提纯
M3消耗自有资产召回并转化为A3
  ↓
高GPM → 触发M2自然流奖励
  ↓
三池融合 → 螺旋上升
```

### 6.4 三池融合算法（2026年核心变动）

**字节跳动完成 M1/M2/M3 三池合并赛马**

| 维度 | 说明 |
|------|------|
| **核心变化** | 自然流和投流数据不再分开计算，改为**合并计算综合得分** |
| **正向效果** | 投流（M3）人群精准 → 点击率/GPM拉高 → 系统判定内容优质 → **奖励更多自然流** |
| **负向风险** | 投流人群不准，数据太差 → **直接拖垮自然流** → 陷入全靠商流的恶性循环 |
| **实操结论** | 投流必须精准，否则不如不投 |

### 6.5 推荐流与商城流的保鲜期差异

| 场景 | 保鲜期 | 说明 |
|------|--------|------|
| **推荐流（被动流量）** | **7天** | 2026年新规，A3蜜月期缩短至7天；7天内无二次互动，刷到品牌概率骤降 |
| **商城流量（主动流量）** | **15天** | 保鲜期相对更长；因商城不占用平台流量成本，平台愿意给更多展示空间 |

### 6.6 抖神神（小程序）与抖音双向互通红利

**2026年最大信息差红利**

| 维度 | 说明 |
|------|------|
| **资产同步** | 抖音端打下的人群资产实时同步到抖神神；抖神神购买行为实时回传抖音，影响排序 |
| **排序逻辑** | **人群资产 > 交易力 > 距离** |
| **核心优势** | 只要是某用户的A4/A5，哪怕销量低、距离远，也会排在肯德基等大牌前面 |
| **实操价值** | 跨平台运营可借助抖神神实现"降维打击"大品牌 |

### 6.7 广告加载率与真实流量占比

**残酷真相：抖音全平台广告加载率严格控制在8%-12%**

| 维度 | 数据 |
|------|------|
| **流量分配** | 常规消费者100条推荐视频中，团购内容约10条 |
| **投流占比** | 10条团购中约9条是本地推广告（M3），仅**2条左右**是自然流 |
| **不投流商家** | 获得曝光概率**不到2%** |
| **结论** | 不投流几乎无法获得自然流量，必须重视投流精准度 |

## 十一、5A人群资产模型深度解析（2026-03-29新增）

### 11.1 5A模型五种形态与形象化比喻

| 人群层级 | 核心行为描述 | 形象化比喻 | 战略意义 |
|----------|--------------|------------|----------|
| **A1 了解 (Aware)** | 被动看到视频、直播或广告，但停留极短 | 街上擦肩而过的人 | 泛流量，仅作为资产储备 |
| **A2 吸引 (Appeal)** | 产生初步兴趣，有点击详情页、停留或点赞 | 停下脚步看你一眼的人 | 初步兴趣，需通过内容加深种草 |
| **A3 种草 (Ask)** | 深度互动，如搜索品牌、加入粉丝团、点击购物车 | 进店询问价格的人（准客户） | **高意向人群，价格杠杆的重点对象** |
| **A4 成交 (Act)** | 完成购买支付、核销等核心转化行为 | 已经付钱买单的人 | 短期收益，商业变现 |
| **A5 复购 (Advocate)** | 产生多次购买、主动分享、评价或推荐给他人 | 逢人就夸你的回头客 | **长效经营，品牌忠诚度** |

### 11.2 转化倍数真相：高层级人群的降维打击价值

**实战数据统计结论**：
- **A2的转化率是A1的2-5倍**：兴趣是转化的第一驱动力
- **A3的转化率是A2的4-8倍**：深度种草人群已经到了成交的临界点
- **A3的转化率是A1的8-40倍**：这不仅是数据的提升，更是降本增效的关键

**深度洞察**：营销的本质是寻找"高位人群"。如果你只盯着A1做拉新，你的获客成本将高得离谱。成熟的操盘手会优先运营高位人群（如A3），因为从这里入手不仅成交率最高，也是实现商业盈利的最短路径。

### 11.3 A3：营销的"门槛"而非"王炸"

**2026年算法语境变化**：
- **A3只是入场券**：如果A3的权重被设得过高，商家只要疯狂堆A3就能轻松收割，那谁还去买流量？字节的广告收入就会受损
- **算法逻辑演变**：平台逻辑正在从"重A3"向"重A4/A5"的战略倾斜

**"割不动"A3的两大死穴**：
1. **人群水份大**：可能是用本地推等泛流量洗出来的"假A3"，他们有互动但没认知，甚至是为了低价券而来的
2. **产品基本功差**：产品缺乏"质价比"，价格体系刚性。特别是加盟品牌，价格如果定得比同行贵（比如人家卖79你卖130），人群再准也收割不了

**A3筛选逻辑**：
- **种草搜**：看了内容后14天内搜索，说明你种草成功了
- **自然搜**：14天没看你内容却直接搜，这才是真正的品牌资产
- **关键指标**：自然搜占比越高，品牌力越强

### 11.4 A4与A5：品牌长效经营的"护城河"

**2026年后算法逻辑**：更像是一种"全域太极般的平衡"，算法正在向A4A5（成交与复购）权重倾斜，鼓励商家从"拉新爆发"转为"长效经营"

| 维度 | 单纯追求A3（拉新思维） | 深耕A4A5（人群资产思维） |
|------|----------------------|--------------------------|
| **获客成本** | 需不断投入广告拉新，成本随竞争水涨船高 | 依靠复购与口碑，单客获客成本摊薄 |
| **ROI表现** | 波动巨大，依赖单场直播或爆款视频 | 稳定且高，有持续的商城流量支撑 |
| **经营稳定性** | 易被同行截流（同质化竞争） | 品牌忠诚度高，形成竞争护城河 |

**核心逻辑**：不要把直播当成收割的终点站，它是中间的"中"。直播完以后，一定要记得用商城流量和人群优惠券去"打扫战场"，把A4/A5沉淀下来。

### 11.5 人群资产的"漏斗"：流失与补充的动态平衡

**人群资产的生命周期特性**：
1. **流失逻辑**：资产受时间窗口（15天/30天）影响。如果用户在周期内没有深层行为或购买，等级会倒退（例如从A3退回A2，甚至消失）
2. **补充逻辑**：每一条新增的播放量和互动，都在为池子"补水"

**避坑指南**："5000曝光并不意味着触达了5000人！" 尤其在本地推中，算法会反复触达你的核心粉丝和高潜人群。如果不加节制地推，就会导致人群消耗殆尽，这就是为什么很多账号投着投着ROI就崩了。

### 11.6 实战路径：不同阶段品牌的资产健康模型

**黄金比例模型**：

**1. 白牌/新店（从无到有）**：
- **种草期（前半年）**：目标比例 7:3（种草成交70%，自然成交30%），重点是破圈洗人
- **发展期**：过渡到 5:5
- **成熟期**：最终目标 3:7

**2. 头部品牌（品牌力驱动）**：
- **起步期**：优先召回老客，比例可达 9:1
- **天花板**：最终回归到 3:7（30%靠种草拉新，70%靠自然流量/商城收割）

**核心金句**：自然成交（搜索/商城）占比越高，品牌力越强，你的生意才越安全。

### 11.7 诊断与排雷：警惕"虚假的人群资产繁荣"

**核心真相**："商城和搜索流量从不骗人。" 如果你的推荐流数据很漂亮，但商城和搜索流量起不来，那说明你的资产是"虚胖"

**诊断公式**：访问人数增长 + 转化率稳定 = 人群精准

| 指标表现 | 潜在问题诊断 | 建议方案 |
|----------|--------------|----------|
| **推荐流虚假繁荣，商城/搜索起不来** | 人群消耗殆尽，或者充斥着"假A3、死A5" | 停止低效投流，启动"白锚点"（洗同城泛流）重新扩充池子 |
| **点击率高，但转化率极低** | 价格体系有硬伤，或产品质价比不足 | 调整产品货盘，利用"绿色锚点"（深度内容）重新种草 |
| **搜索量长周期持续下滑** | 品牌力下降，老顾客流失 | 重新打造老板IP或品牌内容，提升溢价 |
| **门店访问涨，转化率稳中有升** | 人群极度精准，处于爆发前夜 | 加大投入，准备收割，开启直播权益循环 |

**名词解释**：
- **白锚点 (White Anchor)**：用于大规模"洗人"，通过泛同城流量视频触达新人群，扩大A1A2
- **绿锚点 (Green Anchor)**：用于深度"种草"，通过信任感极强的素材（如探店、测评）建立深度A3

**结语**：5A模型的核心不是枯燥的数据，而是对"人"的精细化理解。真正的操盘手，要学会从流量思维转变为资产思维，通过"太极般"的全域平衡，在抖音长跑中生存下去。
