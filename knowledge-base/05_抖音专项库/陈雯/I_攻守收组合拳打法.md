## 一、2026年算法权重核心变化

### 1.1 短期价值 vs 长期价值

| 价值类型 | 指标 | 2026权重 | 备注 |
|----------|------|----------|------|
| **短期价值（已降权）** | 点赞、完播 | 降低 | 只代表当下传播热度，无法代表真正兴趣 |
| **长期价值（高权重）** | 收藏、分享、平均播放时长、主页回访、搜推互动 | **最高** | 决定更长时间维度的推流 |

**实操意义**：
- 不要为点赞数低而焦虑
- 如果视频**分享和收藏比例极高**，系统判定具有长期价值，会在更长的时间维度内给流

### 1.2 2026运营核心公式

```
GPM（效率） = 钱袋子
核销率（信用） = 通行证
券包叠加（财务风险） = 生死线
15/90天周期 = 直播节奏依据
```

## 二、白色锚点的双重用法

| 投放工具 | 目标池 | 触达人群 | 核心目的 |
|----------|--------|----------|----------|
| **抖加（DOU+）** | M1（非交易池） | 全城70%泛流量 | **扩容**——把M1洗成A3 |
| **本地推（门店浏览）** | M2/M3（交易池） | 同行A3精准人群 | **提纯**——截流同行资产 |

### 老板号/蓝V特殊规则

| 账号类型 | 播放一次算 | 说明 |
|----------|-----------|------|
| **老板号/蓝V号** | **直接算A3** | 有效播放（2-3秒）即记录 |
| **素人号（树人号）** | 只算A1曝光 | 需要7次才能转A3 |

> **核心洞察**：同样投抖加，老板号洗出A3的效率是素人号的**数倍**。

## 三、「攻守收」组合拳详解

### 3.1 攻——拉新破圈（抖加扩容）

| 项目 | 内容 |
|------|------|
| **工具组合** | 老板号 + 白色锚点 + 泛生活选题 + 抖加 |
| **目标池** | M1（非交易池，占全站70%流量） |
| **核心动作** | 用泛生活内容（穿搭攻略/避坑指南）吸引M1泛人群 |
| **资产沉淀** | 把全城70%的M1泛人群洗成你的A3资产 |
| **竞争优势** | 避开存量内卷，从增量池里找客户 |

**选题策略**：
- 不讲产品价格，讲目标人群爱看的内容
- 示例：「99%的杭州男生穿错的约会装」「800元搞定杭州一日约会攻略」
- 核心：让目标人群先对你产生兴趣，再导入交易

### 3.2 守——截流提纯（本地推提纯+小蓝词截流）

> **核心洞察**：抖音上的竞争对手不是同行业，而是**同人群**。谁抢到了同一批人的注意力，谁就是真正的竞争对手。

#### 方式1：本地推截流（传统方式）

| 项目 | 内容 |
|------|------|
| **工具组合** | 蓝V/官方号 + 白色锚点 + 门店浏览（本地推） |
| **目标池** | M2/M3（交易池） |
| **核心动作** | 选择"门店浏览"作为目标，精准触达同行客户 |
| **资产沉淀** | 把正在刷同行的优质客户"召回"到你的门店页面 |
| **竞争优势** | 去同行鱼塘里精准抢人 |

#### 方式2：小蓝词截流（2026-03-29新增）

引用：Q_小蓝词截流打法与实战应用

**核心原理：**
- 小蓝词是在竞品视频评论区或搜索框中出现的蓝色超链接搜索词
- 点击后直接跳转到你的品牌搜索结果页
- 截流的是对品类有明确兴趣的精准人群

**小蓝词两种形式：**
| 形式 | 出现位置 | 稳定性 | 号主能否删除 |
|------|---------|--------|-------------|
| **吸顶词（搜索框词）** | 视频顶部搜索建议 | ⭐⭐⭐⭐⭐ 极稳定 | ❌ 无法删除（算法生成） |
| **评论区小蓝词** | 评论列表中关键词 | ⭐⭐⭐ 较稳定 | ✅ 可删除评论 |

**五步操作法：**
1. **监控竞品**：寻找摇篮期视频（播放量1万以内，点赞量不过百）
2. **鱼塘号搜索**：使用10-20个鱼塘号在竞品视频搜索框内多次搜索你的品牌名
3. **评论区留痕**：发布引导性留言（如"某某地方更好玩"）
4. **触发算法**：多个账号的集中搜索行为向算法反馈关联性
5. **承接流量**：确保你的品牌搜索结果页内容完整（商城链接、门店POI、短视频内容）

**关键时间窗口：**
| 时间阶段 | 操作难度 | 截流效果 |
|---------|---------|---------|
| **摇篮期（0-1万播放）** | ⭐ 容易 | ⭐⭐⭐⭐⭐ 最佳 |
| **成长期（1-10万播放）** | ⭐⭐ 中等 | ⭐⭐⭐⭐ 效果好 |
| **爆发期（10万+播放）** | ⭐⭐⭐ 困难 | ⭐⭐ 效果下降 |
| **成熟期（50万+播放）** | ⭐⭐⭐⭐ 极难 | ⭐ 基本无效 |

> **最佳执行时机：必须要在竞品视频爆火之前操作！**

**风险防范：**
| 风险类型 | 防范措施 |
|---------|---------|
| **竞品反击** | 操作吸顶词（无法删除）+ 分散鱼塘号 |
| **账号风险** | 控制操作频率，避免同一IP集中操作 |
| **效果波动** | 持续监控，及时补充操作 |
| **关系破裂** | 小规模、高频次操作，不过分激进 |

### 3.3 收——成交转化（全域收割）

| 项目 | 内容 |
|------|------|
| **工具组合** | 任意账号 + 绿色锚点（团购） + 全域投放（M3） |
| **触发条件** | 前两步积累了足够A3资产后 |
| **核心逻辑** | 全域投放会优先消耗自有5A资产 |
| **转化优势** | 系统优先推给看过你内容的A3人群，ROI极高 |

**全域投放的优先规则**：
1. 优先消耗自有5A资产（抖加+本地推攒下的）
2. 其次才是公域流量
3. 你的A3储备越多，转化成本越低

## 七、核心公式总结

### 三维价值公式

```
抖加 = 扩容（把M1泛流洗成A3）
本地推 = 提纯（把同行A3截流）
老板号 = 提权（1次播放=1次A3，效率7倍）
```

### 组合拳公式

```
天花板打法 = 老板号（攻）+ 蓝V号（守）+ 全域收割（收）

攻：抖加扩容 → M1泛流 → A3资产
守：本地推提纯 → 同行截流 → A3资产
收：全域收割 → A3优先 → 高ROI转化
```

> **一句话总结**：抖加用来"扩容"，本地推用来"提纯"，老板号用来"提权"，三者结合才是真正的天花板打法。
