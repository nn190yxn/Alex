## 一、三种账号类型的权重差异（2026年核心规则）

### 1.1 三种账号类型定义

| 账号类型 | 定义 | A3获取方式 | 获取效率 |
|---------|------|-----------|---------|
| **商家账号** | 蓝V/老板号/门店号 | 播放≥1次 = 直接A3 | ⭐⭐⭐⭐⭐ 最高特权 |
| **达人账号** | 合作达人/职人号 | 15天内累计播放≥7次 = A3 | ⭐⭐⭐ 中等（效率1/7） |
| **素人账号** | 普通用户/UGC | 播放仅算A1，不直接产生A3 | ⭐ 最低 |

### 1.2 核心结论（必须死记）

> **商家账号播放≥1次 = 直接A3（特权）**
> **达人号需15天内累计7次 = A3（效率1/7）**
> **素人号播放仅算A1，不直接产生A3**

### 1.3 权重差异化底层逻辑

```
商家账号 → 系统认定为"品牌官方" → 播放即信任 → 直接A3
达人账号 → 系统认定为"内容创作者" → 需积累信任 → 7次才A3
素人账号 → 系统认定为"普通用户" → 播放=被动接收 → 仅A1
```

### 1.4 老板号/职人号核心红利（2026年最大红利！）

> 引用来源：2026年课程亮点总结（2026-03-28新增）

| 维度 | 商家账号（老板号/职人号/蓝V） | 达人账号 |
|------|------------------------------|---------|
| **A3判定** | 播放≥1次 = 直接A3 | 15天内累计7次 = A3 |
| **流量性质** | 自然流好（素人级流量） | 依赖推荐算法 |
| **A3获取效率** | **达人的7倍** | 效率1/7 |
| **内容运营难度** | 低（不用追求爆款） | 高（依赖内容质量） |

**核心红利总结**：
- 老板号/职人号 = 拥有蓝V的A3特权 + 享有素人的自然流红利
- 是2026年最适合实体商家积累人群资产的账号类型
- 每天发布3-5条视频 → 每条视频播放用户直接变A3 → 稳定持续

## 二、商家账号获取A1/A2/A3完整动作

### 2.1 商家账号天然优势

商家账号（蓝V/老板号/门店号）在2026年享有**特权**：
- 发布视频被用户播放 → 直接计入A3
- 不需要完播、不需要互动次数
- 门槛极低，是最快速的A3积累方式

### 2.2 商家账号A1动作（基础曝光）

| 动作 | 说明 | 触发条件 |
|------|------|---------|
| 发布短视频 | 视频被曝光 | 系统随机推送/同城 |
| POI挂载 | 门店地址曝光 | 挂载门店链接 |
| 团购商品曝光 | 商品被看到 | 商品卡展示 |

### 2.3 商家账号A2动作（浅层兴趣）

| 动作 | 说明 | 触发条件 |
|------|------|---------|
| 视频停留3秒+ | 浅层停留 | 内容引发好奇 |
| 点击评论区 | 查看其他用户评论 | 评论区有趣 |
| 点击主页 | 进入账号主页 | 头像/昵称吸引 |
| 点击门店地址 | 查看门店详情 | POI信息完整 |

### 2.4 商家账号A3动作（强意图/种草）

| 动作 | 说明 | 触发条件 |
|------|------|---------|
| **播放≥1秒** | ⭐商家特权，直接A3 | 发布视频即有机会 |
| 搜索品牌词 | 主动搜索品牌 | 品牌有知名度 |
| 收藏团购商品 | 加入待购清单 | 商品有吸引力 |
| 点击购物车 | 查看商品详情 | 产生购买意图 |
| 预约直播间 | 订阅直播间 | 直播预热内容 |

### 2.5 商家账号运营核心策略

```
商家账号 = 低成本洗A3的利器
每天发布3-5条视频 → 每条视频的播放用户直接变A3
不用追求爆款 → 追求稳定持续的曝光量
```

## 四、素人账号获取A1/A2/A3完整动作

### 4.1 素人账号的限制

素人账号（普通用户/UGC）的权重最低：
- 播放仅算A1，不直接产生A3
- 需要极高的互动质量才能触发A3

### 4.2 素人账号A1动作（被动接收）

| 动作 | 说明 |
|------|------|
| 视频曝光 | 系统随机推送 |
| 直播曝光 | 推荐流看到 |
| 朋友分享 | 社交渠道看到 |

### 4.3 素人账号A2动作（浅层兴趣）

| 动作 | 说明 | 触发条件 |
|------|------|---------|
| 完播30秒+ | 完整看完短内容 | 内容足够吸引 |
| 点赞 | 简单正面反馈 | 情绪触动 |
| 评论 | 留下观点 | 话题引发表达 |
| 关注 | 成为粉丝 | 内容有价值 |

### 4.4 素人账号A3动作（门槛最高）

| 动作 | 说明 | 难度 |
|------|------|------|
| 搜索品牌词 | 主动搜索 | ⭐⭐⭐ 较难 |

### 4.5 素人账号运营核心策略

```
素人账号 ≠ 正规A3积累路径
素人UGC = 口碑传播 ≠ 品牌主动A3积累
做品牌A3 → 必须用商家账号或达人账号
```

### 4.6 素人号三大实战策略（2026-03-29补充）

#### 策略1：激励机制设计（UGC激励）

| 激励方式 | 适用场景 | 成本 | 效果 |
|---------|---------|------|------|
| **到店打卡送券** | 线下门店 | 低 | ⭐⭐⭐⭐ |
| **发布视频享折扣** | 新客引流 | 中 | ⭐⭐⭐⭐⭐ |
| **优质UGC返现金** | 爆款产品 | 高 | ⭐⭐⭐ |
| **UGC排行榜** | 长期运营 | 低 | ⭐⭐⭐ |

**案例：美发门店UGC激励**
- 到店消费后发布打卡视频 → 送50元代金券
- 发布视频带POI定位 + 品牌话题
- 粉丝数>500的优质UGC → 100元现金奖励
- 结果：月均UGC数量增长300%，核销率提升15%

#### 策略2：话题引导与模板（内容引导）

| 引导方式 | 适用场景 | 操作难度 |
|---------|---------|---------|
| **提供拍摄脚本** | 新手用户 | 低 |
| **提供BGM库** | 喜欢音乐的用户 | 低 |
| **提供POI模板** | 需要曝光的用户 | 中 |
| **提供话题标签** | 所有用户 | 低 |

**案例：餐饮门店UGC引导**
- 提供三套拍摄脚本：环境展示、菜品特写、服务员互动
- 统一话题标签：#XX美食探店 #XX好吃到爆
- 结果：UGC内容质量提升，品牌话题浏览量增长50%

#### 策略3：素人号筛选与放大（挖掘优质UGC）

| 筛选标准 | 说明 | 放大方式 |
|---------|------|---------|
| **粉丝数500+** | 有一定影响力 | 转发到品牌官方账号 |
| **视频完播率>50%** | 内容质量高 | 给予更高激励 |
| **品牌调性一致** | 符合品牌形象 | 邀约合作（升级为达人） |

**案例：素人号升级达人号**
- 筛选出粉丝数800、内容质量高的素人UGC创作者
- 邀约成为品牌合作达人
- 结果：从素人号 → 达人号 → A3效率提升7倍

### 4.7 素人号到达人号的升级路径（2026-03-29补充）

```
素人号（普通UGC）
    ↓ 筛选标准：粉丝数500+ + 内容质量高
潜力素人号（重点培养）
    ↓ 邀约合作：提供产品体验 + 创作支持
合作素人号（轻达人）
    ↓ 长期合作 + 成交转化激励
达人号（品牌核心达人）
```

**实战要点：**
- 素人号 → 达人号 = A3效率提升7倍
- 品牌需要建立"素人号达人池"持续挖掘
- 提供创作支持和产品体验，让素人号愿意长期合作

## 五、三种账号类型的实战组合策略

### 5.1 最优组合：商家账号做基础 + 达人账号做精准

```
商家账号（蓝V）
├── 每天3-5条视频
├── 稳定曝光 → 快速A3
└── 成本低，覆盖广

达人账号（职人/合作达人）
├── 每天1-2条高质量内容
├── 精准人群画像
└── 15天积累精准A3

素人账号（UGC）
├── 不作为A3积累主力
└── 作为口碑传播辅助
```

### 5.2 不同阶段的账号组合策略

| 阶段 | 商家账号 | 达人账号 | 素人账号 |
|------|---------|---------|---------|
| 冷启动（0-15天） | 主力，每天3-5条 | 辅助，选1-2个达人 | 不重点 |
| 成长期（15-30天） | 维持2-3条 | 主力，扩大达人合作 | 引导UGC |
| 稳定期（30天+） | 每周3-5条 | 持续合作 | 激励UGC |

### 5.3 三种账号的人群资产继承

| 场景 | 人群资产归属 | 说明 |
|------|------------|------|
| 商家账号产生的A3 | 品牌账户共享 | ⭐最强，所有门店受益 |
| 达人账号产生的A3 | 品牌账户共享 | 达人合作期有效 |
| 素人UGC产生的A1 | 难以利用 | 仅作口碑参考 |

### 5.4 核心结论

```
商家账号 = 品牌A3的主力生产者 = 必须坚持做
达人账号 = 精准A3的补充渠道 = 选对达人很关键
素人账号 = 口碑参考 = 不强求A3贡献
```
