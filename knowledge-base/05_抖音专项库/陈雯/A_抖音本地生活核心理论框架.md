## 2026-03-28下午新增核心知识点

### 价格体系与私域运营
- 价格体系设置：POI常态价、小促价、大促价、会员价需统一规划
- 私域群设置：1号群（通用大群）、2号群（会员老客群）、3号群（高价值老客群）
- 直播价格原则：应在会员价和大促价之间
- 连锁商家：按大区拉齐主推品链接，全国通用引流品，总部补贴策略

### IP打造（2026-03-28新增，2026-03-29更新）
- 无论客单高低，都应打造IP
- IP可视为廉价版的品牌，能为产品提供溢价
- 同城IP打造相对简单，主要考核选题和编导能力

**量化目标（100万人口城市）**：
- 泛人群包（A1-A2）：10-15万
- 精准A3人群：2万（此为进入同城行业头部的硬指标）
- 建立这一规模的人群资产，不仅是为了即时转化，更是为了降低后续直播的获客成本

### 转化率核心数据（2026-03-28更新）
- A2转化率 ≈ A1的2-5倍
- A3转化率 ≈ A2的4-8倍
- **A3转化率 ≈ A1的8-40倍**（从高位入手能获得更高成交率）
- A3是营销的最低门槛，但并非最关键因素；A4、A5更为重要

### A3割不动三大原因（2026-03-28新增）
- 人群质量低：低价团单吸引的人不会买正价品
- 品有问题：缺乏质价比
- 转化链路断：无有效承接

### 人群资产流失规律（2026-03-29新增）
- 人群资产具有极强的时效性
- 若无持续动作，**半个月前的200万泛人群包，在15-30天后可能仅剩20万活跃资产**
- 直播的意义在于不断通过新增流量补足损耗，维持资产水位

### A1-A3人群转化倍数关系（2026-03-29补充）
- **A1人群（泛了解/路过）**：基准值，转化难度极大，浪费成本
- **A2人群（产生兴趣）**：A2转化率 ≈ A1的2-5倍，兴趣不等同于购买欲
- **A3人群（种草/高潜）**：A3转化率 ≈ A2的4-8倍，**A3是A1的8-40倍**
- **高危等级倒退（Regression）**：人群资产具有时效性，如果一个A3用户在15-30天内没有产生深度交互或购买行为，他会"退化"回A1甚至消失
- **"每日新增流量"是对抗资产倒退的唯一解药**

### KFC品牌逻辑（2026-03-29新增）
- 除非品牌像"肯德基"一样具备全民认知的强大品牌力，否则直接从A1泛流量开始营销无异于自杀
- 对于大多数中小品牌，直接"洗"出A3高潜人群是生存唯一路径

### 2026-03-29新增核心理论（来自3场培训）

#### 1. 竞争对手5A数值计算模型
- **计算方法**：以总5A为1700万，比自选三家竞争对手均值增长1.76倍为例，通过公式算出竞争对手均值约615万
- **公式推导**：设竞争对手均值为x，总5A = (1 + 增长率) × 竞争对手均值 × 竞争对手数量
- **应用价值**：通过计算能了解竞争对手的大致水平，为自身业务定位和策略制定提供参考
- **选择建议**：选择三四家竞争对手进行分析，避免因选择过多导致数据平均后失去参考价值

#### 2. 人群精准度诊断框架
- **精准度判断**：某户总人群资产是同行两三倍，但A3和同行相近，说明同行人群模型更精准
- **转化率问题**：总人均资产是同行2-3倍，但支付新客、核销新客、复购和忠诚客户数量均少于同行，整体成交转化率远低于同行
- **品的问题**：商品价格比同行高，如同行卖79，该户卖130，且因招商加盟模式导致价格调整困难

#### 3. 人群优惠券本质理论
- **让强者更强**：运营程度好时，人群优惠券能发挥强大作用；运营差时，券可能发不出去
- **券推一体**：未来POI端看到的是虚价，券推一体（人群优惠券加本地推）看到的才是真实价格
- **人群分层运营**：
  - 人群资产未过100万时，可采用只圈不推的方式，用门店全域替代本地推
  - 人群资产较多时，可尝试将自己的人群包与行业大包混合投放

#### 4. 核销率深度理论
- **低核销率原因**：
  1. 直播间场景易导致消费者冲动消费，第二天清醒后可能退款
  2. 直播后人群资产暴涨，易触达同行，若同行采取截流措施，会影响核销率
- **提升核销率方法**：
  1. **根本方法**：提升商城流量和搜索流的精准人群
  2. **治标方法**：大厂流量停播、发促核销短视频、开核销有礼功能
  3. **价格优惠**：价格优惠也能提高核销率

#### 5. 流量与成交占比健康模型理论
- **推荐流**：流量占比合理范围为70%-90%，成交占比不超过60%
- **商城和搜索**：流量占比控制在10%-20%，成交占比应努力达到60%
- **优秀模型**：推荐流成交40%，商城和搜索成交60%

#### 6. 搜索成交分析理论
- **搜索类型分类**：
  - 种草搜：用户在搜索前14天内看过视频直播、详情页或商品页后进行搜索
  - 自然搜：用户14天内未看任何相关内容直接搜索
- **搜索下滑诊断**：
  - 自然搜长周期下滑指向品牌力问题
  - 自然搜短周期下滑可能是老顾客吃腻
  - 种草搜不增长说明投流、品宣、老板IP或种草达人投放效果不佳

#### 7. 门店页数据分析理论
- **关键指标**：门店页访问人数和成交转化率
- **判断逻辑**：
  - 访问人数增长且转化率稳定或微降，说明人群精准
  - 访问人数高但转化率低，说明人群泛
  - 转化率高且访问人数增长，可考虑收割
- **流量来源模型**：
  - **最优方案**：推荐排第一，搜索排第二，团购第三，其他第四（微付费天花板）
  - **重付费打法**：其他排第一或第二，推荐排第二，搜索排第三

#### 8. 不同品牌发展阶段理论
- **白牌新店（0-6个月）**：种草收70%、自然收30%
- **发展阶段（6-12个月）**：从7:3过渡到5:5
- **成熟期（1年以上）**：自然收占比应越来越高
- **头部品牌**：
  - 起步阶段：先将老顾客召回至抖音，实现9:1比例，优先照顾老顾客
  - 发展阶段：逐步调整为8:2比例
  - 天花板阶段：目前头部品牌能达到的最高比例为3:7

### 主品选择原则（2026-03-28新增）
- 考虑地理位置、库存、人群画像
- 避免盲目跟风，根据自身实际情况和目标人群需求选择
- 人群思维优先于品类思维

### 营销打法（2026-03-28新增）
- **江湖打法**：价格永远比同行低10元 + 拉基建 + 做链接权重 + 开商城工具
- **入门打法**：达人截流 + 动态调价 + 监控人群资产增速

## 八、"人与马"框架（2026年新增核心框架）

> 引用来源：Q_召回与排序（2026-03-28补充资料）

### 框架定义

抖音本地生活推流遵循**"一加四"框架**：

- **"一" = 人与马**
  - 人：5A人群资产（决定召回方向）
  - 马：赛马机制（决定排序优先级）
- **"四" = 四大算法**
  - 短视频推流
  - 直播推流
  - 搜索推流
  - 商品排序

### 召回（Recall）— 对应"人"

- 本质：**"概率预估"**过程
- 海选：系统从千万级内容库筛选出用户可能感兴趣的内容
- 5A标签决定机会：用户与品牌"交情"越深（A等级越高），被召回概率指数级提升
- **核心逻辑**："触达过才更易触达"
- **召回优先级**：A1 < A2 < A3 < A4 < A5（A4/A5是系统推荐频率的天花板）

### 排序（Ranking）— 对应"马"

- 俗称"赛马机制"
- 分层赛马：铁粉 → 活粉 → 自有5A → 同行5A → 同城泛人群 → 全国泛人群
- 行为决定分值：
  - 2026年权重↑：收藏、分享、主页回访、搜推互动
  - 2026年权重↓：点赞、完播
- 指标决定晋级（见H_流量融合漏斗）
- **赢者通吃**：第一层赛马胜出 → 进入下一层级更大规模排序比拼

### "人与马"协同作战

- 召回决定**"有没有机会"**出现在用户面前
- 排序决定**"能跑多远"**
- 5A打法的本质：不断打磨内容赢得赛马得分 + 不断积累人群资产确保高频召回

## 一、人群资产理论

### 1.1 核心定义

**人群资产 = 品牌在抖音积累的A1-A5人群的总称**

- 是抖音本地生活运营的**核心资产**
- 决定品牌能否获得算法推流
- 是2026年竞争的核心壁垒

### 1.2 资产规模公式

```
成功运营 = 90天周期倒推计划
         + 泛内容选题（洗A3）
         + 直播大场（阶梯召回）
         + 定向人群券（精准保底30/90天核销）
```

### 1.3 资产质量判断

**高GPM = 高人群资产质量**

| 人群偏好 | 质量判断 |
|----------|----------|
| 文旅、宠物、个人护理 | 高净值资产 |
| 美食（恩格尔系数原理） | 消费力较弱 |

### 1.4 A3转化率核心数据（2026-03-28新增）

| 人群层级 | 转化率对比 | 结论 |
|----------|-----------|------|
| A1 → 成交 | 基准（1x） | 除非品牌力极强（如肯德基），否则A1直接营销转化率极低 |
| A2 → 成交 | A1的2-5倍 | A2是有一定认知基础的人群 |
| A3 → A2 | A2的4-8倍 | A3是营销最低门槛 |
| **A3 → 成交** | **A1的8-40倍** | A3是核心收割起点 |

**核心结论**：应将A3进行筛选和精准化处理后再使用，而非盲目使用低价引流冲量的A3。

### 1.5 人群资产变化规律（2026-03-28新增）

**资产流失原理**：
- 人群资产受营销活动和时间影响
- 半个月前200万泛流量，半个月后可能只剩20万
- 每天新增播放量可补充部分资产

**播放量≠人数**：
- 一个人可能在同一天多次刷到商品卡、短视频、直播间
- 本地推可能对核心铁粉和高潜人群进行多次曝光
- 5000曝光 ≠ 5000人次

### 1.6 A3高危等级倒退机制（2026-03-28新增）

**触发条件**：
- 起始点处于A3
- 在15天/30天时间窗口内无更深行为
- 未完成购买

**后果**：
- 用户对品牌失去兴趣
- 人群资产高危等级倒退至A1
- 之前的A3积累白费

**预防措施**：
- 保持对A3人群的持续触达
- 设置定向召回机制
- 15天内必须完成转化收割

## 三、GPM（成交密度）理论

### 3.1 公式

```
GPM = 人群精准度（5A运营）× 成交规模（正价体系）
```

### 3.2 GPM与流量关系

| GPM水平 | 系统推流态度 | 后果 |
|---------|-------------|------|
| **高GPM** | 主动奖励自然流（M2） | 流量螺旋上升 |
| **低GPM（如9.9元打法）** | 判定为"模型做歪" | 自然流枯竭 |

### 3.3 九块九打法的毁灭性真相

| 维度 | 九块九低价打法 | 正价体系打法 |
|------|---------------|--------------|
| GPM | 极低 | 极高 |
| 人群资产质量 | 羊毛党，模型跑歪 | 高净值，模型精准 |
| 流量利用率 | 浪费系统分发 | 极高，易触发流量奖励 |
| 最终结果 | 算法限流 | 流量螺旋上升 |

**结论**：低价打法在2026年已死，正价体系是高GPM的唯一出路。

## 四、权重差异化理论

### 4.1 账号类型效率差异

| 账号类型 | A3获取效率 | 原因 |
|----------|-----------|------|
| **商家账号**（蓝V/老板号/职人号） | 播放≥1次=直接A3 | 官方特权 |

| **素人号** | 播放仅算A1 | 最低权重 |

### 4.2 2026年行为权重位移

| 权重变化 | 行为类型 |
|----------|----------|
| **↑ 长期价值上升** | 收藏、分享、评论、主页回访、搜推互动 |
| **↓ 短期价值下降** | 点赞、完播 |

**运营重心转移**：从追求点赞/完播 → 转向引导用户分享、收藏

## 七、优惠券叠加理论（生死线）

### 7.1 核心规则

**抖音所有立减类优惠遵循"券择优，禁叠加"**

- 系统自动选择最高额度立减
- 多个立减叠加会导致品牌**巨额亏损**

### 7.2 风险案例

| 品牌 | 事故 | 损失 |
|------|------|------|
| NKA品牌 | 同时开启获客专享价+人群券 | **亏损300万** |

### 7.3 操作红线

⚠️ **严禁在获客专享价期间叠加任何人群券！**

### 7.4 券类叠斥关系对照表（2026-03-28新增）

|  | 平台优惠（平台券/平台礼金/BML/增量宝/超值券） | 商家券类（粉丝券/新客券/商品券/会员券等） | 商家减类/价类（超值团/获客卡专享/渠道价/新客价/秒杀等） |
| --- | :---: | :---: | :---: |
| **平台优惠** | ✖️ 互斥取优 | ✅ 可叠加 | ✅ 可叠加 |
| **商家券类** | ✅ 可叠加 | ✖️ 互斥取优 | ✅ 可叠加 |
| **商家减类/价类** | ✅ 可叠加 | ✅ 可叠加 | ✖️ 互斥取优 |

### 7.5 人群券特殊规则
- 商家券×商家券：不叠加，择金额大的使用
- 商家券×平台券：叠加，加和使用
- 混合出资场景：如商家出资5元、平台3元，人群券6元 → 用户最终享受9元（平台3元叠加人群券6元）

## 八、反向定价理论

### 8.1 传统做法（错误）

```
门市价 → 往下打折 → 直播价
```

### 8.2 2026年正确做法

```
定向券底价 → 反推直播价 → 反推常态POI价 → 门市原价
```

### 8.3 价格落差设计

| 价格类型 | 落差 | 作用 |
|----------|------|------|
| 直播价 | 基准 | 稀缺感 |
| 常态POI价 | 直播价+10元 | 保护稀缺感 |

### 8.5 价格体系重塑实战案例（2026-03-29新增）

#### 案例：洗浴中心价格体系重塑

**背景问题**：
- 开业期间使用**188元超低价**爆单，累积**1万+销量**
- 开业活动结束后面临"涨价难"困境
  - 直接继续卖188元 → 利润无法支撑
  - 直接涨价 → 消费者因开业价格印象觉得"贵了"，转化率崩盘

**核心策略：三重锚定链接玩法**

1. **三重锚定链接设计**：
   - **1号链接（增量主推品）**：158-168元（周一至周四18小时畅享+全天候自助）
   - **2号链接（次推双人品）**：298-318元（双人套餐+赠送采耳/泡脚等小项目）
   - **3号链接（炮灰锚定款）**：将原开业188元且销量1万+的链接，价格直接涨至**258元**作为"日常常态价"
   - **4号链接（引流品）**：9.9元（拉动直播间浅层数据，不与主推品重叠）

2. **三重锚定心理学原理**：
   - **一重锚定（对比1号与3号）**：消费者看到3号日常价258元时，会瞬间觉得158元的1号链接极其便宜，产生购买冲动
   - **二重锚定（对比3号、2号与开业价）**：通过涨价后的3号链接，强行拉回消费者对价格体系的认知，让他们觉得"188元确实是过去式了，258元才是常态"
   - **三重锚定（对比1号与2号）**：通过1号单人价与2号双人价的微差，促进双人套餐销售，提升客单价

3. **营销节奏配合15天周期**：
   - **种草期（第1-5天）**：挂载白色锚点，价格显示为**258元**最高位，建立价值感知并积累A3资产
   - **洗人群期（第6-11天）**：挂载绿色锚点，价格微降至**248元**，筛选精准人群
   - **收割期（第12天直播）**：放出**直播价238元**（针对3号链接）或**158元**（针对1号链接），召回所有积累的人群资产集中收割
   - **核销期（第13-15天）**：价格恢复，但针对未购买人群投放**满258减30元的人群优惠券**，进行长尾挽留

**核心亮点**：
- **链接资产化**：按此方案执行几个月，沉淀出3条过万销量的稳定链接，为后续进驻"热销榜"和"人气榜"打下基础
- **核销效率**：利用商城流量（M2）进行接力，商城核销率比内容流高出**20%-100%**
- **确定性管控**：直播话术严格遵循"逼单必讲因果"（如：因为是周年庆才给到直播低价），给消费者占便宜的台阶

**价格体系重塑三要素**：
1. **必须有高销量历史**：3号链接必须有1万+真实销量历史，才能作为强力心理锚点
2. **三重锚定配合**：通过1号、2号、3号链接的组合，实现对消费者心智的"三重洗脑"
3. **营销节奏配合**：配合15天周期挂钟，从种草到收割，形成完整的闭环

#### 14.2 多渠道阶梯价格体系设计蓝图

**四层价格体系架构**：
1. **日常价（挂牌价）**：品牌尊严的底线，所有折扣的锚点
2. **小促价（日常折扣）**：用于短视频引流，比日常价略低
3. **大促价（节日/活动）**：极少数节点使用，用于击穿价格敏感人群

```
市场价 + 竞对价 + 品牌溢价得分（IP/差异化）
```
