## 一、团购商城定位

团购商城（货架流）是**自然流量的核心来源**，2026年核心变化：收藏=直接A3。

---

## 二、货架排序核心逻辑

> 引用来源：商城流量与货架排序（2026-03-28新增详细资料）

### 2.1 商城流量特征

| 特征 | 数据 |
|------|------|
| 流量占比 | 约14% |
| GMV贡献 | 超过50% |
| 转化效率 | 极高（远高于推荐流） |
| 排序逻辑 | "先召回、后排序" + 人群资产标签（千人千面） |

### 2.2 召回阶段（海选门槛）

用户打开团购频道的**第一秒**完成初步筛选：

1. **地理范围**：优先周边3公里（最多6公里）
2. **5A人群标签**：用户身上的行业5A标签决定召回优先级
   - 新鲜A3（种草）人群 → 召回优先级极高

### 2.3 排序阶段（核心交易指标）

**排序优先级**：
```
高A人群/铁粉+本地推 > 近期动销 > 订单量 > 核销GMPM > 点击转化率
```

#### 凌驾性超级权重
- **高A人群/铁粉 + 本地推**：2026年商城流量的"通天绿卡"
  - 打了新鲜A3/A4标签或开启本地推全域投放 → 即便销量远低于头部品牌，也能排首页

#### 排序指标详情（从高到低）

| 优先级 | 指标 | 说明 |
|--------|------|------|
| ★★★ | GPM（千次曝光成交金额） | 2026年交易端"生死线"，受人群精准度+客单价驱动 |
| ★★☆ | 近期动销 | 近30天爆单情况，权重高于历史累计销量 |
| ★★☆ | 订单量 | 同层级赛马中越高越靠前 |
| ★★☆ | 核销GMV | 卖多少+核销多少，核销率长期<30%会被限流 |
| ★★☆ | 点击率与转化率 | 商品详情页吸引力 |
| ★☆☆ | 榜单/商城活动 | 热销榜/膨胀券/新客专享价，有额外流量加持 |
| ★☆☆ | 消费标签 | "消费人数5000+""回头客2000+"等数值越高排名越快 |
| ★☆☆ | 直播中 | 开播状态下排名显著上浮（适合医美/旅拍等搜索流行业） |
| ★☆☆ | 新店扶持 | 新入驻商家有短期展示优待 |
| ★☆☆ | 评分 | 经营分/评分保持**4.2分以上**（理想4.5），不及格被限流 |

**效率为王**：系统推1000人给你，产生1万元成交（GPM=10000）的商家，排名远高于GPM=1000的商家。

## 三、提升GPM的两大因子

### 因子一：人群精准度（第一优先级）

引用：Q_商城自然流量优化

- 通过新鲜A3/A4召回，转化率远高于泛人群
- 高A用户在商城产生点击/购买 → 系统判定链接高效 → 同城/团购频道排名提升
- **核心**：人群精准度决定GPM上限

### 因子二：客单价正价体系

- 低客单价天然限制GPM上限
- 2026年趋势：**正价链接**
- 示例：99元5节私教课 > 1元体验课（筛选羊毛党，GPM大幅上涨）

## 四、货架运营核心动作

### 4.1 直播后长尾红利

引用：Q_商城自然流量优化

**时机**：大场直播后1-3天

**动作**：商城价格与直播间拉齐（或使用获客专享价）

**效果**：显示"近30天历史最低"或"直播间同价"标签 → 刺激点击率和转化率 → 短时间冲高GPM → 占据频道首页位置

### 4.2 核销GPM考核（2026年新规）

引用：Q_商城自然流量优化

- 只卖不核销 → 核销率低 → 综合得分下滑 → 商城排名30天后快速下滑
- **餐饮/洗浴行业**：核销率维持40%以上保排序权重

### 4.3 三池融合联动

引用：H_流量融合漏斗 / B_三池融合

- M3（本地推）→ M2（商城自然流）→ 排序提升
- 形成良性循环

### 4.4 营业时间技巧

- 商城/搜索过滤非营业时间门店
- 客资行业可改为24小时营业（配合AI客服）
- 深夜同行竞争缺位 → 精准转化维持高GPM → 白天主时段排名更好

## 五、抖省省（小程序）运营

引用：P9_抖省省红利

**排序公式**：人群资产 > 交易力 > 距离

### 中大型连锁策略
- 集中打造一条10万+超级链接（餐饮）
- 严禁换链接/一城多链接
- 违反：商城权重腰斩

### 小微单店策略
- 线下买单引导关注蓝V
- 持续发布短视频激活"死粉"
- 洗成A3后抖省省自动首屏
