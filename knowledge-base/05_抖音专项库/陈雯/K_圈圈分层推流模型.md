## 一、圈圈模式的结构（由内而外六层破圈）

推流永远遵循**从小批量测试到逐层放大**的逻辑，流量按以下顺序依次破圈：

```
┌─────────────────────────────────────────────────────────────────┐
│                    圈圈分层推流模型（六层破圈）                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   【第一圈】铁粉（核心A3/A4/A5）  ← 系统首轮分发，永远优先        │
│          ↓ 达标后                                               │
│   【第二圈】活粉（30天内互动粉丝）← A1/A2活跃粉丝               │
│          ↓ 达标后                                               │
│   【第三圈】自有5A人群资产   ← 15天（餐中）/60天（酒旅）        │
│          ↓ 无自有资产时                                       │
│   【第四圈】同行5A人群资产   ← 系统直接抓同行的人               │
│          ↓ 开始破圈                                            │
│   【第五圈】同城泛人群       ← 精准度开始下降                    │
│          ↓ 极高在线人数/爆款                                   │
│   【第六圈】全国泛人群       ← 通常只有头部直播间/爆款视频       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 六圈详解

| 圈层 | 人群定义 | 破圈条件 | 精准度 |
|------|----------|----------|--------|
| **第一圈：铁粉** | 核心A3/A4/A5人群 | 系统首轮测试 | 最高 |
| **第二圈：活粉** | 30天内互动过的粉丝 | 第一圈数据达标 | 高 |
| **第三圈：自有5A** | 15天/60天内触达过的人 | 扩容 | 中 |
| **第四圈：同行5A** | 喜欢你同行的人 | 无自有资产时触发 | 低 |
| **第五圈：同城泛** | 同城地域人群 | 开始大规模破圈 | 低 |
| **第六圈：全国泛** | 全国用户 | 极高在线/爆款 | 最低 |

## 二、运转逻辑：召回与排序（赛马机制）

### 2.1 召回（海选）

| 项目 | 说明 |
|------|------|
| **本质** | 系统根据你的标签，从海量内容中"抓取"用户可能喜欢的内容 |
| **召回逻辑** | A等级越高，被召回（获得曝光）的概率越大 |
| **核心要素** | 人群资产越丰富，召回池越大 |

### 2.2 排序（赛马）

| 项目 | 说明 |
|------|------|
| **本质** | 在每个圈层内与同类商家竞争 |
| **打分指标** | 点击率、转化率、GPM、停留时长 |
| **核心逻辑** | 赛马胜出才能开启下一圈层 |

### 2.3 破圈原则

| 条件 | 结果 |
|------|------|
| 当前圈层赛马胜出 | 开启下一圈层流量 |

**赛马指标权重**：点击率（CTR）> 转化率（CVR）> GPM > 停留时长

> 核心结论：你在当前圈层的表现，决定你能进入哪个更大的圈。

## 三、关键洞察

### 洞察一："0到1"最难，初始模型定生死

| 阶段 | 说明 |
|------|------|
| **最难的不是涨粉** | 而是打好最中心的"精准人群圈" |
| **第一轮测试规模** | 通常是100-300人 |
| **数据反馈决定方向** | 第一波进场的人群决定了后续推流方向 |

**两种结局**：

| 第一波人群 | 系统学习结果 | 后续流量走向 |
|------------|--------------|--------------|
| **羊毛党** | 识别为"低价偏好人群" | 持续推羊毛党，难以转化正价客户 |
| **精准高客单** | 识别为"高价值需求人群" | 后续流量越来越精准 |

> **核心启示**：第一波测试人群的选择，直接决定了系统对你的"认知模型"。

### 洞察二：人为定向"喂养"模型

| 手段 | 做法 | 效果 |
|------|------|------|
| **短视频选题定向** | 拍199元美甲而非9.9元 | 让系统识别高客单人群 |
| **私域引导** | 先让精准客户看/互动 | 建联精准铁粉 |
| **鱼塘截流** | 截流同行A3精准客户 | 直接获取高质量人群 |
| **直播间憋单** | 商品点击/评论/停留时长 | 直播间最快做A3的三种动作 |

#### 0-1阶段"模型投喂"技巧（⭐决定生死）

**核心难点**：抖音最难的是初始精准人群圈的建立

**直播开场定江山**：
- 开场前15-30分钟的数据决定整场上限
- 开场数据差，后续流量会被锁死

**烧操作（模型投喂）**：
- 在开全域投放（M3）前的15分钟
- 先利用私域或精准鱼塘账号进场
- 成交几笔高客单价的正价品

**原理**：人为给系统"喂模型"
- 系统学习到高潜成交画像后
- 再开启全域投放，系统会抓取更精准的人
- 避免投流预算浪费在泛人群身上

#### 直播间最快做A3的三种动作

| 动作 | A3效率 | 说明 |
|------|--------|------|
| **商品点击** | 最容易 | 点击商品链接是直播间产生A3最容易的动作 |
| **评论** | 强交互 | 用户评论可快速标记为A3 |
| **停留时长（60秒+）** | 强信号 | 停留60秒以上，系统判定为A3，推更多流 |

> **实战技巧**：用引流款商品+福袋憋单，可同时触发这三种动作，快速积累A3资产。

### 洞察三：流量利用率与GPM

| 指标 | 说明 |
|------|------|
| **GPM定义** | 千次曝光成交金额，代表流量利用效率 |
| **系统偏好** | 更倾向于把流量给"每一千次曝光能卖出更多钱"的商家 |
| **实战价值** | 高GPM = 高圈层权重 = 更多破圈机会 |

### 洞察四：同行"投喂"效应

| 场景 | 后果 |
|------|------|
| **没有自有资产** | 投流时系统优先消耗同行5A人群 |
| **同行低价内卷** | 你买到的流量"又贵又水" |
| **破解方法** | 通过M1（非交易流）洗出自己的A3资产 |

> **核心结论**：M1增量洗流法是破解存量竞争的关键。

## 五、核心公式总结

### 5.1 破圈公式

```
破圈 = 第一圈精准建模 + 赛马胜出（高GPM/高转化）
```

### 5.2 模型喂养公式

```
精准初始模型 = 选题定向（高客单） + 私域引导 + 鱼塘截流
```

### 5.3 一句话总结

> **"0到1"最难，初始模型定生死。第一圈精准建模 + 赛马胜出（高GPM）= 逐层破圈获取海量增量。**
