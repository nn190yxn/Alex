## 来源：2026年3月30日陈雯培训

## 一、全域底层逻辑
### 1. 全域三大特点
#### 特点一：自然流被绑架
全域里成交的钱永远有一部分是即使不投流也极大可能本应成交的，所以需要控制好这部分的比例。

#### 特点二：优先消耗自有5A
不管是全域直播成交还是全域门店，都是优先消耗你自己的5A人群资产，且是由高A等级优先消耗（A345）。

#### 特点三：收割大于种草
全域的本质是收割大于种草，种的速度跟不上割的速度时，全域就进入危险地带（消耗不出或ROI低）。

### 2. 全域进阶公式
```
全域进阶 = (门店基建 + 5A人群资产 + 素材 + 出价) × 成交力
```

| 模块 | 核心要素 |
|------|----------|
| **门店基建** | 三率五分一热度、账户/门店及账号权重、风控与合规 |
| **5A人群** | 大小、比例、人群模型、注水与精泛 |
| **素材** | 内容力、画面、声音、关键数据、出镜人 |
| **成交转化能力** | 品与价（门槛）、主播/运营与场景（直播）、门店背书（评分/榜单等）、人群定向+爆破力、人工干预（鱼塘） |

## 二、全域计划管理
### 1. 计划调整原则
#### 只增不减原则
全域计划在跑好的情况下**只增加不删减**，避免影响平台与商家的利益平衡。
- 除非计划为0消耗或0ROI，否则不要轻易删除
- 效果好的计划可以复制多开，放大效果

#### 利益博弈逻辑
- 商家希望高ROI的精准素材有高消耗
- 平台为了增加可卖广告人数和次数，会限制这类素材的推流
- 平台采用权益分配的方式，平衡商家和平台的利益

### 2. 权益分配与ROI优化
#### 资金分配策略
以100元预算为例：
- 40元投向中等精准和极度精准的人，跑出高ROI
- 60元投向低ROI但高消耗的素材，确保计划能跑起来
- 最终综合ROI控制在50-80左右

#### ROI提升技巧
当权益ROI显示为a时，素材库中一定有素材的ROI至少能达到**a × 1.5倍**。
- 例如：后台显示ROI为30，素材库中一定有ROI能达到45的素材
- 策略：找到这类高ROI素材，重点投放，提高整体ROI

## 三、全域实操策略
### 1. 先标准后全域玩法
**操作步骤**：
1. **开场阶段**：投标准计划拉成交模型，允许ROI低一些，提高标准计划的出价，确保快速消耗M2人群进入直播间
2. **起量阶段**：做出成交模型后，开启全域计划放大效果
3. **稳定阶段**：优化全域计划分配，使总场综合ROI达到预期

**注意事项**：
- 做大厂直播用私域时，应私域导完再开全域，不然ROI会虚高
- 私域导流集中在开场短时间内完成，再开全域，避免人群定向效果变差

### 2. 全域ROI计算避坑
#### 常见误区
- 不要只看全域ROI，全域ROI容易虚高，包含了自然流本应成交的部分
- 建议结合标准ROI一起看，标准ROI更能反映真实投流效果
- 扫码金额等水分要扣除，计算真实投产比

#### 正确计算方法
```
真实ROI = (全域成交金额 - 自然流预估成交金额) ÷ 投流花费
```
自然流预估成交金额可以参考历史同期不投流的成交数据。

### 3. 全域人群运营
#### 人群资产建设
- 投流前要先打短视频，积累人群资产，再进行投流
- 人群资产的精准度直接影响ROI，精准度越高，ROI越高
- 定期清洗人群资产，移除不精准的虚假人群，提高整体质量

#### 人群分层运营
- **高A人群（A3-A5）**：优先收割，用全域计划触达
- **低A人群（A1-A2）**：先种草，用短视频内容培养，转化为高A后再收割
- **精准人群**：用标准计划重点投放，提高转化效率

## 四、行业应用案例
### 餐饮行业
- 投流时间：下午4点到晚上12点
- 投流范围：10公里内
- 策略：先用短视频积累本地美食兴趣人群，再开全域收割，ROI可稳定在30以上

### 丽人行业
- 投流时间：晚上8点到凌晨2点
- 投流范围：15公里内
- 策略：重点投放A3人群，结合私域导流，整体ROI可达40+

### 客资行业
- 不计算ROI，关注获客成本
- 投流范围：20公里内
- 策略：先做内容筛选高意向客户，再用全域放大，获客成本可降低30%
