## 一、货架流量概述

### 1.1 货架流量的定义

在抖音本地生活运营中，**搜索流量**和**团购商城流量**统称为"货架流量"，它们与算法"猜你喜欢"的"推荐流量"有本质区别。

| 流量类型 | 核心逻辑 | 用户行为 |
|----------|----------|----------|
| **推荐流量** | 算法"猜你喜欢" | 人找货（主动搜索） |
| **货架流量** | 人找货的主动需求 | 货找人（算法推送） |

### 1.2 货架流量组成

```
┌─────────────────────────────────────────────────────────────────┐
│                        货架流量                                  │
├─────────────────────────────┬───────────────────────────────────┤
│                             │                                   │
│      搜索流量               │         团购商城流量                │
│                             │                                   │
│  • 大搜（抖音搜索）         │  • 五榜榜单（热销/好评等）          │
│  • 小搜（团购搜索）         │  • 团购频道/同城频道               │
│                             │  • 平台营销活动（一分购/膨胀券）    │
│                             │  • 订单中心/收藏复购               │
│                             │                                   │
└─────────────────────────────┴───────────────────────────────────┘
```

## 二、搜索流量

### 2.1 搜索流量的核心特点

| 特点 | 说明 |
|------|------|
| **主动需求** | 用户因为渴了才会搜"奶茶"，因为想修车才会搜"保养" |
| **最精准流量** | 本地生活里转化率最高的流量类型 |
| **分钟级更新** | 用户搜过某个关键词后，系统会分钟级内更新标签 |

### 2.2 搜索流量的商业价值

| 指标         | 数据        |
| ---------- | --------- |
| **流量占比**   | 仅约14%     |
| **成交金额占比** | 超过50%的GMV |

> **核心洞察**：14%的流量贡献50%的成交，货架流量是存量市场的精准收割工具。

### 2.3 "搜索进，推荐出"原则

| 阶段 | 动作 | 结果 |
|------|------|------|
| **搜索** | 用户主动搜索关键词 | 系统分钟级更新用户标签 |
| **推荐** | 算法在推荐流推送相关内容 | A1/A2人群跃升为A3种草人群 |

## 三、大搜 vs 小搜

### 3.1 核心区别

| 维度 | 大搜（抖音搜索） | 小搜（团购搜索） |
|------|-----------------|-----------------|
| **位置** | 抖音首页右上角全局搜索框 | 进入"团购频道"后的内部搜索框 |
| **数据归属** | "抖音搜索"流量 | "团购商城"下的"团购搜索" |
| **用户心智** | 泛需求/初级种草 | 极强交易心智 |
| **用户意图** | 可能搜具体店，也搜"杭州旅游攻略"等泛词 | 100%带着消费目的来 |

### 3.2 用户心智对比

| 搜索类型 | 用户状态 | 转化特征 |
|----------|----------|----------|
| **大搜** | "我有需求，但还没想好买哪家" | 种草阶段，可建立品牌第一印象 |
| **小搜** | "我已经决定要买了，就在比比价格" | 交易阶段，精准拦截的最后机会 |

## 四、团购商城流量

### 4.1 2026年被定义为"货架大年"

| 项目 | 说明 |
|------|------|
| **商家规模** | 抖音已完成千万级商家供给 |
| **核心阵地** | 商城已成为承接用户稳定核销的核心阵地 |
| **流量性质** | "人找货"的货架场景 |

### 4.2 团购商城组成板块

| 板块类型 | 具体内容 |
|----------|----------|
| **五榜榜单** | 热销榜、好评榜、收藏榜、到手价榜、品牌力榜 |
| **频道入口** | 团购频道、同城频道 |
| **营销活动** | 一分购、膨胀券、限时秒杀 |
| **用户资产** | 订单中心、收藏复购 |

### 4.3 商城流量"先召回、后排序"机制（2026-03-28新增）

#### 召回阶段（第一秒）

1. **地理范围**：优先周边3公里（最多6公里）内门店
2. **5A人群标签**：用户身上的行业5A标签决定召回优先级
   - 新鲜A3（种草）人群 → 召回优先级极高

#### 排序阶段（超级权重 > GPM > 近期动销 > 订单量 > 核销GMV > 点击转化率）

| 凌驾性权重 | 说明 |
|-----------|------|
| **高A人群/铁粉 + 本地推** | 2026年商城"通天绿卡"：打了新鲜A3/A4或开启本地推全域投放，即便销量远低于头部品牌也能排首页 |

| 排序指标 | 说明 |
|---------|------|
| GPM | 2026年交易端"生死线"，受人群精准度+客单价驱动 |
| 近期动销 | 近30天爆单，权重高于历史累计销量 |
| 订单量 | 同层级赛马中越高越靠前 |
| 核销GMV | 核销率长期<30%会被限流 |
| 点击率/转化率 | 商品详情页吸引力 |
| 榜单/商城活动 | 热销榜/膨胀券/新客专享价，有额外流量加持 |
| 消费标签 | "消费人数5000+""回头客2000+"数值越高排名越快 |
| 直播中 | 开播状态排名显著上浮（适合医美/旅拍等搜索流行业） |
| 新店扶持 | 新入驻商家有短期展示优待 |
| **评分** | 经营分/评分保持**4.2分以上**（理想4.5），不及格被限流 |

### 4.4 收藏=直接A3（2026年核心增长点！）

- 在团购频道**收藏商品/门店** = 直接A3
- 代表极强的交易意愿
- 是2026年算法极其看重的长期价值指标

## 五、实战应用策略

### 5.1 大搜应用：制造"看后搜"

| 策略 | 说明 |
|------|------|
| **核心动作** | 通过短视频内容种草，在视频结尾或评论区引导用户去右上角搜索 |
| **人群跃升** | 直接让用户从A1/A2人群跃升为A3种草人群 |
| **覆盖范围** | 大搜覆盖全站内容（包含百科、探店视频等），更适合建立品牌第一印象 |

**"看后搜"引导话术示例**：
- "想了解杭州最值得去的餐厅，搜索XXX"
- "更多干货，搜XXX查看完整攻略"

### 5.2 小搜应用：拦截"精准客"

| 策略 | 说明 |
|------|------|
| **核心动作** | 优化门店名称、商品关键词，通过高GPM抢夺搜索结果排位 |
| **竞争态势** | 这里是同行必争之地 |
| **截流技巧** | 配置高性价比引流款或秒杀活动来截流 |

**小搜优化要点**：
- 门店名称包含核心关键词
- 商品标题优化（品类+特色+优惠）
- 提升GPM获取更好排位

#### 小蓝词配合小搜截流（2026-03-29新增）

引用：Q_小蓝词截流打法与实战应用

**配合原理：**
```
竞品视频（小蓝词） → 你的品牌搜索结果页（小搜占位） → 你的商城/门店 → 转化
```

**组合策略：**
| 打法 | 核心逻辑 | 配合方式 |
|------|---------|---------|
| **小蓝词截流** | 竞品视频 → 你的品牌搜索结果页 | 在竞品视频中埋入你的品牌词 |
| **搜索截流** | 品类词搜索 → 你的品牌优先展示 | 在搜索结果页占位 |

**操作要点：**
- 小蓝词生成后，确保你的品牌搜索结果页排位靠前
- 优化门店名称和商品标题，包含核心关键词
- 配置高性价比引流款承接小蓝词截流来的流量
- 提升GPM以获取更好的搜索结果排位

### 5.3 双轮驱动：推荐做"创造"，搜索做"承接"

| 流量类型 | 核心职责 | 用户状态 |
|----------|----------|----------|
| **推荐流（内容）** | "无中生有"创造需求 | 把没打算买的人变粉 |
| **搜索流（大小搜）** | 精准拦截存量需求 | 收割有明确购买意图的客户 |

### 5.4 连锁品牌红利：跨场景流转

| 场景 | 说明 |
|------|------|
| **大搜打标** | 用户在搜索（大搜）打下的A3标签 |
| **跨场景提升** | 直接提升他在推荐页和商城频道（小搜）看到该品牌门店的概率 |
| **品牌价值** | 五A人群标签跨场景流转，一次种草多次收割 |

## 六、核心公式总结

### 6.1 货架流量价值公式

```
货架流量 = 搜索流量 + 团购商城流量
流量占比 ≈ 14%
成交金额占比 ≈ 50%+
结论：14%的流量贡献50%的成交，是精准收割的主战场
```

### 6.2 大搜小搜分工公式

```
大搜 = 种草延伸（建立品牌第一印象，让A1/A2跃升为A3）
小搜 = 交易临门一脚（精准拦截最后转化机会）
```

### 6.3 双轮驱动公式

```
推荐流 = 创造需求（无中生有，把泛流量变粉丝）
搜索流 = 承接需求（精准拦截，收割存量购买意图）

大搜 = 泛需求种草
小搜 = 强交易心智
```

> **一句话总结**：大搜是种草的延伸，小搜是交易的临门一脚。做好了内容（推荐流），大搜自然会涨；做好了产品和榜单排名（货架），小搜的钱才接得住。
