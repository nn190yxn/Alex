## 文档说明

本文档是核销率提升的"武器库"——一套系统化的核销率提升策略体系。

**使用场景：**
- 直播后核销跟进
- 日常核销率优化
- 团队培训的标准SOP

**核心原理：**
- 核销率是直播的"生死线"
- 餐饮核销率≥50%、酒旅≥40%为合格
- 核销率低于30%会被限流

## 一、核销率核心指标

### 1.1 行业核销率标准

| 行业 | 及格线 | 优秀线 | 危险线 | 说明 |
|------|--------|--------|--------|------|
| **餐饮** | ≥50% | ≥60% | <30% | 餐饮消费高频，核销率高 |
| **酒旅** | ≥40% | ≥55% | <25% | 低频消费，核销率相对低 |
| **洗浴** | ≥40% | ≥55% | <25% | 需要到店消费 |
| **娱乐** | ≥35% | ≥50% | <20% | 到店场景多样化 |
| **客资** | ≥30% | ≥50% | <20% | 最低保底线 |

### 1.2 核销率影响因素

| 因素 | 影响 | 说明 |
|------|------|------|
| 产品吸引力 | 正相关 | 产品价值感越强，核销率越高 |
| 价格优惠度 | 正相关 | 优惠力度越大，核销意愿越高 |
| 到店便利性 | 正相关 | 门店越近越方便，核销率越高 |
| 核销引导 | 正相关 | 引导越到位，核销率越高 |
| 门店服务 | 正相关 | 服务越好，核销率越高 |
| 有效期限 | 负相关 | 期限越长，遗忘率越高 |
| 核销流程 | 负相关 | 流程越复杂，流失率越高 |

## 七、常见问题与解决

### 7.1 核销率低的原因

| 原因 | 解决方案 |
|------|---------|
| 产品价值感弱 | 提升产品价值，增加赠品 |
| 到店不方便 | 增加门店覆盖，优化位置说明 |
| 忘记核销 | 多频次核销提醒 |
| 核销流程复杂 | 简化核销流程，提供预约 |
| 门店服务差 | 提升门店服务质量 |
| 优惠感知弱 | 强化核销引导，强调优惠 |

### 7.2 核销问题处理

| 问题 | 解决方案 |
|------|---------|
| 订单找不到 | 核对订单信息，提供查询方式 |
| 预约满员 | 提供其他时间/门店选择 |
| 门店不认 | 联系客服协调，加强培训 |
| 过期了怎么办 | 争取延期或补偿 |

## 八、核销提升案例

### 8.1 案例：洗浴中心核销提升

**背景：** 直播卖出500单，核销率仅25%

**问题分析：**
- 核销提醒不及时
- 门店位置偏远
- 预约流程复杂

**提升措施：**
- 下播后2小时发送核销提醒
- 给未核销用户发送50元定向券
- 简化预约流程，提供车接服务
- 直播切片持续曝光

**结果：** 核销率提升到55%

### 8.2 案例：餐饮门店核销提升

**背景：** 直播卖出1000单，核销率35%

**问题分析：**
- 忘记核销
- 优惠感知弱

**提升措施：**
- Day 3/7/14三次核销提醒
- 核销即送小菜/饮品
- 周末核销专属优惠

**结果：** 核销率提升到62%
