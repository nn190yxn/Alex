# 短视频脚本模板标准化SOP

> 来源：陈雯2026年3月培训课程 + 补充材料整合
> 整理目标：短视频脚本的标准化模板，包含选题/结构/话术/拍摄要点
> 最新更新：2026-03-29

---

## 文档说明

本文档是短视频脚本的"工具箱"——一套标准化、可复用的脚本模板体系。

**使用场景：**
- 短视频创作前的脚本撰写
- 团队脚本标准化
- 新人培训模板
- 脚本审核标准

**核心原则：**
- 黄金3秒：前3秒必须有钩子
- 完播设计：每5秒都有小高潮
- 核心卖点：不超过3个
- 行动引导：明确的CTA

---

## 一、脚本基础模板

### 1.1 脚本封面

```
【短视频脚本】
【主题】：
【时长】：___秒
【目标】：___（涨粉/转化/曝光）
【类型】：___（种草/科普/剧情/种草）
【拍摄方式】：___（口播/剧情/展示）
【发布时间】：
```

### 1.2 脚本结构（15秒版本）

| 时间 | 画面 | 文案/话术 | 音效/特效 | 备注 |
|------|------|----------|----------|------|
| 0-3秒 | 钩子画面 | 黄金3秒钩子 | 紧张BGM | 留住用户 |
| 3-8秒 | 核心内容1 | 第一个卖点 | 适当特效 | 传递价值 |
| 8-12秒 | 核心内容2 | 第二个卖点 | 适当特效 | 强化认知 |
| 12-15秒 | 结尾引导 | CTA+关注 | 轻快BGM | 引导行动 |

### 1.3 脚本结构（30秒版本）

| 时间 | 画面 | 文案/话术 | 音效/特效 | 备注 |
|------|------|----------|----------|------|
| 0-3秒 | 钩子画面 | 黄金3秒钩子 | 紧张BGM | 留住用户 |
| 3-8秒 | 背景介绍 | 痛点/场景引入 | 舒缓BGM | 引起共鸣 |
| 8-15秒 | 核心内容1 | 第一个卖点+案例 | 适当特效 | 传递价值 |
| 15-22秒 | 核心内容2 | 第二个卖点+案例 | 适当特效 | 强化认知 |
| 22-27秒 | 核心内容3 | 第三个卖点+案例 | 适当特效 | 全面覆盖 |
| 27-30秒 | 结尾引导 | CTA+关注 | 轻快BGM | 引导行动 |

## 二、选题模板

### 2.1 选题来源

| 类型 | 说明 | 示例 |
|------|------|------|
| 痛点型 | 解决用户问题 | "孩子注意力不集中怎么办？" |
| 热点型 | 蹭行业热点 | "xx明星同款训练" |
| 科普型 | 专业知识点 | "感统训练的3个关键期" |
| 案例型 | 真实案例分享 | "从140cm到165cm的蜕变" |
| 对比型 | 前后对比 | "练体操前vs练体操后" |
| 盘点型 | 汇总盘点 | "贵阳感统训练机构推荐" |

### 2.2 选题模板

**模板1：痛点+解决方案**

```
【选题】：___（用户痛点）怎么办？
【角度】：___（解决方案/专业建议）
【钩子】：___（引发好奇）
【结构】：
  1. 痛点引入（2秒）
  2. 原因分析（3秒）
  3. 解决方案（8秒）
  4. 行动引导（2秒）
```

**模板2：热点+关联**

```
【选题】：___（热点事件/话题）
【角度】：___（与自身业务的关联）
【钩子】：___（热点切入）
【结构】：
  1. 热点引入（2秒）
  2. 观点输出（5秒）
  3. 关联业务（6秒）
  4. 行动引导（2秒）
```

**模板3：科普+种草**

```
【选题】：___（专业知识）
【角度】：___（实用建议/科普）
【钩子】：___（引发好奇）
【结构】：
  1. 知识引入（2秒）
  2. 知识讲解（10秒）
  3. 实际应用（5秒）
  4. 行动引导（3秒）
```

## 六、脚本案例

### 6.1 案例1：痛点型

```
【主题】：孩子注意力不集中怎么办？
【时长】：30秒
【类型】：科普+种草

【脚本】
0-3秒（钩子）：
"孩子坐不住，注意力不集中，很多家长都做错了！"

3-8秒（痛点）：
"你是不是经常对孩子发火？'怎么又走神了！'"
"其实不是孩子不想专注，是感统能力没跟上"

8-18秒（解决方案）：
"感统训练就是通过专业的感觉刺激"
"帮助孩子提升注意力、平衡感和身体控制"
"我们追光小牛做感统训练5年了"
"很多孩子从坐不住到能专注40分钟"

18-25秒（案例）：
"就像这个小朋友，来的时候只能坐5分钟"
"现在能专注上完整节课，家长特别开心"

25-30秒（引导）：
"如果你家孩子也有类似问题，评论区扣'1'"
"我来帮你分析一下"
"喜欢的话点个关注，带你了解更多育儿知识"
```
