## 一、投流核心原理

### 1.1 三池融合模型（流量架构基础）

| **流量池** | **占比**  | **性质**     | **对应人群**    | **核心动作** |
| ------- | ------- | ---------- | ----------- | -------- |
| **M1**  | 70%     | 非交易内容/推荐流  | A1/A2（潜在需求） | 拉新、洗流    |
| **M2**  | 10%-20% | 自然交易流/商城搜索 | A4/A5（成交沉淀） | 成交闭环     |
| **M3**  | 8%-12%  | 付费商业流      | A3（精准种草）    | 提纯、召回    |

### 1.2 投流本质：强行插队

**核心公式**：

```
投流本质 = 在自然流队列中强行插队
自然流一天见3人 → 投流一天见3000人
```

### 1.3 洗→泛→流三级火箭

```
M1（泛流量入口）
    ↓ [白色锚点内容建联]
A1/A2（潜在需求人群）
    ↓ [抖加放大+蓝V权重]
A3（精准种草人群）
    ↓ [绿色锚点+全域M3召回]
A4/A5（成交沉淀人群）
    ↓
M2（自然交易闭环）
```

## 二、M1增量洗流法（白嫖流量核心）

### 2.1 核心公式

```
M1增量洗流法 = 老板号 + 白色锚点 + 抖加放大
             = 大量低成本精准A3资产
```

### 2.2 完整三步法

**步骤1：选题定向**

- 账号：必须用**蓝V号或老板号**
- 内容：白色锚点，不讲产品讲人群关心的话题
- 示例：「99%的杭州男生穿错的约会装」

**步骤2：抖加放大**

- 动作：500播放视频投抖加放大到5万播放
- 原理：蓝V号播放即算A3，效率是达人号的7倍

**步骤3：精准收割**

- 动作：发绿色锚点视频，开启全域投放
- 逻辑：系统优先消耗自有A3人群

### 2.3 老板号/蓝V五大特权

1. **A3判定权重**：播放即算A3（达人需看7遍）
2. **7倍效率优势**：同样预算，A3积累效率是达人的7倍
3. **双重红利**：蓝V高权重 + 素人号高自然流
4. **M1提纯器**：低成本提纯泛流量
5. **连锁溢出**：跨地区流量协同

## 三、本地推操作体系

### 3.1 人群包构建策略

**准入门槛**：

- <100万：只圈不推，用"门店全域"
- 100-500万：小规模测试
- > 500万：正式开启本地推

**消耗优先级**：

1. 自有A3人群（转化率≥10%，ROI 15-20）
2. 自有A4/A5人群（复购率≥20%，ROI 20-30）
3. 行业精准人群包（A1→A3转化率≥5%，ROI 10-15）

### 3.2 定向位置选择

**距离参考值**：

- 社区餐饮单店：3-6公里
- 商圈餐饮店：6-10公里
- 热销榜第一名店：12-20公里
- 网红乐园/旅游景区：全国智能投放

**必选项设置**：

- **年龄必选**：避免字节灌水
- 根据产品定位设置性别、兴趣标签
- 设置预算上限和效果监控

### 3.3 素材投放策略

**白色视频（种草）**：

- 定位：投"门店浏览"，打出A1/A2人群
- 特点：不讲产品，讲人群关心的内容
- 时长：30秒以内，快速剪辑

**绿色视频（成交）**：

- 定位：投"门店成交"，实现深度转化
- 特点：直接讲福利、讲因果
- 时长：30-60秒，逻辑清晰

**不动如山原则**：

- 计划表现好时：可增加新素材，**严禁删减旧素材**
- 保留标准：ROI≥10或转化率≥5%，至少保留30天

### 3.4 预算调控策略

**预算加减法**：
| **场景** | **诊断** | **操作** | **幅度** |
|---------|---------|---------|---------|
| ROI下降且GMV不增长 | 精准人群耗尽 | **降低预算** | 减少30%-50% |
| 消耗快ROI稳定 | 人群充足 | **增加预算** | 增加20%-30% |
| 自然流占比>70% | 自然流量过高 | **砍掉预算** | 减少70%-80% |
| 自然流占比<30% | 自然流正常 | **恢复预算** | 恢复原水平 |

**对冲自然流策略**：

- 自然流占比>70%：大幅减少付费预算
- 自然流占比<30%：增加付费预算
- 目的：优化成本结构，提升整体ROI

### 3.5 消耗监控诊断

**消耗速度诊断**：

- **过快**（早上开始，中午跑完）：人群充足，可增加预算
- **过慢**（从早到晚拉长消耗）：精准人群耗尽，停止增加投入
- **正常**（全天均匀消耗）：保持现有策略

**分时投放策略**：

- 早高峰（7-9点）：10%-15%预算，短平快素材
- 上午（9-12点）：15%-20%预算，专业型素材
- 晚高峰（18-21点）：25%-30%预算，促销型素材
- 夜间（21-24点）：10%-15%预算，深度型素材

## 四、截流竞品打法

### 4.1 传统截流（竞品大促后）

**时机**：竞品大促后第2-3天

**操作**：

1. 准备竞品周边6公里鱼塘号
2. 前往竞品直播间密集成交/退款
3. 回流自播间下单核销

**原理**：系统判定"喜欢竞品的用户更喜欢你"

### 4.2 小蓝词截流（2026年新增）

**核心原理**：

- 小蓝词：竞品视频评论区蓝色超链接搜索词
- 点击后跳转到你的品牌搜索结果页
- 截流对品类有明确兴趣的精准人群

**五步操作法**：

1. **监控竞品**：找摇篮期视频（<1万播放）
2. **鱼塘号搜索**：10-20个号在竞品视频搜索框搜索你的品牌名
3. **评论区留痕**：发布引导性留言
4. **触发算法**：集中搜索行为向算法反馈关联性
5. **承接流量**：确保品牌搜索结果页内容完整

**最佳时机**：必须在竞品视频爆火之前操作！

## 五、GPM深度逻辑

### 5.1 GPM定义与重要性

**定义**：每千次曝光成交金额
**公式**：`GPM = (成交金额 ÷ 曝光量) × 1000`
**本质**：流量的利用效率

**重要性**：

- GPM越高，系统越愿意给流量
- 决定自然流量分配的关键指标

### 5.2 影响GPM的两大因素

1. **人群精准度**（第一优先级）：决定转化率下限
2. **成交规模/客单价**（第二优先级）：决定GPM天花板

### 5.3 核销GPM（2026年新增）

**定义**：不仅看成交，更看核销
**风险**：核销率长期低下，系统判定"骗流量"，直接限流
**行业红线**：餐饮/洗浴≥40%，全行业综合≥30%

### 5.4 2026年「九块九打法」失效

| **打法** | **特点** | **效果**         |
| ------ | ------ | -------------- |
| 九块九引流  | 低价诱惑   | 人群不准，GPM低，羊毛党多 |
| 正价链接   | 正价体系   | 筛选精准人群，直接拉高GPM |

> **结论**：正价体系是2026年的正确方向

## 六、鱼塘运营与素人号养号

### 6.1 什么是"养素人号"

**定义**：为构建"鱼塘"准备的账号，模拟真实用户行为获取精准标签

**核心价值**：

1. 提供直播间初始流量和成交模型
2. 发布UGC内容提升POI热度和榜单排名
3. 监控竞品并实现"小蓝词"截流

### 6.2 养号操作

**养号周期**：7-15天
**每日操作**：30分钟，刷目标人群感兴趣的内容

**针对竞品模拟（第3天起）**：

1. 搜索竞品词，进入竞品直播间
2. 停留至少30秒，尝试下单购买
3. 完成核销后退掉竞品订单

### 6.3 应用场景

**场景1：直播间"鱼塘"打法**

- 时机：直播开场前15-30分钟
- 操作：利用养好的账号进行密集成交
- 目的：投喂精准成交模型，诱导算法召回精准流量

**场景2：UGC内容发布**

- 操作：发布9图100字优质评价
- 目的：提升POI热度和榜单排名

**场景3：小蓝词截流**

- 操作：监控竞品视频，触发小蓝词
- 目的：实现搜索截流

### 6.4 适用场景判断

- ✅ 高客单价产品（100元以上）
- ✅ 需要建立直播初始成交模型
- ✅ 需要提升POI热度和榜单排名
- ✅ 需要监控竞品并截流
- ❌ 低客单价产品（10元以下，直接自然流收割）

## 七、投流避坑指南

### 7.1 常见投流坑

| **坑**   | **说明**          | **正确做法**     |
| ------- | --------------- | ------------ |
| 素人号投本地推 | 效率极低，播放仅算A1     | 使用蓝V/老板号     |
| 增量宝     | 平台抽20%佣金，破坏价格体系 | 避免使用增量宝      |
| 达人投播放量  | 只算浅层，不直接产生A3    | 使用蓝V/老板号投播放量 |
| 线下到店投放  | 预估到店人数水分大       | 选择门店浏览投放     |
| 九块九引流   | 人群不准，羊毛党多       | 使用正价体系       |

### 7.2 投流质量判断标准

1. **卡片成交占比**：占比高意味着投到的客人更精准
2. **ROI提升逻辑**：让卡片成交数据往上跑
3. **精准人群消耗完判断**：投10万和20万成交相同，说明精准人群耗尽

### 7.3 消耗不出的原因

| **原因**  | **解决办法**     |
| ------- | ------------ |
| 违规      | 解决违规问题       |
| 风控期     | 等待风控期结束      |
| 电商抢量    | 调整投放时间避开高峰期  |
| 同行抢量    | 调整投放策略避开竞争时段 |
| 人群资产消耗完 | 启动新一轮种草循环    |

### 7.4 计划管理原则

- **跑得好时**：不动如山，可增加新素材但不要删减
- **跑得不好时**：再进行优化调整
- **计划不要轻易停**：可通过调控预算进行微调
