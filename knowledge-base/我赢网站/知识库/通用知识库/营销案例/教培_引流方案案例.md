## 案例1：低价引流方案

**适用场景**：新店开业、招生淡季

### 具体方案

**活动名称**：9.9元抢价值299元体验课

**活动内容**：
- 9.9元抢购价值299元的体验课（2节）
- 赠送学科测评一次
- 赠送学习规划方案一份

**执行步骤**：
1. 制作推广海报，突出低价和价值
2. 发布到朋友圈、社群
3. 设置报名表单，收集信息
4. 邀约到店体验

**成本核算**：
- 9.9元课程成本约20元/人
- 测评成本约30元/人
- 总成本约50元/人
- 目标转化率30%，实际获客成本约170元/人

**转化策略**：
- 体验课后跟进转化
- 提供专属优惠
- 引导即时报名

### 关键要点
- 低价引流要设置门槛
- 后续转化是关键
- 控制成本和转化率

## 案例2：免费测评引流方案

**适用场景**：建立信任、精准获客

### 具体方案

**活动名称**：免费学科诊断

**活动内容**：
- 免费进行学科能力测评（语数英任选）
- 出具详细诊断报告
- 提供1对1学习规划建议

**执行步骤**：
1. 制作测评海报
2. 线上推广：朋友圈、社群、抖音
3. 预约测评时间
4. 现场测评+咨询
5. 转化报名

**话术示例**：
"您好，我们有一个免费学科测评活动，可以帮孩子找出学习中的薄弱环节。很多家长测评后发现，孩子不是笨，是方法不对。请问您孩子几年级？可以预约一个测评时间。"

**转化策略**：
- 测评报告要专业详细
- 现场给出改进建议
- 限时优惠促报名

### 关键要点
- 测评是建立信任的好机会
- 报告要专业有说服力
- 现场转化要自然

## 案例3：老带新引流方案

**适用场景**：维护老客户、降低获客成本

### 具体方案

**活动名称**：老带新，双赢活动

**执行话术**：
"XX妈妈，您的孩子在我们这里学了这么久，效果我们也看到了。您的朋友有没有孩子需要提升的？可以推荐过来试试课。

老带新活动，您推荐一个朋友来，您和朋友都可以获得XX元的优惠券。如果朋友报名成功，您还可以额外获得XX元。相当于您续费又省了一笔钱。"

- 定期联系老学员

- 节日问候、积分奖励

### 关键要点
- 老带新是最有效的获客方式

## 专业深化板块

### 一、行业数据基准

**获客成本行业数据**
- 线上获客成本：约180元/线索
- 线下获客成本：约450元/线索
- 线上转化率：2%-4%
- 线下到店转化率：30%-40%
- 老带新成本：仅为新招成本的20%-30%
- 私域转介绍成交率：25.6%-32.1%

**地推效率数据**
- 单人单天平均收集有效信息：15-25条
- 有效信息到店率：15%-25%
- 到店到成交率：35%-45%
- 综合获客成本：200-400元/人
- 最佳地推时间：放学时间（15:30-17:30）

**低价引流转化数据**
- 9.9元体验课到店率：约60%
- 到店体验后报名率：约25%-35%
- 综合获客成本：150-250元/人
- 二次裂变率：约8%

### 二、专业方法论

**引流活动设计五要素**
1. 钩子：足够吸引的目标（免费/低价/有价值）
2. 门槛：筛选真正有需求的家长（9.9元/填写信息/转发朋友圈）
3. 价值：超出预期的体验（超预期服务+专业测评）
4. 行动：明确的参与路径（扫码/到店/加微）
5. 闭环：从引流到留存到裂变的完整链条

**体育培训引流方案设计要点**
- 低门槛体验：1节体验课（30-45分钟）让家长看到效果
- 安全展示：教练资质、急救设备、教学环境全程透明
- 亲子互动：设计亲子体验环节，增加参与感和趣味性
- 效果可视化：当场测评体测数据，给家长对比参照

**线上引流私域运营SOP**
1. 引流加微：领取资料/预约体验/进群
2. 欢迎破冰：自动回复+价值推送+建立初步信任
3. 价值输出：育儿知识+机构动态+优惠活动
4. 邀约到店：个性化推荐+时间邀约+确认提醒
5. 体验转化：服务+需求挖掘+方案推荐
6. 续费裂变：老带新+积分体系+会员权益

### 三、真实案例数据

**案例1：儿童体适能机构地推方案**
- 活动：99元抢价值599元体测+体验课
- 地点：周边3公里内5个小区轮流地推
- 时间：放学时段连续执行21天
- 投入：2名地推人员+物料+小礼品
- 产出：收集信息487条，到店186人，成交72人
- 获客成本：约280元/人
- 复盘：体测数据是核心竞争力，家长愿意付费获取

**案例2：艺术培训机构社群裂变**
- 活动：邀请3位家长进群，免费领"少儿美术教程合集"
- 裂变系数：1:4.2（每人有4.2人转发）
- 7天新增家长：2300人
- 成本：0元（虚拟资料无成本）
- 转化：推出9.9元体验课，成交87人
- ROI：1:12
- 关键：资料包要足够实用，裂变话术要简单明了

**案例3：早教机构异业合作**
- 合作方：母婴店+儿童摄影+儿童乐园
- 合作方式：互相放置宣传物料+会员权益互通
- 3个月产出：推荐客户127组，成交48人
- 获客成本：约35元/人
- 关键：选择客群重合度高、非竞品的商家

### 四、检查清单

**引流方案设计核查表**
- [ ] 钩子是否足够吸引？（价值感≥成本的3倍）
- [ ] 门槛是否合理？（太低无效流量多，太高参与率低）
- [ ] 价值是否超出预期？（让家长觉得赚到了）
- [ ] 行动路径是否清晰？（扫码→加微→到店）
- [ ] 是否有闭环设计？（引流→留存→转化→裂变）

**地推执行核查表**
- [ ] 物料是否齐全？（传单+礼品+二维码+台账）
- [ ] 话术是否经过培训？（1分钟介绍+3句话吸引）
- [ ] 目标人群是否精准？（年龄+孩子年级+需求阶段）
- [ ] 后续跟进是否及时？（当天加微，当天发消息）
- [ ] 数据是否记录完整？（时间+地点+收集数量）

**私域转化核查表**
- [ ] 是否有欢迎语？（建立信任的第一印象）
- [ ] 是否提供价值？（育儿知识/优惠信息/活动预告）
- [ ] 跟进频率是否合适？（每周2-3次，不刷屏）
- [ ] 是否有个性化推荐？（根据孩子情况推荐课程）
- [ ] 邀约是否明确？（给出具体时间，减少选择）

### 五、常见坑

**坑1：引流不转化**
- 表现：活动一场接一场，人来了不少但报名的少
- 原因：只顾拉新不管留存，价值输出不足
- 纠偏：引流只是开始，私域运营才是关键

**坑2：低价引流吸引羊毛党**
- 表现：9.9元引流来的人都是为了占便宜，不转化
- 原因：门槛太低，没有筛选
- 纠偏：设置多重门槛（转发+测评+信息填写）

**坑3：地推只收集不跟进**
- 表现：地推收集了几百条信息，但没人跟进
- 后果：线索浪费，数据变成死资源
- 纠偏：当天加微、当天发消息、3天内必须电话

**坑4：私域变成广告群**
- 表现：每天发广告，家长纷纷退群或屏蔽
- 原因：只有输出没有互动
- 纠偏：价值内容≥60%，广告内容≤40%，增加互动话题

**坑5：引流裂变后患无穷**
- 表现：为了裂变承诺太多，导致家长期望过高
- 风险：无法满足承诺，负面口碑
- 纠偏：裂变话术要谨慎，承诺要可兑现
