# 品牌屋方法论（Brand Message House）

> 适用工具：品牌定位生成器、品牌诊断工具
> 来源：微信公众号专业文章整理
> 核心理念：品牌屋=战略意图+战术落地

---

## 一、品牌屋的本质

品牌屋全称是**品牌信息屋（Brand Message House）**，本质是一套**战略信息的传达系统**。

好的品牌屋，既可体现战略意图，也可看到战术落地。

**品牌屋=对内组织统领+对外信息统一**：
- **对内**是组织统领，品牌屋应作为企业宪法保证组织效率，要做到有法可依，有法必依。提升组织效率，就是提升经营效率。
- **对外**是信息统一，消费者跟品牌的每一个触点，都直接影响其对品牌的认知。统一的信息，直接影响沟通效率。

---

## 二、品牌屋五大部分

品牌屋五大部分：**战略+心智+论点+论据+落地**

上一层是下一层的来源，下一层是上一层的落地。

```
┌─────────────────────────────────┐
│         战略（品牌定位）           │
├─────────────────────────────────┤
│    心智（用户+口号+调性）         │
├─────────────────────────────────┤
│       论点（核心价值）            │
├─────────────────────────────────┤
│       论据（RTB体系）            │
├─────────────────────────────────┤
│       落地（产品矩阵）            │
└─────────────────────────────────┘
```

## 三、战略（品牌定位）

品牌定位是品牌屋的核心，需要用**一句话**说明自己能解决什么问题。

需要回答五大子问题：
1. **对谁而言**（目标消费者）
2. **你属于什么品类**（消费者心智中的产品类别）
3. **解决什么问题**（消费者未被满足的核心需求）
4. **可以达到什么效果**（消费者可感知的具体利益）
5. **因为你有什么支撑**（RTB体系）

**关键认知**：
- 品类思维的本质是用户思维，这里的"类"是需求类别，"品"是产品如何满足这个需求
- 消费者关心的是**Why**（消费者为何选你），而非企业的**What**（企业在做什么）和**How**（企业是如何做的）

---

## 四、心智（用户+口号+调性）

品牌定位是内部战略共识，而心智占据是将定位翻译成消费者可感知、可记忆、好传达的表达。

### 4.1 目标人群

产品为需求服务，需求来自特定人群。**人群定错，战略全错。**

案例对比：
- 同样是轿车，商务接待的行政向→要气场、舒适、后排体验→品牌调性沉稳大气
- 追求驾控感的运动向→要操控、推背感、弯道极限→品牌调性更激进锋利
- 既要行政又想运动→两处都不讨好，喜欢行政的觉得太轻浮，喜欢运动的觉得太死板

### 4.2 品牌口号

品牌口号是把核心价值用更高效的方式跟消费者沟通，是直接跟消费者高频沟通的那句话。

**三个维度理解品牌口号**：

| 维度 | 要求 |
|------|------|
| 品牌维度 | 传达品牌定位/核心价值主张 |
| 传播维度 | 简短+有记忆点+决策的鼓动性 |
| 执行维度 | 能长期使用+高频出现，经得起时间考验 |

**核心原则**：好的品牌口号，不是玩文字游戏也不是装高级，核心是品牌定位的有效翻译。如果口号脱离了定位，哪怕文案再漂亮都是花里胡哨没啥意义。

如果品牌定位本身具备跟消费者高效沟通的属性，那品牌定位就可以是品牌口号。

### 4.3 品牌调性

品牌口号决定**说什么**，品牌调性决定**用什么方式表达**。

品牌调性就像一个人的特质，决定了消费者如何看待这个品牌。

**案例**：同样讲「安全」
- 沃尔沃：冷静、克制、工程师式的理性，用数据和事实说服
- 理想：温暖、务实、家庭感，告诉你把家人放在这台车里你可以放心

同样的利益点，因为调性不同，消费者感知到的品牌性格完全不同。**调性飘忽不定的品牌，消费者记不住你是谁。**

**调性由两件事决定**：
1. 品牌定位——你选择占据什么心智，就决定了你应该用什么语气说话
2. 目标人群——你服务的人群期待一个什么性格的品牌和他们对话

调性一旦确定，就是品牌所有对外表达的**情绪底色**。

**三个要素的推导关系**：
锁定人群（为谁服务）→ 基于人群需求提炼核心价值并翻译为口号（说什么）→ 用品牌调性统一表达方式（怎么说）

## 五、论点（核心价值）

心智占据解决的是「你是谁」，核心价值（论点）回答的是「你能给消费者什么具体的好处」。

**定好人群才能定好价值，价值分为三层**：

### 5.1 功能价值
产品层解决什么具体问题。最基础的，消费者最先感知到的。对于绝大部分品类而言，功能价值就是根基所在。

案例：
- 理想（增程系列）：长续航+大空间+冰箱彩电大沙发的舒适性，解决家庭出行核心痛点
- 问界：智能驾驶+智能座舱，解决日常通勤省心和车内交互体验

### 5.2 情感价值
让消费者产生什么样的感受。功能价值回答有没有用，情感价值回答用的过程中和之后感觉怎么样。

案例：
- 理想给家庭用户的情感价值：全家人在一起的幸福感和安心感
- 问界带来的情感价值：我站在技术前沿+智能辅助驾驶替我省心+华为出品

### 5.3 人设价值
帮助消费者成为什么样的人或表达什么样的态度。这是品牌溢价的来源，消费者买的不仅是产品，更是买背后的身份认同。

案例：
- 保时捷：「我是一个追求极致性能、懂得品味的人」
- 法拉利：「我站在金字塔尖，我有资格拥有这台梦想之车」

**三层价值的逻辑关系**：
- 功能价值是**入场券**
- 情感价值是**差异化来源**
- 人设价值是**溢价的超级杠杆**

对于绝大部分品类而言：
- 功能价值做不到，品牌就站不住脚
- 只有功能价值，品牌会陷入价格战
- 有了情感价值，品牌开始有温度
- 做到了人设价值，消费者不再是在「买产品」，而是在「选择一种生活方式」——这才是品牌真正的护城河

## 六、论据（RTB体系）

价值表达说的是我能解决你的什么问题，论据支撑（RTB, Reason to Believe）则是我为何能解决。

RTB不是简单罗列RTB1/2/3，而是要有**框架思维**，按类型进行结构化分类，让说服力更强，也更落地。

### 6.1 技术壁垒型
独特的专利技术、生产工艺、自建实验室的持续研发能力。竞品很难复制，直接构成竞争护城河。主要适用于科技驱动型品牌。

### 6.2 成分/原料型
稀缺、高品质或差异化的原料来源。如「法国深海海藻」「日本北海道牧场奶源」「云南高海拔玫瑰」。在美妆、食品、健康等品类中更为重要，消费者可直接感知和验证。

### 6.3 权威认证型
行业认证、临床数据、权威机构推荐、专家背书。借用第三方公信力为品牌背书。如「通过XX认证」「经过XX例临床测试」「皮肤科医生推荐」。对建立信任感非常有效，尤其是决策门槛较高的品类。

### 6.4 品牌资产型
品牌自身积累的历史沉淀、用户口碑、行业地位。如「创立XX年」「服务过XX万用户」「行业销量第一」。适合有一定发展历史的品牌，对新品牌来说相对较弱。

### 6.5 供应链优势型
自建工厂、垂直整合能力、独家供应商关系、全链路品控体系。对B端和投资人讲成本结构优势和长期竞争力，对C端讲品质保障和安全感。同一个RTB，不同场景换不同的表达。

### RTB的构建原则

| 原则 | 说明 |
|------|------|
| ① 可验证 | RTB不是自说自话，而是消费者可以验证或感知到的事实。「技术很先进」是空话，「拥有XX专利，经过XX临床测试」才是RTB |
| ② 与利益点对应 | 每一个利益点背后，都应该有至少一个RTB在支撑。利益点和RTB之间要形成「价值—证据」的闭环 |
| ③ 有壁垒 | 最好的RTB是竞品难以复制的。如果今天讲完明天竞品都能讲同样的话，竞争价值就很有限 |
| ④ 分层使用 | 面向消费者传播时，成分/原料型和权威认证型更直接有效；面向投资人或行业端沟通时，技术壁垒型和供应链优势型更有说服力 |

## 七、落地（产品矩阵）

品牌定位需要产品来落地，定位说的是我是谁，产品提供说的是我能做什么。

**产品矩阵不只是多个产品的组合，更是要一起让品牌定位站住脚。** 每一个产品系列的存在，都应该能够回溯到品牌屋的上层逻辑：这个系列服务的是哪个人群？提供的是什么利益？支撑它的RTB是什么？

如果一个产品系列放进品牌屋后，和上面四层没有任何逻辑关联，那就需要思考：这个产品是在强化品牌定位，还是在稀释它？

### 7.1 引流款（拉新型产品）
- 价格门槛低、使用场景广、容易被消费者初次尝试
- 核心使命不是赚钱，而是让消费者以最低成本体验到品牌核心价值
- 完成从「不知道你」到「愿意试试」的转化
- 是品牌的揽客能手，负责打开市场

### 7.2 利润款（核心型产品）
- 品牌的主力销售担当，贡献最大GMV和利润
- 通常是最成熟、最被市场验证过的产品线
- 功能利益明确，复购率高，承担品牌的基本盘

### 7.3 形象款（旗舰型产品）
- 代表品牌最高水平，定价最高，技术含量或体验感最强
- 核心使命不在于销量，而在于拉高品牌势能
- 告诉消费者「我们能做到这个水准」，为整个品牌建立溢价认知
- 是品牌的天花板

### 7.4 防御款（竞争型产品）
- 针对竞品强势领域或市场空白，推出的防御性产品
- 核心目的是不让竞品在某个细分市场形成垄断，或保护品牌在某个价格带的市场份额

### 产品矩阵搭建原则

| 原则 | 说明 |
|------|------|
| ① 角色分工要清晰 | 每个系列承担什么角色、解决什么问题必须想清楚。角色模糊的产品线往往既不赚钱也不拉形象，反而消耗资源 |
| ② 系列之间有协同而非冲突 | 覆盖不同细分需求、不同价格带、不同使用场景，但彼此之间不内耗。最怕引流款和利润款定价太接近，导致自己打自己 |
| ③ 整体指向同一个品牌定位 | 所有产品合在一起，应该让消费者对品牌的认知更清晰而不是更困惑。产品矩阵是品牌定位的「证据集合体」，每增加一个系列，品牌定位应该更稳固而不是更模糊 |

## 八、总结

**不能为了品牌屋而品牌屋。屋子是形，传达是神。**

品牌屋表达的不仅是企业的战略力，也是沟通的战术力。搭建品牌屋是品牌策略人的基本功，而搭建一个逻辑自洽、上下贯通的品牌屋，考验的是对品牌的全局把控能力。

## 九、案例：保时捷品牌屋拆解

### 战略层（品牌定位）
**兼具赛道基因与日常实用性的豪华跑车品牌**

### 心智层
- **目标用户**：高净值、追求极致驾驶体验且需要兼顾生活场景的精英群体
- **品牌口号**：Porsche. There is no substitute（保时捷 无可替代）
- **品牌调性**：性能驱动、创新卓越、激情与自由、豪华高级、标志性设计

### 论点层（核心价值）
- **功能价值**：赛道级操控性能与全天候日常驾驶的完美平衡
- **情感价值**：掌控感、激情、纯粹的驾驶乐趣
- **人设价值**：懂性能、懂品味、追求极致的人

### 论据层（RTB体系）
| RTB类型 | 具体内容 |
|---------|---------|
| 技术 | 水平对置发动机、后置后驱布局、PDK双离合变速箱 |
| 品牌资产 | 70+年赛车历史，超30000场赛事胜利（勒芒统治力） |
| 权威认证 | 纽北赛道圈速纪录、各类赛事冠军成绩 |
| 供应链 | 祖文豪森工厂手工与自动化结合的制造工艺 |

### 落地层（产品矩阵）
| 产品角色 | 车型 | 定位 |
|---------|------|------|
| 形象款 | 911 | 品牌图腾，灵魂代表 |
| 利润款 | Cayenne / Macan | 核心销量与营收 |
| 引流款 | 718 | 入门体验，拉新 |
| 战略款 | Taycan | 电动化布局，面向未来 |
| 补位款 | Macan EV / Cayenne Electric / Panamera | 填补细分市场，防守竞品 |

### 拆解要点
1. 911作为形象款不追求销量，但拉高整个品牌势能，让所有车型都受益于"保时捷=911级品质"的认知
2. Cayenne/Macan作为利润款贡献最大营收，但定位仍然回溯到"赛道基因+日常实用"的战略层
3. Taycan是战略款——不是当下最赚钱的，但解决"电动化时代保时捷还是不是保时捷"的问题
4. 整个产品矩阵从911到补位款，全部指向同一个品牌定位，没有稀释
