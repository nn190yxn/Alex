# KOL传播Brief模板：达人合作简报完整指南

## 概述

KOL传播Brief（创意简报）是品牌与达人合作的核心文档，用于清晰传递品牌诉求、创作标准与合作要求。一份有效的Brief能确保达人理解品牌信息，创作出符合品牌调性的内容，最终实现精准的用户触达。

## 一、Brief的核心价值

### 对品牌的价值

1. **统一创作方向**：让达人清晰知道“该说什么、怎么说”
2. **保障内容质量**：通过明确标准，避免无效返工
3. **提高沟通效率**：减少反复沟通的成本
4. **沉淀合作依据**：作为双方合作的正式文档依据

### 对达人的价值

1. **快速理解需求**：短时间内掌握合作核心信息
2. **获得创作灵感**：从Brief中获得内容方向指引
3. **明确创作边界**：知道什么是可以做的、什么不可以
4. **保护自身权益**：明确合作条款，保障权益

## 三、Brief撰写注意事项

### 注意事项一：语言通俗易懂

避免使用专业术语或内部用语，用目标用户和达人都能理解的语言表达。

❌ 不推荐：
```
“请在内容中体现产品的核心USP，通过差异化价值叙事建立品牌认知”
```

✅ 推荐：
```
“请在内容中提到产品的3个亮点，让粉丝知道这个产品好在哪儿”
```

### 注意事项二：内容精简

达人阅读Brief的时间有限，尽量将核心信息控制在3页以内。详细内容可以作为附件。

### 注意事项三：尊重达人风格

不同量级的达人需要不同的Brief：

| 达人类型 | Brief侧重 |
|----------|----------|
| 头部达人 | 提供产品核心信息，让其自由发挥专业性 |
| 腰部达人 | 提供具体的内容框架和方向 |
| 尾部达人 | 提供详细的脚本或模版 |

### 注意事项四：提供真实案例

用近期成功的爆款内容作为案例，比纯文字描述更有效。

## 四、Brief审核三不原则

完成Brief后，用以下原则做最后审核：

### 不讲废话

达人30秒内看不完背景介绍，就是失败。核心信息要前置。

### 不留疑义

- 卖点表达是否通俗易懂？
- 红线是否写成了具体动作？
- 时间节点是否清晰？

### 不设枷锁

哪怕你的脚本写得再精彩，也请加一句：“这只是参考，欢迎用你的风格打破它。”

## 结语

一份好的Brief是品牌与达人高效合作的基础。它不需要面面俱到，但要清晰传递核心信息，给达人足够的创作空间。记住Brief的核心原则：**说清楚要什么，给够空间让达人发挥，说清楚底线在哪里。**
