# 品牌资产评估

> 适用工具：数据分析工具、用户调研工具
> 适用行业：通用（餐饮/教培/美业）

---

## 一、品牌资产的核心概念

品牌资产是品牌名称赋予产品的附加价值，它超越产品本身的功能价值，影响消费者的选择和支付意愿。对于中小企业而言，评估品牌资产有助于：
- 明确品牌在市场中的位置
- 量化营销投入的回报
- 识别品牌建设的短板
- 指导战略决策与资源配置

---

## 二、品牌资产评估核心模型

### Aaker品牌资产五星模型

大卫·艾克提出的经典模型，包含五大维度：

| 维度 | 说明 | 评估要点 |
|------|------|----------|
| **品牌知名度** | 消费者对品牌的认知程度 | 无提示知名度/提示知名度/第一提及 |
| **品牌认知度** | 消费者对品牌品质/价值的了解 | 产品类别认知/质量认知/价值认知 |
| **品牌联想** | 消费者心中与品牌相关的印象 | 产品属性/利益/态度/情感 |
| **品牌忠诚度** | 消费者对品牌的偏好程度 | 重复购买意愿/推荐意愿/价格敏感度 |
| **其他资产** | 专利、商标、渠道关系等 | 知识产权/供应链/合作伙伴 |

### 中小企业简化评估框架

对于资源有限的中小企业，可采用简化版评估：

**核心四维指标：**

| 维度 | 评估问题 | 量化方法 |
|------|----------|----------|
| **认知度** | 目标人群中，知道我们品牌的人占多少？ | 抽样调研：100-200人 |
| **美誉度** | 知道的人中，对我们正面评价的占多少？ | 好评率/推荐意愿 |
| **忠诚度** | 购买过的人中，重复购买的占多少？ | 复购率/NPS值 |
| **溢价力** | 我们能否比竞品卖出更高价格？ | 竞品价格对比 |

## 三、关键评估指标详解

### 1. 品牌认知度（Brand Awareness）

**测量方法：**
- 无提示第一提及（Top of Mind）
- 提示后认知（Prompted Awareness）
- 品牌再认测试

**参考标准：**
| 认知水平 | 目标市场占比 | 评估结果 |
|----------|--------------|----------|
| 高 | >60% | 品牌具有较强认知优势 |
| 中 | 30%-60% | 需加强传播投入 |
| 低 | <30% | 认知建设是首要任务 |

### 2. 净推荐值（NPS）

**计算公式：**
```
NPS = 推荐者比例（9-10分）- 贬损者比例（0-6分）
```

**参考标准：**
| NPS值 | 品牌状态 | 建议动作 |
|-------|----------|----------|
| >70 | 卓越 | 维持并激励推荐 |
| 50-70 | 优秀 | 关注细节优化 |
| 30-50 | 良好 | 识别痛点并改进 |
| <30 | 一般 | 系统性提升体验 |

### 3. 品牌忠诚度指标

**核心指标：**
- **复购率**：同一客户首次购买后再次购买的比例
- **客户留存率**：在一段时间后仍活跃的客户比例
- **客户生命周期价值（LTV）**：客户全生命周期的总价值

**参考标准（零售/餐饮）：**
| 复购率 | 评估结果 |
|--------|----------|
| >50% | 优秀 |
| 30%-50% | 良好 |
| 10%-30% | 一般 |
| <10% | 需大幅改进 |

### 4. 品牌溢价能力

**评估方法：**
- 与竞品的价格对比
- 消费者调研：愿意为品牌多付多少钱？
- 促销活动敏感度：降价时销量是否明显上升？

## 四、品牌资产评估实操流程

### 第一步：建立评估基线

**数据收集来源：**
- 内部数据：销售记录、客服记录、退换货记录
- 用户调研：问卷调查、客户访谈
- 第三方数据：平台评价、行业报告

### 第二步：多维度打分

**10分制自评表：**

| 评估维度 | 评分（1-10） | 证据/说明 |
|----------|---------------|------------|
| 品牌知名度 | | |
| 品牌认知度 | | |
| 品牌联想力 | | |
| 品牌忠诚度 | | |
| 品牌溢价力 | | |
| 视觉识别度 | | |
| 传播渗透力 | | |
| 用户满意度 | | |

### 第三步：识别短板与机会

**雷达图分析：**
将各维度得分绘制成雷达图，识别：
- 明显短板（得分<6的维度）
- 相对优势（得分>8的维度）
- 改进优先级

### 第四步：制定提升计划

**SMART目标设定：**
- 具体（Specific）：明确要提升哪个维度
- 可衡量（Measurable）：设定量化目标
- 可实现（Achievable）：基于现有资源
- 相关（Relevant）：与业务目标关联
- 时限（Time-bound）：设定截止日期

### 专业深化

**行业数据基准：**

| 行业 | 优秀NPS | 平均NPS |
|------|---------|---------|
| 餐饮 | >60 | 40-50 |
| 教育培训 | >50 | 30-40 |
| 美妆/护肤 | >55 | 35-45 |
| 零售 | >45 | 30-40 |

**品牌资产评估频率建议：**
- 核心指标（好评率/NPS）：月度监测
- 综合评估：季度一次
- 深度调研：半年度/年度一次

**常见误区避坑：**
1. 只看销售数据，忽视认知/态度指标
2. 评估频率不固定，缺乏趋势对比
3. 有数据无行动，评估流于形式
4. 过度依赖单一指标，忽视综合评估
