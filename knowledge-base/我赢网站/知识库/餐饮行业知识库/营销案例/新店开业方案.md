## 模板1：社区小餐饮开业方案

### 具体内容

| 开业前3天 | 建微信群秒杀活动 | 提前锁客 |
| 开业前1天 | 发布朋友圈文案 | 提醒老客户 |

核心逻辑：低成本+高复购

| 会员绑定 | 扫码关注送饮品 | 沉淀用户 |

**三、商场店获客策略**

```
核心逻辑：借助商场流量+打造打卡点
```

| 渠道 | 具体做法 | 成本 |

### 专业深化

**行业数据基准**：

- **新店流量红利期**：平台新店加权7天，可带来3-5倍曝光提升
- **开业期获客成本**：行业均值约35元/新客（含优惠让利）
- **新店爬坡周期**：通常需要3-6个月达到稳定单量
- **开业期目标评分**：大众点评≥4.5分，美团≥4.8分
- **私域沉淀率**：开业期留存的顾客信息中，最终成为私域用户的比例约30-40%
- **开业期ROI基准**：优秀值≥3倍，合格值≥1.5倍

**专业方法论**：

**1. 新店开业倒计时执行表**
| 阶段 | 时间节点 | 核心任务 | 关键指标 |
|------|---------|---------|---------|
| 蓄水期 | 开业前15-30天 | 私域预热：建群、朋友圈预热 | 私域用户≥500人 |
| 预热期 | 开业前7-14天 | 达人探店、试吃活动 | 曝光内容≥10条 |
| 爆破期 | 开业前3天至开业7天 | 限量大促、排队效应 | 首日订单≥预期150% |
| 维稳期 | 开业8-30天 | 好评维护、差评处理 | 评分稳定在4.8+ |
| 沉淀期 | 开业31-90天 | 私域运营、会员转化 | 私域复购率≥25% |

**2. 开业获客成本测算公式**
```
获客成本 = (开业期营销总投入) / (开业期新增有效客户数)
有效客户定义：完成首单且有完整联系方式/加入私域

ROI = (开业期营收增量 - 开业期营销投入) / 开业期营销投入
目标：开业期ROI ≥ 1.5倍
```

**3. 私域沉淀"鱼塘模型"**
```
引流层（开业期）：低价尝鲜、免费试吃 → 首次到店
信任层（1-3个月）：会员权益、专属优惠 → 重复消费
裂变层（3个月后）：老带新奖励、拼团活动 → 口碑传播
```

**常见坑**：

1. **开业折扣"一放到底"**
   - 为什么是坑：开业后维持折扣导致顾客"等打折"，恢复正常价格后客流断崖
   - 正确做法：开业期分阶段回收优惠，第1周8折，第2周8.8折，第3周会员价，第4周恢复原价

2. **只顾引流不沉淀**
   - 为什么是坑：开业期引来大量顾客，但活动结束后都流失了
   - 正确做法：每个到店顾客都要留下联系方式（微信/电话），拉入私域群，为后续运营储备资产

3. **忽视差评处理**
   - 为什么是坑：开业期是评分定型的关键期，差评会严重影响后续流量
   - 正确做法：建立差评监控和2小时响应机制，诚恳道歉+补偿+私信回访

4. **达人探店"只看不发"**
   - 为什么是坑：花了大价钱请达人试吃，结果达人吃完没发内容
   - 正确做法：明确达人发布要求（文案+图片/视频+定位），签订合作协议，发布后结款

5. **开业期备货不足**
   - 为什么是坑：开业期订单量超出预期，但食材准备不足，频繁缺货导致差评
   - 正确做法：开业前按预期单量的150%备货，宁可剩货也不要缺货
