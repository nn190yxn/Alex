# 品项结构分析

> 适用工具：品项结构诊断
> 适用行业：美业（美容院、皮肤管理、美甲店、综合美业门店）

---

## 一、品项结构概述

### 品项三层结构

| 品项类型 | 定位 | 价格区间 | 特点 |
|---------|-----|---------|-----|
| 引流款 | 吸引新客、激活老客 | 0-199元 | 低门槛、高体验感、效果直观 |
| 利润款 | 门店核心盈利来源 | 200-1000元 | 受众广、复购率高、利润稳定 |
| 高端款 | 拔高客单天花板 | 1000元以上 | 抗衰、定制、锁定高净值客户 |

### 健康品项结构比例

| 品项类型 | 营收占比 | 项目数量占比 | 毛利率要求 |
|---------|---------|-------------|-----------|
| 引流款 | 15-20% | 20-30% | ≥30% |
| 利润款 | 50-60% | 40-50% | ≥65% |
| 高端款 | 25-35% | 20-30% | ≥75% |

## 二、品项结构分析方法

### 1. 营收结构分析

**分析维度**
- 各品项营收占比是否合理
- 引流款是否过低（获客难）
- 高端款是否过低（客单价上不去）

**健康标准**
```
引流款营收占比：15-20%
利润款营收占比：50-60%
高端款营收占比：25-35%
```

### 2. 项目数量分析

**分析维度**
- 各类型品项数量是否匹配
- 项目是否过于分散或过于集中
- 是否存在"僵尸项目"（3个月无人购买）

**健康标准**
```
引流款数量：3-5个
利润款数量：5-8个
高端款数量：3-5个
```

### 3. 复购率分析

**分析维度**
- 各品项的复购周期是否正常
- 哪些品项客户只体验一次就不来了
- 复购率低的品项原因是什么

**健康标准**
```
引流款月复购率：≥40%
利润款月复购率：≥50%
高端款月复购率：≥30%
```

### 4. 毛利率分析

**分析维度**
- 各品项毛利率是否达标
- 毛利率低的品项是否贡献足够客流
- 是否需要调整定价或成本

**健康标准**
```
引流款毛利率：≥30%
利润款毛利率：≥65%
高端款毛利率：≥75%
```

## 七、品项诊断结论

### 当前问题总结

1. 引流款数量不足，占比偏低
2. 利润款定价偏低，毛利率有提升空间
3. 高端款占比过高，客户分层不明显
4. 中间价格带（500-1000元）产品缺失

### 优化建议

1. 增加引流品项至5个，设计梯度价格
2. 利润款整体提价10-15%
3. 优化高端款，聚焦核心明星项目
4. 新增500-1000元中间价格带品项
5. 完善升单路径，实现客户自然流转

### 二、分析方法论

#### 品项结构健康度诊断矩阵

**四象限分析模型（基于营收贡献+毛利率）：**

```
                    毛利率高
                       ↑
                       |
              ★ 明星品项  │  常规品项
              (重点发展)   │  (维持优化)
      营收        ────────┼────────→
      贡献低                │
      低               │  问题品项  │  利润品项
                       │  (优化/淘汰)│  (稳定输出)
                       ↓
                    毛利率低
```

**各象限处理策略：**
- **明星品项（高营收+高毛利）**：重点发展，增加曝光和推荐
- **利润品项（低营收+高毛利）**：稳定输出，适度推广
- **常规品项（高营收+低毛利）**：优化成本或提升定价
- **问题品项（低营收+低毛利）**：分析原因，优化或淘汰

#### 项目淘汰决策标准

**僵尸项目识别标准（符合以下任一条件）：**
1. 连续3个月销量为0
2. 6个月平均月销量<3单
3. 毛利率<30%且无引流价值
4. 客户反馈差评率>15%

**淘汰决策流程：**
```
识别僵尸项目 → 分析淘汰原因 → 制定替代方案 → 通知老客户 → 正式下架
```

### 五、常见坑与避坑指南

**坑1：引流款占比过高**
- **表现**：引流款占营收40%以上
- **后果**：营收高但利润薄，难以支撑运营成本
- **数据**：引流款占比>25%的门店，平均利润率仅15%
- **避坑方法**：引流款严格控制在15-20%

**坑2：高端款定价过高**
- **表现**：盲目对标一线城市定价
- **后果**：当地消费能力支撑不了，销量惨淡
- **避坑方法**：定价需匹配当地消费水平，可参考竞品

**坑3：品项数量过多**
- **表现**：门店有50+品项，美容师记不住
- **后果**：推荐效率低，客户选择困难
- **数据**：品项超过30个，转化率下降30%
- **避坑方法**：保持20-25个核心品项，定期淘汰

**坑4：忽视品项更新**
- **表现**：2-3年不更新品项
- **后果**：客户审美疲劳，失去吸引力
- **避坑方法**：每季度推出1-2个新品，淘汰滞销品

**坑5：品项之间无关联**
- **表现**：品项孤立，客户难以升单
- **后果**：客户只消费单一项目，难以深度绑定
- **避坑方法**：设计品项升级路径，形成闭环

### 六、品项结构优化专项

#### 优化工具：品项健康度评分卡

| 评估维度 | 权重 | 评估标准 |
|---------|-----|---------|
| 营收贡献 | 30% | 占总营收比例 |
| 毛利率 | 25% | 是否达到品类要求 |
| 复购率 | 20% | 月复购率是否达标 |
| 客户满意度 | 15% | 客户评分是否≥4.5分 |
| 操作难度 | 10% | 是否容易被美容师掌握 |

**评分结果应用：**
- ≥80分：核心品项，重点推广
- 60-80分：常规品项，维持运营
- <60分：问题品项，需要优化或淘汰

#### 结构优化四步法

**Step 1：数据收集（1周）**
- 收集近3个月各品项销售数据
- 计算各品项营收占比、毛利率、复购率
- 识别僵尸项目和滞销品

**Step 2：结构分析（2天）**
- 绘制品项结构饼图
- 对标健康结构基准
- 识别偏离项和机会点

**Step 3：方案制定（3天）**
- 确定新增品项（1-2个）
- 确定优化品项（定价/组合）
- 确定淘汰品项（僵尸项目）

**Step 4：执行落地（1个月）**
- 完成品项调整上线
- 培训美容师新话术
- 跟踪数据验证效果
