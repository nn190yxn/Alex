> 来源：陈雯2026年3月培训课程 + 补充材料整合

---

## 文档说明

本文档是价格体系设置的"工具箱"——一套标准化、可复用的价格体系配置方案。

**使用场景：**
- 新品上架定价
- 活动价格设置
- 价格体系梳理
- 团队培训的标准SOP

**核心原理：**
- 价格体系四层级：POI常态价、小促价、大促价、会员价
- 三重锚定：非对称产品体系，破解"涨价即死"
- 直播价格定位：介于会员价与大促价之间

---

## 一、价格体系四层级

### 1.1 四层级定义

| 价格层级 | 定义 | 用途 | 典型折扣 |
|---------|------|------|---------|
| **POI常态价** | 日常门店价 | 门店销售基准 | 100%（基准） |
| **小促价** | 常规活动价 | 日常促销活动 | 8-9折 |
| **大促价** | 直播价/会员价 | 大型活动/直播 | 6-8折 |
| **会员价** | 最高优惠 | 会员专属 | 5-7折 |

### 1.2 价格层级关系

```
价格体系金字塔

     ┌─────────────┐
     │  POI常态价  │  ← 100%（最高）
     │   (日常)    │
     ├─────────────┤
     │   小促价    │  ← 80-90%
     │  (常规活动)  │
     ├─────────────┤
     │   大促价    │  ← 60-80%
     │ (直播/会员)  │
     ├─────────────┤
     │   会员价    │  ← 50-70%（最低）
     │  (最优惠)   │
     └─────────────┘
```

## 五、价格调整策略

### 5.1 涨价策略

| 阶段 | 价格策略 | 话术配合 |
|------|---------|---------|
| Day 1-5 | 258元（常态高价） | "这是我们正常的价格" |
| Day 6-11 | 248元（略微下调） | "最近做活动，稍微优惠一点" |
| Day 12 | 238元（直播最低） | "因为今天是直播大场，所以..." |
| Day 13-15 | 258元+定向券 | "恢复日常价，但还有直播专属券" |

### 5.2 避免"涨价即死"

| 策略 | 说明 | 状态 |
|------|------|------|
| 非对称产品 | 用不同产品替代，避免同产品直接涨价 | ☐ |
| 增量产品 | 推出新产品线，价格略高 | ☐ |
| 组合优化 | 组合产品替代单品涨价 | ☐ |
| 定向优惠 | 老客专属优惠，维持价格体系 | ☐ |
| 会员体系 | 会员价作为最低价，保护普通用户 | ☐ |

## 六、价格异常预警

### 6.1 预警信号

| 信号 | 原因 | 解决方案 |
|------|------|---------|
| 涨价后流量下降 | 价格涨幅过大 | 小幅多次涨价 |
| 涨价后转化下降 | 质价比不足 | 提升产品价值 |
| 竞品价格更低 | 竞品低价冲击 | 差异化竞争 |
| 核销率下降 | 优惠感知弱 | 加强核销引导 |

### 6.2 应对策略

| 场景 | 策略 |
|------|------|
| 竞品降价 | 强化服务/赠品，不直接价格战 |
| 转化下降 | 优化话术/增加赠品 |
| 核销下降 | 加强核销引导/延长核销期 |
| 库存积压 | 限时促销/组合销售 |
