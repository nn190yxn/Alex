# SOP表格体系与问卷工具总览

> **文档类型**：工具体系总览
> **核心目的**：梳理所有可用的表格化、问卷化工具，帮助运营者快速决策和执行
> **更新日期**：2026-03-31

---

## 一、为什么需要表格和问卷？

| 痛点 | 表格/问卷解决方案 | 效果 |
|------|------------------|------|
| **决策慢** | 决策类表格 → 一张表看清该做什么 | 决策时间缩短50% |
| **遗漏多** | 检查清单 → 照着勾选不漏项 | 遗漏率降低80% |
| **标准不一** | 评分表 → 统一评判标准 | 执行一致性提升70% |
| **复盘难** | 记录表 → 数据自动沉淀 | 复盘效率提升60% |

## 六、表格设计原则

### 6.1 好表格的标准

| 标准 | 说明 | 示例 |
|------|------|------|
| **一看就懂** | 表头清晰，不需要解释 | ✅ "播放量≥500为合格" |
| **一填就完** | 选项明确，不需要思考 | ✅ "是/否"、"A/B/C" |
| **一用就够** | 一个表格解决一个问题 | ✅ 大场检查清单解决开播准备 |
| **一存就查** | 数据可沉淀，历史可追溯 | ✅ 每次填写都有记录 |

### 6.2 表格设计禁忌

| 禁忌 | 问题 | 正确做法 |
|------|------|---------|
| **表格太复杂** | 填写时间超过5分钟 | 精简到核心项，控制在5分钟内 |
| **选项不明确** | 需要填写者自己判断 | 给明确选项或判断标准 |
| **没有判断标准** | 填了不知道怎么用 | 每项都有"合格/不合格"标准 |
| **没有后续动作** | 填了不知道下一步做什么 | 每项都有"如果不合格，则..." |

## 七、问卷设计原则

### 7.1 好问卷的标准

| 标准 | 说明 |
|------|------|
| **问题数量控制** | 核心问题≤10个，控制在3分钟内填完 |
| **选项互斥且穷尽** | 选项之间不重叠，覆盖所有情况 |
| **有明确的输出** | 填完问卷要有明确的结论或建议 |
| **可追溯可对比** | 不同时间填写可对比变化 |

### 7.2 问卷输出设计

```
问卷填完 → 自动生成结论 → 给出建议

示例：IP定位问卷
├─ Q1: 你的行业是？→ 餐饮
├─ Q2: 你的身份是？→ 老板
├─ Q3: 你的核心能力是？→ 运营+AI应用
├─ Q4: 你想赚谁的钱？→ 同城实体老板
├─ Q5: 你的变现方式是？→ 咨询+陪跑
│
└─ 【自动生成】
    ├─ IP定位：本地商业导师
    ├─ 目标人群：同城实体老板
    ├─ 内容方向：运营方法论+AI应用+商业认知
    └─ 变现路径：咨询→陪跑→培训→圈子
```
