# 短视频自检清单SOP

> 来源：陈雯2026年3月培训课程 + 补充材料整合
> 整理目标：短视频创作与发布全流程自检检查表
> 最新更新：2026-03-29

---

## 文档说明

本文档是短视频运营的"体检表"——一份从选题到发布再到复盘的全流程检查清单。

**使用场景：**
- 每次短视频创作前的选题核对
- 拍摄前的脚本检查
- 发布前的最终审核
- 发布后的数据监测
- 团队培训的标准SOP

**核心标准：** "2113544"标准
- 2个点赞：1个收藏：1个分享（互动配比）
- 2秒跳出率 < 40%
- 5秒完播率 > 40%
- 4分钟（长视频）或15秒（短视频）完整看完

## 一、选题自检（创作前）

### 1.1 选题来源检查

| 序号 | 检查项 | 标准 | 状态 |
|------|--------|------|------|
| 1.1.1 | 选题来源 | 竞品爆款/行业热点/用户痛点/节日节点 | ☐ |
| 1.1.2 | 选题库更新 | 每日更新选题库（10条/天） | ☐ |
| 1.1.3 | 近期已发检查 | 排除近期已发布选题，避免重复 | ☐ |
| 1.1.4 | 选题与客群匹配 | 符合目标客群（门店属地+人群画像） | ☐ |
| 1.1.5 | 选题时效性 | 热点类选题需在24-48小时内发布 | ☐ |

### 1.2 选题方向检查（按客群）

| 客群类型 | 占比 | 选题方向 | 状态 |
|---------|------|---------|------|
| 深度信任型 | 40-50% | 专业科普/品牌故事/用户案例/服务展示 | ☐ |
| 泛流量型 | 40-50% | 热点话题/搞笑内容/情感共鸣/生活方式 | ☐ |
| 行动型 | 10-20% | 促销信息/团购推荐/限时优惠/到店引导 | ☐ |

### 1.3 选题红线检查

| 序号 | 检查项 | 状态 |
|------|--------|------|
| 1.3.1 | 无违禁词（医美/极限词/虚假宣传） | ☐ |
| 1.3.2 | 无敏感话题（政治/宗教/争议事件） | ☐ |
| 1.3.3 | 无竞品负面信息（不攻击竞品） | ☐ |
| 1.3.4 | 无过度承诺（效果保证/成功率承诺） | ☐ |
| 1.3.5 | 无低俗内容（擦边/恶搞/博眼球） | ☐ |

## 二、脚本自检（拍摄前）

### 2.1 脚本结构检查

| 序号 | 检查项 | 标准 | 状态 |
|------|--------|------|------|
| 2.1.1 | 黄金3秒 | 前3秒必须有钩子（视觉/语言/悬念） | ☐ |
| 2.1.2 | 完播设计 | 每一个5秒都有小高潮或悬念 | ☐ |
| 2.1.3 | 核心信息 | 核心卖点不超过3个 | ☐ |
| 2.1.4 | 结尾引导 | 有明确的行动引导（关注/点赞/购买） | ☐ |
| 2.1.5 | 时长控制 | 短视频15-60秒，长视频3-5分钟 | ☐ |
