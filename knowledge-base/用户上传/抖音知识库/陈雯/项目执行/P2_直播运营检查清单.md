# P2_直播运营检查清单

## 组品逻辑检查（占直播运营成功的51%以上）

**核心原则：**
- [ ] 是否确定"卖给谁"再决定"卖什么"（人群思维）？
- [ ] 是否选择适合的组品公式（公式1/公式2）？
  - 公式1（产品丰富/大场）：秒杀品（福袋）+ 引流品 + 主推品 + 长尾品 + 利润品
  - 公式2（产品单一）：主推品 + 次推品 + 炮灰款 + 抽奖福袋/秒杀

**价格体系：**
- [ ] 是否定好了大促、小促、底价和POI常态价？
- [ ] 是否结合市场、竞对和溢价得分（IP可提供20%溢价）？
- [ ] 价格体系是否在线上、线下、私域和会员间统筹一致？

**选品建模：**
- [ ] 炮灰款是否满足三要素：
  - [ ] 价格虚高（明显高于主推品）
  - [ ] 有一定销量（营造"很多人买"的假象）
  - [ ] 配合话术（主播话术引导对比）
- [ ] 引流品是否满足红线：
  - [ ] 必须是搭售品
  - [ ] 严禁与主推品有任何程度的重叠
  - [ ] 前端可设置"限量"进行催单，但后台可实际"不限量"以维持转化

**商品"整容"（优化）：**
- [ ] 标题优化：是否将促销词（如买一送二、双11大促）前置？
- [ ] 货架排序优化：
  - [ ] 1-2号：放主推品（高曝光）
  - [ ] 3-4号：放锚点引流品（炮灰款）
  - [ ] 利润品：放最后
  - [ ] 福袋/秒杀品：放末位（如25号），**强迫顾客翻完整本货架**
- [ ] 福利搭配优化：
  - [ ] 是否配置高价值福袋（避免低价福袋）？
  - [ ] 是否配置不与主推品重叠的引流品？

**定价参考：**
- [ ] 是否充分利用"生意经"的行业概览功能？
- [ ] 是否分析不同城市的价格带分布？
- [ ] 是否寻找"低竞争、高GMV"的价格带？

---

## 开场定江山检查（前15-30分钟）

- [ ] 开播前15分钟**严禁开启全域推流**？
- [ ] 是否先用私域/鱼塘号密集成交高单价正价品？
- [ ] 是否强行冲高GPM，给系统喂"高客单成交"模型？
- [ ] 再开启全域投放？

**目的：** 防止流量"跑飞"，锁定精准人群

---

## 福袋设计检查

- [ ] 福袋设计是否满足"高价值+零边际成本"？
- [ ] 福袋价值是否中高且调性匹配（避免9.9元低价福袋）？
- [ ] 福袋是否强关联品类（餐饮/酒旅/服饰对应福袋）？
- [ ] 福袋投放节奏是否合理（每10-15分钟一轮，全场30+个）？
- [ ] 福袋份数是否合理（根据预估在线人数计算）？
- [ ] 福袋文字是否设置钩子（如"1号链接为什么比3号便宜很多"）？
- [ ] 福袋文字是否精准打标签（如"深圳亲子遛娃"）？

---

## 引流款设计检查

- [ ] 引流款是否有搭售关系？
- [ ] 是否避免降价主推品？
- [ ] 是否避免低价引流（破坏价格体系）？
- [ ] 是否设计有"搭售关系"的引流款？

**目的：** 做高成交密度，不稀释主推款心智

---

## 三道收割检查

- [ ] 三道收割的价格体系是否设计好了？
  - [ ] 第一道：直播当场收割（99元直播价）
  - [ ] 第二道：商城流量收割（直播后1-3天，109元日常价）
  - [ ] 第三道：定向发券（直播后第2-3天，低于直播价）
- [ ] 券叠加风险是否排查了（获客专享价+人群券禁止同开）？

---

## 直播间话术检查

- [ ] 每逢逼单，必讲"因果"？
- [ ] 每逢互动，不讲"因果"？
- [ ] 数字话术，是否讲"尾数"？
- [ ] 是否执行"三重福利"话术循环（3分钟一轮）？
- [ ] 福袋打标签话术是否引导评论区刷屏关键词？
- [ ] 促核销话术是否提醒用户预约核销？
- [ ] 应对截流/小蓝词话术是否准备？

---

## 画面确定性检查

- [ ] 贴片设计：屏幕上方是否固定展示核心卖点/价格？
- [ ] 道具展示：主播是否手持产品/样品展示？
- [ ] 背景布置：背景是否布置品牌场景/产品陈列？

---

## 排兵布阵检查

- [ ] 黄金时段（07:00-10:00 / 21:00-01:00）：是否安排逼单型/节奏型主播？
- [ ] 平播时段（10:00-21:00）：是否安排互动型/聊天型主播？

---

## 话术效果评估

- [ ] 3分钟循环完成率是否 >80%？
- [ ] 话术合规率是否 100%？
- [ ] 福袋中奖率是否 >5%？
- [ ] 逼单转化率是否 >10%？
- [ ] 核销率是否 >30%（餐饮）/ >50%（酒旅）？

---

## 组品运营黄金法则检查

**法则1：人群思维优先**
- [ ] 组品是否回归"人群思维"，先确定"卖给谁"，再决定"卖什么"？

**法则2：严禁盲目跟风**
- [ ] 是否根据自身库存和位置选择主品，而不是看别人卖什么就卖什么？

**法则3：价格体系一致性**
- [ ] 线上、线下、私域和会员价格是否在"一个盘子里"统筹考虑？

**法则4：炮灰款三要素**
- [ ] 炮灰款是否价格虚高 + 有一定销量 + 配合话术？

**法则5：引流品红线**
- [ ] 引流品是否是搭售品？
- [ ] 引流品是否严禁与主推品有任何程度的重叠？

**法则6：饥饿营销技巧**
- [ ] 引流品前端是否设置"限量"进行催单？
- [ ] 引流品后台是否实际"不限量"以维持转化？

---

## 福袋运营黄金法则检查

**法则1：高价值 ≠ 高成本**
- [ ] 福袋是否具备**高感知价值**？
- [ ] 餐饮行业是否选择小青龙（贵且少、吃不饱）而非正餐套餐？
- [ ] 酒旅行业是否选择行政海景房升房券而非普通房券？

**法则2：强关联品类**
- [ ] 福袋是否与行业强关联？
- [ ] 餐饮是否发美食福袋，酒旅是否发房券福袋，服饰是否发服装福袋？

**法则3：高频循环不断档**
- [ ] 是否每10-15分钟一轮福袋？
- [ ] 6小时直播是否至少30+个福袋？

**法则4：福袋文字钩子化**
- [ ] 是否利用文字"骗"点击？
- [ ] 是否使用"1号链接为什么比3号便宜很多"这类钩子？

**法则5：精准打标签**
- [ ] 福袋文字是否 = 精准关键词？
- [ ] 是否引导评论区刷屏 → 强行让系统识别直播间标签？

**法则6：严禁跨品类福袋**
- [ ] 建材直播间是否严禁发手机福袋？
- [ ] 餐饮直播间是否严禁发现金福袋？

---

## 客资行业私信留资检查

- [ ] A1：是否老板号发布行业资讯/攻略（蓝V+DO+）？
- [ ] A2：是否人设背书/成功案例（真人出镜IP）？
- [ ] A3：是否营销种草+门店浏览（本地推M3）？
- [ ] 私信留资：是否精准收割（触达过才更易触达）？
- [ ] 即使已留联系方式，是否也引导团购核销？
- [ ] 核销率是否30%+保账户权重？

---

## 特别警示

**避免福袋"毁号"：**
- [ ] 建材行业是否避免发新款手机、现金、抱枕？
- [ ] 移动通讯是否避免发美妆用品、食品？
- [ ] 是否防止全平台泛人群涌入，导致画像跑偏？

**避免低价福袋毁号：**
- [ ] 是否避免9.9元低价福袋？
- [ ] 是否使用价格中高、调性匹配的福袋？
- [ ] 是否防止吸引大量不精准的"羊毛党"泛人群？
