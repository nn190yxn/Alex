## 一、销售话术策略

### 1.1 给消费者台阶下的原则

**核心逻辑**：销售话术要遵循给消费者台阶下的原则，从传播学和营销学角度看，这是为消费者提供心理安慰。

**案例**：
- 国货营销强调"支持国货"，让消费者感觉购买国货并非因为买不起高端产品
- 销售中可利用大促让消费者觉得占便宜且心安理得，如强调"一个月就这一次大促"

**实际应用**：
- 在销售218元产品时，告知消费者这是大促活动，让他们觉得自己是在占便宜，而非因为经济原因选择该产品

### 1.2 逼单话术要点

**核心规则**：
1. 逼单时要讲因果关系（每逢逼单必讲因果）
2. 引导关注的话术**不能**出现"因为""既然""所以""才能"等因果词汇（每逢互动不讲因果）

**正确示例**：
- ❌ 错误："想要领我们福袋提高中奖的概率，请关注一下"
- ✅ 正确："今天我们会把福利品秒单、福袋秒杀和引流品融合到一套话术里"

## 二、福袋运营

### 2.1 福袋的六重作用

| 作用 | 说明 | 案例 |
|------|------|------|
| 拉评论 | 增加互动数据 | - |
| 拉停留 | 延长观看时长 | - |
| 引导关注 | 提升粉丝量 | - |
| 搞分享 | 触发分享行为 | - |
| 打标签 | 为直播间打上品类标签 | "深圳亲子遛娃" |
| 提高点击率 | 用好奇心钩子吸引点击 | "1号链接怎么比3号便宜很多" |

### 2.2 福袋投放原则

**原则1：定向精准人群**
- 避免过于泛化
- 案例：移动通讯服务商直播放华为Pro Max 40做福袋 → 吸引全人类点击 → 人群画像不精准 → 难以搂出精准成交模型

**原则2：遵循高价值原则**
- 福袋投放要遵循课件中的高价值原则
- 确保福袋对目标人群有吸引力

### 2.3 福袋话术与节奏

**三重福利话术结构**：
```
第一重：福袋福利
第二重：引流品
第三重：主推链接
```

**话术示例**：
- 开场告知观众福袋福利，如"328双人的游戏演出票，现在仅需48元"

**福袋节奏控制**：
- 一个福袋15分钟放一个新的
- 每轮循环要在3分钟之内搞定
- 在线人数越高，循环越短
- 主播可通过训练形成肌肉记忆，控制话术节奏

## 三、直播间运营

### 3.1 直播间停留原理

**水流模型**：
```
      进水口（进线人数）
           ↓
  ┌──────────────┐
  │   中间水位线   │ = 直播间停留人数
  │  （停留时长）   │
  └──────────────┘
           ↑
      出水口（出线人数）
```

- 进水水流 > 出水水流 → 水位线上升 → 停留人数增加
- 进水水流 < 出水水流 → 水位线下降 → 停留人数减少

### 3.2 浅层数据与深层数据

| 数据类型 | 指标 | 作用 |
|---------|------|------|
| 浅层数据 | 评论、点赞、分享、停留时长 | 带来流量和流数 |
| 深层数据 | 商品点击率、转化率、成交密度 | 带来人群精准度 |

**核心原则**：两者共同构成完美直播间

### 3.3 观看模型与成交模型

**继承关系原则**：
- 直播间应追求观看模型与成交模型的继承关系
- 避免追求绝对精准

**案例：北京故宫直播**
- 观看模型：全国中老年群体，热爱历史、爱听书
- 交付模型：从这个观看模型中可漏出适合销售保健品等产品的成交人群

**案例：旅行社转型**
- 某徒弟之前卖一日游，直播间1500人在线，最高业绩2万，平均3000元
- 转型卖中老年保健品后，盈利模式改善
- **核心洞察**：要从人群思维出发，而非从品类出发进行直播销售

### 3.4 福袋对直播间的影响

**控制流量**：
- 福袋可控制直播间的进线人数和停留时长
- 使进线人数大于出线人数，提高直播间流量
- 案例：开场发福袋份数多，可吸引观众停留，提高浅层数据算法

**赛马优势**：
- 有福袋的直播间在赛马数据上全面领先
- 能获得更多推流，提高直播间在线人数
- 对比刚开播时有/无福袋的直播间：
  - 有福袋：开口小、流失少、点赞/评论等行为决定下一波推流
  - 无福袋：难破层级

### 3.5 三重福利话术循环

**话术结构**：
```
福袋 → 引流品 → 主推链接 → 循环
```

**操作要点**：
- 开场发福袋拉数据
- 按一重福利福袋、二重福利引流品、三重福利主推链接循环
- 根据在线人数调整商品数量
- 控制进线大于出线，使在线人数增长
- 话术循环3分钟内完成
- 逼单与答疑结合
- 通过练习形成肌肉记忆，简单易落地

## 四、主播管理

### 4.1 主播能力评定

**四个维度**：

| 维度 | 考核内容 | 说明 |
|------|---------|------|
| 表现力 | 对话感、人设 | - |
| 洞察力 | 洞察人性、产品痛点 | - |
| 逻辑能力 | 话术说服能力、框架、节奏、应变能力 | 顶级逻辑能力体现为应变能力 |
| 专业能力 | 行业品类的专业度 | - |

**主播类型划分**：
- **互动型**：表现力强、逻辑能力弱
- **逼单型**：洞察力和逻辑能力强
- **聊天型**：...

### 4.2 主播排兵布阵

**黄金时段**：
- 最佳直播时间：上午7点到10点、晚上9点到半夜1点
- 次选时间：中午11点到下午1:30、晚上17点到20点

**主播安排**：
```
开场（7-10点）：逼单型或节奏型主播
中段（10-13点）：平播型或互动型主播
晚间启动（17-20点）：逼单型或节奏型主播
深夜（20-24点）：平播型或互动型主播
```

**优势**：
- 降低人力成本
- 提高直播效率

## 五、短视频运营

### 5.1 短视频数据指标

**2113544标准**（非卖货类内容视频）：
```
2个点赞 = 1个收藏 = 1个分享
点赞率：3%
综合互动率：5%
2秒跳出率：<40%（优秀：<25%）
5秒完播率：>40%（优秀：>60%）
```

**流数判断**：
- 2小时播放量过3000 → 15天总流量大概率能冲到5万以上
- 2小时播放量500 → 不投流情况下最终播放量几千到一两万

### 5.2 短视频投流策略

**追投判断**：
- 白色锚点视频追投看ROI
  - ROI能一直稳定 → 继续追投
  - ROI下降 → 停止追投
- 判断人群是否被稀释：计算点赞率变化
  - 点赞率下滑 → 人群跑歪 → 停止追投

**限流判断**：
| 判断方法 | 说明 |
|---------|------|
| 审核时间 | 过长可能触发风控 |
| 能否投抖加 | 不能投抖加说明视频严重违规 |
| 推荐流占比 | 70%以下可能限流，90%以上大概率会爆 |

## 六、搜索截流

### 6.1 小蓝词截流原理

**概念解释**：
- 小蓝词截流是指在竞品视频中出现自己品牌的搜索词
- 将竞品视频的精准人群引到自己的搜索

**案例**：
- 河南博物馆视频评论区提到"三星堆博物馆更好玩"
- 引发人们搜索"三星堆"
- 实现搜索截流

**操作方法**：
1. 利用鱼塘号监控竞品
2. 找到潜力视频
3. 在视频评论区和搜索框操作
   - 如在竞品视频搜索框搜索自己品牌
   - 一个号多次搜索，然后在评论区留言

### 6.2 截流时机

**最佳时机**：
- 截流最佳时间是在竞品视频播放量几千、点赞不过百时
- 此时视频有火爆潜力，容易吸引后续观众搜索自己品牌

**案例**：
- 某漂流服务商通过一两百号人专门截流
- 在竞品视频中操作，吸引观众搜索自己品牌

## 七、POI热度与达人筛选

### 7.1 POI热度

**热度计算**：
- POI热度可通过挂载地理位置的视频加热
- 包括消费者、蓝V号、达人发布的视频

**案例**：
- 杭州西湖亚朵酒店虽不上团购，但因为口广场有游客打卡，热度排名靠前

**营销案例**：
- 景区、餐厅等可利用UGC视频提高POI热度
- 江苏淮安西游乐园通过游客自拍定位和打造NPC IP吸引流量

### 7.2 达人筛选

**综合指标**：
| 指标 | 说明 |
|------|------|
| 粉丝质量 | 粉丝不是买的 |
| 客单价 | - |
| 下单用户比例 | 下单用户有5%来自粉丝可算有IP |
| 锚点点击 | 不能只看单一指标，要结合其他数据 |
| 稿均点赞 | - |
| 稿均分享 | - |
| GPM | - |

**案例分析**：
- 通过分析不同达人的数据（点赞率、分享率、GPM等），判断达人是否靠谱
- 数据异常的达人要谨慎考虑：
  - 点赞率过高或过低
  - 分享量虚高
  - 可能存在问题
