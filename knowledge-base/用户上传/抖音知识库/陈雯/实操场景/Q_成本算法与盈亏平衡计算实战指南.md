## 二、实体门店成本核算

### 2.1 成本四分类体系

| 成本类型 | 包含内容 | 特点 | 计算方式 |
|---------|---------|------|---------|
| **① 固定成本** | 房租、水电物业、基础工资 | 不随产量变化 | 月度固定支出 |
| **② 商品成本** | 食材、原材料、包装 | 随产量变化 | 销售额 × 成本率 |
| **③ 销售成本** | 销售提成、配送费 | 与销售相关 | 销售额 × 提成率 |
| **④ 营销成本** | 推广费、平台扣佣 | 有固定点数和固定费用两种形式 | 固定费用 或 销售额 × 点数 |

### 2.2 盈亏平衡点计算

#### 场景A：老店（无一次性投入）

```
盈亏平衡点 = (固定成本 + 销售成本) ÷ 毛利率
```

**【案例1：奶茶店盈亏平衡测算】**

| 项目 | 数据 |
|------|------|
| 月固定成本 | 17,500元（房租12,000 + 水电物业2,500 + 基础工资3,000） |
| 月销售成本 | 5,000元（配送费、包装等） |
| 毛利率 | 80%（奶茶行业典型值） |
| **计算** | (17,500 + 5,000) ÷ 0.8 = **28,125元/月** |
| **结论** | 每月营业额需达到28,125元才能保本 |

**验证计算**：
- 月营业额28,125元
- 扣商品成本(20%)：28,125 × 0.2 = 5,625元
- 扣固定成本：17,500元
- 扣销售成本：5,000元
- **利润 = 28,125 - 5,625 - 17,500 - 5,000 = 0元** ✅

---

#### 场景B：新店（含一次性投入）

```
盈亏平衡点 = (固定成本 + 销售成本 + 一次性成本月度平摊) ÷ 毛利率
```

**【案例2：新开加盟店成本核算】**

| 项目 | 数据 |
|------|------|
| 加盟费 + 装修费 | 30万元（一次性投入） |
| 预期回本周期 | 6个月 |
| 月度平摊成本 | 30万 ÷ 6 = 50,000元/月 |
| 月固定成本 | 17,500元 |
| 月销售成本 | 5,000元 |
| 毛利率 | 80% |
| **计算** | (17,500 + 5,000 + 50,000) ÷ 0.8 = **90,625元/月** |
| **结论** | 新店每月营业额需达到90,625元才能保本 |

**与老店对比**：
- 老店保本：28,125元/月
- 新店保本：90,625元/月
- **差距：3.2倍**（一次性投入导致）

### 2.3 成本控制基准（健康标准）

| 成本类型 | 健康占比 | 警戒线 | 超标风险 |
|---------|---------|--------|---------|
| **房租成本** | 5%-15% | >20% | 现金流压力大 |
| **人力成本** | 15%-20% | >25% | 人效低，需优化 |
| **水电杂费** | 2%-5% | >8% | 浪费严重 |
| **营销成本** | 行业差异大 | >毛利30% | 获客成本过高 |

**快速自检表**：

```
✅ 房租 ÷ 月营业额 = ____%  （目标：5%-15%）
✅ 人力 ÷ 月营业额 = ____%  （目标：15%-20%）
✅ 水电 ÷ 月营业额 = ____%  （目标：2%-5%）
```

## 三、抖音投流成本核算

### 3.1 官方算法（有漏洞⚠️）

```
保本ROI = 1 ÷ (毛利率 × 核销率)
```

**问题**：未考虑以下实际成本：
1. 平台扣佣（约4%-7.5%）
2. 服务商/达人抽佣（约5%-10%）
3. 其他营销费用（约5%-10%）

### 3.2 改进算法（实际应用版）

```
保本ROI = 1 ÷ [(毛利率 - 各方抽佣比例 - 其他营销花费比例) × 核销率]
```

**【案例3：抖音投流亏损复盘】**

| 项目 | 数据 |
|------|------|
| 毛利率 | 40% |
| 核销率 | 45% |
| 广告费投入 | 10万元 |

**【错误计算】使用官方算法**：
- 保本ROI = 1 ÷ (0.4 × 0.45) = **5.55**
- 应达到GMV = 10万 × 5.55 = **55.5万**

**【正确核算】实际成本扣除**：

| 扣除项 | 计算方式 | 金额 |
|--------|---------|------|
| 核销GMV | 55.5万 × 0.45 | 24.975万 |
| 扣商品成本(60%) | 24.975万 × 0.6 | 14.985万 |
| 扣平台抽佣(4%) | 24.975万 × 0.04 | 0.999万 |
| 扣服务商抽佣(5%) | 24.975万 × 0.05 | 1.249万 |
| 扣营销费用(5%) | 24.975万 × 0.05 | 1.249万 |
| 扣广告费投入 | - | 10万 |
| **实际利润** | 24.975 - 14.985 - 0.999 - 1.249 - 1.249 - 10 | **-3.5万元** |

**结论**：按官方算法投流10万，实际**亏损3.5万元**！

### 3.3 改进版算法应用

**条件设定**：
- 毛利率：40%
- 平台抽佣：4%
- 服务商抽佣：5%
- 营销费用：5%
- 核销率：45%

**计算**：
```
保本ROI = 1 ÷ [(0.4 - 0.04 - 0.05 - 0.05) × 0.45]
       = 1 ÷ [0.26 × 0.45]
       = 1 ÷ 0.117
       = 8.55
```

**正确目标GMV** = 10万 × 8.55 = **85.5万**（而非55.5万）

## 四、客资行业成本核算

### 4.1 客资行业特殊性

| 特殊性 | 说明 |
|--------|------|
| **核心考核指标** | 人数（线索量）而非GMV |
| **转化链路长** | 获客→到店→升单→复购 |
| **客单价高** | 升单客单价通常是引流品10倍以上 |
| **决策周期长** | 需要信任建立和多次触达 |

### 4.2 线索GMV计算公式

```
线索GMV = 抖音获客数 × 到店率 × 平均升单转化率 × 平均客单价
```

**【案例：教培行业线索GMV计算】**

| 项目 | 数据 |
|------|------|
| 月抖音获客数 | 500人 |
| 到店率 | 40%（200人实际到店） |
| 升单转化率 | 25%（50人购买正价课） |
| 平均升单客单价 | 3,000元 |
| **线索GMV** | 500 × 0.4 × 0.25 × 3,000 = **150,000元** |

### 4.3 线索成本保本线

```
线索成本保本线 = 到店率 × 平均升单客单价 × 毛利率
```

**【案例：教培行业线索成本保本线】**

| 项目 | 数据 |
|------|------|
| 到店率 | 40% |
| 平均升单客单价 | 3,000元 |
| 毛利率 | 70% |
| **线索成本保本线** | 0.4 × 3,000 × 0.7 = **840元/条** |

**应用场景**：
- 如果投流获取一条线索成本 > 840元 → **亏损**
- 如果投流获取一条线索成本 < 840元 → **盈利**

### 4.4 不同引流方案对比

| 引流方案 | 前端价格 | 到店率 | 升单转化率 | 客单价 | 线索成本保本线 |
|---------|---------|--------|-----------|--------|---------------|
| **低价引流** | 9.9元 | 较低(20%-30%) | 较低(10%-15%) | 较低 | 约160元 |
| **正价引流** | 188元 | 较高(40%-60%) | 较高(20%-30%) | 较高 | 约200元+ |

**结论**：低价引流看似门槛低，但实际转化链路更难，综合成本不一定更低。

## 五、自运营成本优势

### 5.1 年框免佣红利

| 项目 | 普通商家 | 年框商家 |
|------|---------|---------|
| 各平台抽佣 | 7.5个点 | 7.5个点 |
| 年框免佣 | - | **-2.5个点** |
| 实际抽佣 | 7.5% | **5%** |

**ROI影响**：
- 原本每投10万需回100万（ROI=10）
- 现在每投10万只需回60万（ROI=6）
- **目标达成难度降低40%**

### 5.2 自运营vs服务商对比

| 维度 | 自运营 | 服务商代运营 |
|------|--------|-------------|
| **成本** | 无额外抽佣 | 5%-10%抽佣 |
| **灵活性** | 高，随时调整 | 低，需沟通 |
| **专业度** | 需培养 | 成熟团队 |
| **适合场景** | 日常运营 | 大节点专项 |

**建议策略**：
- **日常运营**：自运营为主
- **大节点**：专项服务商配合
- **性价比**：提高利润空间

## 七、避坑指南

### 7.1 常见错误

| 错误类型 | 表现 | 后果 |
|---------|------|------|
| **只看官方ROI** | 按5.55投流 | 实际亏损 |
| **忽略核销率** | 按GMV算利润 | 现金流断裂 |
| **成本分类不清** | 固定成本当变动成本 | 决策失误 |
| **不计算平摊** | 新店按老店算 | 目标过低 |

### 7.2 正确做法

| 场景 | 正确做法 |
|------|---------|
| **新店开业** | 必须计算一次性投入平摊 |
| **投流决策** | 使用改进版ROI算法 |
| **客资行业** | 计算线索成本保本线 |
| **长期运营** | 签年框免佣降低成本 |
