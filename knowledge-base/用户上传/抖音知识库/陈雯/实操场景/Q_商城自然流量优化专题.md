# Q_商城自然流量优化专题

> 实操场景 · 问题轴
> 如何利用GPM指标优化商城的自然流量排序
> 来源：陈雯2026年3月补充资料（2026-03-28）
> 最后更新：2026-03-28

---

## 问题

如何利用GPM指标优化商城的自然流量排序？

---

## 答案

### 一、核心排序逻辑转变

**从"成交密度"转向"GPM"**

- 早期算法：更看重成交密度（单量），导致"九块九低价打法"盛行
- 2026年商城排序：GPM权重凌驾于单纯订单量之上

**排序优先级**：
```
高A人群/铁粉+本地推 > 近期动销 > 订单量 > 核销GPM > 点击转化率
```

**效率为王**：GPM=10000的商家排名远高于GPM=1000的商家（同样推1000人）

---

### 二、提高GPM的两大核心因子

**因子一：人群精准度（第一优先级）**

- GPM高低首先取决于人群是否匹配
- 通过新鲜A3/A4召回，转化率远高于泛人群 → 天然抬高GPM
- 高A用户产生点击/购买 → 系统判定链接高效 → 同城/团购频道更高排序

**因子二：成交规模与客单价**

- 摒弃低价策略：低客单价天然限制GPM上限
- 2026年趋势：**"正价链接"**
- 示例：99元5节私教课 > 1元体验课
  - 单量可能减少
  - 但筛选掉羊毛党
  - 总体GPM大幅上涨
  - 获得更靠前货架排名

---

### 三、优化商城排序的实操动作

**动作一：直播后长尾红利**
- 时机：大场后1-3天
- 操作：商城POI价格与直播间拉齐（或使用获客专享价）
- 效果：显示"近30天历史最低"或"直播间同价"标签 → 极大刺激点击率和转化率 → 短时间冲高GPM → 占据频道首页位置

**动作二：关注"核销GPM"**
- 2026年新增核销GPM考核
- 只卖不核销 → 核销率低 → 综合得分下滑 → 商城排名30天后快速下滑
- 餐饮/洗浴行业：核销率维持40%以上保排序权重

**动作三：三池融合联动**
- 通过本地推（M3）带动商城自然流（M2）
- 形成排序提升的良性循环

**动作四：营业时间技巧**
- 商城/搜索过滤非营业时间门店
- 客资行业可改为24小时营业（配合AI客服）
- 同行关店后的深夜时段：竞争缺位 → 精准转化维持高GPM → 白天主时段排名也更好
