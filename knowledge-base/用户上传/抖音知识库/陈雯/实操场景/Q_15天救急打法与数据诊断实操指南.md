## 一、问题诊断框架

### 1.1 核心诊断原则
**"真正的运营，一定要先知道生的什么病，这叫对症下药"**

### 1.2 常见问题类型
| 问题类型 | 典型表现 | 核心原因 |
|---------|---------|---------|
| 业绩下滑 | 国庆期间一周业绩2.6万，比上一周掉一半 | 人群资产消耗完 |
| 流量下降 | 整体营业额下滑、流量下降 | 精准人群消耗完 |
| 成交掉量 | 商城和搜索的精准成交掉得最厉害 | 最近努力的人群为水A3 |
| 消耗不出 | 本地推消耗不出或消耗下降 | 素材衰退和人群质量问题 |

### 1.3 数据对比诊断法
- **竞争对手对比**：计算竞争对手5A数值，了解行业水平
- **自身历史对比**：对比不同时间段数据，发现趋势变化
- **同行对比**：对比同行数据，发现自身问题

## 二、15天救急打法全流程

### 2.1 第一阶段：测试与诊断（第1-3天）

#### 2.1.1 测试目的
- 确定系统对该户的ROI定价
- 排查问题原因（行业限流、电商抢量、同行抢量等）
- 确定问题为素材衰退和人群质量问题

#### 2.1.2 测试方法
```markdown
测试步骤：
1. 选择自动出价，全部智能且自动出价将权益托付给系统
2. 分别在工作日和周末进行测试
3. 观察ROI的波动，确定系统对账户的定价
4. 若测试能消耗出，则排除行业限流、电商抢量、同行抢量、地区没人群等原因
```

#### 2.1.3 测试预算
- **测试金额**：500元
- **测试周期**：3天
- **测试目标**：确定ROI锚定点

### 2.2 第二阶段：制定计划（第4-5天）

#### 2.2.1 计划制定原则
- 基于测试结果制定
- 针对性强
- 可执行性强

#### 2.2.2 具体计划内容
```markdown
1. 让该户掏500块钱做测试
2. 勾选最近5条视频进行抖加投放
3. 投播放量和主页浏览
4. 选择泛流量视频
5. 扩大人群范围，不关心转粉率
6. 以打成本地推人群资产为目标
```

### 2.3 第三阶段：执行与调整（第6-12天）

#### 2.3.1 执行要点
- **短视频发布**：拍摄并发布视频
- **抖加投放**：勾选最近5条白色视频投抖加
- **人群构建**：投播放量和主页浏览，将人群打成本地推的A1A2
- **人群范围**：人群勾选放到全部，控制在半到20公里
- **本地推出价测试**：同时进行本地推出价测试

#### 2.3.2 数据监控
- **每日监控**：消耗情况、ROI变化、成交数据
- **关键指标**：ROI、GMV、消耗速度
- **调整依据**：根据数据变化及时调整策略

### 2.4 第四阶段：复盘与优化（第13-15天）

#### 2.4.1 复盘要点
- **数据复盘**：分析消耗和ROI数据
- **问题诊断**：确定旧素材竞争力弱、新素材跑不出消耗的结论
- **决策制定**：决定启动新一轮循环、关停旧任务

#### 2.4.2 优化策略
```markdown
优化方向：
1. 启动新一轮短视频白色绿色锚点种草 - 直播割草 - 门店权益的新循环
2. 关停旧任务，避免资源浪费
3. 根据复盘结果调整下一阶段策略
```

## 三、关键操作要点

### 3.1 人群优惠券使用策略

#### 3.1.1 券的本质
- **让强者更强**：运营程度好时，人群优惠券能发挥强大作用
- **运营差时发不出**：券可能发不出去，因为券的分发需先保证触达用户

#### 3.1.2 券推一体概念
- **POI端虚价**：未来POI端看到的是虚价
- **券推一体真实价**：券推一体（人群优惠券加本地推）看到的才是真实价格

#### 3.1.3 人群分层运营
| 人群资产规模 | 运营策略 | 说明 |
|------------|---------|------|
| 100万以下 | 只圈不推 | 用门店全域替代本地推 |
| 100-500万 | 尝试混合投放 | 将自己的人群包与行业大包混合投放 |
| 500万以上 | 本地推投放 | 可考虑用本地推投放，先投门店浏览 |

### 3.2 行业人群包创建方法

#### 3.2.1 美发店行业包案例
```markdown
创建步骤：
1. 基础属性：女性、18-24岁年龄段
2. 地域选择：若不是全国连锁可选择所在省份
3. 消费习惯：
   - 美食：奶茶、自助餐、烤肉等
   - 丽人：美甲、美睫、美容美体等
4. 相关品类：运动健身、购物等
```

#### 3.2.2 素材选择原则
- **根据人群理解**：选择能拉近与同行精准女性客户信任的素材
- **信任背书**：考虑自身信任背书、客单价、服务理念等因素
- **套餐优势**：选择能显示套餐优势的素材

### 3.3 本地推投流优化

#### 3.3.1 投流质量判断
- **卡片成交占比**：卡片成交占比高意味着投到的客人更精准
- **ROI提升逻辑**：核心是增加人群资产中的增A3、增A4和增A5

#### 3.3.2 预算调整策略
```markdown
调整步骤：
1. 当出现投10万和20万成交相同的情况，说明精准人群消耗完
2. 先降预算，先从10万砍到12万测试ROI和GMV
3. 若ROI能保住，可逐步增加预算，直到消耗下降则停止增加
4. 可通过发布行业项视频等方式洗出精准人群，再重新投全域
```

#### 3.3.3 自然流与预算调控
- **自然流量过高判断**：当自然流量成交占比过高时
- **调整策略**：适当降低本地推预算，观察数据变化
- **恢复时机**：当自然流缩到30%以下时，恢复预算

## 四、数据诊断方法论

### 4.1 核销率深度分析

#### 4.1.1 低核销率原因
1. **冲动消费**：直播间场景易导致消费者冲动消费，第二天清醒后可能退款
2. **同行截流**：直播后人群资产暴涨，易触达同行，若同行采取截流措施

#### 4.1.2 提升核销率方法
- **根本方法**：提升商城流量和搜索流的精准人群
- **治标方法**：大厂流量停播、发促核销短视频、开核销有礼功能
- **价格优惠**：价格优惠也能提高核销率

### 4.2 流量与成交占比分析

#### 4.2.1 健康模型标准
| 流量类型 | 流量占比 | 成交占比 |
|---------|---------|---------|
| 推荐流 | 70%-90% | ≤60% |
| 商城和搜索 | 10%-20% | ≥60% |

#### 4.2.2 优秀模型
- **推荐流成交**：40%
- **商城和搜索成交**：60%

### 4.3 搜索成交分析

#### 4.3.1 搜索类型分类
- **种草搜**：用户在搜索前14天内看过视频直播、详情页或商品页后进行搜索
- **自然搜**：用户14天内未看任何相关内容直接搜索

#### 4.3.2 搜索下滑诊断
| 搜索类型 | 下滑周期 | 可能原因 |
|---------|---------|---------|
| 自然搜 | 长周期 | 品牌力问题 |
| 自然搜 | 短周期 | 老顾客吃腻 |
| 种草搜 | 不增长 | 投流、品宣、老板IP或种草达人投放效果不佳 |

### 4.4 门店页数据分析

#### 4.4.1 关键指标
- **门店页访问人数**
- **成交转化率**

#### 4.4.2 判断逻辑
| 访问人数 | 转化率 | 人群判断 | 运营建议 |
|---------|-------|---------|---------|
| 增长 | 稳定或微降 | 精准 | 可考虑收割 |
| 高 | 低 | 泛 | 不能收割 |
| 大涨 | 微掉 | 精准 | 可进行收割 |

#### 4.4.3 流量来源模型
- **最优方案**：推荐排第一，搜索排第二，团购第三，其他第四（微付费天花板）
- **重付费打法**：其他排第一或第二，推荐排第二，搜索排第三

## 五、实操案例

### 5.1 案例一：某户10月业绩调整

#### 5.1.1 问题表现
- 10月份业绩下滑
- 国庆期间一周业绩2.6万，比上一周掉一半
- 到14号半个月业绩与9月份相比腰斩

#### 5.1.2 问题诊断
- 人群资产消耗完
- 流量和成交下降
- 尤其是商城和搜索的精准成交掉得最厉害
- 最近努力的人群为水A3，没有带来业绩转化

#### 5.1.3 解决方案
1. **测试阶段**：通过自动出价和智能选择素材，在工作日和周末分别测试
2. **诊断阶段**：测试发现ROI从25掉到15-19，确定问题为素材衰退和人群质量问题
3. **执行阶段**：制定具体计划，让该户掏500元做测试，权益全部交给智能
4. **调整阶段**：拍摄并发布视频，勾选最近5条白色视频投抖加

#### 5.1.4 效果展示
- **调整时间**：10月16日接手调整
- **调整效果**：15天效果显著，业绩先翻两倍再翻两倍共四倍
- **最终业绩**：上半月达10万
- **花费情况**：未做扫码、小卡，真实成交2600，门店权益花1500，ROI为20

### 5.2 案例二：直播带货运营

#### 5.2.1 选品策略
- **优先选择**：有存量且销量不错的旧链接产品
- **价格调整**：改降价格销售
- **避免使用**：0链接销量产品，因链接会自带人群

#### 5.2.2 营销流程
1. **短视频发布**：发布绿色毛领相关内容，以"家人福利"为主题
2. **引导下单**：发布后1-2小时引导线上门店真实顾客从短视频下单
3. **额外优惠**：额外给予5-10元优惠，为链接做成交模型

#### 5.2.3 直播优化
- **首场直播**：3小时卖16,500元，存在白板简陋、直播时长短等问题
- **问题分析**：系统判定无真人出镜为录播违规
- **优化潜力**：若优化画面、延长直播时长至4小时，保底能卖5万，好则达8万

#### 5.2.4 业绩变化
- **11月业绩**：20多万
- **12月业绩**：提升到30多万
- **关键作用**：直播起到关键作用

## 六、关键公式与计算

### 6.1 竞争对手5A数值计算
```
设竞争对手均值为x
总5A = (1 + 增长率) × 竞争对手均值 × 竞争对手数量
1700万 = (1 + 1.76) × x × 3
x = 1700万 ÷ (2.76 × 3) ≈ 615万
```

### 6.2 盈亏ROI计算公式
```
盈亏ROI = 1 ÷ (毛利率 - 各方抽佣比例 - 其他营销花费) × 核销率
```

### 6.3 ROI计算案例
- **真实成交**：2600
- **门店权益花费**：1500
- **ROI计算结果**：20
- **计算公式**：ROI = 成交金额 ÷ 花费
