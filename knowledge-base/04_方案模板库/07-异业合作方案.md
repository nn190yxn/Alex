# 异业合作方案

> 适用对象：本地中小门店，合作预算500-10000元/次

## 合作筛选

### 异业合作匹配原则

**核心原则**：客群重叠但业务不竞争

| 门店类型 | 推荐合作对象 | 客群共同点 |
|---------|-------------|-----------|
| 餐饮店 | 电影院、KTV、健身房 | 年轻消费群体、社交需求 |
| 美业店 | 女装店、花店、婚纱摄影 | 女性消费、追求品质 |
| 教培机构 | 文具店、儿童摄影、游乐场 | 有孩家庭、教育消费 |
| 健身房 | 运动品牌、轻食店、理疗店 | 健康意识、自律人群 |

### 合作对象评估表

| 评估维度 | 权重 | 评分(1-5) | 说明 |
|---------|------|----------|------|
| 客群匹配度 | 30% | | 目标客户重合度 |
| 品牌调性 | 20% | | 品牌形象和定位是否相当 |
| 合作意愿 | 20% | | 对方合作态度 |
| 资源互补性 | 15% | | 双方能否互补优势 |
| 距离远近 | 15% | | 物理距离影响联合活动效果 |
| **总分** | 100% | | 总分≥3.5分可推进 |

### 寻找合作对象的渠道

1. **周边商圈扫街**：1-3公里范围内的互补商家
2. **商会/行业协会**：本地商户交流群
3. **供应商推荐**：共同供应商牵线
4. **线上社群**：本地商家微信群
5. **客户推荐**：询问客户还常去哪些店

## 合作模式

### 常见合作模式对比

| 合作模式 | 合作方式 | 成本 | 效果 | 适合场景 |
|---------|---------|------|------|---------|
| 互放优惠券 | 双方门店放置对方优惠券 | 低 | 中 | 长期合作 |
| 联合套餐 | 打包双方产品/服务 | 中 | 高 | 节日/主题活动 |
| 联合活动 | 共同举办线下活动 | 高 | 高 | 大型节点 |
| 会员互通 | 双方会员权益互认 | 低 | 中 | 客群高度重合 |
| 联名产品 | 共同开发联名产品 | 中 | 高 | 品牌合作 |
| 互相导流 | 社群/朋友圈互推 | 低 | 中 | 日常合作 |

### 合作方案设计模板

**模板一：优惠券互放**
```
【A店×B店 联合优惠】

A店客户专属福利：
凭A店消费小票，到B店享8折优惠

B店客户专属福利：
凭B店消费小票，到A店送价值50元体验项目

合作周期：2026年X月X日-X月X日
结算方式：各自承担优惠成本
效果追踪：每月核销数据对账
```

**模板二：联合套餐**
```
【约会套餐】A餐厅×B影院 联名套餐

套餐内容：
A餐厅双人套餐（原价258元）
+ B影院电影票2张（原价120元）
联名套餐价：299元（立省79元）

购买方式：
- A店前台购买
- B影院小程序购买
- 双方社群限量抢购

利润分成：
A店获得180元，B店获得119元
```

## 执行流程

### 异业合作执行SOP

**第一阶段：接洽沟通（1周）**
- [ ] 确定目标合作商家
- [ ] 通过人脉/上门拜访建立联系
- [ ] 了解对方需求和资源
- [ ] 初步沟通合作意向
- [ ] 交换双方客户画像和经营数据

**第二阶段：方案制定（3-5天）**
- [ ] 确定合作模式和具体内容
- [ ] 明确双方分工和责任
- [ ] 制定优惠力度和成本分摊
- [ ] 确定合作周期和效果目标
- [ ] 签署合作协议（口头或书面）

**第三阶段：物料准备（1周）**
- [ ] 设计联合活动海报/宣传单
- [ ] 制作优惠券/体验券
- [ ] 双方门店布置联合活动物料
- [ ] 员工培训（活动方案和话术）
- [ ] 线上预热内容准备

**第四阶段：活动执行（合作周期内）**
- [ ] 每日跟进活动进展
- [ ] 收集客户反馈
- [ ] 每周数据对账
- [ ] 及时调整优化
- [ ] 社群/朋友圈持续推广

**第五阶段：复盘总结（结束后1周）**
- [ ] 汇总双方数据
- [ ] 分析活动效果
- [ ] 总结成功经验和不足
- [ ] 讨论是否续约
- [ ] 感谢对方团队

### 合作协议要点

```
异业合作简易协议（适用于小型合作）

合作双方：A店（XXX）和B店（XXX）
合作周期：X月X日至X月X日
合作内容：
1. 双方在各自门店放置对方优惠券
2. 每月联合推出1次主题活动
3. 社群互相推广每周各1次

权益分配：
- 优惠券各自承担成本
- 联合活动成本按5:5分摊
- 联合套餐利润按约定比例分成

数据共享：
- 每周五交换核销数据
- 活动结束后汇总分析

退出机制：
- 任何一方提前7天通知可终止合作
- 已发放的优惠券继续有效
```

## 利益分配

### 成本分摊原则

| 费用类型 | 分摊方式 | 说明 |
|---------|---------|------|
| 优惠券成本 | 各自承担 | 各自发放的优惠各自承担 |
| 联合活动费用 | 5:5分摊 | 场地、物料、推广等 |
| 联名产品开发 | 按销量分成 | 按各自销售渠道的销量结算 |
| 推广费用 | 按受益比例 | 谁的渠道谁承担 |

### 收益分配模型

**模型一：按引流效果分配**
- 统计双方各自为对方带来的客户数
- 按引流人数比例分配联合活动收益
- 适合：优惠券互放、互相导流

**模型二：按固定比例分配**
- 提前约定固定分成比例（如5:5或6:4）
- 简单明了，减少结算纠纷
- 适合：联合套餐、联名产品

**模型三：按投入比例分配**
- 按各自投入的成本比例分配收益
- 投入包括：物料、推广、人力等
- 适合：联合活动

### 结算方式建议

- **小额合作**（月结算<3000元）：按月结算
- **中等合作**（月结算3000-10000元）：按周结算
- **大型合作**（月结算>10000元）：预付部分款项+定期结算
- **工具推荐**：使用微信账单/支付宝转账留痕

## 效果评估

### 核心评估指标

| 指标 | 说明 | 目标参考 |
|-----|------|---------|
| 引流人数 | 合作带来的新客流量 | 月均50-200人 |
| 转化率 | 引流客户中实际消费的比例 | 20-40% |
| 新增消费额 | 合作带来的新增营收 | 视合作规模 |
| ROI | （新增消费额-投入成本）/投入成本 | >1.5 |
| 合作满意度 | 双方主观评价 | 4分以上（5分制） |

### 异业合作成功要素

1. **客群高度匹配**：目标客户画像重合度>50%
2. **价值对等**：双方提供的权益价值相当
3. **执行到位**：双方员工都积极参与推广
4. **持续优化**：根据数据调整合作策略
5. **长期关系**：建立信任，形成稳定合作关系
