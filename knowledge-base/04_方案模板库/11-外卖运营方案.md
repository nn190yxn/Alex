# 外卖运营方案

> 适用对象：外卖餐饮门店（快餐、正餐、饮品、甜品），月推广预算500-3000元

## 菜单优化

### 菜单结构设计

**黄金比例**：
| 产品类型 | 占比 | 数量 | 作用 |
|---------|------|------|------|
| 引流款 | 15% | 3-5个 | 低价吸引点击 |
| 利润款 | 50% | 10-15个 | 核心盈利产品 |
| 形象款 | 15% | 3-5个 | 提升品牌调性 |
| 凑单款 | 10% | 2-4个 | 提升客单价 |
| 新品 | 10% | 2-3个 | 保持新鲜感 |

### 产品定价策略

**定价公式**：
- 引流款：成本 × 1.5-2（毛利率30-50%）
- 利润款：成本 × 2.5-3（毛利率60-70%）
- 形象款：成本 × 3-4（毛利率70-75%）
- 凑单款：成本 × 1.5-2（低单价高转化）

**示例（快餐店）**：
| 类型 | 产品 | 成本 | 售价 | 毛利 |
|-----|------|------|------|------|
| 引流款 | 招牌卤肉饭 | 8元 | 15.9元 | 50% |
| 利润款 | 双拼饭套餐 | 10元 | 25.9元 | 61% |
| 形象款 | 和牛便当 | 18元 | 49.9元 | 64% |
| 凑单款 | 卤蛋/饮料 | 1.5元 | 3.9元 | 62% |

### 菜单排版原则

1. **前3个产品决定70%的订单**：放利润最高或转化率最高的产品
2. **分类清晰**：不超过8个分类，分类名简洁易懂
3. **图文匹配**：每款产品必须有高质量图片
4. **描述优化**：产品名称+卖点描述（不超过20字）

## 活动设置

### 平台活动类型

| 活动类型 | 说明 | 力度建议 | 适合阶段 |
|---------|------|---------|---------|
| 满减活动 | 满X减Y | 满25减5、满40减10 | 全阶段 |
| 新客立减 | 新客专属优惠 | 立减3-8元 | 新店/冲量 |
| 折扣商品 | 单品打折 | 7-8.5折 | 日常/清库存 |
| 配送费减免 | 减免配送费 | 减2-5元 | 提升转化 |
| 收藏有礼 | 收藏店铺送券 | 送3-5元券 | 积累粉丝 |

### 活动组合策略

**新店冲量组合（前30天）**：
```
满减：满20减8 + 满35减15
新客立减：立减5元
配送费：减免至0元
折扣商品：3款产品7折
目标：快速积累销量和评价
```

**日常盈利组合（30天后）**：
```
满减：满25减5 + 满45减10
新客立减：立减3元
配送费：减免2元
折扣商品：1-2款引流品8折
目标：保持单量的同时控制成本
```

### 活动成本测算

```
示例：满25减5活动

假设平均客单价30元，毛利率60%
原利润：30 × 60% = 18元
活动后利润：30 - 5（满减）- 12（成本）= 13元
每单让利：5元

关键：确保活动后仍有正毛利
实际毛利率 = (实收金额 - 成本) / 实收金额
```

## 配送管理

### 配送方式选择

| 配送方式 | 配送费 | 时效 | 适合场景 |
|---------|-------|------|---------|
| 平台专送 | 5-8元（客户付） | 30-45分钟 | 全时段 |
| 平台快送 | 6-10元（客户付） | 25-35分钟 | 高峰期 |
| 自配送 | 0-5元（商家承担） | 视距离定 | 近距离/大客户 |
| 混合配送 | 根据订单自动选择 | 综合最优 | 订单量大时 |

### 出餐时效管理

**时效目标**：
- 接单到出餐：10-15分钟
- 出餐到送达：25-35分钟
- 整体时效：35-50分钟

**提升出餐效率**：
1. 高峰前备好半成品
2. 设置热门产品提前预制
3. 出餐口和打包区分离
4. 专人对接骑手交接

### 配送问题处理

| 问题 | 处理方式 | 预防措施 |
|-----|---------|---------|
| 超时 | 联系骑手催单，主动联系客户 | 优化出餐流程 |
| 撒漏 | 补发或退款，加强包装 | 改进包装方式 |
| 错送 | 补发正确产品 | 出餐核对流程 |
| 差评 | 24小时内回复处理 | 提升品质和服务 |

## 评价维护

### 好评率提升策略

**出餐环节**：
- 附赠小卡片："满意请给5星好评哦~"
- 包装内放小零食或饮料（成本0.5-2元）
- 附赠好评返现卡（注意平台规则）

**配送环节**：
- 包装密封完好，贴封签
- 汤面分离，避免撒漏
- 冷热分开，保证口感

**售后环节**：
- 主动联系客户确认满意度
- 有问题第一时间处理（补发/退款）
- 满意客户引导评价

### 差评处理流程

```
收到差评
  ↓
1小时内回复（诚恳道歉+解决方案）
  ↓
联系客户了解具体情况
  ↓
提出补偿方案（退款/补发/下次优惠）
  ↓
客户满意后协商修改评价
  ↓
内部复盘，避免再次发生
```

### 评价数据目标

| 指标 | 目标值 | 说明 |
|-----|-------|------|
| 好评率 | >90% | 4-5星评价占比 |
| 评分 | >4.5分 | 满分5分 |
| 回复率 | 100% | 所有评价都要回复 |
| 差评处理时效 | <2小时 | 及时响应 |
| 月评价数 | >30条 | 持续有新评价 |

## 利润管控

### 外卖成本构成

| 成本项目 | 占比 | 说明 |
|---------|------|------|
| 食材成本 | 30-40% | 菜品原料 |
| 平台抽成 | 15-25% | 按订单比例 |
| 配送补贴 | 5-10% | 商家承担的配送费 |
| 活动让利 | 10-20% | 满减、折扣等 |
| 包装成本 | 3-5% | 餐盒、袋子、餐具 |
| 人工成本 | 10-15% | 出餐、打包人工 |
| 推广费用 | 5-10% | 竞价排名、推广通 |

### 利润测算模板

```
单均利润测算：

产品售价：30元
- 食材成本：-10元（33%）
- 平台抽成：-6元（20%）
- 配送补贴：-2元
- 活动让利：-3元（满减分摊）
- 包装成本：-1.5元
- 推广费用：-1.5元

单均利润：6元（利润率20%）

提升利润的方法：
1. 优化食材成本（寻找更便宜的供应商）
2. 降低活动让利（调整满减档位）
3. 提升客单价（搭配套餐/凑单）
4. 控制推广成本（精准投放）
```
