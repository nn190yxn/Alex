# TVC创意案

> **适用场景**：品牌TVC策划、产品TVC创意、品牌形象片制作
> **行业示例**：母婴行业
> **方案定位**：TVC（电视广告片）的创意策划方案，涵盖创意推导、脚本撰写及创意扩散

---

## 一、创意推导

> 通过系统化的推导过程，找到TVC的核心创意方向。

### 1.1 提出问题

| 问题编号 | 核心问题 | 问题背景 |
|---------|---------|---------|
| 问题1 | XX问题（如：当代父母在育儿过程中最大的焦虑是什么？） | XX社会现象/消费趋势 |
| 问题2 | XX问题（如：消费者为什么选择我们的品牌？） | XX市场现状/竞品分析 |
| 问题3 | XX问题（如：品牌希望在消费者心中建立什么形象？） | XX品牌战略/年度目标 |

### 1.2 表达观点

| 观点编号 | 核心观点 | 观点阐释 |
|---------|---------|---------|
| 观点1 | XX观点（如：最好的爱是陪伴成长） | XX阐释 |
| 观点2 | XX观点（如：专业守护，让爱更安心） | XX阐释 |
| 观点3 | XX观点（如：每个孩子都值得被温柔以待） | XX阐释 |

### 1.3 消费者洞察

| 洞察编号 | 洞察内容 | 洞察来源 | 创意启示 |
|---------|---------|---------|---------|
| 洞察1 | XX洞察（如：新手妈妈最大的恐惧是"做得不够好"） | 社交数据/用户调研 | TVC可以从XX角度切入 |
| 洞察2 | XX洞察（如：爸爸在育儿中的参与感越来越强） | 消费趋势 | TVC可以展现XX场景 |
| 洞察3 | XX洞察（如：母婴消费从"性价比"转向"品质感"） | 市场数据 | TVC可以传递XX品牌价值 |

### 1.4 品牌角色

| 角色维度 | 品牌角色 | 具体描述 |
|---------|---------|---------|
| 功能角色 | XX角色（如：专业的育儿助手） | 品牌在产品功能层面的角色 |
| 情感角色 | XX角色（如：温暖的陪伴者） | 品牌在情感层面的角色 |
| 社会角色 | XX角色（如：科学育儿的倡导者） | 品牌在社会层面的角色 |

## 二、创意呈现

> TVC的核心创意概念、脚本及扩散方案。

### 2.1 核心创意

| 要素 | 内容 |
|------|------|
| 创意概念 | TVC的核心创意概念（一句话） |
| 创意来源 | 创意的灵感来源与推导逻辑 |
| 创意阐释 | 创意的详细解读 |
| 情感内核 | TVC要传达的核心情感 |
| 品牌关联 | 创意与品牌的关联方式 |
| 目标受众 | TVC核心受众 |

### 2.2 创意脚本

#### 2.2.1 脚本基本信息

| 信息项 | 内容 |
|-------|------|
| TVC时长 | 60s / 30s / 15s / 6s 多版本 |
| 拍摄风格 | XX风格（如：纪实/唯美/动画/混搭） |
| 色调 | XX色调（如：温暖/清新/高级灰） |
| 音乐 | XX风格音乐（如：钢琴/弦乐/轻快） |
| 旁白 | 有/无，旁白风格 |

| 镜头3 | 10-15s | XX画面描述 | XX旁白/音效 | XX字幕 |

| 镜头5 | 25-40s | XX画面描述 | XX旁白/音效 | XX字幕 |

#### 2.2.3 多版本脚本规划

| 版本 | 时长 | 用途 | 核心内容 | 投放渠道 |
|------|------|------|---------|---------|
| 完整版 | 60s | 品牌形象/发布会 | 完整故事线 | 线下发布会/品牌官网 |
| 标准版 | 30s | 电视/OTT投放 | 精简故事线 | 电视/OTT/影院 |
| 精简版 | 15s | 社交媒体/信息流 | 核心画面+品牌信息 | 抖音/微博/微信 |
| 短版 | 6s | 前贴片/开屏 | 高光画面+品牌Slogan | 优酷/腾讯/微博开屏 |

### 2.3 创意扩散

> TVC创意在不同媒介和形式的延伸与扩散。

| 扩散形式 | 扩散内容 | 扩散渠道 | 扩散目的 |
|---------|---------|---------|---------|
| 幕后花絮 | 拍摄花絮/导演手记/明星采访 | 社交媒体 | 增加话题度 |
| 系列海报 | TVC画面截帧/主题海报 | 线上+线下 | 延长传播周期 |
| 短视频改编 | TVC改编为竖版短视频 | 抖音/快手 | 适配移动端 |
| UGC模板 | 基于TVC创意的UGC模板 | 抖音/小红书 | 引发用户参与 |
| 线下延展 | TVC创意延展为线下装置/快闪店 | 商场/门店 | 线下体验 |
| 跨界联动 | TVC创意与其他品牌/IP联动 | 全渠道 | 扩大传播范围 |
