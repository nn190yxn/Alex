# 客户裂变方案

> 适用对象：本地生活门店（餐饮、美业、教培、零售），裂变预算1000-10000元

## 裂变设计

### 裂变模式选择

| 裂变模式 | 适用场景 | 裂变系数 | 执行难度 | 适合行业 |
|---------|---------|---------|---------|---------|
| 老带新 | 有稳定老客户基础 | 1带1-3 | 低 | 通用 |
| 拼团 | 有性价比爆款 | 3-5人团 | 中 | 通用 |
| 砍价 | 有知名度产品 | 5-10人 | 中 | 零售、美业 |
| 助力 | 免费体验/低门槛 | 3-8人 | 低 | 教培、美业 |
| 分销 | 高利润产品/课程 | 多级裂变 | 高 | 教培、健康 |

### 裂变路径设计原则

**三要素缺一不可**：
1. **诱饵够大**：奖励要有吸引力（免费体验/大额优惠/实用赠品）
2. **门槛够低**：参与步骤不超过3步，30秒内能完成
3. **路径够短**：分享→好友点击→双方得奖励，链路最短

### 裂变活动模板

**模板一：老带新双方有礼**
```
【老带新福利】推荐朋友来XX店，双方都有礼！

推荐人奖励：
- 每成功推荐1位好友到店消费，得50元代金券
- 推荐满3人，额外送价值198元XXX服务1次
- 推荐满5人，升级为VIP会员享全年8折

被推荐人奖励：
- 首单立减50元
- 送新人体验礼包（价值99元）

活动规则：
1. 老客户通过专属海报/链接分享
2. 新客户通过链接注册并到店消费
3. 消费完成后48小时内奖励到账
```

**模板二：3人拼团**
```
【3人成团】XX服务原价299元，拼团价仅99元！

成团规则：
- 3人即可成团，享99元特价
- 5人成团，享79元超级特价
- 24小时内成团有效，不成团自动退款

使用规则：
- 有效期至X月X日
- 每人限购1份
- 需提前预约使用
```

## 奖励机制

### 奖励设计原则

**有效奖励的特征**：
- 感知价值 > 实际成本（如标价198元的体验卡，实际成本30元）
- 即时满足（参与后立即获得奖励，不要等）
- 双方受益（推荐人和被推荐人都有奖励）

### 奖励成本核算表

| 奖励类型 | 感知价值 | 实际成本 | 毛利率 | 推荐用量 |
|---------|---------|---------|-------|---------|
| 代金券 | 50元 | 50元(抵扣) | 按毛利算 | 每推荐1人 |
| 体验服务 | 198元 | 30-50元 | 75-85% | 每推荐3人 |
| 实物赠品 | 99元 | 20-40元 | 60-80% | 每推荐1人 |
| 会员权益 | 365元/年 | 边际成本低 | 高 | 每推荐5人 |
| 现金红包 | 10-20元 | 等额 | 0 | 即时发放 |

### 阶梯奖励设计

**示例：裂变阶梯奖励**
```
第1阶（1-2人）：每推荐1人得30元券
第2阶（3-5人）：每推荐1人得50元券 + 赠XX礼品
第3阶（6-10人）：每推荐1人得80元券 + 赠XX服务
第4阶（10人以上）：升级为合伙人，享消费返利10%

设计要点：
- 阶梯门槛不要太高，3人就能进入下一阶
- 高级奖励感知价值要明显提升
- 设置"推荐王"额外大奖制造竞争
```

## 执行步骤

### 裂变活动执行SOP

**第一步：活动准备（3-5天）**
- [ ] 确定裂变模式和奖励方案
- [ ] 设计裂变海报/落地页
- [ ] 设置奖励发放机制（自动/手动）
- [ ] 准备活动规则说明文案
- [ ] 培训员工活动流程和话术

**第二步：种子用户启动（1-2天）**
- [ ] 从老客户中筛选100-200人作为种子
- [ ] 一对一私信邀请参与
- [ ] 提供专属推荐码/海报
- [ ] 引导第一批分享行为

**第三步：活动推广（持续进行）**
- [ ] 朋友圈每日推送活动进度
- [ ] 社群每天提醒+晒单
- [ ] 门店布置活动物料
- [ ] 员工个人朋友圈同步推广

**第四步：数据监控（每日）**
- [ ] 追踪参与人数、分享次数
- [ ] 监控新用户注册/到店数据
- [ ] 检查奖励发放是否及时
- [ ] 发现异常及时调整

### 裂变海报要素清单

- [ ] 主标题（痛点/利益点，不超过12个字）
- [ ] 副标题（活动详情补充说明）
- [ ] 产品/服务图片（高清、有吸引力）
- [ ] 价格对比（原价vs活动价，用红色标注）
- [ ] 二维码（扫码参与）
- [ ] 门店信息（名称、地址、电话）
- [ ] 紧迫感元素（"限量50份""仅限3天"）

## 风控规则

### 常见刷单手段及防范

| 刷单手段 | 表现特征 | 防范措施 |
|---------|---------|---------|
| 同一设备多账号 | 相同IP、相同设备号 | 设备号限制、IP限制 |
| 虚假注册 | 无真实消费行为 | 需到店核销才能得奖 |
| 自买自卖 | 推荐人与被推荐人关联 | 同一手机号/微信无法互推 |
| 批量刷号 | 大量新账号短时涌入 | 单日参与次数上限 |
| 刷单群互助 | 集中时段大量参与 | 异常时段数据预警 |

### 风控规则设置建议

**基础规则**：
1. 每人每天最多参与3次裂变活动
2. 推荐人与被推荐人不能是同一微信号
3. 奖励发放需被推荐人完成首次到店消费
4. 同一手机号/设备号只能注册一次

**进阶规则**：
1. 单日新增用户超过50人时触发人工审核
2. 同一IP地址注册超过5个账号时限制
3. 新用户首单金额低于正常值50%时标记异常
4. 设置活动总预算上限，达到后自动停止

### 异常处理流程

```
发现异常数据
  ↓
暂停奖励发放
  ↓
人工核查数据（设备/IP/行为模式）
  ↓
确认刷单 → 取消异常账号奖励，加入黑名单
  ↓
确认正常 → 恢复奖励发放
  ↓
优化风控规则，记录日志
```

## 数据监控

### 裂变核心指标

| 指标 | 定义 | 健康值 | 监控频率 |
|-----|------|-------|---------|
| 参与率 | 参与裂变的老客户/总老客户 | 15-30% | 每日 |
| K因子 | 平均每人带来新用户数 | >1为正向裂变 | 每日 |
| 分享率 | 分享人数/参与人数 | 40-60% | 每日 |
| 转化率 | 新用户到店消费/新用户注册 | 20-40% | 每周 |
| 获客成本 | 活动总成本/新增付费用户 | 低于行业均值 | 每周 |
| ROI | 新用户贡献价值/活动成本 | >2 | 活动结束 |

1. **渠道分析**：哪个渠道带来的裂变效果最好？

4. **奖励分析**：哪种奖励的参与率和转化率最高？
