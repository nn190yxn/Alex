# 门店促销活动方案

> 适用对象：实体门店（餐饮、零售、美业、教培），活动预算1000-30000元

## 促销设计

### 常见促销类型对比

| 促销类型 | 适用场景 | 折扣力度 | 利润率影响 | 引流效果 |
|---------|---------|---------|-----------|---------|
| 满减 | 提升客单价 | 满100减20 | 中等 | 中 |
| 打折 | 清库存/冲业绩 | 7-8折 | 较大 | 强 |
| 买赠 | 推新品/清库存 | 视赠品成本 | 可控 | 中 |
| 秒杀 | 拉新/造势 | 5折以下 | 大 | 极强 |
| 套餐 | 提升连带率 | 组合价8折 | 小 | 中 |
| 会员日 | 会员激活 | 会员专享价 | 可控 | 稳定 |

### 促销活动选择决策树

1. **目标是什么？**
   - 拉新引流 → 秒杀/低价体验
   - 提升客单 → 满减/满赠/套餐
   - 清库存 → 打折/买赠
   - 激活会员 → 会员日/积分兑换

2. **预算有多少？**
   - 1000元以下 → 社群秒杀/朋友圈转发
   - 5000元以下 → 门店打折/买赠活动
   - 10000-30000元 → 主题促销+投放推广

3. **门店类型？**
   - 餐饮 → 套餐、满减、时段折扣
   - 美业 → 体验价、充值优惠、次卡
   - 零售 → 满减、第二件半价、满赠
   - 教培 → 试听免费、团购价、老带新

## 活动预热

### 预热时间轴

| 阶段 | 时间节点 | 动作 | 渠道 |
|-----|---------|------|------|
| 蓄水期 | 活动前7天 | 悬念海报、话题铺垫 | 朋友圈、社群 |
| 预告期 | 活动前3天 | 活动详情、优惠剧透 | 全渠道 |
| 冲刺期 | 活动前1天 | 倒计时、抢购提醒 | 社群、私信 |
| 爆发期 | 活动当天 | 现场直播、实时播报 | 朋友圈、社群 |
| 延续期 | 活动后2天 | 战报晒单、返场优惠 | 社群、朋友圈 |

- [ ] 悬念海报1张（活动前7天）："有大事要发生！"

- [ ] 社群文案3-5条（不同阶段推送）

## 执行流程

### 活动当天执行SOP

**开店前（9:00-10:00）**：
- [ ] 检查活动物料是否到位（海报、展架、价签）
- [ ] 收银系统活动设置确认
- [ ] 全体员工活动规则培训（10分钟晨会）
- [ ] 库存盘点确认（爆款备货充足）

**营业中（10:00-21:00）**：
- [ ] 每2小时在朋友圈/社群播报活动进度
- [ ] 引导到店客户参与活动
- [ ] 收集客户反馈和现场照片
- [ ] 实时关注库存，及时补货

**打烊后（21:00-22:00）**：
- [ ] 统计当天销售数据
- [ ] 盘点库存，记录缺货商品
- [ ] 整理客户信息和新增会员
- [ ] 拍摄门店战报（可选）

|-----|------|------|

| 前台 | 1-2 | 接待引导、活动讲解、收银 |

## 预算分配

### 预算分配比例

| 项目 | 占比 | 说明 |
|-----|------|------|
| 促销让利 | 50-60% | 折扣、赠品、优惠券成本 |
| 物料制作 | 10-15% | 海报、展架、宣传单、包装袋 |
| 线上推广 | 15-20% | 朋友圈广告、本地投放 |
| 员工激励 | 10-15% | 活动提成、奖金、加班费 |
| 应急预留 | 5% | 临时补货、突发支出 |

## 效果评估

### 核心评估指标

| 指标 | 计算公式 | 目标参考 |
|-----|---------|---------|
| 销售额 | 活动期间总营收 | 平日日均3-5倍 |
| 客流量 | 到店人数 | 平日日均2-3倍 |
| 客单价 | 总销售额/订单数 | 较平日提升20%+ |
| 转化率 | 成交人数/到店人数 | 30-50% |
| 新增会员 | 活动期间注册会员 | 日均50-100人 |
| ROI | （销售额-成本）/成本 | >2 |
