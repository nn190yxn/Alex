# 点评运营方案

> 适用对象：入驻美团/大众点评的本地门店（餐饮、美业、休闲娱乐），月推广预算500-5000元

## 店铺装修

### 店铺基础信息优化

| 信息项 | 优化要求 | 示例 |
|-------|---------|------|
| 店名 | 品牌名+品类关键词 | "老王私房菜·川菜火锅" |
| 品类 | 选择最精准的二级品类 | 不要选"美食"大类，选"川菜" |
| 地址 | 详细到门牌号，标注地标 | "XX路XX号（XX商场对面）" |
| 电话 | 保持畅通，设置欢迎语 | 接通后自动播报营业时间 |
| 营业时间 | 准确填写，节假日及时更新 | 标注是否有午休 |

### 图片上传规范

**必备图片类型及数量**：

| 图片类型 | 数量 | 要求 | 优先级 |
|---------|------|------|-------|
| 门店门头 | 2-3张 | 清晰、光线好、包含招牌 | ★★★★★ |
| 店内环境 | 5-8张 | 整洁、有氛围、多角度 | ★★★★★ |
| 招牌产品 | 8-12张 | 高清、有食欲/吸引力 | ★★★★★ |
| 服务过程 | 3-5张 | 展示专业度和服务细节 | ★★★★ |
| 菜单/价目表 | 1-2张 | 清晰可读、价格标注 | ★★★★ |
| 资质证书 | 2-3张 | 营业执照、卫生许可等 | ★★★ |

## 评价管理

### 好评获取策略

**主动引导**：
1. 服务结束后30分钟内发送评价邀请
2. 在收银台放置评价引导台卡
3. 员工话术引导："如果您满意我们的服务，麻烦在点评上给我们一个好评~"
4. 评价后送小礼品/优惠券（注意平台规则，不能直接买好评）

**评价时机选择**：
- 客户情绪最好的时候（刚体验完满意的服务）
- 消费高峰前（上午10点、下午3点推送）
- 节假日前后（客户更愿意分享）

### 差评应对SOP

| 步骤 | 动作 | 时限 |
|-----|------|------|
| 第一步 | 发现差评后30分钟内回复 | 30分钟 |
| 第二步 | 联系客户了解具体情况 | 2小时 |
| 第三步 | 提出解决方案并执行 | 24小时 |
| 第四步 | 客户满意后请求修改评价 | 解决后 |
| 第五步 | 内部复盘，避免类似问题 | 3天内 |

### 差评回复模板

**模板一：服务态度问题**：
```
尊敬的顾客您好，非常抱歉给您带来不好的体验！
关于您反馈的XXX问题，我们已经认真调查并整改。
XXX同事已重新培训，我们保证不会再出现类似情况。
诚挚邀请您再次光临，我们将为您提供更好的服务体验！
联系电话：XXX（店长直联）
```

**模板二：产品质量问题**：
```
您好！感谢您的真实反馈，我们非常重视。
您提到的XXX问题确实是我们工作不到位，已第一时间改进。
为表达歉意，我们为您准备了XXX补偿。
期待您的再次光临，让我们有机会弥补这次的不足！
```

## 推广投放

### 推广工具对比

| 工具 | 计费方式 | 适合场景 | 预算建议 | 效果 |
|-----|---------|---------|---------|------|
| 竞价排名 | CPC（按点击） | 提升搜索排名 | 50-200/天 | 精准流量 |
| 推广通 | CPM/CPC | 首页曝光 | 100-500/天 | 品牌曝光 |
| 优惠券推广 | CPS（按核销） | 活动促销 | 按效果付费 | 直接转化 |
| 会员推广 | 包月/包年 | 会员拉新 | 500-2000/月 | 长期价值 |

### 投放策略

**新店期（入驻前3个月）**：
- 目标：快速积累评价和销量
- 策略：大力度优惠+竞价排名
- 预算：100-300元/天
- 重点：冲销量、攒评价

**成长期（3-6个月）**：
- 目标：稳定排名，提升转化
- 策略：精准投放+优化详情页
- 预算：50-200元/天
- 重点：提转化、稳排名

**成熟期（6个月以上）**：
- 目标：维护排名，降低获客成本
- 策略：精准定向+老客户复购
- 预算：50-100元/天
- 重点：控成本、提利润

## 排名优化

### 排名影响因素权重

| 因素 | 权重 | 优化方法 |
|-----|------|---------|
| 销量/订单量 | 25% | 持续增加有效订单 |
| 评价数量和评分 | 20% | 引导好评、处理差评 |
| 店铺信息完整度 | 15% | 完善所有信息字段 |
| 点击转化率 | 15% | 优化主图、标题、价格 |
| 推广投入 | 15% | 合理投放推广通 |
| 复购率 | 10% | 提升客户回头率 |

### 排名提升策略

**短期策略（1-4周见效）**：
1. 增加推广投入，提升竞价排名
2. 推出限时优惠活动，快速拉升销量
3. 集中引导近期客户写评价
4. 优化主图和标题，提升点击率

**中期策略（1-3个月见效）**：
1. 持续稳定出单，积累有效销量
2. 保持评价增长（每周5-10条新好评）
3. 完善店铺信息，提高完整度
4. 优化套餐和价格，提升转化

**长期策略（3个月以上）**：
1. 建立稳定的客户复购体系
2. 持续产出优质内容（笔记、视频）
3. 维护良好的评价生态
4. 品牌建设和口碑积累

## 数据分析

### 核心数据指标

| 指标 | 含义 | 健康值 | 优化方向 |
|-----|------|-------|---------|
| 曝光量 | 店铺被看到的次数 | 逐月增长 | 推广、排名 |
| 访问量 | 点击进入店铺的人数 | 曝光量×3-5% | 主图、标题 |
| 转化率 | 访问→下单的比例 | 5-15% | 详情页、评价 |
| 客单价 | 平均订单金额 | 行业均值+ | 套餐搭配 |
| ROI | 推广投入产出比 | >3 | 精准投放 |
