> 适用对象：中小门店（餐饮、美业、零售、教培），单节日预算1000-20000元

### 节日筛选策略

**必做节日（全年8-10个）**：
- 春节、国庆：全民消费高峰
- 情人节、七夕：情侣消费场景
- 妇女节、母亲节：女性消费场景
- 双十一、双十二：电商消费心智
- 行业特定节日：如教培的开学季、餐饮的中秋

**选做节日（根据门店定位）**：
- 预算有限：选做3-4个大节即可
- 特色节日：可自创"店庆日""会员日"

## 营销策划

### 节日营销四步法

**第一步：确定主题**
- 结合节日属性+门店特色
- 主题要朗朗上口、有记忆点
- 示例："七夕，让爱更美味"（餐饮）、"女王节，做最美的自己"（美业）

**第二步：设计活动**
- 1个主打活动（引流）+2-3个辅助活动（转化）
- 活动力度要有诚意，不能敷衍
- 示例：主打7折引流+满减转化+充值锁客

**第三步：准备物料**
- 线上：海报、推文、短视频、社群文案
- 线下：展架、吊旗、台卡、赠品包装

**第四步：全渠道推广**
- 朋友圈提前7天开始预热
- 社群每天推送进度
- 老客户短信/私信定向通知
- 门店提前布置节日氛围

### 节日活动套餐模板

**餐饮节日套餐示例**：
```
【情人节双人浪漫套餐】原价398元，节日价298元

包含：
- 主菜2份（牛排/意面）
- 甜品2份（提拉米苏/慕斯）
- 饮品2杯（红酒/气泡水）
- 节日限定小食1份
- 玫瑰花1支

限量50份，需提前预约
```

**美业节日套餐示例**：
```
【女神节焕颜套餐】原价598元，节日价298元

包含：
- 深层清洁护理1次
- 补水修护面膜1次
- 肩颈放松按摩1次
- 送价值99元护肤小样套装

仅限3月1日-3月8日使用
```

## 活动执行

### 节日活动执行时间轴

| 阶段 | 时间 | 关键动作 |
|-----|------|---------|
| 策划期 | 节前20天 | 确定主题、活动方案、预算审批 |
| 准备期 | 节前10天 | 物料设计、产品备货、员工培训 |
| 预热期 | 节前7天 | 线上推广开始、社群预热、预约开放 |
| 冲刺期 | 节前3天 | 倒计时海报、最后预约提醒 |
| 爆发期 | 节日当天 | 活动上线、现场执行、实时播报 |
| 收尾期 | 节后3天 | 数据复盘、客户回访、活动战报 |

### 常见节日营销陷阱

| 陷阱 | 表现 | 避免方法 |
|-----|------|---------|
| 盲目跟风 | 什么节都做，没有重点 | 精选5-8个核心节日 |
| 优惠力度小 | 打着节日旗号，优惠没诚意 | 折扣至少比平时多5-10% |
| 准备仓促 | 节前3天才开始策划 | 至少提前20天启动 |
| 缺乏差异化 | 和周边店活动一模一样 | 加入门店特色元素 |
| 重拉新轻留存 | 活动结束就没了下文 | 设计节后跟进和复购机制 |
