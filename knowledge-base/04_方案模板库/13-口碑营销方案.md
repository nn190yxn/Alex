# 口碑营销方案

> 适用对象：本地中小门店（全行业），口碑营销预算500-10000元

## 口碑设计

### 口碑传播要素

**可传播的口碑必须包含**：
1. **话题性**：有讨论价值，客户愿意主动分享
2. **利益点**：对客户有实际好处（省钱/省时/效果好）
3. **情感共鸣**：能引发情感共鸣（惊喜/感动/有趣）
4. **社交货币**：分享后能提升客户的社交形象

### 口碑场景设计

| 行业 | 口碑触发场景 | 传播点设计 |
|-----|-------------|-----------|
| 餐饮 | 上菜时/结账时 | 超大分量/隐藏菜单/生日惊喜 |
| 美业 | 护理完成照镜子时 | 即时效果对比/增值服务 |
| 教培 | 课程结束后/考试出分 | 孩子进步/家长沟通/教学成果 |
| 零售 | 开箱时/使用后 | 超预期包装/实用赠品 |

### 口碑故事模板

**模板：惊喜体验型**
```
要素：
- 背景：客户来店里做XXX
- 期待：原本只期望XXX
- 惊喜：结果超出预期XXX
- 传播：忍不住拍下来分享到朋友圈

示例：
"本来只是随便吃个饭，没想到老板送了个生日蛋糕！
说看我朋友圈今天过生日。真的被暖到了，必须发个圈！"
```

## 体验优化

### 客户体验旅程地图

| 阶段 | 触点 | 体验要点 | 口碑机会 |
|-----|------|---------|---------|
| 到店前 | 预约/导航 | 预约便捷、路线清晰 | 发送温馨提示 |
| 到店时 | 迎接/等候 | 热情接待、等候舒适 | 等候时提供茶水小食 |
| 体验中 | 服务过程 | 专业、贴心、有惊喜 | 超预期服务/个性化关怀 |
| 体验后 | 送别/跟进 | 暖心送别、及时回访 | 发送感谢信息+小礼物 |

### 制造"峰值体验"的方法

**方法一：超出预期的赠品**
- 餐饮：免费赠送一道招牌小菜
- 美业：护理后赠送面膜+护肤小贴士
- 教培：课后赠送学习礼包
- 成本控制在3-10元/人

**方法二：个性化服务**
- 记住客户姓名和偏好
- 生日/纪念日准备小惊喜
- 根据客户需求定制服务
- 关键：提前收集客户信息

**方法三：仪式感设计**
- 餐饮：上菜时有仪式感（火焰菜、桌边服务）
- 美业：护理完成后提供拍照打卡区
- 教培：结业仪式+证书
- 目的：制造拍照分享的冲动

### 体验检查清单

- [ ] 环境是否整洁舒适
- [ ] 员工是否热情专业
- [ ] 服务流程是否顺畅
- [ ] 是否有超出预期的惊喜
- [ ] 客户离开时是否有好的感受
- [ ] 是否有引导分享的机制

## 传播机制

### 口碑传播路径

```
优质体验（种子）
  ↓
客户主动分享（朋友圈/群聊/口头）
  ↓
朋友看到产生兴趣（曝光）
  ↓
到店体验（转化）
  ↓
新的口碑传播（裂变）
```

### 引导分享的方法

**方法一：拍照打卡点**
- 门店设置高颜值的拍照区域
- 提供拍照道具（手举牌、背景板）
- 拍照引导："拍张照片打卡送XX"

**方法二：分享有礼**
- 规则：分享门店体验至朋友圈
- 要求：带门店定位+不少于3张图
- 奖励：下次到店享折扣或送小礼品
- 注意：不要直接买好评，避免违规

**方法三：话题引导**
- 创造有趣的互动话题
- 引导客户在社交媒体参与
- 示例："#我在XX店的治愈时刻#"

### KOC培育计划

**KOC定义**：关键意见消费者（消费频次高、乐于分享的客户）

**筛选标准**：
- 月均到店2次以上
- 社交媒体活跃（朋友圈日更）
- 乐于推荐和分享
- 对品牌有好感

**培育方法**：
1. 建立KOC专属群（10-30人）
2. 新品/活动优先体验
3. 定期邀请参加品牌活动
4. 专属折扣和福利
5. 给予"品牌体验官"称号

## 效果评估

### 口碑营销指标

| 指标 | 计算方式 | 健康值 | 追踪频率 |
|-----|---------|-------|---------|
| NPS净推荐值 | (推荐者%-贬损者%) | >30% | 每月 |
| 口碑传播率 | 分享客户数/总客户数 | 15-30% | 每周 |
| 转介绍率 | 转介绍新客/总新客 | 20-40% | 每月 |
| 好评增长率 | 新增好评数/月 | 持续增长 | 每月 |
| 搜索提及量 | 品牌词搜索量 | 逐月增长 | 每月 |

### NPS调查问卷

```
您有多大可能向朋友推荐XX店？（0-10分）

0-6分：贬损者（需要重点关注和改进）
7-8分：被动者（满意但不会主动推荐）
9-10分：推荐者（会主动推荐给别人）

附加问题：
1. 您最喜欢我们的哪一点？
2. 我们有哪些可以改进的地方？
```
