# 地推引流方案

> 适用对象：本地门店（教培、美业、餐饮、健身），单场地推预算500-5000元

## 地推准备

### 地推前评估

**选址评估标准**：
| 评估维度 | 权重 | 说明 |
|---------|------|------|
| 人流量 | 30% | 日均经过人数>5000人 |
| 目标客群密度 | 25% | 目标客户占比>30% |
| 停留时间 | 15% | 人群停留时长>2分钟 |
| 竞争程度 | 15% | 周边同类地推<3家 |
| 场地费用 | 15% | 成本可控（0-500元/天） |

**推荐地推地点**：

| 行业 | 最佳地点 | 时段 | 人群特征 |
|-----|---------|------|---------|
| 教培 | 学校门口、小区出入口 | 7:30-8:30, 16:00-17:30 | 家长群体 |
| 美业 | 商圈步行街、商场门口 | 10:00-12:00, 15:00-18:00 | 年轻女性 |
| 餐饮 | 写字楼楼下、地铁口 | 11:30-13:30, 17:30-19:00 | 上班族 |
| 健身 | 小区门口、公园入口 | 6:30-8:00, 18:00-20:00 | 运动人群 |

### 核心数据指标

| 指标 | 计算方式 | 健康值 | 说明 |
|-----|---------|-------|------|
| 接触率 | 接受单页人数/经过人数 | 20-40% | 场地和时段影响大 |
| 留资率 | 扫码留资人数/接触人数 | 25-50% | 礼品和话术影响大 |
| 有效率 | 有效线索/留资人数 | 40-60% | 目标客群匹配度 |
| 到店率 | 到店人数/有效线索 | 20-40% | 后续跟进质量 |
| 获客成本 | 地推总成本/到店人数 | 30-100元 | 综合评估ROI |

### 地推ROI计算

```
地推ROI = （到店客户总消费额 - 地推总成本）/ 地推总成本

示例计算：
地推3天，总成本：3000元
留资：280人，有效线索：135人
到店：54人（到店率40%）
消费：28人消费，总消费额28000元
ROI = (28000 - 3000) / 3000 = 8.3

结论：ROI>3为合格，>5为优秀，>8为极佳
```

## 成本控制

### 地推成本构成

| 成本项目 | 占比 | 说明 |
|---------|------|------|
| 场地费 | 20-30% | 部分场地免费 |
| 物料费 | 20-25% | 一次性投入可复用 |
| 礼品费 | 25-35% | 核心引流成本 |
| 人员费 | 20-25% | 员工或兼职 |
| 交通餐饮 | 5-10% | 地推当天支出 |

### 降本增效建议

1. **礼品选择**：实用性强、成本低、印有品牌Logo
   - 推荐：纸巾包、环保袋、钥匙扣、手机支架（成本1-5元/个）

2. **兼职vs员工**：
   - 兼职成本低（100-150元/天），但效果不稳定
   - 员工成本高，但专业度和转化率高
   - 建议：核心岗位用员工，辅助岗位用兼职

3. **场地选择**：
   - 优先免费场地：小区出入口、公园
   - 付费场地：评估人流量和留资率
   - 与合作商家共享场地降低成本

4. **物料复用**：
   - 展架、桌布、工作服等可多次使用
   - 单页内容可设计为通用版，活动信息用贴纸替换

> **索引标签**：地推引流 线下获客 地推执行 门店引流 低成本获客
