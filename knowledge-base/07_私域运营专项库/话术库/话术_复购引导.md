# 话术_复购引导

> 版本：v1.0 | 创建日期：2026-05-04

## 一、首单后复购话术

### 1.1 T+3回访

```
XX您好～上次[产品/服务]用得还满意吗？
有没有什么问题或者建议？
您的反馈对我们很重要～
```

### 1.2 T+7二单引导

```
XX您好～上次您购买的[产品]，今天给您推荐搭配[关联产品]
老客户专享价XX元（原价XX元）
搭配使用效果更好哦～
```

## 二、定期复购话术（快消品）

### 2.1 周期性提醒

```
XX您好～您上次买的[产品]应该快用完了吧？
现在补货有老客户优惠
XX元/件（原价XX元）
还是给您寄到原来的地址吗？
```

### 2.2 新品推荐

```
XX您好～咱们上了新品[产品名称]
您是老客户，先给您内部体验价
XX元（原价XX元）
前50名下单还送[赠品]
您要不要试试？
```

## 三、沉睡激活话术

### 3.1 T+30温和唤醒

```
XX您好，好久不见～
最近咱们上了不少新品，还有老客户专享优惠
有空来看看呀😊
```

### 3.2 T+60主动召回

```
XX您好，最近工作忙吗？
好久没见您过来了，是不是有什么不满意的地方？
您的意见对我们很重要
如果方便的话，我给您申请一个老客户专属福利：
[超预期优惠]
您看这周有空过来吗？
```
