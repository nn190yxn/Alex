# 话术_异议处理

> 版本：v1.0 | 创建日期：2026-05-04

## 一、常见异议及处理话术

### 1.1 "太贵了"

```
理解您的感受～我给您算一下：
咱们单次XX元，但包含[价值清单]
市面上同品质的至少要XX元
而且老客户复购还有折扣
算下来每次只要XX元
您觉得呢？
```

### 1.2 "我再看看"

```
没问题～您主要还想了解哪方面？
是产品效果？还是价格？
我可以帮您对比一下
```

### 1.3 "不需要"

```
理解的～您现在确实可能不太需要
不过咱们这个新人福利确实划算
您可以先体验一下，反正也不吃亏
万一以后用得上呢？
```

### 1.4 "怕效果不好"

```
这个担心很正常～
咱们有X位客户用过后反馈[真实评价]
而且我们承诺[零风险承诺]
如果不满意，随时可以退
您完全没有风险的～
```

## 二、行业特定异议

### 2.1 餐饮

| 异议 | 话术 |
|------|------|
| "太远" | "我们有配送服务/新店开业满减，值得跑一趟" |
| "吃过类似的" | "咱们主打[特色]，和别家不一样，您试试就知道" |
| "一个人不想去" | "咱们支持双人套餐，叫个朋友一起来更划算" |

### 2.2 教培

| 异议 | 话术 |
|------|------|
| "孩子没时间" | "咱们周末/晚间都有课，时间很灵活" |
| "不知道适不适合" | "先体验一节课，孩子喜欢再报，不喜欢也没关系" |
| "价格高" | "一节课XX元，但包含[服务内容]，算下来比别家性价比高" |

### 2.3 美业

| 异议 | 话术 |
|------|------|
| "怕没效果" | "先体验一次，效果看得见再决定后续" |
| "怕推销" | "咱们纯服务，不强制消费，您放心体验" |
| "没时间" | "一次只要X小时，一周来一次就当放松" |
