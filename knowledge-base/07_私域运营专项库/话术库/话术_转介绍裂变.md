# 话术_转介绍裂变

> 版本：v1.0 | 创建日期：2026-05-04

## 一、转介绍铺垫话术

### 1.1 满意度最高时提出

```
XX您好～看您今天体验挺好的
身边有没有朋友也有[需求]的呀？
推荐朋友来，您和朋友都能获得[奖励]
就当帮朋友一个忙，还能拿优惠～
```

### 1.2 复购后提出

```
感谢您第N次光临！
您是我们的忠实客户了，身边有没有朋友也需要[服务]的？
您推荐的朋友，第一次体验都享[新客价]
您也能获得[奖励/积分/优惠券]
```

## 二、裂变活动话术

### 2.1 拼团活动

```
【拼团通知】
XX您好～咱们正在做拼团活动
[产品/服务] 3人成团享XX元（原价XX元）
您还差X人就能成团啦
拉朋友一起拼，大家都便宜～
```

### 2.2 邀请有礼

```
【邀请福利】
XX您好～邀请您参加"老带新"活动
每邀请1位朋友添加企微，您得XX元优惠券
邀请3位，额外得[大奖]
朋友还能享新人体验价
双赢哦～
```

## 三、阶梯激励话术

| 邀请人数 | 奖励 | 话术 |
|---------|------|------|
| 1人 | XX元优惠券 | "推荐1位朋友，您就获得XX元优惠" |
| 3人 | XX元+赠品 | "再推荐2位，总共送XX元+赠品" |
| 5人 | 免单1次 | "推荐5位，直接免单一次！" |
| 10人 | VIP特权 | "推荐10位，升级VIP永久折扣" |

```
XX您好～告诉您个好消息！
您已经推荐了X位朋友，再推荐X位就能解锁[下一级奖励]
目前全群只有3个人达到这个级别
您加油哦～
```
