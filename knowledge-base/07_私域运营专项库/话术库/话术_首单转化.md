# 话术_首单转化

> 版本：v1.0 | 创建日期：2026-05-04

## 一、通用首单转化话术

### 1.1 欢迎后2小时（私聊）

```
XX您好～刚才给您发的新人福利看到了吗？
今天下单的话还能额外享受[赠品/加量]
我给您预留名额，您看今天方便吗？
```

### 1.2 欢迎后24小时（私聊）

```
XX您好，昨天的新人福利还剩最后2小时～
错过就要恢复原价了
现在下单我再帮您申请[额外福利]
您看要不要给您留着？
```

### 1.3 犹豫客户逼单

```
理解您还在考虑～不过这个新人价只有今天有
您先体验一下，不满意随时退
我这边先帮您下单？收到后试用再决定
```

## 二、餐饮首单转化话术

```
XX您好～咱们[门店名]的新人体验套餐还有最后5份
原价XX元，新人只要XX元
包含：[菜品清单]
您看今天还是明天过来？我帮您提前预留位置～
```

## 三、教培首单转化话术

```
家长您好～咱们体验课本周只剩3个名额了
您看周六上午还是下午方便？
提前约好，体验课后孩子喜欢的话
还能再享新人报名优惠～
```

## 四、美业首单转化话术

```
XX您好～咱们的新客体验项目还剩最后2个名额
原价XX元，新客体验只要XX元
包含：[项目清单]
您看这周哪天有空？我帮您安排最好的技师～
```

## 五、关键技巧

1. **限时紧迫感**：新人福利倒计时
2. **稀缺性**：名额有限/库存有限
3. **降低决策门槛**：先体验再决定
4. **额外福利加码**：犹豫时追加赠品
5. **主动替客户做决定**：提供二选一（今天/明天）
