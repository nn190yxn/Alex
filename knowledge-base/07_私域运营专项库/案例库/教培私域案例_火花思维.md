# 教培私域案例：火花思维私域运营拆解

> 版本：v1.0 | 创建日期：2026-05-04

## 一、案例背景

火花思维是在线教育行业私域运营的标杆，通过"体验课引流+企微跟进+社群转化"模式，实现高转化率。

## 二、私域架构

```
抖音/小红书（内容引流）
    ↓
体验课报名（免费/低价）
    ↓
企微顾问1v1跟进
    ↓
正式课转化（社群+私聊）
    ↓
续费+转介绍
```

## 三、核心策略

### 3.1 体验课引流
- 抖音/小红书发布教育干货
- 主页留企微二维码
- 免费体验课诱饵
- 结果：日均新增线索5000+

### 3.2 企微跟进SOP
- T+0：欢迎语+体验课预约
- T+1：体验课前提醒
- T+2：体验课后回访
- T+3：正式课优惠推送
- T+7：1v1沟通报名意向

### 3.3 社群运营
- 体验课群：集中转化
- 正式课群：服务+续费
- 会员群：转介绍裂变

### 3.4 续费+转介绍
- 续费预警：课时剩余20%触发
- 成长档案：每月推送学习报告
- 老带新：双方各获2课时

## 四、关键数据

| 指标 | 数据 |
|------|------|
| 体验课转化率 | 30-50% |
| 正式课续费率 | 70%+ |
| 转介绍率 | 25-35% |
| 私域GMV占比 | 50%+ |

## 五、可借鉴点

1. **体验课诱饵**：低门槛获取精准线索
2. **SOP跟进**：标准化流程提升转化率
3. **成长档案**：增强价值感知促进续费
4. **转介绍裂变**：老带新降低获客成本

**适用行业**：教培、在线教育、素质教育
