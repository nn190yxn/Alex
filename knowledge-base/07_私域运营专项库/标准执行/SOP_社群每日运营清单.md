# SOP_社群每日运营清单

> 版本：v1.0 | 创建日期：2026-05-04

## 一、每日运营时间表

| 时间 | 内容类型 | 示例 | 目标 |
|------|---------|------|------|
| 08:00 | 早安问候 | 行业早报+今日预告 | 唤醒社群 |
| 11:00 | 专业价值 | 干货/技巧/避坑指南 | 建立信任 |
| 14:00 | 互动活动 | 投票/问答/抽奖 | 提升活跃 |
| 17:00 | 营销推广 | 限时优惠/新品上市 | 促进转化 |
| 20:00 | 生活日常 | 团队日常/客户故事 | 拉近距离 |

## 二、内容比例检查

- [ ] 专业价值内容 ≥ 40%
- [ ] 生活日常内容 ≥ 20%
- [ ] 互动活动内容 ≥ 20%
- [ ] 营销推广内容 ≤ 20%

## 三、每日检查清单

### 3.1 内容发布

- [ ] 5条内容已按时发布
- [ ] 内容无错别字/链接可点击
- [ ] 图片清晰/排版整齐
- [ ] 无敏感词/违规内容

### 3.2 互动管理

- [ ] 群内消息及时回复（2小时内）
- [ ] 客户问题已解答
- [ ] 广告/ spam已清理
- [ ] 活跃客户已互动

### 3.3 数据记录

- [ ] 今日新增人数：___
- [ ] 今日退群人数：___
- [ ] 今日发言人数：___
- [ ] 今日成交额：___

## 四、每周固定活动

| 日期 | 活动 | 目标 |
|------|------|------|
| 周一 | 本周福利预告 | 提升期待 |
| 周三 | 会员日专属折扣 | 促进转化 |
| 周五 | 周末活动预热 | 提升活跃 |
| 周日 | 本周总结+下周预告 | 建立习惯 |
