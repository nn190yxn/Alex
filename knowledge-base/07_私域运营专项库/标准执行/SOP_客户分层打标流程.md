# SOP_客户分层打标流程

> 版本：v1.0 | 创建日期：2026-05-04

## 一、5维度标签体系

### 1.1 基础属性

| 标签 | 值 | 来源 |
|------|---|------|
| 性别 | 男/女 | 企微资料 |
| 年龄段 | 18-25/26-35/36-45/46+ | 企微资料/沟通 |
| 职业 | 白领/宝妈/学生/其他 | 沟通记录 |
| 地域 | 周边3km/3-5km/5km+ | 地址信息 |

### 1.2 来源渠道

| 标签 | 值 |
|------|---|
| 渠道 | 抖音/小红书/美团/门店/转介绍/地推 |
| 时间 | 添加日期 |
| 活动 | 首次接触的活动名称 |

### 1.3 消费行为

| 标签 | 值 |
|------|---|
| 首单日期 | YYYY-MM-DD |
| 消费次数 | 数字 |
| 累计金额 | 数字 |
| 平均客单价 | 数字 |
| 最近消费 | YYYY-MM-DD |

### 1.4 意向程度

| 标签 | 值 | 判断标准 |
|------|---|---------|
| 高意向 | 🔴 | 主动咨询/多次进店/对比竞品 |
| 中意向 | 🟡 | 偶尔互动/浏览产品/价格敏感 |
| 低意向 | 🟢 | 被动添加/很少互动/无消费 |

### 1.5 生命周期

| 标签 | 值 | 定义 |
|------|---|------|
| 潜在客户 | ⚪ | 已添加但未消费 |
| 新客 | 🔵 | 首单后30天内 |
| 活跃客 | 🟢 | 30-90天，2-3次消费 |
| 忠诚客 | 🟣 | 90天+，会员/储值 |
| 沉睡客 | 🟠 | 60-90天未消费 |
| 流失客 | 🔴 | 180天+未消费 |

## 二、打标SOP

### 2.1 自动打标

- 添加时自动标记来源渠道
- 首单后自动标记消费行为
- 60天未消费自动标记沉睡

### 2.2 手动打标

- 1v1沟通后更新意向程度
- 消费后更新消费行为
- 每月复盘更新生命周期

### 2.3 打标频率

| 标签类型 | 频率 | 负责人 |
|---------|------|-------|
| 基础属性 | 添加时+每月更新 | 系统+人工 |
| 来源渠道 | 添加时 | 系统 |
| 消费行为 | 每次消费后 | 系统 |
| 意向程度 | 每周更新 | 人工 |
| 生命周期 | 每日更新 | 系统 |
