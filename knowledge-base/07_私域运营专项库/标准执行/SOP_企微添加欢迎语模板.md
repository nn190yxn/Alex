# SOP_企微添加欢迎语模板

> 版本：v1.0 | 创建日期：2026-05-04

## 一、欢迎语设计原则

**黄金10分钟法则**：客户添加企微后10分钟内必须通过并发送欢迎语，通过率下降50%+

## 二、标准欢迎语模板

### 2.1 通用版

```
您好！欢迎添加[品牌名]企业微信～

🎁 新人福利：
[具体福利内容]
回复"1"立即领取

📋 专属服务：
- 1v1专属顾问
- 每周专属福利
- 优先预约权

有任何问题随时联系我，祝您生活愉快！😊
```

### 2.2 餐饮版

```
您好！欢迎来到[门店名]客户专属服务～

🎁 新人专享：
首次到店体验价XX元（原价XX元）
回复"体验"立即预约

📋 群福利：
每周三会员日专属折扣
每日特价菜群内预售
不定期抽奖活动

回复"进群"加入VIP福利群～
```

### 2.3 教培版

```
家长您好！欢迎加入[机构名]学习交流群～

📚 新人福利：
免费体验课1节（价值XX元）
回复"体验"立即预约

📋 专属服务：
- 1v1学习规划
- 每周教育干货
- 学员成果展示

请问孩子目前几年级？我为您推荐合适的课程～
```

### 2.4 美业版

```
您好！欢迎加入[门店名]美丽顾问服务～

🎁 新人专享：
首次体验价XX元（原价XX元）
回复"体验"立即预约

📋 专属服务：
- 1v1肌肤咨询
- 定制护理方案
- 会员日专属折扣

请问您目前最想改善的肌肤问题是？
```

## 三、欢迎语跟进SOP

| 时间 | 动作 | 目标 |
|------|------|------|
| T+0 | 自动发送欢迎语 | 建立第一印象 |
| T+2h | 1v1私聊跟进 | 确认收到福利 |
| T+24h | 推送首单优惠 | 促进首单转化 |
| T+3天 | 体验回访 | 收集反馈 |

## 四、注意事项

1. **个性化**：根据来源渠道定制欢迎语
2. **简洁**：不超过5行，重点突出
3. **行动指引**：明确告知客户下一步操作
4. **避免营销**：首条消息以欢迎+福利为主
