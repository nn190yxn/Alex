# SOP_沉睡客户激活流程

> 版本：v1.0 | 创建日期：2026-05-04

## 一、沉睡客户定义

| 行业 | 沉睡阈值 | 流失阈值 |
|------|---------|---------|
| 餐饮 | 30天未到店 | 60天未到店 |
| 教培 | 课时剩余20% | 课程结束未续费 |
| 美业 | 45天未到店 | 90天未到店 |
| 同城服务 | 60天未消费 | 180天未消费 |

## 二、激活SOP（四阶段）

### 阶段1：T+30（预警期）

**动作**：
- 系统标记"沉睡预警"
- 推送定向优惠券（8折/满减）
- 朋友圈定向可见（仅沉睡客户）

**话术**：
```
XX您好，好久不见！
最近我们上了[新品/新活动]，老客户专享价XX元
这个月回来体验一下？给您预留名额～
```

### 阶段2：T+45（触达期）

**动作**：
- 1v1私聊了解原因
- 推送个性化推荐（根据历史消费）
- 邀请参加会员日活动

**话术**：
```
XX您好，最近工作忙吗？
好久没见您过来了，有什么需要我帮忙的吗？
```

### 阶段3：T+60（激活期）

**动作**：
- 电话回访（非消息）
- 提供超预期激活方案
- 记录流失原因

**电话脚本**：
```
【开场】
XX您好，我是[门店名]的[姓名]，好久没见您过来了，
特意打电话问候一下～

【探询原因】
最近是不是太忙了？还是有什么不满意的地方？

【激活方案】
这样吧，我给您申请了一个老客户专属福利：
[超常规优惠/免费体验/赠品]
您看这周有空过来吗？
```

### 阶段4：T+90（最终召回）

**动作**：
- 最终召回方案（年度最大优惠）
- 如无响应标记为"流失"
- 纳入季度召回名单

## 三、激活效果追踪

| 指标 | 目标值 | 计算公式 |
|------|-------|---------|
| 预警触达率 | ≥90% | 已触达数/沉睡总数 |
| 激活成功率 | ≥10% | 激活数/沉睡总数 |
| 激活后留存率 | ≥50% | 激活后30天仍活跃数/激活数 |
