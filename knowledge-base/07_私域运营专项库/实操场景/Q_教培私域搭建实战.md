# Q_教培私域搭建实战

> 版本：v1.0 | 创建日期：2026-05-04

## 一、教培私域搭建全流程（0-90天）

### 第1-2周：基建期

**企微账号设置**：
- 企业微信认证（教育机构资质）
- 顾问号配置（1个顾问负责50-100个家长）
- 社群分类（体验课群/正式课群/会员群）
- 渠道活码（抖音/小红书/地推/转介绍）

**欢迎语SOP**：
```
【自动欢迎语】
家长您好！欢迎加入[机构名]学习交流群～

📚 新人福利：
免费体验课1节（价值XX元）
回复"体验"立即预约

📋 群福利：
每周教育干货分享
学员成果展示
不定期免费公开课
```

### 第3-4周：引流期

**线上引流**：
- 抖音/小红书发布教育干货
- 主页留企微二维码
- 朋友圈广告投放（定向周边5公里/有孩家庭）
- 目标：日均新增20-50人

**线下引流**：
- 地推活动（学校周边/商场）
- 体验课邀约
- 目标：日均新增30-80人

### 第5-8周：转化期

**体验课转化**：
- 体验课前1天提醒
- 体验课后24小时内回访
- 48小时内推送正式课优惠
- 目标：体验课→正式课转化率30-50%

**正式课跟进**：
- 每周学习反馈
- 每月成长档案
- 目标：续费率60-80%

### 第9-12周：留存期

**续费预警机制**：
- 课时剩余30%：开始铺垫续费
- 课时剩余20%：触发续费提醒
- 课时剩余10%：1v1沟通续费方案
- 目标：续费率≥60%

**转介绍裂变**：
- 老带新奖励（双方各获2课时）
- 荣誉家长评选
- 学员成果展示（家长朋友圈转发）
- 目标：转介绍率≥25%
