# Q_复购率提升实战

> 版本：v1.0 | 创建日期：2026-05-04

## 一、复购率诊断模型

### 1.1 复购率计算公式

```
复购率 = 周期内2次以上消费客户数 / 总客户数 × 100%

行业基准：
- 餐饮：25-35%（月）
- 教培：60-80%（季度）
- 美业：40-60%（月）
- 同城服务：20-30%（季度）
```

### 1.2 复购率低的原因诊断

| 可能原因 | 诊断方法 | 解决策略 |
|---------|---------|---------|
| 首单体验差 | 回访收集反馈 | 优化产品/服务 |
| 缺乏触达 | 检查触达频率 | 增加朋友圈/私聊/社群触达 |
| 没有会员体系 | 检查是否有储值/积分 | 上线会员体系 |
| 竞对分流 | 调研竞对活动 | 差异化竞争+锁定机制 |
| 需求变化 | 分析客户生命周期 | 推送关联产品 |

## 二、复购提升四大策略

### 策略1：会员储值锁定
- 储值金额=月均消费×3-5倍
- 赠送比例16-30%
- 预期效果：复购率+15-25%

### 策略2：会员日固定化
- 每周/每月固定日期
- 专属折扣8.5-9折
- 预期效果：复购率+10-20%

### 策略3：沉睡客户激活
- 30/60/90天分级触达
- 定向优惠券+1v1回访
- 预期效果：激活率10-20%

### 策略4：转介绍裂变
- 老带新双向奖励
- 阶梯激励（推荐越多奖励越高）
- 预期效果：转介绍率15-25%
