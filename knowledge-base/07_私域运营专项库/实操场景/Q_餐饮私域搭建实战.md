# Q_餐饮私域搭建实战

> 版本：v1.0 | 创建日期：2026-05-04

## 一、餐饮私域搭建全流程（0-90天）

### 第1周：基建期

**企微账号设置**：
- 企业微信认证（需营业执照）
- 客服号配置（1-2个，负责1v1私聊）
- 社群号配置（按门店/区域分群）
- 渠道活码部署（门店/抖音/美团/公众号）

**欢迎语SOP**：
```
【自动欢迎语】
您好！欢迎来到[门店名]客户专属服务群～

🎁 新人福利：
首次体验专享价XX元（原价XX元）
回复"1"立即领取

📋 群福利：
每周三会员日专属折扣
每日特价菜群内预售
不定期抽奖活动
```

### 第2-3周：引流期

**门店引流**：
- 收银台二维码（扫码点餐+入群）
- 桌贴二维码（扫码领优惠券）
- 服务员引导（"加群享会员价"）
- 目标：日均新增50-100人

**线上引流**：
- 抖音主页留企微二维码
- 美团/大众点评留联系方式
- 朋友圈广告投放（定向周边3公里）
- 目标：日均新增20-50人

### 第4-6周：转化期

**首单转化**：
- 新人专享券（入群即送）
- 限时优惠（24小时内有效）
- 1v1私聊跟进（入群后2小时内）
- 目标：首单转化率8-15%

**二单引导**：
- 首单后3天推送二单优惠
- 首单后7天回访+关联推荐
- 目标：二单转化率40-60%

### 第7-12周：留存期

**会员体系上线**：
- 储值方案：充500送80/充1000送200
- 会员日：每周三会员专享折扣
- 积分体系：消费1元=1积分
- 目标：会员转化率25-35%

**社群运营常态化**：
- 每日内容日历（5条/天）
- 每周会员日活动
- 每月拼团/秒杀活动
- 目标：社群活跃度>15%

## 二、餐饮私域核心数据指标

| 指标 | 目标值 | 当前值 | 状态 |
|------|-------|-------|------|
| 日均新增好友 | 50-100人 | - | - |
| 首单转化率 | ≥8% | - | - |
| 二单转化率 | ≥40% | - | - |
| 会员转化率 | ≥25% | - | - |
| 复购率（月） | ≥25% | - | - |
| 储值率 | ≥15% | - | - |
| 社群活跃度 | >15% | - | - |

## 三、餐饮私域避坑指南

1. **不要只加粉不运营**：好友数增长但活跃度为0
2. **不要每日群发广告**：内容价值:营销 = 4:1
3. **不要忽视首单转化**：加群后24小时内必须促单
4. **不要没有会员体系**：复购率低于15%说明缺乏锁定机制
5. **不做数据追踪**：每周复盘引流/转化/复购数据
