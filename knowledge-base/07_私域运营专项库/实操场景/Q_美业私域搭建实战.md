# Q_美业私域搭建实战

> 版本：v1.0 | 创建日期：2026-05-04

## 一、美业私域搭建全流程（0-90天）

### 第1-2周：基建期

**企微账号设置**：
- 企业微信认证（美业资质）
- 美容顾问号配置（1个顾问负责100-200个客户）
- 社群分类（新客群/会员群/VIP群）
- 渠道活码（抖音/小红书/美团/门店）

**欢迎语SOP**：
```
【自动欢迎语】
您好！欢迎加入[门店名]美丽顾问服务～

🎁 新人福利：
首次体验专享价XX元（原价XX元）
回复"体验"立即预约

📋 专属服务：
1v1肌肤咨询
定制护理方案
会员日专属折扣
```

### 第3-4周：引流期

**线上引流**：
- 抖音/小红书发布护肤干货/前后对比
- 主页留企微二维码
- 朋友圈广告投放（定向周边3公里/女性）
- 目标：日均新增30-60人

**门店引流**：
- 前台二维码（扫码预约+入群）
- 护理师引导（"加企微享会员价"）
- 目标：日均新增20-40人

### 第5-8周：转化期

**首单转化**：
- 新人体验券（入群即送）
- 1v1肌肤咨询（建立信任）
- 推荐定制护理方案
- 目标：首单转化率10-20%

**二单引导**：
- 首单后3天回访（护理感受）
- 首单后7天推送关联项目
- 目标：二单转化率50-70%

### 第9-12周：留存期

**会员卡体系**：
- 次卡：10次卡/20次卡（锁定消费）
- 储值卡：充1000送200/充3000送800
- 周期卡：月卡/季卡/年卡
- 目标：办卡率≥40%

**耗卡追踪**：
- 卡项剩余50%：提醒使用
- 卡项剩余30%：主动邀约
- 卡项剩余10%：推荐续卡
- 目标：耗卡率≥70%
