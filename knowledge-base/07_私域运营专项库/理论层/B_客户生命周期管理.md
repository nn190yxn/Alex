# B_客户生命周期管理

> 来源：整合自企业微信私域运营SOP、续费活动方案、会员储值方案、会员卡方案
> 版本：v1.0 | 创建日期：2026-05-04

## 一、客户生命周期模型

```
潜在客户 → 新客(首单) → 活跃客(2-3单) → 忠诚客(会员) → 沉睡客 → 流失客
   ↓           ↓            ↓            ↓          ↓         ↓
  引流       转化培育      复购提升      会员锁定    激活挽回   召回或放弃
```

### 1.1 各阶段定义与特征

| 阶段 | 定义 | 特征 | 运营重点 | 预期转化率 |
|------|------|------|---------|-----------|
| 潜在客户 | 已添加企微但未消费 | 观望、对比、信任不足 | 首单钩子、信任建立 | 8-15% |
| 新客 | 完成首单（30天内） | 体验中、评价形成期 | 回访关怀、二单引导 | 40-60% |
| 活跃客 | 2-3次消费（30-90天） | 认可价值、开始依赖 | 会员转化、储值引导 | 25-40% |
| 忠诚客 | 会员/储值客户（90天+） | 高频消费、主动推荐 | 专属权益、转介绍 | 60-80% |
| 沉睡客 | 60-90天未消费 | 需求变化、竞对分流 | 激活优惠、电话回访 | 10-20% |
| 流失客 | 180天+未消费 | 已转移、满意度低 | 召回或放弃 | 3-5% |

## 二、客户生命周期管理SOP

### 2.1 T+0（首单当天）

**动作**：
- 首单后2小时内发送感谢消息
- 24小时内发送使用指南/注意事项
- 引导添加企微/入群（如未添加）

**话术模板**：
```
【感谢消息】
感谢您的首次体验！使用过程中如有任何问题，随时联系我～
附上使用指南：[链接]

【入群引导】
我们有个VIP客户群，每周有专属福利和秒杀活动，邀请您加入：
[群二维码]
```

### 2.2 T+7（首单后第7天）

**动作**：
- 首次体验回访（电话/企微私聊）
- 收集反馈，解决不满
- 推荐关联项目/二单优惠

**回访话术**：
```
【回访模板】
XX您好，上次体验的[项目名称]感觉怎么样？
有什么需要改进的地方吗？

【二单引导】
这周我们有[关联项目]的体验活动，老客户专享价XX元，
名额有限，帮您预留一个？
```

### 2.3 T+30（首单后第30天）

**动作**：
- 推送会员专享优惠
- 引导办理会员卡/储值
- 邀请参加会员日活动

**会员转化话术**：
```
【储值引导】
XX您好，我们本月有储值活动：
充500送80，充1000送200
相当于直接打折，而且长期有效
很多老客户都办了，您考虑一下？
```

### 2.4 T+60（沉睡预警触发）

**动作**：
- 系统标记为"沉睡预警"
- 发送定向激活优惠券
- 1v1私聊了解原因

**激活话术**：
```
【沉睡激活】
XX您好，好久不见！
最近我们上了[新品/新活动]，老客户专享价XX元
这个月回来体验一下？给您预留名额～
```

### 2.5 T+90（沉睡激活）

**动作**：
- 电话回访（非消息）
- 了解流失原因
- 提供超预期挽回方案

**电话回访脚本**：
```
【开场】
XX您好，我是[门店名]的[姓名]，好久没见您过来了，
特意打电话问候一下～

【探询原因】
最近是不是太忙了？还是有什么不满意的地方？
您的反馈对我们很重要...

【挽回方案】
这样吧，我给您申请了一个老客户专属福利：
[超常规优惠/免费体验/赠品]
您看这周有空过来吗？
```

## 三、客户分层运营策略

### 3.1 RFM分层模型

| 层级 | R(最近消费) | F(消费频次) | M(消费金额) | 运营策略 |
|------|-----------|-----------|-----------|---------|
| 重要价值客户 | ≤30天 | ≥4次 | ≥2000元 | VIP专属服务、优先体验新品 |
| 重要发展客户 | ≤30天 | 1-3次 | ≥1000元 | 引导储值、提升频次 |
| 重要保持客户 | 31-60天 | ≥4次 | ≥2000元 | 激活回访、防止沉睡 |
| 重要挽留客户 | 61-90天 | ≥4次 | ≥2000元 | 电话回访、超预期挽回 |
| 一般价值客户 | ≤30天 | 1-3次 | <1000元 | 推送优惠、提升客单价 |
| 一般发展客户 | ≤30天 | 1次 | <500元 | 新客培育、引导二单 |
| 一般保持客户 | 31-60天 | 1-3次 | <1000元 | 定期触达、防止流失 |
| 一般挽留客户 | 61-90天 | 1-3次 | <500元 | 激活优惠、低成本召回 |

### 3.2 各层级触达频率

| 层级 | 朋友圈可见 | 私聊频率 | 社群 | 电话 |
|------|-----------|---------|------|------|
| 重要价值 | 每日可见 | 每周1次 | VIP群 | 每月1次 |
| 重要发展 | 每日可见 | 每2周1次 | 普通群 | 每季度1次 |
| 重要保持 | 每日可见 | 每周1次 | 普通群 | 每2月1次 |
| 重要挽留 | 每日可见 | 每周2次 | 普通群 | 每月1次 |
| 一般客户 | 每日可见 | 每月1次 | 普通群 | 不主动 |

## 四、行业生命周期差异

### 4.1 餐饮行业

**生命周期特征**：
- 新客→活跃客：7-14天（高频）
- 活跃客→忠诚客：30-60天
- 沉睡阈值：30天未到店
- 流失阈值：60天未到店

**关键动作**：
- 首单后3天推送二单优惠
- 30天未到店触发沉睡预警
- 会员日固定化培养消费习惯

### 4.2 教培行业

**生命周期特征**：
- 新客→活跃客：1-2个月（体验课→正式课）
- 活跃客→忠诚客：3-6个月（续费率关键期）
- 沉睡阈值：课时剩余20%
- 流失阈值：课程结束未续费

**关键动作**：
- 课时剩余30%开始续费铺垫
- 课时剩余20%触发续费预警
- 课程结束前1个月启动续费方案

### 4.3 美业行业

**生命周期特征**：
- 新客→活跃客：14-30天
- 活跃客→忠诚客：60-90天（办卡/储值）
- 沉睡阈值：45天未到店
- 流失阈值：90天未到店

**关键动作**：
- 首单后7天回访+二单引导
- 卡项剩余30%主动邀约
- 45天未到店触发沉睡激活

## 五、客户生命周期数据看板

### 5.1 核心监控指标

| 指标 | 计算公式 | 健康标准 |
|------|---------|---------|
| 新客转化率 | 首单客户数/新增好友数 | ≥8% |
| 二单转化率 | 2单客户数/首单客户数 | ≥40% |
| 会员转化率 | 会员数/活跃客户数 | ≥25% |
| 复购率 | 周期内2次以上消费客户数/总客户数 | 餐饮≥25%/教培≥60%/美业≥40% |
| 沉睡激活率 | 激活沉睡客户数/沉睡客户总数 | ≥10% |
| 客户流失率 | 流失客户数/期初客户数 | ≤15%/月 |
| 平均生命周期 | 客户首次消费到最后一次消费的天数 | 餐饮≥180天/教培≥365天/美业≥270天 |

### 5.2 生命周期价值(LTV)计算

```
LTV = 客单价 × 年均消费频次 × 平均留存年数

餐饮示例：
客单价 50元 × 月均4次 × 12月 × 1.5年 = 3,600元

教培示例：
客单价 5,000元 × 年均1.5次 × 2年 = 15,000元

美业示例：
客单价 300元 × 月均2次 × 12月 × 2年 = 14,400元
```
