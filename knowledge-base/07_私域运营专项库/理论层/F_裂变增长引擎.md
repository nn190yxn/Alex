## 一、裂变增长核心模型

### 1.1 K值（裂变系数）模型

```
K = 每个客户平均推荐人数 × 被推荐人转化率

K > 1：指数增长（病毒式传播）
K = 0.3-0.8：线性增长（稳健但缓慢）
K < 0.3：需要持续外部流量输入
```

### 1.2 裂变漏斗模型

```
参与活动人数
    ↓ × 参与率（20-40%）
分享活动人数
    ↓ × 分享转化率（15-30%）
被推荐点击人数
    ↓ × 注册转化率（30-50%）
新注册用户
    ↓ × 首单转化率（20-40%）
新付费客户
```

## 二、四大裂变模式

### 2.1 转介绍裂变（K=0.3-0.8）

**适用行业**：教培、美业（高信任、重口碑）

**激励机制**：
- 双向奖励：老客得XX元优惠券，新客得XX元体验价
- 阶梯奖励：推荐1人得A，推荐3人得B，推荐5人得C
- 荣誉激励：荣誉家长、推荐达人排行榜

**预期效果**：转介绍率15-25%、新客中老客户推荐占比30-50%

### 2.2 拼团裂变（K=0.5-1.5）

**适用行业**：餐饮、同城服务（低决策门槛）

**玩法设计**：
- 3人成团享X折（7-8.5折）
- 团长额外优惠（免单/双倍积分）
- 限时成团（24-48小时）

**预期效果**：单次活动参与率20-40%、新客占比50-70%

### 2.3 分销裂变（K=1.0-3.0）

**适用行业**：美业、教培（高客单价、高佣金空间）

**机制设计**：
- 一级分销：推荐成交获10-20%佣金
- 二级分销：间接推荐获5-10%佣金
- KOC培养：从活跃客户中培养分销员

**预期效果**：KOC人均月推荐3-5人、分销收入占总收入15-30%

### 2.4 内容裂变（K=0.2-0.6）

**适用行业**：全行业（低成本、长期效应）

**内容类型**：
- 客户见证/案例展示（社交认同）
- 专业知识/干货分享（价值传递）
- 趣味互动/话题讨论（社交传播）

**预期效果**：单篇内容转发率5-15%、间接获客10-20%

## 三、裂变活动设计SOP

### 3.1 活动设计五步法

1. **设计诱饵**：高感知价值、低边际成本（体验课/招牌菜/护理体验）
2. **设置规则**：明确参与条件、奖励机制、有效期
3. **种子用户**：从最活跃的20%客户中邀请参与
4. **社交传播**：通过企微群、朋友圈、小程序分享扩大影响
5. **数据追踪**：每日监控参与率、转化率、K值，及时调整

### 3.2 裂变活动检查清单

- [ ] 诱饵价值感知是否足够强？
- [ ] 参与门槛是否足够低？
- [ ] 奖励是否即时发放？
- [ ] 分享路径是否顺畅（1-2步完成）？
- [ ] 是否有紧迫感（限时/限量）？
- [ ] 是否有社交货币（可炫耀、可分享）？
- [ ] 数据追踪是否到位？

## 四、行业裂变策略差异

| 行业 | 推荐模式 | K值预期 | 核心诱饵 |
|------|---------|---------|---------|
| 餐饮 | 拼团裂变 | 0.8-1.5 | 秒杀套餐/折扣券 |
| 教培 | 转介绍裂变 | 0.5-0.8 | 免费课时/教材 |
| 美业 | 分销裂变 | 1.0-2.0 | 项目体验/佣金 |
| 同城服务 | 转介绍裂变 | 0.3-0.6 | 服务优惠券 |
