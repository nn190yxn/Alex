# E_复购留存模型

> 来源：整合自续费活动方案、会员储值方案、会员卡方案
> 版本：v1.0 | 创建日期：2026-05-04

## 一、复购留存核心模型

### 1.1 复购率计算公式

```
复购率 = 周期内2次以上消费客户数 / 总客户数 × 100%

行业基准：
- 餐饮：25-35%（月）
- 教培：60-80%（季度，续费率）
- 美业：40-60%（月）
- 同城服务：20-30%（季度）
```

### 1.2 客户留存曲线

```
100% ┤ 新客
     │
 80% ┤ 首单后7天
     │
 60% ┤ 首单后30天
     │
 40% ┤ 首单后60天（沉睡预警）
     │
 20% ┤ 首单后90天（沉睡）
     │
  5% ┤ 首单后180天（流失）
```

## 二、复购提升四大策略

### 2.1 策略一：会员储值锁定

**原理**：客户预付资金后，心理账户已消费，复购率提升50%+

**设计要点**：
- 储值金额设置为月均消费额的3-5倍
- 赠品选择高感知价值、低实际成本的项目
- 储值长期有效，降低决策压力

### 2.2 策略二：会员日固定化

**原理**：培养周期性消费习惯，形成条件反射

**执行要点**：
- 固定日期（每周三/每月8号）
- 专属折扣（8.5-9折）
- 提前3天预热（朋友圈+私聊+社群）

### 2.3 策略三：沉睡客户激活

**触发条件**：
- 餐饮：30天未到店
- 教培：课时剩余20%
- 美业：45天未到店

**激活流程**：
1. T+30：推送定向优惠券
2. T+45：1v1私聊了解原因
3. T+60：电话回访+超预期方案
4. T+90：最终召回或标记流失

### 2.4 策略四：转介绍裂变

**激励设计法则**：
- **即时性**：推荐成功立即奖励
- **双向性**：新老双方都获利
- **递增性**：推荐越多奖励越高
- **社交性**：奖励可分享、可炫耀

## 三、行业复购策略差异

### 3.1 餐饮行业

| 策略 | 执行方式 | 预期效果 |
|------|---------|---------|
| 会员日锁定 | 每周三会员专享折扣 | 复购率+15-25% |
| 储值返利 | 充500送80/充1000送200 | 客单价+30% |
| 积分兑换 | 消费1元=1积分 | 月均到店+1.2次 |
| 生日关怀 | 生日前3天推送专属套餐 | 到店率+40% |

### 3.2 教培行业

| 策略 | 执行方式 | 预期效果 |
|------|---------|---------|
| 续费预警 | 课时剩余20%触发提醒 | 续费率+20% |
| 成长档案 | 每月推送学习进度报告 | 留存率+25% |
| 老带新 | 双方各获2课时 | 转介绍率+35% |
| 成果展示 | 季度汇报会 | 口碑推荐+30% |

### 3.3 美业行业

| 策略 | 执行方式 | 预期效果 |
|------|---------|---------|
| 耗卡追踪 | 卡项剩余<30%主动邀约 | 耗卡率+40% |
| 项目升单 | 基础→进阶→定制 | 客单价+50% |
| 会员沙龙 | 每月护肤课堂 | 到店频次+2次/月 |
| 效果档案 | 护理前后拍照对比 | 信任度+60% |
