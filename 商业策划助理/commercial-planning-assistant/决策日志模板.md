## 决策记录

> 每次用户确认、修改或否决时追加一条记录。

### 记录格式

| 编号 | 日期 | 章节 | 决策类型 | 内容 | 原因 | 影响章节 |
|---|---|---|---|---|---|---|
| D001 | | | 确认/修改/否决 | | | |

### 决策类型说明

- **确认**：用户确认了初稿内容，该章节状态更新为verified
- **修改**：用户修改了内容，记录修改前后差异
- **否决**：用户否定了某个方向或判断，记录否决原因，后续章节不可重复该方向
