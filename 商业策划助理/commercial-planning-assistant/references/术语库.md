# 术语库

本文件收录商业地产行业专业术语，写作时按需查阅。

## 一、空间与规划

| 术语 | 含义 | 使用场景 |
|---|---|---|
| 动线/客流动线/人流动线 | 消费者在商业空间内的移动路径 | 分析楼层间客流传递、铺位可达性 |
| 柱网/柱距/进深/门面宽 | 建筑结构参数，影响铺位分割和业态适配 | 评估空间对业态的适配性 |
| 退台/露台/连廊 | 建筑外部空间元素 | 描述空间特色和外摆条件 |
| 容积率/建筑密度/绿地率 | 规划指标 | 项目概况描述 |
| 计容建筑面积/GFA | 总建筑面积 | 项目体量描述 |
| 可租赁面积/GLA | 可供出租的面积 | 招商和租金测算 |
| 得房率 | 可使用面积与建筑面积之比 | 评估实际可用空间 |
| 层高/净高 | 楼层高度参数 | 评估业态适配性 |
| 楼板荷载 | 楼板承重能力 | 评估业态适配性（如餐饮需较高荷载） |

| 术语 | 含义 | 使用场景 |
|---|---|---|
| 主力店/次主力店 | 引流能力强的大面积业态/次级引流业态 | 业态规划 |
| 首层租金/套内租金/保底租金 | 租金类型 | 租金测算 |
| 坪效/月坪效 | 单位面积产出 | 经营效率评估 |
| 扣率/扣点 | 按销售额抽成的租金模式 | 招商条件 |
| 业态/业态组合/业态配比/业态落位 | 商业类型及其在空间中的分布 | 业态规划 |
| 业种 | 零售业种分类（如服装/餐饮/服务） | 业态细分 |
| 冷区/热区 | 客流少/多的区域 | 铺位分析 |
| 调商率/换租率 | 租户更换频率 | 运营健康度评估 |
| 品牌级次/品牌矩阵/品牌落位 | 品牌档次和分布 | 招商策略 |
| 首店经济 | 品牌首次进入某区域开店 | 项目亮点 |
| 装修补贴 | 业主为租户提供的装修费用支持 | 招商条件 |
| 筹开期/预招商 | 项目筹备开业阶段 | 实施路径 |

## 三、市场与运营

| 术语 | 含义 | 使用场景 |
|---|---|---|
| 辐射范围/辐射半径/辐射能级/辐射人口 | 商业项目影响范围 | 市场分析 |
| 核心辐射范围 | 步行或驾车时间圈内的人群覆盖区域 | 核心客群分析 |
| 主力辐射范围 | 扩大时间圈后的人群覆盖区域 | 次核心客群分析 |
| 外围辐射范围 | 更远时间圈的人群覆盖区域 | 机会客群分析 |

辐射范围优先按步行或驾车时间圈测算，距离范围根据项目类型、交通方式、道路阻隔和城市密度确定，不固定为特定公里数。

| 术语 | 含义 | 使用场景 |
|---|---|---|
| 渗透率 | 辐射人口中到访项目的比例 | 客流估算 |
| 客质 | 客群质量（消费力/消费意愿） | 客群评估 |
| 客单价 | 单次消费金额 | 经营分析 |
| 空置率/出租率/签约率/入住率/入驻率 | 商业经营健康度指标 | 市场分析 |
| 新增供应/市场存量 | 市场供给量 | 市场分析 |
| 外溢消费/客群外溢 | 消费需求流向项目外 | 供给缺口分析 |
| 目的性消费/目的性到访 | 为特定业态专程到访 | 业态策略 |
| 同质化竞争 | 业态/品牌雷同 | 竞争分析 |
| 截留 | 在客流到达目标项目前被竞品拦截 | 竞争分析 |
| 内生性 | 项目内部客群支撑能力 | 混合业态分析 |
| 吸附力 | 商业项目吸引客流的能力 | 项目评估 |
