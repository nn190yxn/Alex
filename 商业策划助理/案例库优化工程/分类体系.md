# 分类体系

## 一级分类：商业模型

沿用原有五类，必要时增加复合标签，不强制每个案例只能归入一类：

1. 区域型购物中心/综合体
2. 城市级概念/产业文商旅
3. 街区/滨河/历史文化街区
4. 社区型非标商业
5. 混合业态资产激活

## 二级分类：项目问题

- 客流不足或客流结构单一
- 夜间消费不足
- 周末/工作日时段失衡
- 首层可见度或进入率不足
- 深层空间或边角空间低效
- 同质化竞争
- 招商填铺压力
- 品牌级次不足
- 目的性消费不足
- 社区复购不足
- 资产与内容脱节
- 商业与文旅资源脱节
- 存量资产改造约束
- 运营内容不可持续

## 三级分类：解决机制

- 错位定位
- 高频消费补足
- 首店/独家资源引入
- 主理人和本地品牌组合
- 快闪测试后转长期店
- 公共空间内容化
- 屋顶、地下或边角空间再利用
- IP/节事持续运营
- 会员与社群运营
- 异业联动
- 商业与物业服务绑定
- 街区动线和节点重组
- 品类深度运营
- 文化资源的商业化表达
- 数字化工具与消费闭环

## 四级分类：适用条件

- 城市能级
- 客群结构
- 资产类型
- 规模等级
- 空间开放程度
- 可投入强度
- 运营团队能力
- 招商资源能力
- 改造限制
- 产权和物业限制

## 标签使用规则

1. 标签必须能帮助筛选案例或形成判断，不能只描述项目宣传语。
2. 一个案例至少需要一个“问题标签”和一个“机制标签”。
3. 无原始依据的标签留空或标记“待判断”。
4. “高端、年轻、网红、品质、复合”等宽泛标签不得单独使用，必须补充可观察对象。
5. 分类和标签分开维护：分类回答“它属于哪类项目”，标签回答“它解决什么问题、用了什么机制”。
