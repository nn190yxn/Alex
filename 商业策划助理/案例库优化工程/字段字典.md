# 字段字典

## 基本字段

| 字段 | 含义 | 填写规则 |
|---|---|---|
| case_id | 原始案例编号 | 保留原编号，不重新命名 |
| project_name | 项目名称 | 使用公开来源中的正式名称 |
| aliases | 别名 | 只记录来源中明确出现的别名 |
| city | 城市 | 项目所在地 |
| model | 一级商业模型 | 沿用原有五类，可增加复合标签 |
| project_type | 项目类型 | 购物中心、街区、园区、文旅综合体等 |
| size | 体量 | 保留原始口径和单位，不自行换算 |
| space_type | 空间类型 | 盒子、开放街区、滨水、园区、复合资产等 |
| evidence_status | 优化后的证据状态 | 未整理/线索/部分核验/已核验/不采用 |

## 商业判断字段

| 字段 | 含义 |
|---|---|
| target_problem | 案例主要解决的问题 |
| customer_type | 目标或主要客群 |
| operation_goal | 经营或资产目标 |
| asset_condition | 资产、位置和空间的前提条件 |
| core_mechanism | 最核心的商业机制 |
| traffic_mechanism | 客流获取和转化机制 |
| space_mechanism | 空间、动线和场景机制 |
| tenant_brand_mechanism | 招商、品牌和业态机制 |
| content_operation_mechanism | 内容、活动和会员运营机制 |
| revenue_or_asset_effect | 可观察的经营或资产效果 |
| transferable_elements | 可迁移要素 |
| migration_conditions | 迁移成立的前提 |
| migration_difficulty | 迁移难度：低/中/高 |
| non_transferable_elements | 禁止直接迁移的条件或资源 |
| recommended_project_types | 推荐用于哪些项目类型 |
| verification_priority | 核验优先级：P0/P1/P2 |

## 证据字段

| 字段 | 含义 |
|---|---|
| source_url | 来源地址 |
| source_level | A/B/C 来源等级 |
| source_published_at | 来源发布日期 |
| accessed_at | 访问日期 |
| fact_scope | 来源支撑的具体事实范围 |
| verification_conclusion | 已确认/部分确认/冲突/无法确认 |
| reviewer_notes | 审查意见和待补录事项 |
