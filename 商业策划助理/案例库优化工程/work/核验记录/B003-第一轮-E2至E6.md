# B003第一轮核验｜案例E2至E6

访问日期：2026-08-14。

## E2 东京虎之门之丘（海外）

- 状态：部分核验。
- 项目身份：虎之门之丘（Toranomon Hills）是森大厦在东京虎之门地区推进的多阶段混合功能开发，由办公、住宅、商业、酒店和公共交通节点组成。
- 已确认机制：开发商将零售置于居住与办公集聚的城市功能复合体内，以整体街区运营、店铺联动及活动协同而非单店出租创造价值。
- 证据：森大厦商业业务页确认其商业设施嵌入“居住和工作”的城市综合体，并明确采用整体优化与店铺协同运营；公开资料可确认项目多阶段建设。
- 迁移边界：可借鉴“长期持有运营 + 多功能密度 + 站城连接 + 整体商业策划”；前提是有多主体协调能力、高密度稳定使用者和长期资产管理能力。不可复制东京核心区位、轨道网络和森大厦的土地整合能力。
- 待补：项目各塔楼的正式面积、开业时间、零售租户结构、客流和经营表现须补开发商项目页或年度报告。

## E3 深圳后海片区

- 状态：部分核验。
- 项目身份：后海片区是南山区“两核”之一、深圳湾CBD组成部分，承担商业商务、综合服务和居住生活等复合功能；它不是单一商业项目。
- 已确认机制：片区层面以总部商务、公共生活、滨海空间、步行连廊和夜景/公共空间提升共同塑造活力，而不是仅靠单一商业载体。
- 证据：深圳市政府工作报告确认后海—深圳湾片区的城市国际客厅定位与世界级商圈建设；南山区政府资料确认后海公共空间、连廊、滨海界面与夜间经济相关提升。
- 迁移边界：仅可作为CBD片区综合运营样本，借鉴“就业密度 + 公共空间 + 慢行连接 + 夜间内容”的协同方法；不得把片区级规划成果或公共投入直接归因于某个商业项目。
- 待补：原始案例所指的具体资产、运营主体、商业边界和项目级经营数据必须先完成消歧。

## E4 上海西岸梦中心

- 状态：部分核验。
- 项目身份：GATE M 西岸梦中心是华之门资本在上海徐汇西岸黄浦江畔运营的商业及公共文化空间。
- 已确认机制：项目以约800米滨江岸线和水岸/落日剧场等开放场景承接露天电影、音乐会和主题活动，再通过票根优惠连接餐饮、零售与休闲商户，把文化活动转化为夜间消费。
- 证据：上海徐汇官方账号转载的上观新闻报道确认运营主体、滨江场地、电影活动形态及票根联动机制。
- 迁移边界：可借鉴“滨水开放空间 + 文化内容日历 + 商户权益联动”的夜间消费模式；前提是有可开放的高质量公共空间、内容合作方、噪声/安全管理与稳定商业承接。不能脱离滨江公共资源和活动期流量，直接推断常态经营。
- 待补：正式开业时间、项目面积、租户结构、客流销售和活动转化率须以运营方年度资料补充。

## E5 东莞旗云广场

- 状态：部分核验。
- 项目身份：旗云广场位于东莞站TOD核心区，是东实集团打造、东莞文旅公司运营的莞北片区综合商业体，2025年12月31日开业。
- 已确认机制：依托铁路枢纽和区域生活配套，以首店/旗舰店矩阵、影院和主题快闪等内容，将交通节点转化为区域消费与社交目的地。
- 证据：东莞市石龙镇政府栏目和南方日报确认开发运营主体、13万平方米体量、开业时间、出租/开业率及开业期表现。
- 迁移边界：可借鉴“TOD通勤客流 + 区域级一站式配套 + 首店与活动”的组合；前提是具备持续可达的交通客流、周边居住消费基础、招商和活动运营能力。四天开业数据仅代表活动期，不可推作常态经营。
- 待补：正式租户清单、日常客流销售、交通客流转换率、租赁与联营结构。
