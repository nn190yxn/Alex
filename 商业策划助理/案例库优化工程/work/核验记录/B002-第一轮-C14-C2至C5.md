# B002第一轮核验｜案例C14、C2至C5

访问日期：2026-08-14。

## C14 成都CPI（麓湖CPI商业公园）

- 状态：部分核验。
- 项目身份：麓湖CPI商业公园位于四川天府新区，原为麓湖别墅样板间集合岛；一期于2024年3月底投运，后续分期建设。
- 已确认机制：以自然绿化、低密度独栋和非标准游逛路径弱化传统盒子商业感；以时尚零售、生活美学、设计师选品及体验业态为主体，并用品牌定制活动和社群内容维持复访。
- 证据：新华网和科技日报报道披露一期商业面积、自然绿化、独栋集群、业态比例、2024年客流与营业额，以及运营方对本地/外地客群和品牌活动的说明。
- 迁移边界：可借鉴“非标自然场景 + 独栋探索式游逛 + 高比例生活方式业态”的机制；需要拥有可步行停留的景观资源、低密度空间、精细招商和内容运营能力。不能直接复制麓湖湖区生态、样板间存量资产及高客单品牌资源。
- 待补：各期面积、品牌数量和经营数据须按时间口径拆分；运营数据尚需项目方年度正式资料交叉核验。

## C2 悉尼岩石区（The Rocks）

- 状态：部分核验。
- 项目身份：The Rocks 是悉尼最早的历史滨水街区之一，由新南威尔士州政府 Placemaking NSW 持有并管理。
- 已确认机制：历史街巷、遗产建筑和博物馆等成为日常游逛内容，而非孤立展品；运营端通过本地创作者市集、餐饮与节庆活动维持公共空间活力。
- 证据：新南威尔士州规划部门确认 Placemaking NSW 对 The Rocks 的持有与管理；The Rocks 官方平台确认历史建筑、博物馆和面向本地创作者、手作与餐饮的市场活动。
- 迁移边界：可借鉴“统一遗产管理 + 低干预建筑保护 + 常态化本地创作者市集”的组合；需要明确产权/运营权、严格而可执行的店招与外摆规则，并有稳定文旅和公共交通客流。不能复制悉尼港、海港大桥及殖民历史等城市级资源。
- 待补：原始材料中的店铺数、摊位数、外立面审批细则及具体经营表现均需按官方资料继续核验。
