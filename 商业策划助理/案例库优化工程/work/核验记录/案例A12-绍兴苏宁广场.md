# 案例A12｜绍兴苏宁广场

- 优化状态：部分核验
- 优先级：P0
- 访问日期：2026-08-14

## 已确认事实

绍兴市人民政府公开信息显示，项目于2026年6月18日开业，位于镜湖新区，商业建筑面积约17.5万平方米，总建筑面积约26万平方米，接驳地铁1、2号线。项目采用盒子MALL、露天中央广场、街区和屋顶花园的复合形态，并设置中央广场、屋顶花园和城市露营等场景。品牌数量、首店比例在不同官方/媒体信息中存在口径差异，暂不合并为单一数字。

- 问题：存量/复杂项目盘活、区域商业供给升级、单一盒子形态局限
- 机制：TOD接驳、盒子+街区+屋顶、公园化场景、酒店与商业联动、会员权益
- 迁移边界：只能借鉴复合空间和客流联动机制，不能直接复制项目体量、TOD条件和政府协同背景。
