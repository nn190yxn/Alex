# B002第五轮核验｜案例B6至B9、E1

访问日期：2026-08-14。

## B6 伦敦巴特西发电站

- 状态：部分核验。
- 项目身份：Battersea Power Station 是伦敦原发电站及周边棕地的混合功能再开发项目，保留并活化列级保护的发电站主体。
- 已确认机制：以遗产地标修复为识别核心，将零售、餐饮、娱乐、办公、住宅、公共空间及轨道交通接入置于同一片区；持续引进首店、展览和亲子服务，保持街区而非单一商场的复合使用。
- 证据：项目方公告确认其2022年开放后持续扩充零售、休闲和文化供给；工程顾问项目页确认原棕地、遗产修复、公共空间和零售餐饮混合开发。
- 迁移边界：可借鉴“遗产核心锚点 + 大片区混合功能 + 交通接入 + 持续招商更新”的长期开发逻辑；前提是具备长期资本、统一总体规划、遗产审批和多阶段运营能力。不可将其国际地标、伦敦住房办公市场及地铁新增站资源简单复制。
- 待补：各阶段投资、产权结构、分业态租赁表现、客流与商业收益的统一口径。

## B7 北海阿萨卡

- 状态：部分核验。
- 项目身份：阿萨卡网红城市/数字游民社区位于北海银滩片区滨江数字科技园，是以盘活非住宅存量为目标的数字产业与旅居消费复合项目。
- 已确认机制：项目将直播基地、影院、美术馆、餐饮、酒店等功能叠加，通过数字内容生产、创业旅居和消费场景而非传统住宅销售导入人流；同时承接城市级文化活动。
- 证据：广西媒体报道及北海市政府工作报告确认项目一期建设、数字游民社区定位，以及其作为文化活动场地的使用。
- 迁移边界：可借鉴“低效非住宅载体 + 数字内容生产 + 旅居服务 + 消费配套”的盘活路径；前提是有稳定的产业导入、运营主体、住宿和公共服务配套。不可把打卡流量或单次大会的热度等同于常态化经营成果。
- 待补：产权与运营主体、已开放面积、入驻企业/住客口径、租赁和消费数据、数字游民社区的实际留存率。

## B8 上海EKA·天物

- 状态：部分核验。
- 项目身份：EKA·天物位于上海浦东金桥路535号，由原上海航海仪器总厂改造，属工业遗存活化的非标准商业及文化街区。
- 已确认机制：以保留工业构件和多建筑师改造形成可漫步的建筑群，再通过首店、文创、餐饮、展览、运动和社群活动把短期打卡转化为全时段复合消费。
- 证据：上海市文旅推广网确认原厂址、开发主体、30余栋建筑改造及策展/市集/社交办公等功能；新华网报道补充40余栋厂房、商户/首店结构与2025年销售增长等运营方口径。
- 迁移边界：可借鉴“工业记忆保留 + 非同质建筑群 + 首店组合 + 高频公共内容”的更新机制；前提是具有可步行的空间颗粒度、策展招商能力和长期维护预算。不能把首店比例、销售增长或热点客流直接迁移为一般项目预期。
- 待补：不同建筑数量和面积口径、产权/运营安排、出租率、首店销售贡献及客流数据需由项目方年度材料复核。

## B9 北戴河阿那亚

- 状态：部分核验。
- 项目身份：北戴河新区阿那亚是滨海社区型文旅项目，以孤独图书馆、礼堂、美术馆及文化活动构成识别系统，并兼具居住、度假和日常消费功能。
- 已确认机制：以高辨识度公共文化建筑建立目的地认知，再通过戏剧、音乐、艺术等高频内容和社群运营带动住宿、餐饮、零售及社区服务协同消费。
- 证据：新华网报道确认其滨海文旅定位、主要文化设施、活动形态及2024年游客和社区收入数据。
- 迁移边界：可借鉴“公共文化地标 + 内容日历 + 社群运营 + 度假消费承接”的系统，而非孤立复制某个地标建筑；前提是持有或可协调长期运营权、具有稳定内容生产能力、公共服务配套及淡旺季经营策略。不能复制滨海资源、环京客源、既有品牌认知和活动影响力。
- 待补：项目方对住宿、商业、业主及访客的分项口径，年度活动频次、租赁经营和淡季表现须进一步核验。

## E1 东京OIMACHI TRACKS（海外）

- 状态：部分核验。
- 项目身份：OIMACHI TRACKS 是JR东日本在东京大井町站广町地区原社宅用地推进的站城开发项目，2026年3月开街。
- 已确认机制：由铁路运营商以站点周边土地为基础，将交通节点升级为覆盖办公、酒店、商业和公共空间的城市目的地，并纳入“广域品川圈”的连续开发与运营。
- 证据：JR东日本官方管理层信息确认约3公顷用地、项目主体、2026年3月开街和区域协同定位；项目相关供应商资料补充其复合业态属性。
- 迁移边界：可借鉴“轨道运营方主导的TOD开发 + 站区公共空间 + 多业态协同”的逻辑；前提是拥有可统筹的站区土地、交通换乘能力、分期开发资金及长期资产运营权。不可复制东京通勤客流、铁路土地权属和品川区域集聚效应。
- 待补：正式项目总面积、分业态面积与租户、实际开业表现、客流和收益数据须以JR东日本项目公告或年度报告补齐。
