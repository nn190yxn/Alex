# B002第四轮核验｜案例B15、B2至B5

访问日期：2026-08-14。

## B15 洛阳魏坡新序

- 状态：部分核验。
- 项目身份：魏坡新序位于洛阳市孟津区朝阳镇卫坡村，以魏家坡古民居保护活化和周边废弃仿古商业街更新为核心。
- 已确认机制：不把遗产保护局限于修缮，而以艺术赋能、文化再造和设计共生植入创意资源及内容场景，解决阶段性开发遗留的低效仿古街问题。
- 证据：中国美术学院美丽中国研究院案例库确认时间、地点、合作机构、存量问题和更新逻辑。
- 迁移边界：可借鉴“先识别低效存量载体，再用本地文化/艺术内容重做目的地”的方法；前提是历史资源真实、社区可参与、运营方具备持续策展与招商能力。不可复制魏家坡古民居和洛阳文旅资源。
- 待补：开业时间、空间规模、品牌/业态、客流与商业表现须补项目方或属地政府资料。

## B2 广州聚龙湾

- 状态：部分核验。
- 项目身份：广州聚龙湾太古里是太古地产与广州珠江实业集团合作的综合发展项目零售部分，位于广州荔湾区。
- 已确认机制：项目以大体量城市更新为底座，未来导入零售、餐饮、生活休闲店铺及展览活动，与片区居住、产业和文化功能协同。
- 证据：太古地产官方项目页和广州市国资委披露合作主体、建设阶段、分期落成计划及“文商旅创居”融合定位。
- 迁移边界：现阶段只能把它作为大型更新项目的筹备案例，借鉴片区级复合开发与前置内容导入思路；不能把计划开业、规划业态或未来商业效果写成已发生事实。
- 待补：已开业部分及其时间、项目更新范围、运营策略、招商名单和实际经营数据。

## B5 北京亮马河

- 状态：部分核验。
- 项目身份：亮马河是北京朝阳区的重要河道和滨水更新项目，更新覆盖岸线整治、桥梁改造、慢行连通、景观亮化、河湖贯通和通航旅游等系统工程。
- 已确认机制：先通过水生态修复与公共空间开放建立滨水可达性，再以游船、灯光、艺术季、节庆和沿线商业形成全年内容供给；商业不只是出租，而要围绕水岸场景主动编织活动。
- 证据：北京市生态环境部门和人民日报报道确认治理工程、生态改善、周边客流/商业变化及内容运营方向。
- 迁移边界：可借鉴“生态治理 + 慢行开放 + 水上/岸上内容联动”的滨水运营系统；前提是水体安全、岸线公共性、跨部门治理、环保容量和长期维护资金。不能脱离河道治理基础单独复制灯光秀或游船活动。
- 待补：各河段商业主体、租赁和消费数据，及活动对常态复购的真实贡献。
