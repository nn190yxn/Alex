# B001第五轮核验｜案例C10至C13

访问日期：2026-08-14。

## C10 广州黄沙上堓

- 状态：部分核验。
- 项目身份：广州市荔湾区黄沙水产交易市场原址临摆区的“黄沙上堓”文旅集市，于2026年4月28日开幕。
- 已确认机制：项目采用低干预更新，保留旧市场的水泥柱、旧渔网、老砖墙等场地肌理；经营上以约40家固定店铺为基本盘，并将约20%铺位用于按月更换主题与主理人的“慢闪”。
- 内容与业态：首场活动以精酿、海鲜美食等市集内容启动；后续主题活动将疍家渔耕、龙舟等在地文化转化为展览、餐饮和互动内容。
- 证据：广州市人民政府转载广州日报报道确认开业时间、旧址、固定店铺和慢闪机制。
- 迁移边界：可借鉴“原场地记忆保留 + 固定经营基本盘 + 可轮换内容席位”的轻更新机制；前提是场地有可识别的原生记忆、允许灵活经营，并具备持续主题策划和主理人招商能力。不可复制黄沙旧鱼市、珠江滨水及广府渔港文化的特定资源。
- 待补：运营主体、完整面积、开业后客流和销售、固定/轮换铺位的实际比例与续租表现。

## C11 上海M+幸福里

- 状态：部分核验。
- 项目身份：位于上海市长宁区番禺路381号（幸福路67号）的M+幸福里，前身为上海橡胶制品研究所老厂房；长宁区政府将其列为城市更新项目，资料显示其自2016年亮相。
- 已确认机制：项目将创意办公、文化艺术与商业休闲结合，以社区休闲和小而美业态组织街区消费；2025—2026年利用邻近婚姻登记处的区位条件，围绕“幸福经济”导入生活服务、文创艺术、社群活动与时尚定制消费。
- 内容与业态：政府报道确认“心动幸福里”市集、商户联动优惠和主题品牌活动；2026年又引入福闹百货上海首店，并以婚嫁、定制、体验类业态延长登记后的停留与消费链路。
- 证据：上海长宁门户网站和上海市人民政府转载解放日报报道。
- 迁移边界：可借鉴存量厂房的低密度复合业态、公共街区市集，以及把相邻公共服务节点转成主题消费链路的做法；前提是具备可步行的开放界面、稳定社区/办公客群、可持续内容运营和政策协同。不能将原始视频中的租金涨幅、设计团队自营等未获可靠来源支持的描述当作事实。
- 待补：正式改造时间线、产权/运营主体、实际空间尺度、招商结构与长期经营数据。

- 核验结论：本轮未取得可供引用的项目方、运营方、政府或可靠专业媒体来源；搜索服务在继续检索前已返回支付限制，故不能确认“巡津街”为统一运营的更新项目，也不能确认体量、开业时间、空间改造主体或经营机制。
- 暂存迁移假设：如果后续能确认多店共建或街区运营主体，可进一步核验“低成本存量空间改造 + 街角外摆 + 差异化饮品/手作小店”的机制。
- 待补：项目是否存在统一运营主体、具体物业与改造范围、店铺开业及持续经营情况、外摆合规条件和街区客群数据。
