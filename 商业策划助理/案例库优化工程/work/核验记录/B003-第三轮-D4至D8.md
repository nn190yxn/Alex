# B003第三轮核验｜案例D4至D8

访问日期：2026-08-14。

## D4 上海PAC购物中心

- 状态：部分核验。
- 项目身份：PAC购物中心位于上海静安寺商圈常德路688号，是以红砖街区、树荫步道和宠物公园组织的开放式小体量商业空间。
- 已确认机制：以首店集聚和夜间场景双轮驱动，围绕餐饮、国际酒类市集、轻演出和宠物友好空间形成“逛、饮、赏”一体的街区消费。
- 证据：上海市政府英文网站及静安区政府发布的夜经济活动资料确认项目位置、空间特征、首店餐饮比例和夜间内容安排。
- 迁移边界：可借鉴“开放街区空间 + 高比例小众首店 + 夜间市集/轻演出 + 宠物友好”的场景组合；前提是有步行可达的高密客群、外摆与夜间活动许可、噪声管理和持续内容供给。不可将活动期间的市集或客流视为常态收益。
- 待补：开发运营主体、项目面积、完整租户清单、客流、租赁和销售数据。

## D5 三亚东岸麓洲

- 状态：部分核验。
- 项目身份：三亚东岸麓洲是万华在三亚推进的主理人商业街区及复合社区项目。
- 已确认机制：项目将非标开放街区、主理人商业和在地生活场景结合，作为万华从成都麓湖向其他城市输出“生态型城市发展”及社区运营能力的一部分。
- 证据：ELLE DECORATION 对万华的专题报道明确将其称为“三亚东岸麓州的主理人商业街区”；其他房产营销页面仅作线索，不用于确认具体面积、开街和店铺事实。
- 迁移边界：可借鉴“社区开发与主理人商业同步营造”的方向；前提是开发商具有长期运营意愿、社区客群基础和可持续招商能力。尚无可靠经营成果，不能以概念或房产营销口径替代实绩。
- 待补：项目正式名称/用字、地址、开发运营主体官方公告、已开业范围、品牌结构和日常经营数据。

## D6 武汉招商蛇口社区营造

- 状态：部分核验。
- 项目身份：此案例并非单一资产，指向招商蛇口在武汉开展的“未来welike”等本地化社区社群营造实践。
- 已确认机制：以业主/社区主理人为内容发起者，运营方提供资源、场地和组织支持，通过在地社群而非自上而下的单次活动建立长期社区连接。
- 证据：明源不动产研究院对招商蛇口社群体系的报道确认武汉的城市社群品牌及主理人机制；该来源为行业观察，尚需招商蛇口官方材料补强。
- 迁移边界：可借鉴“放权给主理人 + 资源托举 + 城市化社群品牌”的社区运营方法；前提是有稳定常住人群、公共空间、社群负责人和长期资源投入。不能将企业层面方法论直接等同于某一武汉项目的商业结果。
- 待补：涉及的具体社区、招商蛇口官方运营资料、活动频率、参与率、商业转化和成本口径。

## D7 武汉上岸公园

- 状态：部分核验。
- 项目身份：上岸公园位于武汉光谷花山新城，是湖北联投在花山河沿岸打造的“公园+滨水+商业”POD综合体；一期花涧商业区于2025年开街。
- 已确认机制：以滨水公园和步行场景补齐新城生活配套缺口，再用首店、艺术节、市集、戏剧与宠物友好活动实现公共空间和商业联动；项目分期形成河岸商业生态。
- 证据：极目新闻、东原致新城更集团和湖北商务厅报道确认项目定位、开发运营背景、开街、首店、内容活动与分期规划。
- 迁移边界：可借鉴“新城公共绿地 + 滨水慢行 + 社区商业补配 + 艺术内容”的POD路径；前提是区域具有稳定居住/就业导入、公共空间长期维护、滨水安全管理和商业分期耐心。开业季表现不得代替常态经营数据。
- 待补：各期面积、产权和运营分工、日常客流销售、首店留存与公共空间维护成本。

## D8 上海浦发唐镇印象汇

- 状态：部分核验。
- 项目身份：上海浦发唐镇印象汇位于浦东新区德淳路288号，由浦发集团与印力集团联合打造，2025年9月28日开业，建筑面积约6万平方米。
- 已确认机制：围绕国际社区日常需求，以生活服务、首店、宠物/滑板/运动空间和社区共办活动形成“商业—社区”共生，并与浦发唐城印象天地联动补全片区消费生态。
- 证据：印力集团官方开业公告确认主体、地址、体量、空间配置、业态逻辑及社区联动措施。
- 迁移边界：可借鉴“社区刚需 + 体验升级 + 户外活动空间 + 社区资源共建”的社区商业机制；前提是有稳定的周边常住人口、社区组织、可持续服务业态和项目间协同。开业期品牌及活动不能直接等同为长期经营表现。
- 待补：开业后客流、销售、会员、租户留存和两项目协同转化数据。
