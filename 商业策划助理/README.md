# 商业策划助理 Skill

## 项目定位

商业策划助理是面向商业地产策划工作的 OpenCode Skill，用于起草或审查商业定位、招商策略、运营诊断、资产盘活、业态规划和商业方案。它以项目资料和已确认决策为主要上下文，目标是形成可供专业策划师审阅和深化的完整初稿，并通过运行时记录保持跨章节口径一致。

当前发布版本：`8.0.0`

## 核心能力

1. 任务分流：支持快速任务、快速完整初稿、逐章共创和基于既有上下文的续写。
2. 动态上下文：完整报告任务维护`项目上下文.md`、`决策日志.md`和`内部质量记录.md`。
3. 证据分级：区分已确认事实、综合判断、研究假设和待核验商务信息。
4. 案例检索：先读取轻量索引筛选Top 3至5个候选案例，再按`case_id`读取案例正文。
5. 案例准入：`verified`案例可进入客户正文；`pending`案例仅进入内部质量记录；`rejected`案例记录否决原因。
6. 提案表达：以项目条件、商业判断和落地动作组织正文，并对关键段落执行表达质检。
7. 交付校验：检查案例数量、索引行号、分类统计、标题格式、标准章节、重复组、业态标签覆盖率和状态枚举。

## 8.0.0修订内容

### 策划判断

- 增加章节的关键事实、本章判断和落地动作字段，避免章节只保留标题级状态。
- 增加关键判断卡，统一记录事实、矛盾、判断、动作、预期结果、条件与影响章节。
- 完善品牌方向记录，要求同步说明客群、价格带、面积/楼层条件和适配理由。

### 提案表达

- 新增提案表达风规范：以项目条件、商业判断和落地动作组织正文，避免模板化句式。
- 将固定起草句式降级为内部推理，不再作为客户正文的常用表达。
- 新增关键段落的表达质检与首层业态取舍的正反例对照样本。

### 案例证据

- 新增《案例匹配与核验规范》，定义100分匹配评分、状态准入、核验优先级和案例迁移链。

- 索引生成脚本合并人工补录字段，索引重建不会覆盖人工标注。

### 质量闭环

- 新增社区型非标商业、混合业态资产激活、街区/文商旅三类匿名项目测试夹具。
- 发布校验新增人工补录字段和三类项目测试夹具完整性检查。
- 扩展机械检查与内部质量记录，覆盖提案表达和案例迁移记录。
