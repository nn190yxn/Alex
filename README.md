# 我赢AI - 中小企业AI工具平台

## 项目结构
- `frontend/` - 前端项目（Vue 3 + Vite）
- `backend/` - 后端项目（Express.js）
- `knowledge-base/` - 行业知识库
- `skills/` - 诊断 skill 定义
- `.monkeycode/` - 项目规范和记忆
- `docs/` - 工程文档

## 启动方式

### 前端
```bash
cd frontend
npm install
npm run dev
```

### 后端
```bash
cd backend
npm install
NODE_ENV=development npm run dev
```

## 核心功能
- 企业增长诊断（三阶段：行业画像 → 创始人能力 → 快速扫描）
- 115+ 工具（计算器、表格模板、AI生成、诊断评分）
- 会员订阅体系（free/starter/pro/annual）
- 行业专版（餐饮/教培/美业/生活服务）
