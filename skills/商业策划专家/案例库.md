# 商业策划专家案例库

## 使用说明

本文件是 `商业策划专家` 的配套案例库。

使用时按以下顺序调用：

1. 先判断本案属于哪一种商业模型。
2. 再判断本案更接近哪一种提案结构。
3. 到对应案例条目中提取：
   - 可借鉴的结构
   - 可借鉴的亮点组织方式
   - 可借鉴的文字逻辑与表达口径
   - 可借鉴的专业用词
4. 最后完成“案例映射”，明确本案能借什么、不能借什么。

案例库只提供参照框架，不允许直接照搬结论、案名、品牌组合或场景口号。

---

## 一、商业模型与提案结构映射

| 商业模型 | 常见项目类型 | 优先提案结构 | 关键工作 |
|---------|-------------|-------------|---------|
| 区域型购物中心 / 综合体 | 盒子mall、自持零售、TOD商业 | 标准商业定位型 | 本体判断、辐射范围、客群、竞品、楼层布局、收益逻辑 |
| 城市级概念 / 产业文商旅 | 城市名片、产业商业融合、目的地项目 | 顾问总纲型 | 愿景、定位、战略、平台、引爆点、功能落位 |
| 街区 / 滨河 / 历史文化 / 夜经济 | 长街区、开放式街区、滨河商业、市井街区 | 街区组团型 | 在地文化、总定位、组团主题、场景落位、品牌方向、公区配套 |
| 社区型非标商业 | 小体量社区商业、垂直非标商业、邻里中心升级 | 社区非标型 | 项目判断、客群基础、竞争关系、分层功能、主力内容、运营抓手 |
| 混合业态资产激活 | 写字楼+公寓+底商+酒店+物业私域等复合资产 | 操盘型概念方案 | 资产单元定位、混合业态联动、权益互通、收益假设、分阶段落地 |

## 二、案例条目

### 案例 A

#### 名称

`龙湖中央公园项目自持商业定位报告-0619.pptx`

#### 商业模型

- 区域型购物中心 / 综合体

#### 提案结构

- 标准商业定位型

#### 结构特点

1. 区域宏观介绍
2. 项目本体介绍
3. 项目辐射范围界定
4. 辐射范围人口规模及预测
5. 辐射区域目标消费群体画像
6. 商业定位
7. 楼层业态及布局
8. 收益与测算

#### 亮点组织方式

- 先把立地条件、交通条件、辐射条件讲透，再进入定位与楼层。
- 重点结论通常来自交通、人口、竞品和到达性综合判断。
- 楼层价值会结合到达性、展示性、连接性来判断。

#### 文字逻辑

- “基础条件判断 -> 辐射范围修正 -> 客群画像 -> 定位 -> 楼层布局”
- 结论多服务于招商、楼层落位和收益测算。

#### 表达方式

- 语气克制
- 标题偏判断式
- 强调量化和客观依据

#### 专业用词

- 核心辐射范围
- 次级辐射范围
- 外围辐射范围
- 立地条件分析
- 商业价值最大楼层
- 客流发动机
- 楼层业态及布局

#### 可迁移要素

- 适合借鉴辐射范围、客群、楼层价值判断的组织方式。
- 适合借鉴“先本体后定位”的标准定位写法。

#### 不宜直接照搬

- 大体量购物中心的主力店逻辑
- 完整收益测算结构

### 案例 B

#### 名称

`20221208高力国际-中国（贵阳）国际酒博城商业策划案.pptx`

#### 商业模型

- 城市级概念 / 产业文商旅融合项目

#### 提案结构

- 顾问总纲型

#### 结构特点

1. 城市与产业认知
2. 发展机遇
3. 项目愿景
4. 总体定位
5. 发展战略
6. 三大中心、六大赋能
7. 平台或引爆点展开
8. 具体实操方案

#### 亮点组织方式

- 先用大命题抬高项目站位。
- 再用“平台”“赋能”“引爆点”把大命题拆成可执行模块。
- 通过关键词、特色模块和活动体系强化项目差异化。

#### 文字逻辑

- “城市机会 -> 项目愿景 -> 功能体系 -> 引爆点 -> 场景落位”
- 逻辑更强调整体战略和平台构建，而不是先讲楼层和铺位。

#### 表达方式

- 顾问感强
- 常用“通过……形成……”“打造……平台”“最终实现……”
- 适合城市级、产业级、文商旅融合型项目

#### 专业用词

- 项目愿景
- 总体定位
- 发展战略
- 三大中心
- 六大赋能
- 引爆点矩阵
- 平台构建
- 产业目标

#### 可迁移要素

- 适合借鉴“愿景 - 定位 - 战略 - 平台”的总纲表达。
- 适合借鉴如何把大概念拆成若干功能模块。

#### 不宜直接照搬

- 过于宏大的城市站位表达
- 不适用于小体量社区商业的产业平台语言

### 案例 C

#### 名称

`（已压缩）未来方舟沿河七公里项目定位.pdf`

#### 商业模型

- 滨河街区 / 市井文化街区 / 夜经济街区

#### 提案结构

- 街区组团型

#### 结构特点

1. 城市印象与在地文化提炼
2. 认识本地人和消费习惯
3. 项目优势、短板与破题思路
4. 项目愿景与总体定位
5. 功能定位、客群定位、竞争定位
6. 一心一带串联五大组团
7. 每个组团分别展开：
   - 场景定义
   - 业态方向
   - 参考品牌
   - 主力店
   - 工程条件
8. 市政公区、导视、灯光、小火车等配套要求

#### 亮点组织方式

- 先讲城市文化和市井气质，再讲项目如何承接这种文化。
- 把长线街区拆解成多个组团，每个组团对应一个明确生活场景。
- 组团之后再配品牌、主力店和工程条件，形成较完整的落位链条。

#### 文字逻辑

- “在地文化 -> 项目命题 -> 总定位 -> 组团定位 -> 品牌与工程条件”
- 场景表达先行，再由业态和品牌补强。

#### 表达方式

- 标题偏直给式判断
- 强调贵阳在地文化和生活方式
- 对街区项目会加入景观、小品、导视、交通接驳等公区动作

#### 专业用词

- 滨河商业街
- 市井文化展场
- 24小时滨江商旅文体生态经济圈
- 一心一带
- 五大组团
- 精神堡垒
- 主力店
- 工程条件
- 景观小品
- 夜景灯光秀

#### 可迁移要素

- 适合借鉴街区型项目的组团化组织方式。
- 适合借鉴“总定位 - 组团主题 - 业态 - 品牌 - 工程条件”的展开顺序。

#### 不宜直接照搬

- 过强的文旅化、夜市化表达
- 适用于七公里长街区的交通和公区配置逻辑

### 案例 D

#### 名称

`F3组团底商产品培训课件20200612(1).pptx`

#### 商业模型

- 社区型非标商业 / 项目基础资料

#### 提案结构

- 产品条件型基础资料

#### 结构特点

- 不属于完整策划提案，更偏产品培训材料。
- 重点提供体量、面积、铺位结构、层高、入口和动线条件。

#### 可迁移要素

- 可作为项目本体和楼层条件判断的原始证据。
- 适合支撑空间可行性判断，不适合直接借鉴提案语言。

### 案例 E

#### 名称

`方舟聚场最终修整稿`

#### 案例性质

- 内部校准样本 / 操盘型概念方案正例

#### 商业模型

- 混合业态资产激活

#### 提案结构

- 操盘型概念方案

#### 结构特点

1. 项目概况与本体条件
2. 区域经济、产业、写字楼、零售、酒店市场
3. 写字楼 + 公寓 + 底商的混合业态属性
4. SWOT 与核心竞争关系
5. 1.5km / 5km / 10km 辐射范围
6. 客群画像与消费需求
7. G7 竞品关系与差异化生存空间
8. 龙湖欢肆、aa 安安、Regular 源野对标案例
9. 方舟聚场总定位、双主力店和五层业态
10. 写字楼、公寓、酒店、物业联动和时段经营
11. 分阶段落地目标

#### 亮点组织方式

- 把项目从“底商定位”提升为“混合业态资产激活”。
- 先用硬条件和市场数据建立判断，再进入定位和命名。
- 把外部对标案例转成具体动作，例如空间互嵌、权益互通、社群共创、中庭即主力店、品牌即展品。
- 允许保留有经营含义的强判断和记忆点句式，例如“G7 是大而全，F3 是小而精”“下楼即消费”“空间本身就是主力店”。

#### 可迁移要素

- 适合所有写字楼、公寓、底商、酒店和物业私域叠加的复合资产项目。
- 适合校准操盘型概念方案的结构、颗粒度和语言力度。
- 适合提醒撰写者补充经营假设、阶段目标、楼层角色、资产单元定位和运营联动。

#### 不宜直接照搬

- F3 专属数据、楼层、命名和品牌组合。
- 未经核验的市场数据和经营假设。
- 已被用户否定或有外部项目占用风险的命名。

## 三、案例调用规则

### 1. 先判模型，再调案例

优先顺序如下：

1. 判断本案属于哪一类商业模型。
2. 判断本案更接近哪一种提案结构。
3. 选 1 个主案例，最多再选 1 个辅助案例。

### 2. 主案例负责结构，辅助案例负责局部

- 主案例负责：整体目录、判断逻辑、表达口径。
- 辅助案例负责：局部亮点、节点空间、品牌组织、工程条件或运营抓手。

### 3. 每次必须输出案例映射

使用案例时，必须明确写出：

- 本案借鉴了案例的什么部分
- 本案不借鉴什么部分
- 为什么这个案例适合当前项目

## 四、方舟聚场当前对应关系

`方舟聚场` 当前更接近：

- 商业模型：混合业态资产激活
- 辅助模型：社区型非标商业
- 提案结构：操盘型概念方案

当前最适合的参考方式：

- 以 `龙湖中央公园` 借鉴“项目判断、客群、竞争、楼层价值”的标准写法
- 以 `沿河七公里` 借鉴“场景命名、亮点组织、节点表达”的部分方法
- 以 `F3组团培训资料` 作为项目本体证据
- 以 `龙湖欢肆、aa 安安、Regular 源野` 借鉴“公寓商业联动、小体量非标商业、地下空间内容化”的操盘动作
- 以 `方舟聚场最终修整稿` 校准操盘型方案的主线、颗粒度和语言力度

不建议直接套用 `高力酒博城` 的城市级总纲表达。

特别注意：F3 不能只按 1.17 万㎡底商处理。正式方案要把写字楼、公寓、底商、酒店、物业私域和社区客群作为一个复合资产系统来写，商业定位要服务整体资产激活。
