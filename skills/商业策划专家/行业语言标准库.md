# 商业策划行业语言标准库

## 定位

本文件用于给 `商业策划专家` 提供正式商业汇报语言的统一标准。

本标准库重点解决以下问题：

1. 语言是否符合商业地产行业常见汇报口径
2. 专业概念是否采用行业通用表达
3. 标题、判断句、分析句、落位句是否具备正式提案结构
4. 文案是否存在 AI 化、宣传化、讨论稿化问题

文字审核师和提案撰写师在处理正式商业材料时，必须调用本标准库。

## 一、语言总原则

所有正式输出都遵循以下原则：

1. 先判断，后解释，再落位
2. 先讲项目，后讲概念，最后讲包装
3. 先讲经营逻辑，后讲空间和品牌
4. 先讲事实与支撑，后讲价值与意义
5. 标题服务于决策，正文服务于执行
6. 正文稿要体现行业专家经验，讲清商业运营规律、招商取舍、楼层逻辑和执行前提
7. 去 AI 化不等于缩短文本，专业正文需要保留解释、推演和现场判断
8. 操盘型概念方案要允许强判断、强命名和适度生活化表达，但每一句都必须能回到客群、空间、业态、运营或收益

对于正式汇报稿，还要同时满足：

1. 页面有判断力
2. 结构有推进感
3. 亮点有记忆点
4. 语言克制但不干瘪
5. 文案可直接进入 PPT 页面

对于操盘型概念方案，还要同时满足：

1. 方案有清晰的资产经营主线
2. 项目本体、市场数据、对标案例和经营假设能够互相支撑
3. 业态、楼层、品牌、运营、物业、会员和收益之间形成闭环
4. 允许使用“下楼即消费”“空间本身就是主力店”“吃在聚场，请客吃在 G7”等有判断力的方案句
5. 生活化表达必须服务商业判断，不能变成随口举例

## 二、标准标题写法

### 1. 优先标题类型

正式商业汇报优先使用以下标题类型：

- 项目判断类
- 市场基础类
- 竞争关系类
- 客群定位类
- 定位落位类
- 楼层布局类
- 业态规划类
- 招商策略类
- 经营逻辑类
- 工程条件类
- 执行路径类

### 2. 标准标题示例

- 项目判断
- 市场基础
- 商圈格局
- 竞争关系
- 客群基础
- 项目定位
- 定位落位
- 业态配比
- 楼层布局
- 主力店布局
- 品牌导入方向
- 经营抓手
- 收益逻辑
- 合作模式
- 前置条件
- 实施路径

### 4. 汇报型标题要求

正式汇报稿中的标题应同时满足三点：

1. 一眼能看出当前页的核心判断
2. 能与上一页、下一页形成推进关系
3. 能直接作为 PPT 页标题使用

### 3. 标题禁忌

以下标题不进入正式汇报：

- 一句话判断
- 为什么是它
- 这个名字为什么成立
- 我们的理解
- 可以概括为
- 三个关键词
- 真正的机会
- 下一步怎么做

## 三、标准句式结构

### 1. 判断句

用途：先给结论。

标准结构：

- 项目判断是……
- 本案更适合……
- 当前核心矛盾在于……
- 项目的竞争机会来自……
- 该楼层更适合承接……

示例：

- 项目判断是做区域高频生活消费承接，而不是再造一个目的地型购物中心。
- 当前核心矛盾在于项目本体条件偏分散，现有表达没有把客流组织逻辑讲清楚。

### 2. 支撑句

用途：解释判断成立的依据。

标准结构：

- 这一判断主要基于……
- 支撑该判断的核心依据包括……
- 从……来看，项目具备……
- 周边……决定了项目更适合……

示例：

- 这一判断主要基于周边居住密度、办公客源、竞品供给结构和项目到达条件。
- 从现有竞品格局来看，区域内目的性消费供给已有承接，日常高频消费供给仍有空白。

### 3. 落位句

用途：把判断落到动作、空间、品牌或经营。

标准结构：

- 因此，项目应重点落在……
- 对应到业态层面，建议……
- 对应到楼层规划，适合……
- 对应到招商层面，应优先引入……

示例：

- 因此，项目应重点落在餐饮社交、夜间轻娱乐和生活配套三类高频内容。
- 对应到楼层规划，低楼层优先承担引流和昭示，高楼层承担目的性消费与停留。

### 4. 风险句

用途：提示方案边界和前提。

标准结构：

- 该定位成立的前提是……
- 该方案的主要风险在于……
- 若……无法兑现，项目将面临……

### 5. 执行句

用途：将方案转成动作。

标准结构：

- 在执行层面，建议分阶段推进……
- 首阶段优先完成……
- 为确保该定位落地，需要同步解决……

## 四、汇报感边界

文字审核和去 AI 化过程中，必须守住以下边界：

1. 正式提案保留决策判断和提案张力
2. 方案亮点保留明确的空间记忆点和经营落位
3. 场景表达保留必要的识别度、画面感和商业动作
4. 概念方案正文稿保留完整论证、段落展开和阅读连续性
5. 原文去 AI 化任务优先在原稿结构内完成语言和逻辑校正
6. 操盘型方案中有经营含义的短句、比喻和命名不按口语化问题处理，先判断它是否强化了项目记忆点和经营逻辑

正式汇报稿允许保留以下内容：

1. 有判断力的命名体系
2. 有节奏变化的模块组织
3. 有记忆点的空间亮点表达
4. 有克制感但仍有提案锋芒的结论句

概念方案正文稿允许保留以下内容：

1. 对定位命名的完整解释
2. 对空间场景的连续描述
3. 对楼层业态和经营动作的展开说明
4. 对案例迁移关系的必要解释
5. 对风险、前置条件和测算口径的说明

## 四、专业概念标准口径

### 1. 市场与商圈

优先表达：

- 城市能级
- 商圈成熟度
- 核心辐射范围
- 次级辐射范围
- 外围辐射范围
- 客源发生器
- 到达性
- 昭示性
- 消费分层
- 错位竞争

避免表达：

- 市场很大
- 人很多
- 流量很好
- 周边需求旺盛

### 2. 客群与消费

优先表达：

- 核心客群
- 次核心客群
- 机会客群
- 到访动机
- 消费频次
- 消费时段
- 停留场景
- 客单区间
- 复访逻辑

避免表达：

- 年轻人喜欢
- 大家愿意来
- 消费者更注重体验

### 3. 定位与产品

优先表达：

- 项目定位
- 定位落位
- 差异化锚点
- 内容承接
- 主力场景
- 功能分层
- 组团定位
- 楼层价值

避免表达：

- 超级概念
- 情绪价值空间
- 自带流量属性
- 高颜值打卡地

### 4. 招商与品牌

优先表达：

- 主力店
- 次主力店
- 品牌级次
- 品牌矩阵
- 品牌落位
- 首店资源
- 招商节奏
- 招商难点
- 业态配比

避免表达：

- 网红品牌都来
- 先把氛围做起来
- 找一些有调性的品牌

### 5. 运营与资产

优先表达：

- 客流组织
- 销售转化
- 坪效
- 出租率
- 内容运营
- 经营闭环
- NOI 改善路径
- 资产提效
- 退出路径

避免表达：

- 后期自然会更好
- 做起来就有收益
- 整体价值会提升

## 五、案例沉淀出的高频行业表达

以下表达可优先使用：

- 项目判断
- 市场基础
- 商圈格局
- 竞争关系
- 客群基础
- 定位落位
- 楼层布局
- 主力内容
- 主力店布局
- 品牌导入方向
- 经营抓手
- 价值兑现
- 资产提效
- 实施路径
- 前置条件

以下动词可优先使用：

- 承接
- 形成
- 支撑
- 落位
- 匹配
- 带动
- 兑现
- 构成
- 强化
- 释放

## 六、一票否决表达

以下表达出现时，文字审核师应直接要求重写：

- 一句话判断
- 这几个字
- 真正的
- 可以理解为
- 我们认为
- 我们觉得
- 像是
- 相当于
- 底盘
- 今天吃什么
- 下班坐一会儿
- 顺手消费
- 自带流量
- 情绪价值拉满
- 既要……又要……还要……连续堆叠
- 不仅……更……连续堆叠
- 赋能、打造、升级、引领连续堆叠且无对象无结果

以下表达需要结合交付物判断：

- 下楼即消费
- 空间本身就是主力店
- 吃在聚场，请客吃在 G7
- 小而精
- 楼上人下楼消费

如果这些表达用于正式审查意见，应改为行业化表述；如果用于操盘型概念方案，并且后文已经落到客群、空间、业态和经营动作，可以保留。

## 七、AI 化常见病灶与修正法

### 1. 套话开头

问题示例：

- 随着城市商业不断发展……
- 在当前消费升级背景下……

修正方式：

- 直接进入项目判断。

### 2. 空泛概念堆叠

问题示例：

- 打造集社交、体验、文化、消费于一体的复合型生活方式目的地。

修正方式：

- 拆成客群、场景、业态、品牌、经营抓手。

### 3. 讨论稿表达

问题示例：

- 这个名字更像……
- 我们可以把它理解成……

修正方式：

- 改成明确判断句。

### 4. 只有概念没有动作

问题示例：

- 通过内容升级提升项目活力。

修正方式：

- 写清由谁执行、在哪一层、承接什么客群、形成什么经营结果。

### 5. 过度精炼导致机器人语气

问题示例：

- 项目应做高频生活消费承接，建立错位竞争。

修正方式：

- 补充行业判断、经营原因、招商条件和落地动作，让读者看出方案背后的运营经验。

### 6. 过度审查导致方案失去锋芒

问题示例：

- 将“空间本身就是主力店”机械改成“项目应强化空间体验属性”。
- 将“下楼即消费”机械改成“形成近场高频消费转化”。

修正方式：

- 先判断原句是否承载了清晰商业逻辑。若原句能够让甲方快速理解客流、空间或经营关系，可以保留原句，并在后文补充经营依据和落位动作。
- 操盘型概念方案需要有提案锋芒，文字审核的目标是校正空泛和失真，不能把所有表达磨成同一种顾问腔。

## 八、文字审核师检查清单

文字审核师最终审核时，必须逐项确认：

1. 标题是否为判断式或落位式表达
2. 是否存在口语化、讨论稿化、宣传稿化句子
3. 是否存在自造概念和生硬表达
4. 是否存在空泛价值词连续堆叠
5. 是否使用了行业常见的专业概念口径
6. 是否形成判断句、支撑句、落位句结构
7. 是否有结论没有依据，或有概念没有经营动作
8. 是否与案例语言体系保持一致
9. 是否存在过度精炼、过度规整、像机器人摘要的问题
10. 是否体现商业地产招商运营经验和现场落地判断
11. 对操盘型概念方案，是否保留了必要的强判断、记忆点和具体经营假设
12. 是否因为过度追求正式口径，削弱了方案的操盘感、可讨论性和项目辨识度

## 九、最终原则

商业策划语言的核心任务，是把项目判断讲清楚，把经营逻辑讲成立，把执行动作讲落地。
