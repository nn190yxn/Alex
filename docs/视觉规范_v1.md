# 我赢AI 视觉规范 v1

## 1. 适用范围
- 项目：我赢AI（网页端第一阶段）
- 版本：v1（MVP）
- 生效时间：2026-04-30
- 适用页面：首页、工具页、诊断页、报告页、会员页、支付页、用户中心

## 2. 设计方向（已冻结）
- 视觉基线：Notion 可读性 + Stripe 产品感 + Claude 温暖感（本地化改造）
- 品牌气质：实战、可信、专业、接地气
- 用户感知目标：3 秒看懂价值，30 秒开始使用，3 分钟看到结果

## 3. 设计 Token（唯一真相）

### 3.1 颜色系统
- `--brand-primary: #1E3A8A`（主品牌蓝，导航/标题/核心信息）
- `--brand-primary-weak: #3B82F6`（主品牌浅蓝，悬浮态/次高亮）
- `--brand-accent: #F97316`（行动橙，主按钮/关键 CTA）
- `--brand-accent-weak: #FB923C`（行动橙浅色，悬浮态）
- `--bg-base: #FFFFFF`（主背景）
- `--bg-soft: #FAF8F5`（温暖浅底，报告/内容区）
- `--bg-subtle: #F8FAFC`（弱分区背景）
- `--text-main: #0F172A`（主文本）
- `--text-secondary: #475569`（次文本）
- `--text-muted: #94A3B8`（弱提示）
- `--line-default: #E2E8F0`（边框）
- `--state-success: #16A34A`（成功）
- `--state-warning: #D97706`（警告）
- `--state-danger: #DC2626`（风险）

### 3.2 字体系统
- 中文主字体：`"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`
- 英文/数字补充：`"Inter", "Segoe UI", sans-serif`
- 字重规范：400（正文）/ 500（强调）/ 600（小标题）/ 700（主标题）
- 数字展示：ROI、金额、百分比使用 `font-variant-numeric: tabular-nums`

### 3.3 字号与行高
- H1：36px / 44px / 700
- H2：28px / 36px / 700
- H3：22px / 30px / 600
- H4：18px / 26px / 600
- Body-L：16px / 26px / 400
- Body-M：15px / 24px / 400
- Body-S：14px / 22px / 400
- Caption：12px / 18px / 400

### 3.4 间距系统（8pt）
- 间距单位：4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64
- 页面横向留白：移动端 16，平板 24，桌面 32
- 卡片内边距：16（紧凑）/ 24（常规）/ 32（报告）

### 3.5 圆角与阴影
- 圆角：按钮 10，输入框 10，卡片 14，弹层 16
- 阴影（仅三档）：
  - `shadow-sm: 0 1px 2px rgba(15,23,42,0.06)`
  - `shadow-md: 0 8px 24px rgba(15,23,42,0.10)`
  - `shadow-lg: 0 16px 40px rgba(15,23,42,0.14)`

## 4. 组件规范

### 4.1 按钮
- 主按钮（Primary）：橙底白字（`--brand-accent`）
- 次按钮（Secondary）：白底蓝边（`--brand-primary`）
- 危险按钮（Danger）：红底白字（`--state-danger`）
- 高度：40（默认）/ 48（重要 CTA）
- 禁止：渐变彩虹按钮、过重发光、过度动效

### 4.2 表单
- 输入框高度：44
- 边框：`1px solid --line-default`
- Focus：`2px` 外发光，颜色 `rgba(30,58,138,0.18)`
- 错误提示：紧跟输入项下方，使用 `--state-danger`

### 4.3 卡片
- 标准卡片：白底 + `shadow-sm` + 14 圆角
- 结果卡片：`--bg-soft` 底 + 左侧品牌色强调条
- 会员卡片：按级别加轻色区分，不改变结构模板

### 4.4 导航
- 顶部导航高度：64
- 品牌区左对齐，功能区中间，登录/会员入口右对齐
- 当前页使用蓝色文字 + 2px 下划线指示

## 5. 页面模板规范

### 5.1 首页
- Hero 结构：价值主张 + 关键数字 + 主 CTA + 次 CTA
- 主文案模板：
  - 标题：让每个老板都用上 AI
  - 副标题：贵阳实体老板的 AI 生意军师
- 模块顺序：核心价值 -> 工具预览 -> 用户案例 -> 会员方案 -> FAQ

### 5.2 工具页
- 固定三段：输入区 -> 计算/生成动作区 -> 结果区
- 结果区必须支持：复制、再次生成、保存到历史
- 右上角展示当前会员和剩余额度

### 5.3 诊断页
- 问答式流程：单题单屏 + 顶部进度条
- 每题操作：上一题、下一题、保存并退出
- 节奏提示：每 5 题显示一次阶段说明，降低流失

### 5.4 报告页
- 固定结构：总分概览 -> 维度评分 -> 核心问题 -> 改进建议 -> 下一步行动
- 图表色彩仅使用品牌色系，不使用高饱和彩色拼盘
- 支持导出截图版（MVP 可先做打印样式）

### 5.5 会员页与支付页
- 三档卡片横排（移动端纵排）
- 价格视觉层级突出：进阶会员为默认推荐态
- CTA 明确：立即开通 / 升级 / 续费

## 6. 动效规范
- 统一时长：150ms（微交互）/ 240ms（页面元素入场）
- 统一曲线：`cubic-bezier(0.2, 0.8, 0.2, 1)`
- 动效仅用于：按钮反馈、结果刷新、模块淡入
- 禁止：大面积持续动画、闪烁动画、与功能无关的炫技动画

## 7. 响应式规范
- 断点：
  - `sm`: 0-639
  - `md`: 640-1023
  - `lg`: 1024+
- 移动端优先，核心动作按钮在首屏可见
- 表格在移动端转卡片，不允许横向滚动影响关键阅读

## 8. 文案与语气规范
- 用词风格：老板听得懂，不堆术语
- 输出结构：先结论，后解释，再建议
- 语气：直接、专业、有温度

## 9. 可用性与可访问性
- 正文对比度不低于 WCAG AA
- 交互控件可点击区域不小于 40x40
- 键盘可访问：Tab 顺序清晰，焦点可见

## 10. 实施要求（强制）
- 所有新页面必须使用本规范 Token，不允许临时自定义主色
- 新增组件必须先复用现有样式变量，再考虑扩展
- 每次视觉调整需同步更新本文件版本记录

## 11. 版本记录
