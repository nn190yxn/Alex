# 全工具公式与知识库基线

## 0. 文档目的

本文件记录每个工具的正确名称、输入字段、公式、阈值、知识库来源和恢复依据。未来发生回退时，以本文档作为快速定位正确实现的基线。

## 1. 维护规则

- 每恢复或审核一个工具，必须同步更新本文档。
- 每个工具都要写明正确版本依据，不能只写“参考线上”或“参考本地”。
- 公式、阈值、知识库路径必须可追溯到具体文件。
- 知识库路径必须指向当前工作区真实存在的文件，缺失路径要记录替代方案。
- 所有计算类工具必须记录公式和适用边界。

## 2. 审核状态

| 状态 | 含义 |
|---|---|
| 待审核 | 尚未逐一核对代码、公式和知识库 |
| 已核对 | 已记录公式、阈值和知识库，但尚未恢复代码 |
| 已恢复 | 代码已按基线恢复 |
