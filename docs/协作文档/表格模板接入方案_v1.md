# 表格模板接入方案 v1

来源：`.monkeycode/docs/template-integration-plan-v1.md`

## 这份文档解决什么问题

- 告诉新 Agent 第一轮表格模板怎么接进前端
- 不是做完整表格系统，而是先做结构接入

## 当前已经有的数据

位置：`business-toolkit/src/constants/toolCatalog.js`

已新增模板元数据：
- `industryTemplateEntries`
- `templatesByIndustry`
- `getTemplateByCode()`
- `getIndustryTemplatesBySlug()`

## 第一轮 6 张优先模板

1. 餐饮：食材成本核算表
2. 餐饮：翻台率统计表
3. 教培：课时消耗统计表
4. 教培：续费率追踪表
5. 美业：会员管理表
6. 美业：拓客转化追踪表

## 建议的实现顺序

1. 先在行业页展示模板卡片
2. 再在工具详情页展示关联模板
3. 最后才做在线填写、导出和协作

完整版本请查看：`../.monkeycode/docs/template-integration-plan-v1.md`
