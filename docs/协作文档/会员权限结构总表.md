# 我赢AI会员权限结构总表

来源：`.monkeycode/docs/membership-permission-architecture.md`

## 文档用途

- 给新 Agent 快速理解四层会员体系
- 给前端确定页面展示和锁定提示
- 给后端确定权限层级和免费限次逻辑
- 给后续知识库、表格挂载提供统一口径

## 当前结论

| 层级 | 代号 | 核心定位 | 主要卖点 |
|------|------|----------|----------|
| 免费版 | `free` | 感知价值 | 先体验高频内容和基础计算 |
| 初阶版 | `starter` | 日常经营 | 把行业经营工具真正用进门店 |
| 进阶版 | `pro` | 诊断增长 | 看清问题、判断增长方向、使用平台经营能力 |
| 高阶版 | `annual` | 专项系统 | 老板IP、小红书、深度抖音和知识库驱动能力 |

## 免费层原则

- 高频内容工具必须限次
- 基础计算工具可以体验，但不能无限次
- 企业增长诊断、抖音经营专项、老板IP、小红书运营不开放免费完整版

## 建议免费额度

| 功能类别 | 免费额度建议 |
|------|------|
| 爆款标题 / 朋友圈 / 卖点 / 钩子 | `3次/天` |
| 通用脚本生成 | `2次/天` |
| 通用选题生成 | `2次/天` |
| 基础 ROI / 回本 / 简单计算器 | `3次/天` |
| 行业基础计算器 | `1次/天` 或仅开放简版结果 |

## 行业层级结论

| 行业/能力 | 建议层级 |
|------|------|
| 通用基础内容能力 | `free` |
| 通用基础计算能力 | `free` |
| 行业基础经营能力 | `starter` |
| 行业制度/表格/模板 | `starter` |
| 诊断与增长能力 | `pro` |
| 平台经营能力 | `pro` |
| 老板IP与专项系统 | `annual` |

## 高阶专项归属

| 专项 | 建议层级 |
|------|------|
| 抖音经营 | `pro` 主体，部分 `annual` |
| 企业增长诊断 | `pro` |
| 老板IP | `annual` |
| 小红书运营 | `annual` |

## 组织原则

- 同一能力不重复造工具，采用“通用底层能力 + 行业/场景包装层”
- 行业页优先按老板工作场景组织，不按技术名词组织
- 后续上传的表格和知识库优先作为输入模板、输出报表或行业动作模板接入
