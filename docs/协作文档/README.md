# 协作文档入口

这个目录用于给后续对话和新 Agent 提供一眼可见的固定入口。

## 关键文档

1. `会员权限结构总表.md`
用途：定义四层会员体系、免费限次原则、行业子板块层级和高阶专项归属。

2. `行业工具权限矩阵.md`
用途：定义 `行业 -> 子板块 -> 工具 -> 会员等级 -> 免费策略 -> 开发状态` 的正式映射。

3. `行业表格模板矩阵.md`
用途：定义 `行业 -> 表格模板 -> 建议层级 -> 优先级 -> 挂载工具` 的正式映射。

4. `表格模板接入方案_v1.md`
用途：定义第一轮 6 张高价值表如何接入前端共享结构和行业页。

5. `../工程开发进度.md`
用途：记录当前开发进度、最近改动、验证结果和下一步。
