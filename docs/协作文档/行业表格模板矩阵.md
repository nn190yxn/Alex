# 我赢AI行业表格模板矩阵

来源：`.monkeycode/docs/industry-template-matrix.md`

## 文档用途

- 给新 Agent 快速理解表格模板在产品里的位置
- 给后续“表格 + 计算器 + 诊断工具”联动提供统一口径

## 当前结论

### 表格模板的三种角色
- 输入模板：先填表，再驱动计算器或诊断
- 经营记录表：持续记录，产出趋势和预警
- 输出报表：工具计算后生成复盘结果

### 权限建议
- 通用记录类：`starter`
- 行业核心经营表：`starter`
- 强分析型行业专用表：`pro`
- 高阶专项联动表：`annual`

### 第一轮优先接入的 6 张表
1. 餐饮：`食材成本核算表`
2. 餐饮：`翻台率统计表`
3. 教培：`课时消耗统计表`
4. 教培：`续费率追踪表`
5. 美业：`会员管理表`
6. 美业：`拓客转化追踪表`

### 关键联动
- 餐饮 `食材成本核算表` -> 毛利率 / 菜品定价
- 教培 `续费率追踪表` -> 续费率计算器
- 美业 `拓客转化追踪表` -> 拓客转化率 / ROI
