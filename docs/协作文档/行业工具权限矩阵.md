# 我赢AI行业工具权限矩阵

来源：`.monkeycode/docs/industry-tool-access-matrix.md`

## 文档用途

- 给新 Agent 快速理解“行业 -> 子板块 -> 工具 -> 权限”的正式关系
- 给前端行业专版继续补真实工具时直接查表
- 给后端后续配置会员权限和免费额度时直接查表

## 当前核心结构

### 餐饮
- 经营计算：`roi`、`payback`、`schedule`
- 活动获客：`headline`、`friend`、`festival`
- 平台经营：`meituan`
- 待开发重点：毛利率、盈亏平衡、菜品定价、食材损耗、外卖利润

### 教培
- 招生与转化：`close-deal`、`friend`、`fission`
- 制度管理：`salary`、`sop`
- 老板表达：`topic`
- 待开发重点：续费率、课时消耗率、消课率、获客成本、场地利用率

### 美业
- 拓客种草：`friend`、`xiaohongshu`、`festival`
- 会员与储值：`membership-design`
- 老板表达：`ip-agent`
- 待开发重点：耗卡率、项目利润、LTV、复购率、拓客转化率

### 生活服务
- 品牌表达：`selling-point`
- 服务流程：`sop`
- 获客转介绍：`fission`
- 诊断增长：`competitor`、`marketing-calendar`
- 待开发重点：报价毛利、人效、订单回本、客诉与服务复盘

### 抖音专项
- 已上线底层：`headline`、`hook`、`script`、`roi`、`topic`
- 已上线进阶：`meituan`
- 已上线高阶：`ip-agent`
- 待开发重点：投流保本ROI、GPM、福袋份数计算器

## 优先级

1. 先做餐饮/教培/美业的高频经营计算器行业版
2. 再做强场景工具：教培续费消课、美业耗卡复购、餐饮外卖利润
3. 抖音优先补 `投流保本ROI` 和 `GPM`
