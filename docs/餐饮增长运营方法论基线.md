# 餐饮增长运营方法论基线

## 品类拆分

- 正餐：重点看菜品毛利、桌台效率、包间/宴请场景、会员复购和招牌菜表达。
- 小吃：重点看单品爆款、动线效率、低客单高频复购、外卖利润和短视频转化。
- 火锅：重点看翻台率、锅底毛利、套餐核销、聚餐场景和排队氛围。
- 奶茶：重点看出杯效率、配方成本、新品爆品、高峰排班和会员复购。
- 轻食：重点看食材损耗、低卡人群、客单结构、外卖利润和健康内容种草。
- 西式：重点看空间体验、约会场景、套餐定价、菜品贡献和小红书种草。

## 基础工具

- 经营测算：`gross-margin-restaurant`、`break-even-restaurant`、`payback-restaurant`、`cashflow-restaurant`、`profit-rate-restaurant`。
- 成本效率：`salary-cost-ratio-restaurant`、`turnover-rate-restaurant`、`food-waste-rate`、`food-yield-rate`、`inventory-turnover`。
- 菜品结构：`dish-pricing`、`dish-contribution`、`drink-cost`、`cup-efficiency`。
- 平台外卖：`delivery-profit`、`delivery-analysis`、`meituan`。

## A 类经营工具

- 品类毛利：先看菜品/套餐毛利，再判断引流品、利润品和形象品比例。
- 盈亏平衡：把租金、人工、食材、平台抽成和营销费用拆清楚，确认保本营业额。
- 翻台/出杯：正餐、火锅看翻台，奶茶、小吃看出杯效率和高峰压力。
- 外卖利润：拆包装、平台佣金、配送补贴和满减，避免外卖单量越多亏损越大。
- 菜品贡献：用销量和毛利率做四象限，决定主推、保留、优化和淘汰。

## A 类营销工具

- 抖音团购：`douyin-restaurant` 负责短视频脚本、团购组品、直播核销和同城到店。
- 小红书种草：`xiaohongshu-restaurant` 负责探店笔记、同城搜索、菜品种草和私信/POI 承接。
- 活动复盘：`campaign-roi` 看投入、客流、成交、核销和复购。
- 获客成本：`channel-cac` 对比抖音、美团、地推、转介绍和私域。
- 促销利润：`promotion-profit` 判断折扣、满减和套餐活动是否真正赚钱。

## 抖音打法

- 正餐：拍招牌菜、宴请场景、包间体验和老板/厨师长信任。
- 小吃：拍单品爆款、排队、出餐速度和高频复购。
- 火锅：拍锅底、蘸料、聚餐、套餐核销和直播福利。
- 奶茶：拍新品、出杯、联名、下午茶和高峰效率。
- 轻食：拍低卡配餐、备餐过程、上班族午餐和外卖复购。
- 西式：拍空间、摆盘、约会、套餐和拍照点。

## 小红书打法

- 标题和正文前 50 字放入城市/商圈、品类、菜品/套餐、人群和场景词。
- 封面突出点单攻略、套餐值不值、附近约饭、第一次来怎么点。
- 正文结构按场景、点单建议、真实体验、价格权益和到店动作组织。
- 评论承接菜单、套餐、排队、营业时间和预约；私信承接团购券和到店提醒。

## 验证口径

- 静态审计看工具目录、专属路由、权限、配额和后端执行链路。
- 接口验证看 `douyin-restaurant`、`xiaohongshu-restaurant` 能生成结构化方案。
- 线上 AI Key 缺失时允许规则兜底，结果需带 `isRuleFallback: true`。
