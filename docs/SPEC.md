# 企业工具箱 - 项目规范

## 1. 项目概述

**项目名称**：企业工具箱 (Business Toolkit)
**项目类型**：面向本地商家的企业工具型网站
**核心功能**：企业自诊诊断、抖音投流ROI计算、获客成本计算
**目标用户**：二三线城市中小企业主（1-200人）

**商业模式**：
- 基础功能免费使用（企业诊断自测、简单ROI计算）
- 短视频引流 + 干货内容
- 后续增值功能需付费解锁

---

## 2. 功能规格

### 2.1 企业增长诊断（核心免费功能）

#### 功能描述
将 Alex 的企业增长诊断 skill 转化为互动式网页自测工具，模拟对话式问答体验。

#### 诊断流程
```
阶段0：行业诊断（8问）
    ↓
模块F：创始人能力诊断（直接版/间接版）
    ↓
阶段1：快速扫描（6维度评分）
    ↓
阶段2：深度诊断（按需，A-E模块）
    ↓
阶段3：综合诊断报告
```

#### 核心问题设计

**阶段0：行业诊断（8问）**

| # | 问题 | 选项 |
|---|------|------|
| 1 | 您的客户类型是？ | 个人消费者 / 企业客户 / 渠道经销商 |
| 2 | 平均客单价区间？ | 100元以下 / 100-1000元 / 1000-1万元 / 1万元以上 |
| 3 | 客户决策周期？ | 当场决定 / 短期(1周内) / 中期(1月内) / 长期(1月以上) |
| 4 | 线上化程度？ | 10%以下 / 10-30% / 30-70% / 70%以上 |
| 5 | 竞争格局？ | 蓝海 / 轻度竞争 / 中度竞争 / 红海 |
| 6 | 客户复购属性？ | 一次性 / 低频(年均1次) / 中频(季度1次) / 高频(月均1次+) |
| 7 | 地域覆盖？ | 单店 / 同城多店 / 区域连锁 / 全国 |
| 8 | 当前最大困扰？ | 获客难 / 不赚钱 / 复制不了 / 团队跟不上 / 不知道往哪走 |

**模块F：创始人能力诊断（直接版，6项能力1-5分）**

| 能力 | 描述 |
|------|------|
| 商业洞察 | 能否判断行业趋势，识别客户需求变化 |
| 获客能力 | 理解各渠道逻辑，能独立设计获客方案 |
| 团队领导 | 能吸引、激励、留住核心员工 |
| 财务意识 | 清楚真实盈利状况，能做正确的投资决策 |
| 学习进化 | 保持学习习惯，快速掌握新工具 |
| 角色定位 | 清楚自己最强能力，发挥核心优势 |

**阶段1：快速扫描（6维度1-5分评分）**

| 维度 | 1分 | 3分 | 5分 |
|------|-----|-----|-----|
| 获客能力 | 靠随机，不可控 | 有稳定渠道，成本偏高 | 自增长机制，成本可控 |
| 盈利效率 | 亏钱或持平 | 能赚但不到3倍 | 3倍以上 |
| 复购与推荐 | 很少推荐 | 偶尔推荐 | 经常推荐 |
| 复制能力 | 完全依赖创始人 | 部分可复制 | 标准流程，快速复制 |
| 组织能力 | 创始人干所有事 | 有人但能力不足 | 体系完善，梯队健全 |
| 战略清晰 | 完全迷茫 | 有方向不聚焦 | 目标清晰路径明确 |

#### 报告输出
- 行业画像摘要
- 创始人能力雷达图
- 6维评分可视化
- 核心瓶颈分析
- 增长建议（分短/中/长期）

### 2.2 抖音 ROI 计算器

#### 简单版（免费）
**公式**：ROI = 成交金额 ÷ 广告消耗

**输入**：
- 广告消耗（元）
- 成交金额（元）

**输出**：
- ROI 值（显示为 "1:X" 格式）
- 盈亏判定（行业参考值）

#### 完整版（后续付费）
**公式**：ROI = (成交金额 - 成本) ÷ 广告消耗

**输入**：
- 广告消耗（元）
- 成交金额（元）
- 商品成本（元）或 毛利率（%）
- 退款率（%）
- 平台佣金（%）
- 物流成本（元）

**输出**：
- 实际 ROI
- 净利润
- 各项成本占比
- 盈亏分析

### 2.3 获客成本计算器

**公式**：获客成本 = 渠道总投入 ÷ 有效获客数

**输入**：
- 渠道名称
- 渠道总投入（元）
- 有效获客数（人）
- 同期营收（元）

**输出**：
- 单客户获取成本
- 客户价值（LTV估算）
- 投入产出比

## 3. 页面结构

### 导航结构
```
首页
├── 企业增长诊断（核心功能）
│   └── 诊断问卷 → 报告结果
├── ROI 计算器
│   ├── 简单版
│   └── 完整版（需付费）
├── 获客成本计算器
│   └── 计算页面
└── 关于/联系
```

### 页面设计风格
- **风格**：专业、简洁、现代感
- **配色**：深蓝色主色调（信任、专业）+ 橙色点缀（活力、行动）
- **布局**：卡片式设计，清晰的信息层级
- **交互**：流畅的表单体验，实时计算结果
