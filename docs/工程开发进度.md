## 2.2.1 2026-05-02 当前前台改版约束
- 当前正在重构：`frontend/` 首页、工具箱、行业入口层级与图标系统。
- 本轮目标不是继续堆长页面，而是把前台改成更短、更清晰、更模块化的结构。
- 本轮明确约束：
  - 行业专版只保留真实行业入口：`餐饮 / 教培 / 美业 / 生活服务`

   - 新版：天数维度，公式 = `剩余课时 ÷ (每周次数 × 每次课时) × 7`
   - 输入改为：剩余课时、每周上课次数、每次课时数、课程有效期
   - 输出：预计耗完天数 + 有效期风险预警 + 催课建议

4. **美业耗卡率计算器**（`CardConsumptionRateBeauty.vue`）— **公式修正**
   - 旧版：使用总售卡次数/已消耗次数百分比
   - 新版：储值卡维度，输入改为：卡面总额、当前余额、月均耗卡金额、剩余有效期
   - 公式：耗卡率 = (卡面总额-当前余额) ÷ 卡面总额；沉淀风险 = 当前余额 - 月均耗卡 × 剩余有效期
   - 输出：耗卡率 + 预计耗完月数 + 沉淀风险金额 + 建议最低月耗

5. **盈亏平衡计算器**（`BreakEvenRestaurant.vue`）— **安全边际判断修正**
   - 新增"实际月营业额"可选字段
   - 安全边际率 = (实际营业额 - 保本营业额) ÷ 实际营业额
   - 行业标准：>30%健康，10-30%需警惕，<10%危险
