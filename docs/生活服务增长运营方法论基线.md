# 生活服务增长运营方法论基线

## 服务分层

- 上门服务：重点看派单半径、准时率、上门流程、客诉处理和复购提醒。
- 到店服务：重点看预约转化、到店接待、套餐升单和会员复购。
- 项目服务：重点看报价拆分、进度节点、案例证据和验收标准。
- 车辆服务：重点看车主痛点、套餐结构、到店效率和售后回访。
- 专业服务：重点看专业背书、信任资料、咨询转化和长期复购。

## 经营指标

- 报价毛利：拆服务范围、基础价、加收项、人工成本、材料成本和售后成本。
- 派单效率：看人员排班、服务半径、路程时间、准时率和日均可服务单量。
- 预约转化：看曝光、咨询、报价、预约、履约、成交和复购各环节流失。
- 履约质量：看准时率、一次解决率、客诉率、返工率和评价率。
- 复购转介绍：看老客回访、售后触达、复购提醒和推荐奖励。

## 抖音打法

- 内容核心：痛点钩子、真实案例、服务过程、报价透明、预约动作。
- 账号分工：老板号讲标准，师傅号讲过程，案例号讲结果，品牌号讲服务范围。
- 转化承接：评论领清单，私信问需求，企微收资料，电话确认时间，履约后回访。

## 小红书打法

- 内容核心：案例拆解、避坑攻略、报价说明、流程展示、同城搜索。
- 标题结构：城市/商圈 + 服务类型 + 客户痛点 + 案例证据 + 预约动作。
- 转化承接：评论领报价表，私信确认范围，企微收集照片/地址/时间/预算。

## 风险边界

- 报价范围、服务边界、加收项和售后规则需要保持一致。
- 客户案例、现场图片、评价截图和员工出镜发布前需要确认授权。
- 专业服务表达重点放在方法、流程、资质和适用场景，避免绝对化承诺。
