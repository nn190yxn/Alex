# 美业增长运营方法论基线

## 适用范围
- 本文档用于沉淀美业抖音、小红书、私域、老板 IP 和拓客活动工具的共同方法论。
- 所有高频营销工具必须保持“知识库 + AI”主链路，并围绕美业到店、办卡、耗卡、复购和升单输出。

## 美业增长主链路
- 公域触达：抖音同城、小红书搜索、本地生活团购、老板 IP 内容共同承担新客触达。
- 信任建立：通过专业人设、真实门店、服务流程、顾客授权案例和护理知识降低顾客决策顾虑。
- 预约到店：评论、私信、企微、电话和团购核销必须收敛到预约、检测、体验三个动作。
- 体验转卡：新客体验后围绕项目适配、护理周期、卡项权益和复购节奏完成转化。
- 耗卡复购：通过耗卡提醒、护理周期、生日/节日权益、沉睡唤醒和老客转介绍形成复购闭环。

## 美业 IP 四标签
- 身份标签：一句话说明门店角色和专业方向，例如“8年皮肤管理院长，专做敏感肌护理方案”。
- 形象标签：稳定出现的视觉符号，例如检测仪器、护理床、门店前台、流程白板、顾客反馈卡。
- 语言标签：稳定重复的专业表达，例如“先判断适不适合，再决定做不做”“护理看周期，也看居家配合”。
- 行为标签：固定栏目或固定动作，例如每周拆一个案例、每周讲一个项目避坑、每周直播答疑。

## 抖音美业链路
- 内容类型：痛点口播、流程实拍、团购避坑、顾客授权案例、直播答疑、院长 IP、老客复购提醒。
- 视频结构：前 3 秒痛点钩子，10 秒内给专业判断，中段展示流程证据，结尾引导检测、体验或预约。
- 承接路径：评论关键词触发私信，私信确认需求，企微发体验权益，预约到店检测，体验后转卡。
- 复盘指标：完播率、互动率、主页访问、私信数、预约数、到店数、团购核销数、办卡转化率。

## 小红书美业链路
- 账号矩阵：官方号承接门店可信度，院长号承接专业信任，顾客视角号承接真实体验，项目科普号承接搜索长尾。
- 内容类型：项目科普、门店探店、护理避坑、真人案例、到店流程、产品/仪器解释、价格权益说明。
- SEO 结构：标题和正文前 50 字必须包含项目、人群、城市或场景、核心痛点和预约动作。
- 转化路径：笔记引发收藏，评论触发私信，私信提供护理建议，企微确认需求，预约到店检测。

## 私域美业链路
- 新客分层：按来源、项目兴趣、预算、到店时间和体验反馈打标签。
- 办卡转化：先解释护理周期和项目适配，再给储值/次卡/疗程卡选择，避免只靠低价促销。
- 耗卡提醒：按项目周期设置到店提醒，区分正常耗卡、低耗卡、沉睡和高风险退款客户。
- 老客复购：围绕生日、节日、季节护理、项目升级和老带新权益持续触达。

## AI 内容矩阵原则
- AI 负责批量生成选题、标题、封面文案、正文框架、脚本和私信话术。
- 人工负责校验项目事实、顾客授权、合规措辞、价格权益和本地化细节。
- 每个工具输出必须给出可发布内容、承接话术、复盘指标和下一步动作。
