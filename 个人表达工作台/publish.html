插件调用协议

创建任务使用 POST /api/integrations/tasks，查询使用 GET /api/integrations/tasks/:id，失败任务使用 POST /api/integrations/tasks/:id/retry。返回体固定为 {ok,data}，状态包括 queued、running、completed、failed；创建和重试需要 write 权限。以下示例设置 demoMode:true，模型未配置时返回示例内容。

const created = await fetch('/api/integrations/tasks', {method:'POST', headers:{'content-type':'application/json'}, body:JSON.stringify({source:'待改写文本', demoMode:true})}).then(r => r.json());
const status = await fetch(`/api/integrations/tasks/${created.data.taskId}`).then(r => r.json());
const retried = await fetch(`/api/integrations/tasks/${created.data.taskId}/retry`, {method:'POST'}).then(r => r.json());
