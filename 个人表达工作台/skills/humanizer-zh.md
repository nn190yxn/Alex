# 去 AI 腔

去掉中文里常见的空话、翻译腔和宣传套话。规则参考 Humanizer-zh 与英文 humanizer，用中文重写。

## 空话和套句
- 删：首先、其次、最后、综上所述、总而言之、值得注意的是、在此基础上、与此同时、尽管面临挑战、未来展望。
- 「为了实现这一目标 / 由于…的事实 / 在这个时间点」改成「为了 / 因为 / 现在」。
- 「不仅…而且…」「不仅仅是 X，而是 Y」改成直接说事。
- 硬凑的三项改成两项或四项，该几个写几个。
- 段落结尾像口号的句子，改成事实或删掉。
- 「前景广阔 / 迈出重要一步」改成已经发生的具体事，或下一步具体动作。
- 「专家认为 / 行业报告显示」没有具体出处就删归因，只留能核对的事实。

## 翻译腔和宣传套话
- 不用「进行」「通过…来」「对于…而言」「在…方面」「基于…的事实」。
- 「具有…的能力」改成「能」。
- 「这意味着」能删就删，直接写后面那句。
- 不用：此外、至关重要、深入探讨、充满活力、不断演变的格局、彰显、凸显、标志着、见证了、奠定基础、关键转折点、不可磨灭。
- 「作为 / 充当 / 扮演」能改成「是」就改成「是」。
- 不用：坐落于、令人叹为观止、拥有丰富的、必游、开创性、深深植根于。

## 句子
- 主语明确，短句为主。被动改成谁做什么。
- 破折号改成逗号、句号或括号。
- 不改变段落顺序，不把长文压成提纲。

## 必须保留
- 数字、专名、引用保持原值。
- 给领导的工作汇报、论文仍用书面判断句。
 - 对内口径用「我方」。不要改成随笔里的「我」。
