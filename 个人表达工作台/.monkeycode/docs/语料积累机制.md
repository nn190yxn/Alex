# 语料积累机制

这份文档说清工作台怎么攒语料、攒什么、攒多少够用，以及语料在出稿时怎么被用上。

## 一、为什么攒

出稿要像你，靠的是你认的写法，不是通用好文。语料攒的是一篇篇「你认的稿」，模型照着它改口气。

## 二、攒三种料

| 料型 | 从哪来 | 用途 |
| --- | --- | --- |
| 正例 | 你认的成稿：整篇方案 / 一段口气 / 标题写法 / 判断句 / 表格说明 | 出稿时当口气参照 |
| 改稿对 | 出稿后你又动过的地方，「改前 → 改后」 | 抽出说法规则 |
| 反例 | 你明确不要的写法 | 只在标注时提醒，不进正例池 |

## 三、谁来做

助手主导，你只做三个动作：**收下 / 不要了 / 再用回来**。

收下之后后台自动跑：按场景档（这篇写给谁）和料型归位、抽五维度特征、去重、算分布指纹。这些不用你点。

## 四、四个收料入口

只有这四处能收语料，功能不重复：

1. 我的语料：贴一篇你认的稿，或上传 txt / Markdown。
2. 改一稿 → 把改过的这一稿收回来：自动对齐出「改前 → 改后」句对，勾上即收。
3. 用词习惯：练习里你手改的句子，收成规则。
4. 我的写法：题库校准或文稿校准，改完列出修正，勾上即收；也可以直接记一条。

## 五、怎么攒（每次的动作）

1. 出现一段你改过的文字，或一篇你认的稿。
2. 点收下。助手按固定规则先分一档，分错你改标签。
3. 数字、专名、引用按原文收下，不改。
4. 攒出的规则先进「我的写法」待确认，确认后才进规则集。

## 六、攒多少够用

- 冷启动：每个场景档 5–8 篇整篇，加 20–30 条句对。
- 稳定可用：每档 20–50 篇。
- 覆盖度：政府 / 品牌方 / 内部三档各要有料。单档攒再多，也只管那一档的口气，别的档不顶用。

## 七、出稿时怎么用

1. 先按「这篇写给谁」选同场景档的语料。
2. 取最近几篇当口气参照，塞进模型提示。
3. 带上五维度分布指纹：节奏 / 顺序 / 详略 / 立场 / 用词。
4. 带上你确认过的规则。
5. 数字、专名、引用锁死，保持原文。

## 八、沉淀成规则

改稿对 → 抽 from / to → 归到五个维度 → 进「我的写法」待确认 → 确认后进规则集 → 下次出稿自动带上。

## 九、边界

- 数字、专名、引用一律按原文，不因语料改写。
- 反例只在标注时用，不进正例取材池。
- 语料里的事实不复制到新稿。
- 只有「收下 / 不要了 / 再用回来」三个显式动作，其余按规则自动跑。
