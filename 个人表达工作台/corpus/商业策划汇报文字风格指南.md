# 商业策划汇报文字风格指南

> 适用场景：招商运营负责人向集团领导汇报的 PPT / 汇报文档
> 风格定位：行业专家的专业陈述 —— 专业、详实、具体，有判断但不张扬

---

## 一、核心原则：专业陈述式

**一句话定义：像一个资深的招商运营负责人在汇报——陈述事实，给出判断，不绕弯子，不耍花腔。**

底层逻辑是：
- 不说"A 好，但是有条件 B"，而是直接说"A 是什么样，B 是什么样，两者是什么关系"
- 不说"我们比对手强"，而是说"对方是什么定位，我们是什么定位"
- 不说"我们省了多少钱"，而是说"双方如何分工，各自创造什么价值"
- 不说"这是我们独有的优势"，而是说事实本身——事实摆在那里，领导自己会判断

---

## 二、标题原则：标题即判断

每页的主标题就是结论，不是中性描述。

| 反面（中性标题） | 正面（判断式标题） |
|----------------|------------------|
| 竞争品牌：孟关汽贸、通源汽车文化广场 | 竞争格局：跟孟关比体验，跟通源比集中度 |
| 调研结论 | 调研结论：三个业态都能做，但不能平摊 |
| 方案一定位 | 方案一：教育 + 新能源，确定性最高的路径 |
| 潮玩风险提示 | 关于意向合作方案的风险评估 |

**判断标准**：看完标题，领导不需要看内容就知道你这页想说什么。

---

## 三、禁用表达清单

### 1. 转折句式——全部改为陈述式

**核心问题**：用"但是""然而""不过"制造转折，显得绕弯子、找补，不符合正常人脑回路。

| 禁用 | 改为 |
|------|------|
| 收入确定性最高，但依赖 6 号馆落地 | 收入确定性高，与教育综合体联动推进 |
| 客群闭环最紧，但投入和退出风险最大 | 客群闭环紧，投入与退出风险也较高 |
| 潮玩有真实需求，但严格控制在 4,000㎡ 以内 | 潮玩有真实需求，体量控制在 4,000㎡ 以内 |
| 与场馆资源协同最高，但三馆客流不互通 | 与场馆资源协同性高，三馆客流各自独立 |

**规律**：把"但是"换成"也""同时""并"，或者直接分成两句话。转折关系本质上是并列关系，只是角度不同。

### 2. 自夸式强调——让事实自己说话

**核心问题**：在陈述完一个事实后，非要加一句"这是别人做不到的""我们独有""核心优势"，画蛇添足。

| 禁用 | 改为 |
|------|------|
| 这条别人复制不了 | （直接删掉，事实本身就是优势） |
| 我们独有的资源 | 场馆资源（让资源名称自己说话） |
| 核心优势是…… | （直接说事实，不加"核心优势"标签） |
| 最大的竞争力 | （陈述竞争力的具体表现） |

**规律**：好东西不需要贴标签说它好。你说清楚它是什么，领导自然知道它好不好。

### 3. 对抗型表述——改为定位表述

**核心问题**：把商业关系描述成"打仗""抢地盘"，格局小了。专业的说法是"差异化定位"。

| 禁用 | 改为 |
|------|------|
| 我们怎么打 | 本项目定位 |
| 抢客流 | 客源分流 / 客群竞争 |
| 比不过 | 不追求规模 / 形成差异化定位 |
| 错位竞争 | 差异化定位 |
| 竞品 | 同类项目 / 同片区项目 |
| 打赢、打好 | 推进、落地 |

**规律**：从"我们跟对手比怎么样"变成"对方是什么样的，我们是什么定位"。不打擂台，只做专业陈述。

### 4. 省钱思维——改为分工思维

**核心问题**：把"我省了什么成本"挂在嘴边，像小老板算账。专业说法是"双方分工，各创造各的价值"。

| 禁用 | 改为 |
|------|------|
| 我方不必另组内容团队 | 我方聚焦场地管理与整体运营统筹 |
| 不用再引入第二家主力 | 与我方形成清晰的内容与场地产权分工 |
| 活动联动有现成通道 | 具备官方文化资源对接渠道，联动效率更高 |
| 单位使用面积租金下降 | 单位面积租金成本相应降低 |
| 收益上限锁死 | 收益上限较为固定 |
| 说不清 | 存在争议 / 认定存在分歧 |
| 接不住 | 无法有效承接 |
| 拉客流 | 导流 / 带动客流 |

**规律**：不说"我省了什么"，说"双方怎么分工、各自承担什么"。前者是占便宜心态，后者是职业经理人心态。

### 5. AI 腔 / 工程腔——能用大白话讲就别用行话

**核心问题**：堆砌行业黑话，显得不真诚。行话该用就用，但不堆砌。

| 谨慎使用 | 替代方案 |
|---------|---------|
| 引擎 | 业态 / 方向 / 支撑 |
| 闭环 | 循环 / 联动 / 衔接 |
| 赋能 | 带动 / 支撑 |
| 抓手 | 切入点 / 着力点 |
| 打法 | 策略 / 路径 |
| 底层逻辑 | 核心逻辑 / 基本逻辑 |
| 打造 | 建设 / 布局 / 做（慎用） |
| 构建 | 建立 / 形成 |
| 矩阵 | 集群 / 组合 |
| 生态 | 体系 / 环境 |

**判断标准**：这句话把行话去掉之后，意思是不是更清楚了？如果是，就去掉。

### 6. 太口语化的表达

| 禁用 | 改为 |
|------|------|
| 家长认这个牌子 | 在本地家长中品牌认知度较高 |
| 家长要在几个点之间跑 | 家长需在多个点位间往返 |
| 正好补场馆的晚间低谷 | 可有效填补场馆晚间客流低谷 |
| 搞不定 | 难以实现 / 存在困难 |
| 撑不起 | 不足以支撑 |
| 空转 | 客流不足 / 难以保障 |
| 谈成 | 形成 / 达成 |
| 这个阶段先不定 | 本阶段暂不确认 |
| 我们的 | 我方 |
| 它自己 | 合作方自行 |

## 四、句式偏好

### 偏好的句式

1. **陈述式**：A 是什么，B 是什么，A 和 B 是什么关系。
   > 孟关是规模型专业市场，本项目聚焦中高端新能源市场，两者形成差异化定位。

2. **因果递进式**：先讲事实，再讲意味着什么。
   > 教育为刚需型消费，消费频率稳定，每周固定将家庭客群引入场馆。

3. **并列陈述式**：用"以及""并""同时"连接，不用"但是"。
   > 基础租金为合作前提，超出约定营业额的部分再做分成。

### 不偏好的句式

1. **转折式**：A 很好，但是 B。（改为：A 是什么样，B 是什么样）
2. **自问自答式**：怎么做？我们的打法是……（改为：本项目定位为……）
3. **口号式**：一句话总结 + 感叹语气（改为：平实陈述）
4. **编号堆砌式**：每页都是 01/02/03/04/05（优势劣势压缩到 3 条核心的）

## 五、结构逻辑偏好

### 1. 叙事顺序：先立标杆，再说落地，最后说怎么做

**正确顺序**（以 6 号馆为例）：
1. 对标样板是什么（心霖公社）——先给个参照物
2. 为什么适合我们（客群、区位、空间条件）——为什么这个模式行得通
3. 谁来落地（笃一）——执行方是谁，能力怎么样
4. 做成什么样（空间、业态、面积）——具体规划
5. 怎么合作（模式、收益）——商务条款

**错误顺序**：
- 先讲合作方，再补对标案例 → 变成"先找了合作方，再找案例背书"

### 2. 每页的结构：结论先行，论据跟进

> **标题（结论）**
>
> **核心判断 1** + 支撑事实
> **核心判断 2** + 支撑事实
> **核心判断 3** + 支撑事实

不是先列一堆数据再给结论，而是先给结论，再用数据支撑。

### 3. 优势劣势的写法

- **不追求数量**，不凑 5 条，核心的 3 条就够
- **每条先给判断，再给事实支撑**
- 优势不说"核心优势是 XX"，直接说"XX（事实），带来 XX 价值"
- 劣势不说"最大的问题是 XX"，直接说"XX（事实），会造成 XX 影响"

## 六、语气和姿态

### 有"我们"的视角，但不主观

- 用"我方"不用"我们"
- 有判断、有主张，但用事实支撑
- 不绝对化，留有余地（"较为""相对""约""大概"）

### 协作感，不是对立感

- 讲合作方的时候，说"双方协同""共同运营""各展所长"
- 不讲"我们掌握主动权""我们说了算"
- 租金谈判也是"商务口径"，不是"底线"（除非确实是底线）

### 克制，不张扬

- 好东西不喊出来，摆在那里让人自己看
- 不说"最""第一""唯一""独有"
- 用数据和事实说话，不用形容词堆砌

---

## 七、快速自检清单

写完一页之后，问自己这几个问题：

1. **标题是不是结论？** 领导只看标题能不能 get 到这页想说什么？
2. **有没有"但是"？** 能不能改成"也""同时"或者分成两句话？
3. **有没有自夸？** "独有""核心优势""别人做不到"——能不能删掉，让事实自己说话？
4. **有没有对抗感？** "抢""打""竞品"——能不能改成"差异化定位""同类项目"？
5. **有没有省钱思维？** "省""不用""不必"——能不能改成"分工""各自承担"？
6. **是陈述还是绕弯子？** 正常人会不会这么说话？
7. **术语是不是必要的？** 去掉行话之后意思是不是更清楚了？

## 八、反面教材 vs 正面教材

### 反面
> **核心优势**
> 漫展就在隔壁馆办，常驻和大展双向导流成本最低，**这条别人复制不了**。
> 我们跟孟关比，比规模**比不过**，但我们**主打**体验和效率。
> 我方**不必另组**内容团队，**省了**一大笔成本。

### 正面
> **资源协同**
> 漫展在本场馆 2、4 号馆举办，常驻商业与大展双向导流，成本较低。
> 相对于孟关的规模优势，本项目聚焦中高端新能源市场，强化后端服务。
> 笃一负责内容输出与教学运营，我方聚焦场地管理与整体运营统筹。
